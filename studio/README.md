# 纸艺世界重构工作室

这是 **横版开放纸艺世界**的实现入口。默认场景为序幕「21:00，放学归途」的校门—便利店街段：连续人行道、独立车道、纸片学校/店铺/高楼、动态汽车和冷色城市光影。角色可以左右漫游、随时折返，在校牌和便利店附近按 E 或触屏「查看」阅读场景内容。当前是第一段可玩样片，完整回家路线、商店室内和现代学生角色资产仍在后续制作范围。

`?scene=forest` 保留上一版森林展示场景；`?play=1` 进入游戏布局，参数可以组合。两种场景使用独立存档键，旧森林位置不会进入城市。角色 Z 固定为 0，街道汽车在独立 Z 车道上行驶。布景表面保持彩纸分色、薄纸板切边和真实层距，保留丁达尔光柱、层间遮蔽和四时光线。

美术以 Paper Mario 的薄立体彩纸为主体，结合 Paper Trail 式绘本配色：大色面、柔和色阶、少量手绘细节和浅色裁切边缘。近景保持干净，用暖光、柔和投影和层间遮蔽表现纸张厚度；表面采用 Lambert 漫反射，避免塑料高光与密集颗粒。房屋的瓦片、窗、木梁和植物绘入共享 1024 图集，只有墙、屋顶、烟囱轮廓保留薄几何。当前两栋房屋共 160 个三角形，连同路牌、围栏共 400 个三角形、2 次绘制；预算上限为房屋 400、全部布景 1000 个三角形。

## 本地打开

在仓库根目录运行 `npm run dev:studio`（或 `node tools/studio-server.mjs`），打开 `http://127.0.0.1:4173/studio/`。无需安装依赖。不要双击 HTML；浏览器需要通过服务器读取模块和贴图。

服务器只监听本机。关闭它后本地网址不可用。GitHub Pages 发布对应目录后，入口为 `/paperchalk-world/studio/`；`/paperchalk-world/` 子路径也能在本地服务器上验证。工作室本身是静态网页，不需要长期运行个人电脑来提供在线演示。

## 操作

- A/D 或左右方向键：左右移动，随时自由折返。
- 手机按住左侧方向按钮移动；右上角打开暂停菜单。
- 序幕中接近校牌或便利店时，可按 E 或点右下「查看」。关闭查看会恢复漫游；暂停菜单、返回键和触屏输入互相协调。
- 游戏视角固定为横向镜头，跟随角色行进和地面起伏。工作室视图可拖动环绕、滚轮或双指缩放。
- 回到起点：复位角色；重置视角：恢复默认角度并看向角色。
- 场景设置：切换四时光线、纸雾、阴影、体积雾及纸材质参数。
- 保存/读取进度：保存此浏览器、此站点下的角色位置和运动状态。读取后会贴合当前地面高度，可从该处继续向任一方向漫游。不会跨电脑同步，也不保存光影设置。
- 切到后台或离开页面时自动保存角色进度；回到前台清空旧按键并重置物理时钟，避免离开期间角色继续移动。不同发布路径使用同一站点、同一存档键，不把版本号混入存档键。
- 暂停：冻结模拟与场景时间，仍可观察镜头和调整材质。

## 结构和依赖方向

```
app.js                 单一帧循环、固定物理步、界面接线
core/                  角色物理、独立版本化存档
input/                 键盘和触屏输入
world/                 人工编排的舞台地面轮廓，渲染和碰撞共用
rendering/             从 Demo 提取的渲染模块
index.html, studio.css 工作室外壳
```

物理不依赖 Three.js、DOM 或渲染循环。渲染器只消费角色状态，不自行推进游戏。应用层持有唯一 requestAnimationFrame，每 1/60 秒推进物理；渲染按需更新。纹理加载错误、存储失败和图形上下文丢失都有可见状态。

`world/PaperStageWorld.mjs` 定义连续地面轮廓、厚度与前后范围。`core/StagePlayerSimulation.mjs` 使用相同轮廓处理加速、刹停、转向和贴地漫游；`rendering/terrain.js` 把轮廓渲染为整体纸艺地面。当前没有裂隙、跳台或通关门槛；地面与道具直接编排，不再读取体素或密度地形。

城市首段横向范围 X = −8 到 24，周围布景向两侧延伸；森林展示范围仍是 X = −12 到 25。二者是视觉与漫游样片，尚未实现大世界流式加载。城市存档键为 `paperworld.city-prologue.save.v1`，森林为 `paperworld.stage.save.v1`；同一场景的发布版本共享存档，更新画面后可以继续当前位置。

原始 `visual-demo.html` 保留为视觉基准；旧主站和旧系统保留。独立的 Android 测试版通过 `app/channel.json` 加载成功发布的新工作室；浏览器也可打开 `app/` 进入最新测试版本。当前提供连续地面、自由漫游、位置存档和光影调节。开放模拟玩法、互动、正式角色骨骼动画和存档云同步仍待建设。

## 手机外壳接口

- `window.PaperchalkSaveNow()`：同步保存角色状态，仅在存储真正成功时返回 `true`。尚未准备好、存储被禁用或配额已满都会返回 `false`；原生外壳可据此暂停版本切换。
- `window.PaperchalkHandleBack()`：先关闭场景设置或性能弹层；处理成功返回 `true`，否则返回 `false`，由原生外壳继续处理返回键。
- 外壳向 `window` 派发 `paperchalk:pause` / `paperchalk:resume` 事件。暂停时保存、清空输入并挂起帧更新；恢复时重置时钟并通知布局重新测量。不会改变用户手动选择的暂停状态。
- 页面底部从相对路径 `studio/build-info.json` 显示当前实际构建。发布文件包含 `version`、`publishedAt`、`channel`；开发文件明确显示“开发预览”。

生命周期处理保留浏览器往返缓存。真正离开页面时清理事件和原生接口，防止新页面继承旧监听器。手机横屏与竖屏均有触控布局，`viewport-fit=cover` 配合安全区边距处理刘海及系统手势区。

## 回归检查

`npm run test:studio`：物理、输入、存档、原始 GLSL 一致性、模块资源相对路径，以及本机与 Pages 子路径的服务测试。

`npm test`：确认旧主站的原有回归约束仍通过。合入发布前，另需打开工作室人工检查真实画面和手机尺寸。
