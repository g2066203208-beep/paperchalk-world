# 纸艺世界重构工作室

这是 **横版开放纸艺世界**的实现入口。默认场景为序幕「21:00，放学归途」的月灯市。现在可以沿连续街道走过 12 个城区：学园街、榆树老城、晨星集市、灯影商业街、中央车站、云端商务区、市民广场、月河公园、南湾港口、彩纸艺术街、白榆医院区和星灯住宅区。校舍与三家原有店铺之外新增 100 栋建筑、11 个地标；地标包括车站、剧院、图书馆喷泉、河岸步桥、灯塔船只、医院和住宅庭院。当前提供城市外景、居民交谈和四段「放学归途」目标链；室内、可乘坐交通和日常生活活动暂未制作。

`?scene=forest` 保留上一版森林展示场景；`?play=1` 进入游戏布局，参数可以组合。两种场景使用独立存档键，旧森林位置不会进入城市。角色 Z 固定为 0，街道汽车在独立 Z 车道上行驶。布景表面保持彩纸分色、薄纸板切边和真实层距，保留丁达尔光柱、层间遮蔽和四时光线。

美术参考薄立体彩纸舞台的构成，用建筑自身的薄厚、折面、窗台、浅色切边和真实层距表现纸艺。暖色窗光与深靛夜空分离，保留适量天空，不用围住画面的舞台侧板遮挡角色。镜头在横竖屏下保留人物全身及屋顶，前景仅有低花箱；人行道露出瓦楞纸芯，汽车在独立的低位车道行驶。

城市近景采用两张共享图集（2048 × 1024 彩色、1024 × 512 发光），文字按实际建筑比例补偿，窗台与印刷窗口对齐；学校和三家店铺共用两种 Lambert 材质。近景布景为 3516 个三角形、6 个几何批次。远景在 Z = −10、−18、−28 分层，152 栋街屋、剪纸月亮、星星和云共 2123 个三角形、5 个批次，不增加纹理和灯光。背景随昼夜变色，月亮、星星和窗光在日间淡出；这些数量不含地面、角色、汽车以及阴影与后处理的额外绘制。森林沿用原有独立美术和镜头。

扩展街区采用另外两张共享图集，建筑与道具总计 69,252 个三角形、24 个批次，按当前位置只显示邻近分区（最多 8 个批次）。72 名有姓名、身份和本地台词的居民分布在 12 区，有往返步行、停留、腿部轻摆和脚底影；24 种纸偶共用一张图集和两个实例化批次。交通包含 12 个公交站、6 个地铁入口、双向公交及地下列车场景。地面站点按距离显示，地下乘车时隐藏地面建筑、交通和居民。

## 本地打开

在仓库根目录运行 `npm run dev:studio`（或 `node tools/studio-server.mjs`），打开 `http://127.0.0.1:4173/studio/`。无需安装依赖。不要双击 HTML；浏览器需要通过服务器读取模块和贴图。

服务器只监听本机。关闭它后本地网址不可用。GitHub Pages 发布对应目录后，入口为 `/paperchalk-world/studio/`；`/paperchalk-world/` 子路径也能在本地服务器上验证。工作室本身是静态网页，不需要长期运行个人电脑来提供在线演示。

## 操作

- A/D 或左右方向键：左右移动，随时自由折返。
- 手机按住左侧方向按钮移动；右上角打开暂停菜单。
- 序幕中接近校牌或便利店时，可按 E 或点右下「查看」。关闭查看会恢复漫游；暂停菜单、返回键和触屏输入互相协调。
- 序幕会依次给出四个步行目标：便利店、中央车站、月河公园、星灯住宅区。走到对应路段自动推进；目标进度独立保存在当前浏览器，远处旧位置存档会自动补齐已经经过的节点。
- M 或右上「城市地图」：查看 12 区及路线，选择街区设置步行导航。地图显示方向和剩余距离；地图本身不直接传送角色。
- 公交站牌和地铁入口目前作为连续城市布景与路线参照保留；乘车交互暂未开放。
- 走近居民时按 E /「交谈」，阅读姓名、身份及与该城区相关的短句。居民没有任务、交易、好感或需求机制。
- 游戏视角固定为横向镜头，跟随角色行进和地面起伏。工作室视图可拖动环绕、滚轮或双指缩放。
- 回到起点：复位角色；重置视角：恢复默认角度并看向角色。
- 场景设置：切换四时光线、纸雾、阴影、体积雾及纸材质参数。
- 保存/读取进度：保存此浏览器、此站点下的角色位置和运动状态。读取后会贴合当前地面高度，可从该处继续向任一方向漫游。不会跨电脑同步，也不保存光影设置。
- 切到后台或离开页面时自动保存角色进度；回到前台清空旧按键并重置物理时钟，避免离开期间角色继续移动。不同发布路径使用同一站点、同一存档键，不把版本号混入存档键。
- 暂停：冻结模拟与场景时间，仍可观察镜头和调整材质。

## 结构和依赖方向

```
app.js                 单一帧循环、固定物理步、界面接线
core/                  角色物理、独立版本化存档
input/                 键盘和触屏输入
world/                 人工编排的舞台地面轮廓，渲染和碰撞共用
rendering/             从 Demo 提取的渲染模块
index.html, studio.css 工作室外壳
```

物理不依赖 Three.js、DOM 或渲染循环。渲染器只消费角色状态，不自行推进游戏。应用层持有唯一 requestAnimationFrame，每 1/60 秒推进物理；渲染按需更新。纹理加载错误、存储失败和图形上下文丢失都有可见状态。

`world/PaperStageWorld.mjs` 定义连续地面轮廓、厚度与前后范围。`core/StagePlayerSimulation.mjs` 使用相同轮廓处理加速、刹停、转向和贴地漫游；`rendering/terrain.js` 把轮廓渲染为整体纸艺地面。当前没有裂隙、跳台或通关门槛；地面与道具直接编排，不再读取体素或密度地形。

城市横向范围 X = −48 到 1380，共 1428 个单位，约为原 32 单位街段的 44.6 倍；周围布景向两侧延伸。森林展示范围仍是 X = −12 到 25。城市目前将几何常驻内存、按区隐藏远景外的建筑，尚未实现按需下载的流式世界。城市存档键仍为 `paperworld.city-prologue.save.v1`，森林为 `paperworld.stage.save.v1`；旧城市存档可继续使用，最远住宅区的位置也可保存和读取。读取远处位置、乘车到站或回到起点时，镜头会立即对齐角色。

原始 `visual-demo.html` 保留为视觉基准；旧主站和旧系统保留。独立的 Android 测试版通过 `app/channel.json` 加载成功发布的新工作室；浏览器也可打开 `app/` 进入最新测试版本。当前提供连续地面、自由漫游、四段序幕目标、城市地图、居民交谈、位置存档和光影调节。更完整的开放模拟玩法、室内互动、可乘坐交通和存档云同步仍待建设。

## 手机外壳接口

- `window.PaperchalkSaveNow()`：同步保存角色状态，仅在存储真正成功时返回 `true`。尚未准备好、存储被禁用或配额已满都会返回 `false`；原生外壳可据此暂停版本切换。
- `window.PaperchalkHandleBack()`：先关闭场景设置或性能弹层；处理成功返回 `true`，否则返回 `false`，由原生外壳继续处理返回键。
- 外壳向 `window` 派发 `paperchalk:pause` / `paperchalk:resume` 事件。暂停时保存、清空输入并挂起帧更新；恢复时重置时钟并通知布局重新测量。不会改变用户手动选择的暂停状态。
- 页面底部从相对路径 `studio/build-info.json` 显示当前实际构建。发布文件包含 `version`、`publishedAt`、`channel`；开发文件明确显示“开发预览”。

生命周期处理保留浏览器往返缓存。真正离开页面时清理事件和原生接口，防止新页面继承旧监听器。手机横屏与竖屏均有触控布局，`viewport-fit=cover` 配合安全区边距处理刘海及系统手势区。

## 回归检查

`npm run test:studio`：物理、输入、存档、原始 GLSL 一致性、模块资源相对路径，以及本机与 Pages 子路径的服务测试，并执行城市扩展专项。`npm run test:city` 可单独检查整城道路与交通拓扑、最远存档、建筑分区剔除、公交停靠与暂停、乘车切换、居民运动与交谈查找、GPU 资源释放。角色可见性检查包含原街段横竖屏与旧侧板的阳性校验，以及新增城区道路和车站入口的遮挡检查。

`npm test`：确认旧主站的原有回归约束仍通过。合入发布前，另需打开工作室人工检查真实画面和手机尺寸。
