# 纸艺世界重构工作室

这是新的 **2.5D 横版冒险**实现入口。角色在 X/Y 平面移动和跳跃，Z 固定为 0；3D 场景负责纵深、光照和环绕观察。默认画面直接复用 visual-demo 的着色器、纸张参数、昼夜、森林雾和体积光合成。

## 本地打开

在仓库根目录运行 `npm run dev:studio`（或 `node tools/studio-server.mjs`），打开 `http://127.0.0.1:4173/studio/`。无需安装依赖。不要双击 HTML；浏览器需要通过服务器读取模块和贴图。

服务器只监听本机。关闭它后本地网址不可用。GitHub Pages 发布对应目录后，入口为 `/paperchalk-world/studio/`；`/paperchalk-world/` 子路径也能在本地服务器上验证。工作室本身是静态网页，不需要长期运行个人电脑来提供在线演示。

## 操作

- A/D 或左右方向键：左右移动；空格：跳跃。
- 拖动画面：环绕；滚轮或双指：缩放；镜头水平跟随角色。
- 回到起点：复位角色；重置视角：恢复默认角度并看向角色。
- 场景设置：切换四时光线、纸雾、阴影、体积雾及纸材质参数。
- 保存/读取进度：保存此浏览器、此站点下的角色位置和运动状态。不会跨电脑同步，也不保存光影设置。
- 暂停：冻结模拟与场景时间，仍可观察镜头和调整材质。

## 结构和依赖方向

```
app.js                 单一帧循环、固定物理步、界面接线
core/                  角色物理、独立版本化存档
input/                 键盘和触屏输入
world/                 横版碰撞世界
rendering/             从 Demo 提取的渲染模块
index.html, studio.css 工作室外壳
```

物理不依赖 Three.js、DOM 或渲染循环。渲染器只消费角色状态，不自行推进游戏。应用层持有唯一 requestAnimationFrame，每 1/60 秒推进物理；渲染按需更新。纹理加载错误、存储失败和图形上下文丢失都有可见状态。

原始 `visual-demo.html` 保留为视觉基准；旧主站、旧系统和 Android 包暂未切换。工作室现在具备可运行的移动、跳跃、碰撞、存档和光影调节基础，尚不是完整重构后的游戏：正式关卡、互动、战斗、角色骨骼动画和存档云同步仍需按新架构建设。

## 回归检查

`npm run test:studio`：物理、输入、存档、原始 GLSL 一致性、模块资源相对路径，以及本机与 Pages 子路径的服务测试。

`npm test`：确认旧主站的原有回归约束仍通过。合入发布前，另需打开工作室人工检查真实画面和手机尺寸。
