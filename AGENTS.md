## 2026-11-12 GAMEPLAY PRIORITY — exactly FIVE FIXED XP TYPES

Read [`docs/game/XP_COLLECTION_AND_FUSION_CORE_20261112.md`](docs/game/XP_COLLECTION_AND_FUSION_CORE_20261112.md) before designing XP, fusion or items.

**CURRENT USER-CONFIRMED XP TAXONOMY**:
1. **PROFESSION / OCCUPATIONAL CLOTHING** — a SINGLE XP type: profession is expressed through role-specific uniforms/clothes (knight armor, hunter coat, witch clothes, maid outfits, merchant uniform etc.). **NEVER create a separate wardrobe/clothing XP type**, as this would duplicate the profession category.
2. **BODY TYPE** — independent character physique XP.
3. **RANDOMIZED PERSONALITY** — preserve the personality system agreed earlier; recruits receive personality traits randomly and base minion portraits do not hard-code personality. The complete approved list was not identified in the current repo, so do not invent replacements.
4. **RACE / SPECIES** — specifically required again by user: catgirl, vampire, demon, human, etc.; **mutually exclusive within the RACE type, never catgirl+vampire together**. This OVERRIDES the earlier rejection of race as fourth XP. Existing demon/vampire minion illustrations must remain unchanged. How nonhuman T1 character identity coexists with an XP4 slot activated at T2 is still to be carefully designed, not assumed solved.
5. **FIFTH XP TYPE — UNDECIDED**. Must be completely independent of profession/outfit, physique, personality, and species. User rejects generic combat power, wardrobe duplication, or selecting arbitrary groups from an open 28-type macro-category catalog.

Exactly five FIXED XP types across the whole game; T1 = 3 traits, T2 = 4 traits, T3 = 5 traits, one per type. In same-tier unit fusion, two source characters plus grade-matched single-use fusion material produce a genuinely NEW third character C, not an A reskin or A absorbing B. Same-type XP candidates are mutually exclusive; player chooses which one. Fusion without the additional XP may yield a new character of the same tier. Keep consumable fusion materials distinct from globally persistent Isaac-style relic buffs. No literal cooking of characters in a cauldron.

The [959-tag research catalog](docs/game/XP_TAG_CATALOG_RESEARCH_20261112.md) and [JSON](docs/game/XP_TAG_CANDIDATES_20261112.json) are noncanonical **research**, not approved XP types or approved personality values. The [open two-macro-type architecture](docs/game/XP_TAG_GAMEPLAY_ARCHITECTURE_20261112.md) is USER-REJECTED and archival only. Do not reintroduce it. Species and faction organization are not identical; preserve approved artwork unchanged.

Whenever an Anima image is supplied, inspect each view individually: front symmetry, true left-facing side silhouette (head/shoulders/feet), full back, number of figures, identical outfit, intact head/feet, and absence of extra objects. Reject bad results rather than passing them to game assets.
