# 战壕 V01

Standalone WebGL exploration prototype, 152×152 game-unit terrain, interconnected fictional trenches, roofed passage, concrete shelters, planks, bags, decorative wire and steel obstacles, mud, puddles, animated smoke/fire/rain, 3 weather modes, WASD/drag/touch, crouch, decorative first-person prop with view transition. No shooting or damage simulation. Terrain mesh 69289 triangles. CPU mesh previews omit live effects and view model; browser runtime and deployment not verified. Original game untouched.
