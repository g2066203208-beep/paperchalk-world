# 10格卡牌战斗：数值平衡测试 V0.4

> 这是一份**机器人策略模拟**，不是已经经过真人验证的“完美平衡”。目的是暴露数值问题、确定下一轮可测试的参数。

- 每组 120 个独立固定种子；总模拟战斗 **7680 场**。
- 比较4职业×2流派、单人/四人NPC辅助、战术AI/偏随意AI。
- 胜利率在不同敌人组合之间不能直接比较；不同策略的差异反映玩法上限，但AI策略并不等于真人熟练度。
- 14轮仍未结束的局计入超时，不能当作胜利。
- 敌我时间格结算、牌库重整、跨轮行动、破防/晕倒使用同一份 engine.js。

## V0.4 初始固定数值

| 机制 | 参数 | 说明 |
|---|---:|---|
| 时间格/回合 | 10 | 1格对应游戏内1分钟 |
| 手牌上限 | 4 | 每次付费重整后抽至上限 |
| 空手换手 | 1格 | 消耗至少1格且锁定此前排程 |
| 非空手重整 | 2格 | 弃掉当前未使用手牌，锁定此前排程 |
| 破防失能 | 3格 | 包括破防发生格 |
| 晕倒失能 | 6格 | 包括晕倒发生格 |
| 绝杀门槛 | 100能量 | 目标≤55%生命或被标记/破防 |
| 敌人预告 | 10格 | 完整显示前摇/生效/后摇 |
| 跨轮动作 | 仅最后一张 | 占据下轮对应格 |

## 核心注意事项

1. **评分不是胜利率**：守护职业可能活得久但超时更多；需同时查看平均回合和剩余生命。
2. **不存在绝对平衡**：卡组构筑、敌人AI、联机协作、玩家水平变化都会改变最优策略。
3. 仍需真人测试：新手能否看懂前后摇、手动洗牌锁定是否挫败、手机拖动精准度、4人配合时间开销。
4. Demo 已内置“预演”和“自动排程”，但是没有网络多人同步服务器；NPC协助模式用于检验多人时间轴兼容性。
5. 测试主要覆盖初始12卡牌、5类敌人配置；最终装备/遗物/卡池扩展后必须重新做大规模测试。
