# 深夜便利店 · 第一晚（规则怪谈 × 模拟经营）

入口：`/convenience-store/night/`；原日常便利店依然在 `/convenience-store/`；不会修改里世界战斗、角色素材或剧情存档。

## 已完成

- 23:00–06:00 一整夜，时钟由玩家行动与可暂停的值班计时驱动。每次互动会保存，切换窗口时不增加游戏时间。
- 收银真的逐件扫码、核对订单、收款、交货；特殊订单需要不装袋；工资与违规统计真实结算。
- 收银、货架、冷柜、仓库、监控室、雨夜店外六个区域；收银设备使用已有的 8 个 SVG 独立部件。
- 12 条规则：5 条正式基础规则、5 条店长可核实的超自然规则、2 条来源可疑的假规则。
- 自动门三次响、01:17 低头戴帽的人、4号监控中的自己与十秒断电、冷柜第六人、仓库敲门、陌生来电、旧员工证据。
- 6 路监控、手机、规则簿、行动记录、营造不安的照明变化、按需启用的程序化音效。
- 三条实装结局：普通生存、揭开录像真相、被取代。任意时间可重开该支线存档。
- 真实浏览器与 Node 检查分别位于 `tests/convenience-night-browser.mjs` 和 `night-core.test.cjs`，Actions 产生可复现的16张游戏截图与视频。

## 技术

纯静态 HTML/JS/SVG/WebP，Github Pages 直接发布，不需要数据库、常驻服务器或云 API。运行引擎遵循确定性转移，`night-core.js` 也可在 Node 运行；自动存档 key 独立，不与表世界其他存档互相污染。

## 注意

当前是完整第一晚的可玩原型，而非整部恐怖游戏所有章节。辅助仓库、办公室及店外素材为独立 SVG 绘制；收银主背景复用已定稿的便利店场景美术。没有制作超过首晚范围的第二晚、多周经营、完整城市地图与里世界内容。
