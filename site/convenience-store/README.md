# 便利店 V1：表世界剧情场景 + 真正的收银小游戏

- `assets/convenience-story.webp`：1600×900 的独立剧情室内背景，从本轮绘制的第一张概念效果图中裁切；无文字、对话和人物。用户原始 PNG 另附。
- `parts/*.svg`：真实独立 SVG 美术资源，共 8 个：柜台主体、台面、收银电脑、扫码枪、收款设备、热食柜、购物袋、货架。独立 `<img>` 组装，绝非把 UI 示意图整张贴上去。
- `index.html`：两种模式，剧情显示同一背景，收银模式真正可点击、存档。
- `store-core.js`：独立纯状态机，商品库存、顾客订单、扫码匹配、收款、装袋、工资、疲劳、评分、补货、清洁、班次与本地存档。
- `store.js`：DOM 事件、触屏和键盘、可拖动的部分柜台模块。`?view=work` 直接进入收银。
- `store.css`：自适应横屏/手机布局。

玩法：开始晚班 → 选择小票商品 → 扫码 → 所有商品扫描完毕后收款 → 装袋 → 下一单；共五位顾客，每单计入工资，最后发底薪。可补货、清洁；使用“调整柜台”独立移动收银设备与热柜，位置存档。

无须后端：浏览器本地运行，可在静态网站和 GitHub Pages 部署；资源路径均为相对路径，不使用外部 CDN。里世界卡牌战斗不受影响。
