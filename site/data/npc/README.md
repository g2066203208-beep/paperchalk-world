## 活着的乘客，而非站桩

NPC 的四格是基础美术，真正进入游戏仍需要动作层和时间、身份驱动。候车、上车、下车、看手机、打盹、读报、聊天、打闹、听歌、照顾小孩、推行李等活动，由**各自的行为动机与事件**触发；无需让每个人都有所有动作。站台空间、人群与车门用同一 3D 坐标和时间推进，禁止随机瞬移、无条件穿门、无休止重复同时做一件事。校园学生、普通工人、老人、亲子、游客要根据时间段出现，年龄及常见职业覆盖逐步扩充。
