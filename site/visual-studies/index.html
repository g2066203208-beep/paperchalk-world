ORIGINAL GITHUB VISUAL STUDIES · 2026-11-17

战斗立绘与 2.5D 舞台 · 三种独立方案

直接看游戏运行画面，所有场景由程序绘制；立绘仅引用 GitHub 已有 Anima 原图。不同案例各有独立页面、交互和视觉规则，并非拿原游戏截图贴背景。

01 · PORTRAIT BATTLE

留白立绘战斗

低对比远景、简单的实景结构、完整全身立绘、透视地面、脚底接触阴影与少量柔和光。

 02 · STAGE COMBAT

剧场式立绘战斗

分层前后景、暗红幕布、聚光灯、舞台材质、电影化攻击与击退，突出大立绘的表演。

 03 · PAPER THEATRE

奇想机关游园

参考《幻象游园剧》的立体绘本构图，原创折纸旅人、转动齿轮、花灯、纸片远近层和透视视差。

操作：切换每个页面的光照与演出按钮，桌面可移动鼠标查看视差。Space 触发动作，游园场景方向键可让纸片旅人短距离移动。
