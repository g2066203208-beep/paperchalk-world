# 剧情系统提案：GALGAME 对话 + 2.5D 纸片舞台 + 3D 卡牌战斗

> **设计提案，尚未视为玩家批准的剧情方案。** 这份文件描述未来的模块接口，不擅自改动已经确定的战斗与七牌盒手动摸牌规则。

## 定位

不是纯文字的 GALGAME，也不是开放世界大地图。用 GALGAME 的对话、人物立绘、情绪和分支，配合近距离可控分镜的 **2.5D 纸片舞台事件**，在需要时无缝进入现有 3D 卡牌棋盘。

核心循环：**剧情演出 → 角色互动/选择 → 遭遇/战斗 → 结算 → 后续剧情**。

## 最小模块分工

- **`engine/story-graph.js`（未来）**：剧情节点、前置条件、分支、旗标、任务进度。纯数据/纯逻辑，绝不直接调用 DOM 或 WebGL。
- **`engine/story-runner.js`（未来）**：执行剧情节点，处理暂停、跳过、等待、选择，调用事件接口；对存档暴露安全的进度快照。
- **`engine/cinematic-director.js`（未来）**：根据指令使用已有 3D 摄影机、卡片式人物立绘、纸片前中后景、灯光、场景切换和音效，负责一次性出入场动效。
- **`ui/story-dialogue.js`（未来）**：对白文字、人物名、角色立绘、表情、下一句、选项、历史记录、自动推进。与逻辑完全分离。
- **`story/chapters/*.js`（未来）**：每章只存文本、节点和事件参数；通过注册加载，不直接复制游戏场景引擎。
- **已有 `engine/level-engine.js` + `engine/combat-turn-controller.js`**：剧情节点进入战斗后，由通用战斗引擎独立接管，不在剧情脚本里模拟 HP 或回合。

## 剧情指令建议

| 指令 | 作用 |
| --- | --- |
| `scene` | 选择或切换森林、室内等模块化场景 |
| `portrait` | 显示 Anima 人物画作、姿态、表情；可切左右站位 |
| `say` | 姓名与台词、文字速度、语音/音效入口 |
| `camera` | 由演出导演控制镜头的具体移动与构图；保留战斗镜头的边界规则 |
| `stage` | 2.5D 前中后景、纸片动画、光影变化和局部事件 |
| `choice` | 选项、条件、分支旗标 |
| `battle` | 装载指定 level manifest，等待胜利或失败结果 |
| `condition` | 根据角色状态、已经取得的物品、关系和战斗结果分流 |
| `end` | 结束当前事件，恢复正常关卡或菜单 |

## 最小实机竖切片建议（尚未开发）

1. 森林场景中角色的短对白：不切到另一个网页
2. 背景与前景分层演出，敌人出现、短镜头切换
3. 剧情触发 `forest-01` 卡牌战场；玩家手动摸牌
4. 战斗胜利与失败分别触发不同对白
5. 旗标记录结果；退出、重开可正确恢复

## 需要遵守的原则

- 所有立绘采用已经注册的 Anima 图片，不擅自用程序人物替代
- 不将剧情写成专门针对这一关的网页流程脚本
- 不在剧情文本或事件里重新实现部署、攻击、回血和回合
- 不强行用浮动对白遮住 3D 战场操作
- 人物演出为事件触发的动作，不恢复持续摇摆和漂浮
- 先验证一段完整竖切片，再扩展章节/关系/支线
