# WORK 原版金币 · 三维几何与像素渲染研究室

**托管入口**：https://g2066203208-beep.github.io/paperchalk-world/card-battle/slots-daggers/coin-lab/index.html

这不是重新画的金币，而是从 Git blob `244779b322b33559c31aa1ae11bf6f0f7d15fe0c` 的 `site/card-battle/slots-daggers/coin-art.js` 提取的**原版逻辑**。原文件不改。

## 源码实证
- `coin-art.js:60–86`：6 个同轴十边形圆环，各 10 顶点，60 顶点，52 个多边形（两个十边帽面 + 50 个边面），三角扇展开为 116 三角面。轮廓用 3D 几何，面边厚度与倒角是真实的。
- `coin-art.js:87–136`：使用 `dieHeight(x,y,side)` 生成双面浮雕高度函数，`makeDies()` 为每面 48×48 像素计算偏导法线（及第四通道亮度扰动）。**纹章是法线光照假浮雕，并没有提高几何面数**。
- `coin-art.js:137–167`：手工 256 级金色查找表、方向漫反射、反射向量、窄高光、近似菲涅耳项。这是自定义 CPU 光照模型，**不是 WebGL PBR shader，也不是真实环境路径追踪**。
- `coin-art.js:168–229`：软件光栅：3D 旋转矩阵 → 2D 投影 → 每个多边形三角扇 → 重心坐标 → 浮雕法线采样 → 着色 → `ImageData` → `putImageData`。
- `coin-art.js:230–271`：高光阈值激活的暖色辉光、实体几何投影出的轮廓阴影。
- `coin-art.js:272–683`：金币随机个体、四元数姿态更新、1/240 s 固定物理步长、弹跳、上下支撑、扁平金币之间的距离/高度近似碰撞、托盘接触、滚动收敛、姿态与亮度量化缓存。**真实 3D 几何/姿态，但不是通用完全 6 自由度刚体引擎**。

## 实验室实现方法
- 页面将 `coin-art.js` 保留**逐字原样嵌入**，另附研究室专用仪表版本。研究仪表版只改 43px 采样分辨率常量为可变，重建采样贴图，开放本来位于闭包中的 `mesh`、`dies`、`dieHeight` 等对象，以及一个辉光显示开关；其余渲染与物理逻辑保持相同。
- 初始运行时**把原版金币和研究仪表版同时绘制为同样姿态、相同参数的两张 Canvas**，比较每个像素的 RGBA。43px 基准版本在 Chromium 测试得出 **0 个 RGBA 通道差异**。
- 默认以 129×129 的内部分辨率展示金币，使用**相同法线、环境灯、金色调色表和 CPU 光栅算法**进行重新取样；这一实验模式不是原游戏的性能基准。
- 右侧线框采用研究版**实际的 mesh 顶点数组与多边形数组**。紫色法线图直接取原版 Float32Array 数据；高度图直接取原版函数输出。
- 原 `CoinTable` 实例另外运行在物理小窗内：调用未修改的 `update()` / `draw()`，可进行额外投币测试。

## 几何模型导出
提供仅包含原版 3D planchet 外壳的 GLB（60 顶点、116 三角面、watertight）。**这个 GLB 不含程序化浮雕着色，不应误以为它能单独呈现原版金属质感**；完整质感必须运行 `coin-art.js` 的逐像素金属着色器。

`.github/workflows/work-coin-3d-study-qa.yml` 在 Chromium 实际运行研究页，验证顶点/面数、浮雕法线、原始像素一致性、43/172px 切换、真实 3D 姿态、物理演示，并保存桌面/手机截图与录屏。
