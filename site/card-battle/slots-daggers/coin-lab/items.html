设计原则

WHY THIS LAYOUT WORKS
1. 左总览 / 中聚焦 / 右拆解一次能看很多物品，但视觉重心只保留一个对象，适合你后面继续把遗物、武器、设施都塞进来。
2. 卡牌视觉语言参考 Work 的金属光照当前为厚卡、金属边、压印层、受光高光和翻面演示；尚未接入金币原版 CPU 浮雕光栅器及 GitHub 角色立绘。
3. 先做人物卡，后面横向扩展最快卡体结构、控制台、筛选总览都已经搭好，后续只要换模型与浮雕内容即可扩类。
Prototype focus：把单物品研究台升级为“多物品单件审阅台”。 当前仅完成人物卡分类，但已具备多物品浏览骨架。
