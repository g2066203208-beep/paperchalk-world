# 机台军团 · Codex 接手入口

## 用户最后确认的方向

保留已认可的《Slots & Daggers》机台质感，用摇柄招募小兵，玩家负责配队和投兵，双方在横向战场自动推进。小兵要与托盘金币一样有实体感。最高优先级是敌方重怪一击将一群小兵扫飞：逐个根据位置、质量、抓地和接触点受力，轨迹、旋转、落地与二次碰撞各不相同。队友要能被撞到，存活的小兵落稳再归队。用原创资产，宣传片和实况只用作观察。桌面和手机均须实际进入游戏验证。

“另一个老虎机”是玩法描述，具体标题尚未获用户确认。《转运军团 Slotbound》官方说明有摇轮召兵、整队及自动对战，可作玩法参考。现有较早的 21 点、单敌人时机判定和森林自动滚屏等记录属于历史阶段。当前工作以本说明和后续用户指示为准。

## 基线入口与可复用源码

- [当前公开网页](https://g2066203208-beep.github.io/paperchalk-world/card-battle/soul-table.html) 对应 `site/card-battle/soul-table.html`。这是可离线的内联构建产物，修改应从模块源码开始。
- [已认可机台的模块入口](../index.html)。同级 `cabinet-art.js` 创建机壳、桌面与玻璃，`coin-art.js` 解算并绘制金币，`reel-art.js` 创建铸模及转鼓，`light-field.js` 计算桌面灯场，`sound.js` 合成机台声音。
- [旧版动作模型及测量](../study/model-checks.md)、[视频来源及时间码](../study/video-catalog.md)。这些测量用于维持已经认可的金属、光影和运动表现。
- 在仓库根目录执行 `python3 -m http.server 8000 --directory site`，从浏览器打开 `http://localhost:8000/card-battle/soul-table.html`。Pages 工作流为 `.github/workflows/character-editor-pages.yml`。仓库还有大量无关游戏内容，提交聚焦 `site/card-battle/`。

## 下一个可玩的闭环与验收

1. 摇出盾卫、枪兵、弓手、锤兵和医师五种招募符号。整队有七个编队位置。玩家选择集结路线、保留一个鼓、投入金币重摇、出阵或增援。士兵自己走、瞄准和攻击。
2. 在同一战场模拟位置、航道纵深、离地高度、速度、质量、倾角、角速度和接触。影子留在地面，随着离地变化。重兵同等冲量下移动较少，空中士兵不能边飞边走。
3. 大怪蓄势后用连续扫过的范围命中多个独立兵体；同一只怪、同一次攻击各命中者只结算一次。记录实际命中人数、起飞、最高点、落点、落地反弹和重新站立。大怪能受伤或被击败。
4. 用正常交互打完一场，验证增援、失败/胜利、继续下一关、暂停、重开、移动端点按；保留真实运行画面、重怪慢放或逐帧检查和运行命令。
