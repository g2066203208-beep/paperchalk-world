# V15 solid-color hair

- One uniform RGB (184,166,132) for all hair polygons. No textures, gradients or painted highlights. Optional flat facet lighting, switchable to fully unlit.
- 89 quads / 116 hair vertices. Angular crown, asymmetric hard-fold bangs and tapered four-sided low ponytail. Body unchanged.
- CPU render front/45/side/rear, unlit 30-degree view, 32-frame turntable. Face and clothes not modeled. Some hard angular transitions remain provisional; web deployment not checked.
