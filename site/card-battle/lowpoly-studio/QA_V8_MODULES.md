# V8 模块化头部

用户更正：基础人体（完整头骨、脸、下巴、颈、躯干、四肢）才是一体化连续蒙皮网格；发型、左耳、右耳必须可独立替换，不得与头骨焊死。保留 V3 的76个非头顶点（含颈部）、146个非头三角面及原骨骼权重。V8重新建33个头部点与68个面，包含完整颅顶与下颌底面。

| 网格 | 顶点 | 三角面 |
|---|---:|---:|
| 基础人体 |109|214|
| 发型A或B |72|140|
| 单耳（长或短） |6|8|
| 默认组合 |193|370|

Python trimesh 与实际 GitHub JS 源码在 V8 运行环境分别核验：全部7个单独对象闭合、单连通、Euler=2、非流形边和退化面均0、有向体积一致。原身体坐标、面、权重均不变。耳朵的4个根部点中3个位于基础头骨内部（有向立体角检测），不是依赖头发悬挂；模块根部与头骨有意重叠用于遮挡连接，不能宣称模块之间零交叉。头部模块绑定同一 head bone，独立选择器、分解视图、组合 OBJ 独立对象导出均已接入；3×3×3=27个可选组合。实际同相机 CPU 光栅生成4种组合3视图、线框、分解图、旋转GIF；不是线上 WebGL 截图。浏览器脚本语法检查通过，新增 Playwright 切换、骨骼随动、手机截图断言已提交，未确认实际浏览器运行成功。当前是模块化技术基线，脸型及发型美术尚未最终验收。
