# Pixel texture V01

Actual 256x256 authored pixel atlas, nearest-neighbor UV sampling on existing pose mesh. All vertices unchanged. Front/back coat panels, painted facial features, hair, trousers, gloves, boots, wood/metal/optics. Provisional planar UV mapping (seams and hair visibility need refinement); pose geometry not approved; no animation or deployment test. The image previews are rasterizations of the textured mesh, not standalone generated artwork.
