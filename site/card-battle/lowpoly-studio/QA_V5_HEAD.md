# V5 头部三视图建模试验

用户认可的 GPT Image 三视图是本轮造型蓝图，非 Esukevi 原作者源模型。按正面、侧面与背面共同确定刘海、侧发、后脑、短下颌及马耳的位置。发梢和耳朵均连接同一网格，未用独立拼装物体。原 V3 的 76 个非头顶点（含颈部）、146 个非头三角面、蒙皮权重及骨骼位置保持不变。新增头部 84 顶点、170 三角面（含颈部连接），全身 160 顶点、316 三角面；闭合单连通、Euler=2、非流形边0、退化面0。JS 与 Python 有向体积一致 1.14334666187409。

本地 CPU 深度光栅渲染已检查正面、侧面、背面、3/4及旋转GIF。先发现侧发穿插，重新选点后，中性及绕Y轴 -0.85 至 +0.85 rad 共9个采样转头姿态的非相邻三角形严格非共面穿越测试均为0，边长比范围 .8595–1.1977。此测试不排除共面或未采样状态的自交。面部与头发采用不同浅灰白材质及平面法线，无贴图。

当前局限：蓝图三视图由生成图给出，不是严格的原始正交工程图；尚未精确轮廓误差验收，发束层次、耳朵根部及背部折面仍有差距。头部三角面超过蓝图建议96–144，暂不为减面牺牲造型，后续仅优化头部。实际浏览器/手机QA尚未确认；本地截图及GIF在对话附件，生成蓝图PNG尚未写入仓库。不得把本地渲染说成线上WebGL截图。
