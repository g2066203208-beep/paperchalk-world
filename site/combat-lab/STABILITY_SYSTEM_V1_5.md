# 时序断点 · 硬直、失稳、破防与固定格中断 V1.5

状态：已接入 `site/combat-lab` 可玩原型及实时预演；**不是主游戏最终正式规则，也不是真实联机**。

## 本轮已实现

- **统一10格时间线**：4友方+4敌方，每个人继续拥有等高双轨。给队友的保护/稳固仍只消耗施术者自己的格子。
- **硬直积累值（Poise）**：从0上涨至上限。敌人、玩家均遵循同一套积累、衰减与失稳条件；角色左侧血量条下面增加一条独立硬直条，显示本轮实时推演前→后的变化。
- **安静恢复**：在一个没有有效接触的时间格结束时，硬直积累 -4（下限0）。被命中、或成功格挡仍产生接触的时间格不会自然恢复。完全成功闪避视为无接触。
- **命中硬直压力**：`ceil(实际扣血 × 0.48) + ceil(成功抵挡量 × 0.14) + 卡牌poisePower + 标记联动(+2) + 遗物加成`。连续攻击每个生效格独立计算。完全格挡保留较小冲击，成功闪避为0。硬直被打满立刻触发失稳。
- **主动稳固**：`稳固呼吸`、`回稳屏障`帮助自己或队友降低硬直。`断势冲击`与部分原有卡牌更擅长造成硬直。另增加两件对应遗物，并纳入战后奖励/超市池。
- **同格速度先后**：依然先结算速度高的行动；相同速度为同格同批伤害。在一格中真正受击时改变硬直、护盾和中断，后续慢速动作可能被打断。
- **控制完全不挪位**：硬直满造成的失稳2格、破防3格、晕倒6格。只取消与 `[控制发生格, 控制结束格)` **相交**的当前及后续整张卡。后续不相交卡牌不推迟、不取消、按原时间执行。
- **防无限硬控**：进入控制恢复后，在恢复结束后还有2格抗失稳保护；期间可受伤但不会立刻被硬直条再次控制。更强的晕倒等特殊控制仍按其独立规则处理。
- **实时推演与正式执行同一引擎**：预演中显示预计硬直、预测恢复格（琥珀色）与预计取消的动作（划线/取消符号）；确认时用相同引擎运行。
- **手机时间轴重新适配**：宽度 ≤700px 时，独立时间轴每页显示5格，`1–5` / `6–10`切换，可横向轻扫切换；桌面仍一次显示10格。不是再叠加一行重复数字。保留底部固定手牌与确认行动。

## 控制实例（0-based内部时间，下文 T1-based展示）

T4受到连续攻击，硬直条达到最大值，触发2格**失稳**：T4与T5为控制恢复区。原定T5–T7的三格动作与恢复区相交，**整张动作取消**；原定T8–T9的另一张卡与恢复区不相交，**原位照常执行**。系统绝不能将T5–T7自动挤到T6–T8，造成连锁排程偏移。

强控制时若一张卡已开始但未完成，取消整张卡的剩余作用格/后摇；已发生的命中不可倒带。尚未开始且被取消的卡按既有牌库规则归还或结算，不凭空重复抽牌。跨轮控制沿全局绝对时间继续占格。

## V1.5 可配置数值

| 参数 | 当前测试值 | 理由 |
|---|---:|---|
| 每轮时间格 | 10 | 保持既定布局 |
| 失稳恢复 | 2格 | 最轻短控 |
| 破防恢复 | 3格 | 护盾被打穿的明确惩罚 |
| 晕倒恢复 | 6格 | 强控制、持续更长 |
| 无接触每格衰减 | 4点 | 避免零散攻击积攒到无条件失稳 |
| 普通生命伤害对应硬直 | 实际伤害的48%向上取整 | 与伤害相关但独立于HP |
| 已挡伤害对应硬直 | 抵挡伤害的14%向上取整 | 防御有效但非完全免疫冲击 |
| 后续抗失稳窗口 | 2格 | 防止被连续无限控 |
| 我方硬直阈值 | 斧卫30、枪手26、守护36、调律24 | 明确不同角色定位 |
| 敌方硬直阈值 | 按HP的36%计算，限制在24–42 | 精英/Boss更抗打断 |
| 标记联动 | +2额外硬直/有效命中 | 枪手标记→斧卫破势；保留玩家安排顺序价值 |

**注意：以上是基线候选，仍需真实玩家与完整肉鸽成长流程验证**。硬控造成的“损失多少计划卡”比纯胜率更重要，后续需追踪该指标。

## 新增战术构筑

- `reversal` 断势冲击：攻击8、额外硬直压力10，3格（前1/作用1/后1）；增强破势时机。
- `steady` 稳固呼吸：目标友方硬直 -14，2格（作用1/后1）；为后排或队友解除即将失稳的压力。
- `respite` 回稳屏障：持续防御2格，共享护盾11，同时施放时减少6点硬直；总体耗时3格。
- `poise_strike` 裂隙骨针：所有有效命中额外+2硬直压力，不绕过失稳免控时间。
- `calm_bell` 回响怀表：格挡时额外降低3点硬直。

## 手机可用性要求

所有角色始终双轨等高，目标编号固定，生命预测和硬直预测同处角色资料块。选中卡牌后合法起点轻提示、冲突位置不允许放置；未锁动作可移动或取下；洗牌锁定的只是已排卡而非留空格。一次显示5格并切换的代价是不同时看到全部十格，之后可根据真人可用性测试评估是否增加“10格缩略概览”，不能随意再添加重复时间刻度。
