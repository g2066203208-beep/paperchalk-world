# 时序断点 · 时间轴卡牌战斗 V0.5：数值与肉鸽闭环审计

> 2026-11-06 · **原型基线，不是宣称“完美平衡”**。报告和随附 JSON、测试代码同版本，可重跑。战斗机器人只代表固定策略，不能替代真实玩家、复杂联机或经济学上的所有最优策略。

## 1. 本轮必须解决的用户反馈——已接入可运行网页

1. 原来战斗结束后只有评分文字，**没有真正获得新卡/成长**：现已改成完整 5 关肉鸽路线，**结算评分 → 金币与回复 → 不重复的三选一卡或跳过 → 深夜超市 → 下一场带着新牌库、HP、遗物、绝杀能量继续**。
2. **每轮开始免费补牌/自动重洗**：回合边界不耗时间，将当前手牌补到4（遗物可变5）；玩家不需要“打空手牌”才能获得下一回合的补牌。
3. **玩家主动换手**：空手1格，非空手2格；锁定之前已放置的卡牌，**不是封死之前的空格**。新抽出的牌可以填此前留空的位置（本作明确采用“排程阶段重整资源”的抽象规则，不以现实因果为模拟目标）；已锁的卡牌本身不可修改，不可放在有牌或洗牌占用格。
4. **修复重复抽取漏洞**：计划中已经放置但尚未执行的牌作为“预留牌”，不能在同一轮被提前算入弃牌堆无限重抽。抽牌堆耗尽需要等实际行动结算并回收到弃牌堆。
5. **全体攻击**：4个职业的预设牌库分别加入全体攻击（长斧横扫/散射/盾墙震荡/群星共振）。生效格对全体活敌逐个产生伤害，支持多段防御、失衡、死亡与中断，不能只显示“群体”却实际只打一个。
6. **商店**：深夜超市出售3个卡牌商品、1件遗物、回复、升卡、删卡；每次交易消耗金币，永久修改本局的牌库/角色属性；重抽商品第一次3金币，之后逐次增加2金币；已购商品本店售罄。
7. **分数与奖励范围**：C/B/A/S/SS 五档对应稀有掉率 0/0/5/15/33%，同时改变奖励金币；首关不掉稀有，限制在关卡奖励池内；三张奖励只选一张，跳过换2金币。专属绝杀收尾有额外4金币（操控角色完成时）及战斗评分分项。
8. **继承**：HP、绝杀能量、金币、遗物、加牌、升级牌、删牌与关卡推进跨战斗保留。单人、3NPC队友模式共用战斗逻辑，关卡敌人数量/倍率根据队伍规模分开校准。

## 2. 配置、卡池与可穷举规模

- 4职业，**每个2套官方预设流派，共8套**：斧卫（裂甲猛攻、回旋连击）；枪手（快速连射、精准狙击）；守护（反击铁壁、破势护卫）；调律（失衡调律、共振支援）。每套起始12张卡。
- 原型各职业可选卡的种类分别为10、9、8、9，共36个职业卡池项（部分卡跨职业共享）。
- **枚举了16,588个“至多5次加卡的最终牌种计数多重集合”**，不计加入顺序、强化、删卡、超市购买和遗物；**并不代表16,588个策略流派都已平衡或实际有同概率抽到**。如果严格每关均获得1张卡、共5张，有10,736种最终牌计数组合。细分见 `enumeration-v05.json`，枚举算法见 `tests/enumerate-decks.cjs`。
- 升级和商店又增加组合数，使真实可达到的最终组合远大于这个简化枚举；由于概率、抽牌顺序、战斗时机和联机人数会产生组合爆炸，不可能宣称穷举所有真实游戏局面。

### 本轮明确采用的场景强度校准

为避免“单人对四怪必败、四人队伍随便打通”，只有**肉鸽路线**采用以下校准，不影响独立战斗引擎的通用时间轴判断：
- 单人关卡敌人数：1 / 2 / 2 / 3 / 1。敌人生命系数0.78，后四关敌方造成伤害系数0.55（基础关除外）。
- 四人NPC关卡敌人数：1 / 2 / 3 / 4 / 2。敌人生命系数2.72、伤害系数1.40，已独立调校。团队模式目前是假NPC，不是已实现真实联网。
- 每关通过后得到基础金币+评分加成+个人绝杀金币（如果触发）；按分数获得6+floor(评分/15)点战后生命恢复（不能超过上限）。

## 4. 6,400场完整肉鸽冒险自动测试

2026-11-06 固定参数版本；运行方式：`RUN_SEEDS=100 node tests/run-benchmark.cjs` 以及 `RUN_SEEDS=100 node tests/team-benchmark.cjs`。每个8预设流派×4构筑选择策略（伤害优先、生存优先、平衡、随机）×100种固定种子×2队伍规模 = **6,400个五关冒险样本**；失败/超时即终止，因而不是32,000场完整战斗。附 `balance-solo-v05.json` 和 `balance-team-v05.json` 可逐策略审查。

下面是**“平衡构筑策略”自动玩家**的整局五关通关率，不应当解释成真人玩家通关率：

| 职业 | 预设流派 | 单人100局 | 四人NPC100局 |
|---|---|---:|---:|
| 斧卫 | 裂甲猛攻 | 71% | 62% |
| 斧卫 | 回旋连击 | 67% | 67% |
| 枪手 | 快速连射 | 84% | 88% |
| 枪手 | 精准狙击 | 80% | 93% |
| 守护 | 反击铁壁 | 90% | 87% |
| 守护 | 破势护卫 | 85% | 87% |
| 调律 | 失衡调律 | 71% | 75% |
| 调律 | 共振支援 | 83% | 77% |

**结论：现在仍不完全平衡**。单人同策略8流派的差距为23个百分点（67%到90%）；四人NPC队伍为31个百分点（62%到93%）。守护和枪手在不少条件下更稳定；斧卫团队表现偏弱，部分组合可能需要增益。仅靠一个通关率不能决定最终数值，还应测单位时间伤害、防御覆盖率、事件得分、绝杀收尾率、游玩时长与实际玩家策略多样性。

## 5. 用例与未解决风险

- Node核心测试：`tests/engine.test.cjs` 16项，覆盖时间段切分、跨界、自由留空、主动洗牌锁定且空位可填、换回合免费补牌、AOE群伤、防御值池破防、不可随意改已锁卡、NPC共享结算等。
- Node肉鸽测试：`tests/campaign.test.cjs` 9项，覆盖评分奖励、唯一三选一、超市购买/升级/删卡、金币、HP/绝杀继承与五关通关。
- Chromium浏览器：PC 1440×900、手机390×844均在无网络环境使用内联脚本跑过页面初始化、自动排程、模拟预览、结算；人工构造合法胜利状态还验证了奖励→购买→下一关的交互。**并没有验证真实互联网多人同步**。
- 需要继续真人验证：手机触屏长期拖牌手感、精英和Boss特殊机制、玩家的最优组牌方法、多人联机竞争抢绝杀、复杂四怪同格动作、绝杀能量超前耗尽、升级卡延迟、生存流拖战。

### 已知设计局限

主动洗牌允许新牌倒填旧空位，是主创明确选择的**排程游戏抽象规则**，而非真实时间因果模拟。为避免复杂性，已排牌不能被回收重抽；在新牌前填空位仍可享受战术调整，但角色在执行中被破防会取消尚未发动的动作。这一点需要实战检查是否对高技巧玩家过强。

**禁止宣称所有构筑完美平衡。** 当前产物是可玩可复现、具备肉鸽闭环的 V0.5 基线，用于下一轮真实玩家反馈与多目标参数搜索。
