# 时序断点战斗实验室 V0.7｜等高双轨 + 默认实时预测

状态：2026-11-06 独立实验网页已实现；不代表主游戏已集成或真实多人联机完成。

## UI 核心规范

- 全部在场角色（最多我方4位、敌方4位）采用完全相同高度的**双轨道**。玩家自己的行不额外放大。
- 每行**上轨（大）**专门放“我对这个目标使用的卡牌”，**下轨（小）**专门显示“这个目标自己正在执行的行动”。把我的攻击放在敌人A上轨，消耗的是我自己的行动时间，不会占用敌人行动时间；小轨只读。
- 全局只有**一条**T1—T10刻度，移除冗余的第二排时间按钮。允许留下空格，提前放好卡牌，直接在上轨按时间格指定目标。
- 上轨支持点卡再点格、电脑拖放、移动已排动作换时间与目标、从上轨拖回手牌或点取下。**洗牌锁定此前排程，但空位仍可使用**。
- 前摇浅色、作用格主色、后摇深色。同一刻动作按速度由高到低计算，同速按既定批次规则结算。

## 实时预测（必须默认显示）

- 一进入规划阶段就运行与正式执行相同的`simulateRound(game,{preview:true,collectTrace:true})`，**无需按“预演”按钮**。
- 任意放牌、移动、取下或重新规划均重新调用这一计算。每人左侧一眼可见`当前生命 → 预计生命`、增减数值与预测后的血条；右侧所有敌我角色都有`预计受伤`或回复明细。
- 不放任何玩家卡牌，也会根据敌人已经公布的行动计算**我方预计承伤**。
- 点击某一时间格可以查看截至该格的血量与状态；默认查看本轮结束时，若点击“查看整轮预测”可返回整轮结算。
- 预测依赖当前已知敌方意图，不应伪称能够预知未公开的未来行动。

## 验证与限制

- 代码测试：16项基础引擎 + 7项速度/目标 + 9项肉鸽 = 32项通过。
- Playwright Chromium：1440px和390px 浏览器均实际渲染，4对4时存在8组**等高双轨**、80个上轨格与80个下轨格，全局10个刻度；放牌、换目标、移动、取下操作正常。
- 单人种子样例：初始女主`77→59（预计承伤18）`；攻击敌人后敌人血量从`51→51`变为`51→31（预计伤害20）`，战斗尚未正式提交。该测试有截图与自动化断言。
- 390px手机模拟器验证了点牌与点格；**真实触屏拖拽仍需设备测试**，不能冒充已验证。
- 团队4v4极限关可能造成大量损伤：这是目前难度数据而不是 UI 计算错误，仍需要进一步平衡。
