# V1.0 战斗双轨：受击预告与洗牌空位修复

状态：已进入战斗实验室 Demo；数值仍属于原型，不宣称已平衡所有流派。

## 一、目标清晰

- 每个角色仍是同样大小的两轨：大轨放本机玩家对该目标使用的卡；小轨展示该角色自己的行动。
- 只有一条 T1–T10 公用时间刻度；不另加导航时间轴。
- 所有敌方已预定命中的作用格都从现有行动表解析成 `T时间 敌人→目标 -伤害`。全体攻击会对应展示各受击目标。
- 伤害预告出现在三个互补位置：顶部一行可横滑的紧凑威胁提示、敌人自身小轨的箭头和伤害、受击友方大轨对应时间格的危险标记。角色左侧显示预测生命和最接近的受击提示。
- 威胁提示可直接点击：选用当前手中的防御牌，寻找能够覆盖受击时刻且不与施术者已有动作冲突的起始格，施放在受击队友身上；动作消耗**施术者**时间而不是受击队友时间。
- 角色真实/预计血量由游戏模拟器 `simulateRound({preview:true})` 计算；警报上的数字是敌人预定原始攻击值，可能被防御、速度先手或中断改变。两者含义不同，不应混淆。

## 二、洗牌：锁牌不锁空位

- 洗牌花费时间：空手 1 格、非空手 2 格。
- 点击洗牌确定后，当时已经排在时间轴上的动作被锁定，时间/目标/卡牌不可再改。
- **不锁空白格**：洗牌后新获得的手牌可以安排到此前留白的任意时间格，哪怕这个空白格在洗牌动作之前。新牌依旧可以移动和取下，只要它本身尚未锁定。
- 洗牌花费的行动格依然真实占用出牌者自己的行动时间。
- 牌库重洗在换手动作内部处理，不另收一次时间成本；不能通过预定却未执行的卡牌无限重抽。
- 本规则是明确的“规划阶段换手再回填空白”的抽象机制，不是模拟现实世界时间因果。程序的预演/提交必须共用这个解释。
- 跨轮末尾动作与角色自身冲突继续按原规则校验。

## 三、手机操作

- 竖屏默认收起职业、流派和关卡配置，点击“调整职业、流派与战斗关卡”展开。
- 手牌固定在屏幕底部，便于先点卡牌再点时间格。
- 8组轨道保持等高，时间轴可横向/纵向滚动；左边角色姓名和预计生命保持粘性。
- 威胁提示可以点击一键排防，减少反复定位敌人和队友轨道的操作。

## 四、验证

- 引擎用例：旧牌 T5、洗牌 T9、新牌回填 T1；之后可移动/取下新牌，旧牌锁定不许改。
- 浏览器 1440×900、390×844：8组轨道、80个目标时格、攻击预告、1排刻度、卡牌操作与预演可正常显示。
- 实机浏览器验证“点击敌人威胁→自动给目标队友排防”，且该动作属于施术者自己的时间轴。
- 保留旧的 16+7+9 项规则/速度/肉鸽基线测试。
