# Ring Arena V22 · 同空间攻击导演（2026-11-06）

基线：固定左机位、真正平视、主角 3/4 背面、四名敌人的真实 WebGL/L2D 战场。此次只重构视觉导演，不改现有卡牌结算、角色库、原始 L2D 或世界坐标。

## 删掉旧版错误
- **不再做全屏动作海报切页**：DOM 中旧两张全屏切入图片与黑幕、标题、速度线在战斗状态下完全不可见。
- **不再攻击者消失 / 受击者消失**：所有五名角色始终参加同一次 3D 绘制，攻击与受击姿势直接切换各自角色的真实 world-space billboard GPU 纹理，攻击接触帧里两人**同时出现**。
- 不再有按时间慢慢推镜头。普通攻击期间摄影机保持原样，视线 y=1.5m，横轴固定，切换视角入口仍然被关闭。
- 旧男角色受击原图把 `12` 烘焙进画作。新增经过**非破坏性导出**的 `enemy-suit-hit-no-hud.webp`，清除右上角的数字与背景碎片，原有 `enemy-suit-hit.webp` 保留。真正伤害数字由独立 DOM 层在 3D 目标接触点投影处生成，并不与角色贴图绑定。

## 技术设计
- `site/game/ring-arena-director.js` 是 pure / deterministic 时间轴与每个角色的 poseFor。
- `site/game/ring-arena-runtime.js` 内创建两张只上传一次的 WebGL 纹理（`hero-attack` 和 `enemy-2-hit`），复用原 billboard 顶点、3D 摄影机矩阵与人物脚点，不创建 CSS 大图镜头。
- 攻击只把 actor 世界锚点复制成当帧 `presented` 实例进行前冲和目标后仰。实际 `LAYOUTS` 冻结对象绝不修改。阴影随当帧渲染副本移动。
- 仅 **2号男敌**可以用该男性受击姿势；其他目标沿用各自 L2D，使用局部单目标闪白和击退，避免身份错误。
- 兼容 `?scene=ring-arena&directorQA=1` 定帧，截取 185、290、375ms 的真实 WebGL 画面；此控制只对显式测试参数开放。
- 游戏目标选择用 1–4 号敌人，演示 HP 每目标 36，命中一次伤害 12（数值只用于视觉预览）。任何掉帧不会跳过伤害结算；播放完严格恢复原机位与原始世界坐标。
