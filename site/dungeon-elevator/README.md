# 地牢电梯 · 3D 场景原型
入口：原托管游戏主菜单「地牢电梯 · 3D 场景」，直达 `/dungeon-elevator/`。

## 已实现
- 同一部真正的 WebGL/Three.js 方盒子货运电梯，两种固定镜头：**电梯门正面**、**转身看空电梯内部**。
- 门口沿深度方向分两层：**内侧全高安全门**、**外侧半高营业门**，独立滑开/关闭；门外暂以纯白背景占位，不虚构楼层场景。
- 侧墙、地板、天花板为独立绘制的轻度磨损纹理，使用 3D 透视拼装；画风是朴素破旧、非网游式，没有货架/柜台/乘客。
- 大型上/下行键、紧急回地表、双门控制、状态读数浮在画面上；不把3D空间切成多个UI栏目。
- 出行时双门必须关闭；不能超载；楼层移动消耗电量；紧急回地表消耗耐久并只能使用一次。

## 暂未实现
交易、商品、乘客立绘、委托、排行榜、正式电梯外楼层和复杂演出。都不是本次场景构建任务，不得在验证截图中冒充已完成。

## 操作
主菜单进入，点击「门口镜头 / 电梯内部」切换；箭头按钮移动；方向键上/下也能行驶；V切镜头。门口视角能够看到高/矮门，内部视角没有柜台和货架，保留站人空间。

## 技术与验收
`elevator.js` 加载仓库内 `../sphere-maze/vendor/three.module.js`，该文件精确对应 Three.js **r180**，依赖同目录的 `three.core.js`（r180，上游版权见 `LICENSE.three.txt`）。不使用外部 CDN。
`tests/dungeon-elevator-browser.mjs` 在1920×1080浏览器内验证门锁、载重、紧急返航、两台镜头并生成3张真实截图，`.github/workflows/dungeon-elevator-proof.yml` 发布可下载工件。
