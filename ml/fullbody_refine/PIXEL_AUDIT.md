# 每一个像素都要有理由：当前可证范围

2026-10-30 新人物原生192×256，严格4固有色+透明。GPU大型扩散模型及RLHF不是当前数据能支撑的精修方案。已实现的是**真实训练的上下文单步强化学习决策** (REINFORCE contextual bandit)，针对四连通色块碎点，结合邻域一致性、轮廓锁定和人工风险限制修改内部颜色。

- 独立随机噪声用于训练和验证。这里的奖励=去除人工破坏的真实正确像素与误伤惩罚，绝不是观众审美反馈。
- 完整覆盖地图：每一个原生像素标记透明、受保护头部、受保护轮廓、保持/语义未知、修改/有局部证据之一。没有真实语义标签的部分公开标记 **未知**，不虚构“这个点必定是腰带扣”。
- 编辑台账记录每个改动的XY坐标、原色/新色、4连通色块大小、邻域投票、5×5支持、模型选择概率、所属大致区域和**语义未证实**。
- 旧色块与新色块组件统计、独立合成破损集恢复差值、外轮廓/脸部保护都由CI强制测试；无改善则失败；人物艺术完成度由人工另验。
- [PixelDiT 2025](https://arxiv.org/abs/2511.20645)介绍像素空间扩散的全局语义/局部细节双级结构；[SpatialReward 2026](https://arxiv.org/abs/2602.07458) 强调空间区域验证；[DDPO 2023](https://arxiv.org/abs/2305.13301) 研究扩散+RL。它们不是在这个单人物上可直接复现的模型性能；不能为了“前沿”乱加技术名词。
- 目前严禁声称完成了新细节语义修图。下一阶段需要专业画师标注：人物每像素的材质/部位/线条意图、修前修后的成对地面真值，按身份隔离验证。之后可训练带区域条件的离散调色板扩散模型，并用真实审美反馈优化。

运行: `python -m ml.fullbody_refine.semantic_cleanup` → `python -m ml.fullbody_refine.verify_semantic`.
