# 全身人物机器学习精修 | ML Full-body Refiner

目标人物：`site/pixel-lab/assets/hostess-redraw-v1-192x256.png`。输入是一整张**192×256真正原生四色+透明全身人物**，不是头像、小人或人体模板。

工作步骤：完整原画→建立模拟像素污点监督任务→训练局部上下文卷积网络→用从未参与训练的污点分布评测→在原画上提出高置信度服装内部像素修改→保持头脸及全部透明轮廓→导出索引PNG+报告。输出训练模型权重、编辑清单和前后对比。

**真实限制：** 目前只有一张候选完整人物，没有“坏稿→画师重绘好稿”的人工标注对；模型只能证明对人工构造的颜色污点有去噪能力，不能自称修复了五官、重新设计服装、补出新肢体或掌握一般人物画法。真正的全身语义精修需要高质量**成对**人工标注的完整立绘，并按角色身份独立分割训练/测试。网页与报告必须显示实际改动像素数，绝不把无改动原画或等比例放大冒称精修成功。

本方案学习了 Pixelloid 的原生网格/索引化原则、Pixel_Art_Converter 的边缘保护+轮廓清理思路和 Aseprite 的索引色流程；这里是自己的独立实现，不复制外部许可证受限代码。

`python -m ml.fullbody_refine.refine --steps 70` → `python -m ml.fullbody_refine.verify`。正式工作流 `.github/workflows/fullbody-refiner.yml`。
