## 核心理念

**有生活质地的美感，而不是批量精致。** 校园与家宅本身可以平常，人物的视觉个性要通过骨相差异、眉眼节奏、头发自然重量、微表情与站姿建立。长相应该让玩家在黑白、缩图、无配件条件下也记得住。好看可以体现在五官关系、气质、留白及线条上，不需要每个人都有标准V脸、猫眼、完美皮肤或高鼻梁。

## 统一的游戏画风与不统一的长相

- **统一：** 画面干净的日系二维人物立绘；轮廓线有主次粗细；肤色不过度粉白；光源、阴影块逻辑、校服面料、绒布边缘、衣扣和鞋子属于同一画师风格。用已批准人物母图校准整体风格，不拿外部商业角色的独特脸当设计模板。
- **不能统一：** 头颅宽高比、颧骨/下颌转折、额头空间、上眼睑厚度、眼裂横纵比、左右眼形细差、眉眼间距、鼻长与鼻翼、唇厚与嘴角、耳位、发际线、发束剪影。男女角色不能只把同一五官放到另一具身体。
- **自然的不对称：** 一个眼睑稍重、一侧眉略高、嘴角有非常轻的偏向可以保留，但不靠大疤痕、异色瞳、花哨项链和脸上的随机痣强行造独特。
- **表情不是标准模板：** 冷淡不只是缩小眼睛；活泼不等于大眼脸红；温和不等于眼尾下垂加完美微笑。先定义一个人如何思考/观察，再决定他哪里松弛、哪里绷紧。
- **身材区别：** 学生也有较宽上身、圆肩、瘦长、紧实的腿、不同手掌比例；禁止所有学生共用模特长腿、窄腰和同一肩斜度。保持校服设计系统一致。
- **头发：** 发根方向和发束重量感自然，刘海大小有节奏；反对所有男学生完美中分、少女全员长发、无理由发色渐变或超强荧光高光。
- **画面审校：** 判断顺序是脸能否记住 → 五官能否重画 → 跟已验收角色是不是同一画风 → 制服是否同校 → 全身是否完整。细节误差不无限返工。只有明显换脸、剽窃性高度近似、重大神态失真才拦截。
