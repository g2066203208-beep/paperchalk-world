# 《错位日常》｜表世界日常模拟经营 RPG · 可玩原型 V1

> 2026-11-06 直接接入托管游戏。这是**第一版可交互系统**，尚非完整城市 RPG；城市外景、正式里世界出入场尚待制作。设计与实现状态必须区分。

## 玩法目标

玩家白天上学、打工、吃饭、购物、休息、交往与调查；随着**游戏内日历**推进，都市从隐秘怪谈渐变为公开异常灾害和全民危机。原有卡牌战斗、L2D、场景雾和正式角色剧情不被生活系统重做。

## V1 已经做进网页的功能

- **独立游戏日历**：原型起点为2026年4月13日07:00，行动按分钟推进，日期和星期自行计算，完全独立于用户设备时间；离线不推进。
- **已有场景接入**：卧室、客厅、厨房、玄关使用原来的自动场景系统、角色和黑雾。
- **可交互的城市地点**：学校使用已存在的教室素材；便利店、咖啡店、商场和公园已有独立SVG原型背景，经统一场景路由加载。它们是明确的美术搭建初稿，尚非最终插画。
- **日程与经营**：上课/自习、咖啡店兼职、散步、收集街区见闻、整理房间、休息和等待；结算现金、精力、知识、调查证据。
- **购物与背包**：便利店及商场商店有购物界面、商品库存、价格、付款验证；背包读取唯一存档，支持用品/重要物品分类、数量、说明和真实使用/医疗效果。作业本与钥匙不允许误消耗。
- **NPC 互动**：同学、店员、邻居各有地点、星期与时间窗口，同一NPC每天最多交谈一次，关系点存档；对白随世界阶段变化。
- **新闻与社会阶段**：从都市传说→异常频发→社会动荡→公开灾害→全民危机；由游戏日期与世界压力的原型指标驱动，阈值属于可调候选值而非正式平衡。
- **22:00规则**：在卧室22:00前睡着，直接进入次日06:00且清醒强制召回不触发；如果22:00仍清醒，记录必须召回并禁止继续普通日常活动，不提供假“跳过夜间”。
- **保存与兼容**：单独版本化存储，含余额、物品、精力、日数、地点、关系、每日行动次数和日志。不能覆盖现有故事/人物/L2D/卡牌存档。
- **真实入口（修订）**：主菜单「开始游戏」从卧室醒来序幕开始；平时只有必要的手机、背包、地图按钮。背包与折叠地图按需打开，手机承载女二催作业消息、联系人主页及关系信息。旧大型生活管理面板已删除。

## 2026-11-06 界面定稿方向修订：完全沉浸式、极简交互

**已撤销上一版的网游式「今天的生活」管理面板。** 删除 `site/game/daily-life-ui.js` 和 `site/game/daily-life-ui.css`，不在游戏中显示日程页签、实时余额/精力计分面板、关系点数、统计卡片或固定任务清单。

- 画面默认仍然是主角观察到的室内环境、原有文字对话与必要的游戏按钮，**不为日常另建大面板**。
- 只有可交互时才出现一至两个小而清楚的场景动作字样，例如卧室「查看书包」「去玄关」，玄关「出门」；动作后短暂浮现自然叙述，不弹出任务完成弹窗。
- 女二的未接来电、作业消息、回复、联系人与亲密度都在**已认可的原版角色手机**里。猫耳锁屏素材不改；解锁后可将手机应用画面拉近阅读。背包和城区地图是有实际功能的按需操作界面，不常驻场景。
- 城区地图显示道路示意、当前位置、开放情况、路程与「前往」操作；必须经过玄关出门。地图本身是地图工具，不把任务收入、亲密度等无关数据塞进去。
- 显示信息遵循**按需原则**：后台时间、财务、NPC关系、危机阶段仍运算/存档，但只有会影响当前决策的信息才在对应交互中出现，不能用游戏经营表格代替恐怖氛围。
- 城市地点已有独立背景初稿，学校使用已有教室图；便利店/咖啡店/商场/公园使用可替换的原创建筑SVG。场景不复用卧室图，也不伪造人物L2D立绘已完成。
- 运行时入口是 `site/game/overworld-runtime.js`；背包/地图/货架共用 `site/game/overworld-surfaces.js`，剧情入场对白使用 `site/game/overworld-director.js`，场景定义在 `site/scene-modules.js`。日常数据核心仍为 `site/game/daily-life-state.js`。
- GitHub Actions真实浏览器测试流程：`tests/overworld-intro-browser.mjs`，截图会收集到 `docs/screenshots/overworld/`。

## 进入游戏试玩

1. 打开 https://g2066203208-beep.github.io/paperchalk-world/，选择主菜单**开始游戏**。
2. 播放女主在卧室醒来的安静序幕后，打开原有手机，查看女二六通未接电话和催作业消息，可选择回复。
3. 关闭手机，卧室选择「去玄关」，然后「出门」。选择城区地图上的学校，路程会按游戏内日历结算。快捷地图按钮也会打开同一张地图。
4. 到学校可以补完并交作业，或与女二交流；从地图也能到便利店、咖啡店、商场与公园。城市背景为已绘制的SVG美术初稿，尚待正式风格精修和人物L2D演出。
5. 世界时间推进与22:00睡眠/清醒强制召回仍在后台，不新增悬浮管理界面；正式里世界战斗出入场尚未接入。


## 文件与接口

| 文件 | 用途 |
|---|---|
| site/game/daily-life-state.js | 无DOM依赖核心，支持Node/CommonJS测试，游戏日历/行为/存档 |
| site/game/overworld-runtime.js | 极简场景互动、手机集成、房间和城市地点过渡 |
| site/game/overworld.css | 只在需要时出现的轻量文字交互 |
| site/game/overworld-surfaces.js/.css | 统一的折叠地图、实体背包、货架购物界面 |
| site/game/overworld-director.js | 可跳过、可取消的城市入场及人物对话演出 |
| site/game/phone-focus.css | 保留猫耳锁屏，解锁时扩大手机阅读界面 |
| site/assets/locations/*.svg | 四个城市地点的原型环境美术 |
| site/index.html | 宿主入口与真实时钟/游戏时钟切换 |
| tests/daily-life.test.cjs | 日历、收支、NPC日程、睡眠、召回、存档回归 |
| .github/workflows/studio-pages.yml | 托管游戏发布流水线加入生活核心测试 |
