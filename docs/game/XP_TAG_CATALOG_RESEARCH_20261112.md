# 七人阵营小游戏｜二次元角色 XP 候选词库 · 网络资料归纳版 V1

> 研究范围截至 2026-11-12。本文按公开角色标签体系与二次元萌属性资料进行**原创筛选归纳**，不宣称穷尽互联网所有词条；同义词、作品专属词、组合词会不断增加。**这只是候选数据库，不等于正式采用的游戏 XP 分类**。本文件机器版见 `docs/game/XP_TAG_CANDIDATES_20261112.json`。

**规模：28 个分类，959 个候选条目。**

## 研究判断

- **网上的“XP”不是一个封闭列表**，可以是外貌特征、身份、性格、穿搭、关系、人设结构，也可以由多个元素组合而成。不要把网上任意“场景”“动作”或色情标签一概塞进人物融合槽。
- Danbooru 的标注分类覆盖发型、眼睛、服装、配件和姿态；VNDB 角色 trait trees 覆盖头发、眼睛、身体、服饰、道具、性格、身份、行为及关系；萌娘百科把萌属性扩展到外貌/服饰/性格/关系/身份等；人设补完计划特别区分字段元素、符号、人设结构与观众实际偏好。
- **玩家 XP 的“原子标签”和“复合萌点”必须分开**。如“黑长直傲娇”=黑发 + 长直发 + 傲娇；“冷面却爱甜食”=冷峻气质 + 爱甜食 + 反差组合。不能将每个组合占为独立不可拆的类型。
- **用户已确定**：小兵 3 个维度（职业、身材、随机性格），同类型只能选 1；二级总 4 XP、三级总 5 XP。**尚未确定**：第四和第五个独立 XP 家族。此词库先供比较，不提前宣布“种族”“异能”“特殊萌点”是第四类。
- **种族不是组织**：已有恶魔职员和吸血鬼小兵可以照常保持原设计，不能为了整理 XP 修改原图。
- **非性化人物外观与关系**：小个子/幼态等角色只能按人物设计描述，不与色情化物品或恋爱/性行为词条联动；全库不收录露骨性行为或侵害类标签。

## 在游戏里怎样规划，避免“收集大全”变成“大杂烩”

### 可执行分层

| 系统层 | 词库家族 | 是否直接记入角色 XP |
|---|---|---|
| 一级 3 个基础维度 | 职业、体型、随机性格 | **是；已有方向** |
| 视觉表达候选 | 发色、发长、发型、瞳色、眼形、面容、肤色、服装、饰品 | **待设计；需保证独立与可视化** |
| 交往与故事候选 | 言语、习惯、爱好、人际、气质、身世、剧情钩子 | **待设计；有些更适合剧情而非固定 XP** |
| 世界观元数据 | 种族、所属组织、社会身份、幻想器官 | **不默认成为 XP**；可供新 C 的种族与阵营设置 |
| 角色专长与配件 | 技能、装备、主题 | 需区分战斗能力、装备槽与角色审美 XP，防止重叠 |
| 复合人设 | 反差、对人互动 | 多种原子标签的**衍生识别/成就**，不应无成本当作基本 XP |

### 五条 XP 上限应该怎样解读

**建议保持“最多五条”，而不是把全网二十多个分类硬塞成五类。** 先收录广泛候选池，再评价每个候选体系的独立性、玩家收集欲望、可视化结果、自动战斗反馈与美术生产成本，最后用户批准正式第四/第五类。不要先设计一件道具，就宣称它定义了完整的新 XP 体系。

### 兼容融合规则（已确认）

- 两名同等级人物 + 对应等级消耗式融合材料 → **全新第三个人物 C**；旧 A/B 不在角色库存；角色原画/身份不得沿用其中任何一个。
- 同类型 XP 二选一；终局仅有 3 XP 则新一级、4 XP 则新二级、5 XP 则新三级。遗物是另一套持续性 Buff，不与消耗式融合材料混淆。
- 融合成功后 C 正式持有的 XP 不依赖已消耗材料继续存在；旧角色资产原图不改。

## 收录与排除口径

**入库**：人物自身可识别、可持续表现、可筛选或可在融合里选择的属性，附上互斥粒度。**不直接入 XP**：摄影角度、出图画质、背景场景、单次动作、作品名、画师名、暂时情绪、组织名等。**需拆分**：复合人设和多条件口头标签。**需额外人工审查**：同义词、不同年龄阶段、种族外观与组织制服冲突、战斗/剧情临时增益。
