## 实际玩法与棋盘

1. 农田属于**农民组织工程师（农耕少女）**的独有设施，不是普通攻击；数据层已有 `ENGINEER_CARDS` 的 `id:'farm-field'`。
2. **占地1×1物理地形方块**，放在左右设施区；可用的我方设施列为左侧 `1,2,3,4`、右侧 `10,11,12,13`，我方占 `tileR=3,4,5`；总数 24 个我方设施格，敌方另有24个供敌人等阵营使用。
3. 禁止在中间敌我3×3角色格、非设施格、敌方设施区，以及已有卡牌的位置落下。已有农田所在格不能再挖高或压低地形。
4. 首版真实可视功能：从工具区点击原图「农田」测试卡 → 合法格变绿 → 点击设施格 → 3D卡牌放下并播放弹性入场；只允许放一张（重新开始关卡可重新放）。
5. **第一关只有战士伐木少女，没有正式部署的工程师**。因此目前是标注为**测试入口**的手动放置流程；不是声称工程师职业已经可招募、可抽设施牌。等工程师入场后，将正式改用其职业牌堆 `farm-field` 的手牌来执行放置，并在打出时消耗该手牌。
6. 资源产出（每回合粮食数量、成熟时间、占地多格升级、和召唤师联动）**未获用户确认，不擅自固定数字**。当前农田是能部署和持续存在的设施占位物；没有擅自产生游戏数值。
7. 保持原版16×6（96格）真实3D地形；底部七格白膜牌盒继续保持，无盖子翻转。卡面不是附加大 UI 或替换场景。
