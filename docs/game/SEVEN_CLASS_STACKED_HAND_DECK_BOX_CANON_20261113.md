# 七职业独立牌盒 × 通用/组织专属行动牌 × 顶牌出牌（2026-11-13）

> 用户当次直接确认的卡牌机制，必须与已经删除的旧“纸牌时序·暗木桌战斗”区分。
> **这是一份设计基线，尚未全部实装到 3D 卡牌战场。** 建议牌数等参数不得冒称用户已确认。

## 1. 人物卡和行动卡必须分离（用户明确）

- **画面上方：人物牌/已部署角色**，属于参战角色、血量与能力的独立系统。
- **画面下方：一排七个职业卡牌盒**，分别对应工程师、守卫、战士、射手、游击者、医师、召唤师。
- **人物卡不参与回合结束的洗牌**；人物身份、部署状态与行动牌库不是同一张可反复洗回来的牌。
- 每个职业牌盒拥有自己的行动牌顺序，不把不同职业行动卡全部混成一个大牌堆。

## 2. 职业通用卡 ＋ 组织×职业专属卡（用户明确）

- **同职业的通用卡跨组织共享规则**。例如农民组织战士和猎人组织战士都可以使用普通攻击等基础战士行动卡。
- **每个组织的七职业分别有自己的专属卡池**。例：农民战士和猎人战士都叫“战士”，但分别具有伐木/乡村劳动与狩猎/猎杀对应的不同机制；工程师、守卫、射手、游击者、医师、召唤师也完全照此原则。
- 人物独特机制可与上述卡牌发生联动，但“每人必须单独有第三套专属行动牌”尚未确认，不能自行扩大工作量。
- 不只是换皮或数值+10%；卡牌应产生真正的位置、环境、状态、资源和职业连锁变化。

## 3. 七盒顶牌规则（用户明确）

1. 开局战斗界面底部展示一排七个职业盒子。
2. **每个盒内的牌上下叠放，只有最上层那张牌当前可见、可操作。**
3. 玩家把当前顶牌**打出去**，或主动**丢弃**，才露出下面的下一张牌。
4. 无法绕开顶牌直接从该盒内部抽取下一张；七个盒彼此独立。
5. **打完进入下一回合时，对行动卡洗牌/重新开始回合流程；人物牌不参与洗牌。** 已部署人物不能当普通行动牌回洗。

> “每回合洗牌”具体是剩余/弃牌/所有已用行动牌如何重构、是否保留盒内排序、弃牌是否有成本等细节仍待进一步核对；**绝对不能默认套用已删除的旧 Timegrid 单职业4张随机手牌逻辑**。

## 4. 关于“基本手牌多少张”的建议（非确认数值）

- **同时可操作的顶牌上限为 7 张**：七个职业盒各露一张。若某职业未招募/没有可用行动牌，该盒为空或不可操作，不能捏造卡牌。
- **建议首测每个已解锁职业牌盒放 5 张行动牌**（例如 3 通用＋2 对应组织专属），但**用户还未确认每盒5张**。
- **首关只有我方一名萝莉伐木工**，所以战士盒可用；其他六个职业盒是否要置灰、是否还能提供通用动作由后续规则决定，勿未经确认就赋予无队员职业行动能力。

## 5. 示意排版（非最终美术）

```
                  敌方 3×3 人物阵列
                  我方 3×3 人物阵列
            （人物卡/已上场角色区域）

 [工程师] [守卫] [战士] [射手] [游击者] [医师] [召唤师]
    □       □     [顶牌]   □      □       □      □
  (各盒堆叠行动牌，只能打出或丢弃顶牌，才露出下张)
```

第一关独立目标：森林3D场地，我方伐木工一名、敌方两名；实际敌人身份和角色原画待定。

## 7. 实装前必问/必核对的剩余决策

- 每职业的初始正式牌数是否采纳建议 5 张。
- 职业盒中间的人物牌是否另有可打出、丢弃流程；本文件严格不把人物牌混到洗牌行动卡池。
- 玩家每回合可从七个盒合计打出几张，是否有资源/回合次数限制。
- 各盒牌的弃牌、重洗与回合结束时顺序如何处理。
- 首关仅战士时，其他六职业盒的展示及解锁条件。
