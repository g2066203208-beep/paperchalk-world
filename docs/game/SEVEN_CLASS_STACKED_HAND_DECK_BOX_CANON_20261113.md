# 七职业独立牌盒 × 通用/组织专属卡 × 堆叠手牌 × 先摸后打（2026-11-13）

> **最新用户规则（覆盖所有旧建议）：在打出本回合第一张行动牌以前，可以从任意可用职业牌盒不限次数摸牌，直到总手牌10张满。只要打出第一张牌，本回合普通摸牌立即锁定，后续仅特殊卡牌/人物/遗物等机制可以额外摸牌。**
>
> 本文是**待实装的游戏设计规范**，不是声称目前 GitHub 3D 游戏已完成。与已退役的旧 Timegrid 暗木桌系统完全不同。

## 一、七职业与两类行动牌

- 七职业（固定）：**工程师、守卫、战士、射手、游击者、医师、召唤师**。
- **职业通用卡**跨组织一致。例如农民战士、猎人战士皆能使用基本攻击、基础防御等战士通用行动卡。
- **组织×职业专属卡**有不同机制。农民战士可围绕伐木、木材与林地，猎人战士可围绕猎杀与弱点；其他六职业也各有对应组织专属卡。
- **人物卡**在上方战场独立部署和维持，**不进入任何行动牌盒、不计手牌容量、不参与行动牌洗牌或回合清空**。

## 二、七职业牌盒与叠牌操作

1. 战斗界面下方常驻一排 **7个职业牌盒**。每个职业各有一个独立牌库与独立手牌堆。
2. 玩家可以指定一个**可用职业盒**，按该盒的顶部牌序摸到对应职业手牌堆；不能挑选盒内深层牌。
3. 同职业摸来的牌堆叠，**只有该手牌堆的最上面一张能被正常打出**。打出顶牌后露出下一张。
4. **普通主动丢牌不是基础功能**；如卡牌、人物、遗物或敌人效果触发特殊弃牌，才允许移除顶牌并露出下层。此前“玩家可随意丢掉顶牌”的旧描述作废。
5. 可自由切换七职业的手牌堆顶牌；**总手牌最多10张**，这个数是七个职业叠牌区合计，而非每盒10张。
6. 同职业可以连续抽取多张并叠压；因此手里总牌数可能超过7，但不同职业最多各有1张露出的顶牌。

## 三、摸牌阶段锁定（最新已确认硬规则）

**本回合尚未打出任何牌：**

- **没有每回合摸牌次数上限**；仅受**总手牌10张**、对应职业是否可用、对应牌盒是否还有卡限制。
- 可以自由从七盒中选择来源，一张一张摸。摸到8张还能摸2张；摸到10张普通摸牌自动不可用。
- “开局自动5张”来自先前讨论的首测提案；即使采取此提案，玩家仍可在出第一张牌前按职业盒主动补到10张。**开局自动数量尚未最后明确拍板**。

**本回合一旦打出第一张行动牌：**

- 立即设置 `normalDrawLocked = true`；**整个本回合**都不能再通过点击牌盒等普通方式摸牌。
- **即使打出后手牌由10变9、8甚至0，也不能再普通摸牌**；空出容量不解除锁定。
- 之后若有卡牌、人物特性、遗物等**特殊机制明确给予摸牌**，可以按效果继续摸（通常仍需遵守10张手牌容量，除非特效文字明确改变容量）。
- 普通弃牌本身不会恢复普通摸牌，也不会解除本回合锁定。
- 进入**下一回合**后重置 `normalDrawLocked = false`，重新获得自由摸牌阶段。

**典型错误严禁出现**：每回合固定可摸5张；打一张后空位就能继续普通摸；打完又回旧 Timegrid 四张随机手牌。

## 四、回合结束 / 洗牌

- **回合结束手牌全部清空，不保留到下一回合**（用户最新方向）。
- 回合清空的行动卡按照所属职业归入对应弃牌/重洗流程，不与其他职业牌盒混洗。
- **人物卡绝不参与清空或洗牌**。
- “弃牌重洗的具体时点、某职业牌堆耗尽如何处理、初始是否自动摸5张、每回合可打出牌数及费用”仍待定；不得凭旧系统照搬。
