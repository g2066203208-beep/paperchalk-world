## 1. 职业通用牌与组织专属牌

- 正式七职业：**工程师、守卫、战士、射手、游击者、医师、召唤师**。
- 同职业跨组织共享 **基础职业行动牌**。如不同组织战士都可用普通攻击、基础格挡、破甲类。
- 每个组织×职业有自己的 **组织专属行动牌**。如农民战士/伐木工偏木材、斧击、林地；猎人战士偏猎杀与怪物弱点，其余六职业完全同理。
- 保持单位牌和行动牌分离：人物卡在上方战场/人物区，**不进入七职业行动卡牌盒，也不参与行动牌洗牌**。职业盒里含通用与对应组织职业专属行动卡。
- 不强制每位人物额外再制造全套独特技能牌；人物自身机制可调整行动卡效果。

## 2. 七职业牌盒与堆叠式手牌

1. 屏幕底部有 **7个职业牌盒**，每个盒有独立行动牌库/可摸的队列。
2. 玩家每次**自己选择从哪个可用职业盒摸牌**；同回合可以从同一盒多次摸，也可以任意职业混合选择，前提是该职业可用且剩余牌足够。
3. 从盒内摸牌时只能按该盒顶部/当前队列摸，不能看穿盒子任意挑深层牌。
4. 摸出的行动牌放进手牌区中该职业对应的纵向堆叠列，新摸到的牌盖在之前的牌上面；**同职业手牌列只有顶牌能打出或丢弃**，被压着的牌必须等顶牌移走才可以使用。这保留“只有把上面的牌打出去或者丢弃才能打下面的牌”的玩法。
5. 七职业各自顶牌可以自由切换；**总手牌上限10张，指七职业手牌列合计，不是每列10张**。同一职业可在手牌里拥有多张堆叠牌，所以总数可以超过7。
6. 人物卡仍在战场上方，不参与动作手牌容量、弃牌和洗牌。

> 此处把“牌盒内牌序”和“手中按职业堆叠的可出牌顶层”区分开，避免产生“最多只能同时握7张”的错误解释。若用户后续明确要求的抽牌/遮挡交互与此不同，按照用户版本调整。
