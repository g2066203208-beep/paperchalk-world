# 七职业真实牌堆 × 十张自由出牌手牌（2026-11-13 最新正式规则）

> **最高优先级：2026-11-13 用户最新澄清：“卡牌盒必须是真实一张张卡牌堆啊，而且手牌10张排开任意打”。** 因此此前的“手牌按职业堆叠、只能打顶牌”是错误理解，永久废弃。**堆叠的是下方七个职业牌盒，抽入手里的牌横向平铺，每一张均可任意选择打出。**

## 一、人物卡独立，七职业共享基础、组织有专属

- 角色上场位置在战场；人物卡永远不属于行动牌牌库，也不参与回合结束洗牌/清空。
- 战斗职业固定七个：工程师、守卫、战士、射手、游击者、医师、召唤师。
- 每个职业有跨组织通用的行动牌（普通攻击等）和**每个组织×职业**独有的行动牌（农民战士伐木，农民射手狩猎，猎人组织射手另有猎人特色）。
- 农民组织已经批准的角色原画：战士=萝莉伐木工、工程师=农夫、射手=猎户。后两人可以注册到游戏人物收藏库，**第一关仍只上阵伐木工一人**。

## 二、七个牌盒：真实一张张牌叠在牌堆里

1. 画面底部固定七个职业卡牌盒，每盒内部有对应职业行动卡的**真实牌序和剩余张数**，卡面叠放，只有盒子最顶的一张能被摸出；不能翻查盒子下面的牌。
2. 每抽出一张，**这一张牌就从该盒牌堆移出，实体可视层数减少一张**。
3. 同一个职业盒可以连续摸多次，七个盒可以跨职业自由选择；某职业未上场时对应盒可以显示，但在该关卡不可摸。
4. **盒子的卡叠与“手牌”完全是两种结构**；不可把同职业手牌重新放成上下遮挡的列。

## 三、手牌：最多十张，一字排开，任意出牌

- **所有摸到的行动牌都进入同一个横排手牌区**，不按职业叠压、不按职业限制手牌槽。
- **手里任意一张卡都可以选中并打出**：第1张、第5张、第10张都能打，没有“必须先打最上面的牌”规则。
- 最大容量10张是总手牌数，不是每个职业10张。
- 正常情况下不得主动弃牌；只有明确的卡牌、遗物、人物等特殊效果能弃牌。
- 手机屏幕空间不足时可通过横向滑动浏览十张手牌，但十张仍是同一个自由出牌区。

## 四、先摸后打的阶段锁定

- **本回合第一张行动牌尚未打出**：玩家可从任意可用职业盒**不限次数**普通摸牌，直到手牌到10张/该职业盒没牌。
- **一旦打出本回合第一张行动牌**：立即禁止本回合所有普通摸牌，哪怕手里变成9张或0张，也不恢复。此后只能由明写的特殊机制摸牌。
- 本回合后续手牌仍可任意挑一张打，不必按抽牌顺序打。
- 每个新回合解除普通摸牌锁定；回合结束清空当前所有行动手牌，再对各职业盒行动牌分开洗牌，人物卡不参与。
- **开局自动发5张**为当前第一关首测参数，可以继续讨论是否修改；不是“每回合最多摸5张”的限制。
