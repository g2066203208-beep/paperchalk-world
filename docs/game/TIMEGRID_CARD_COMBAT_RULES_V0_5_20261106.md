# 时间轴卡牌战斗 V0.5｜正式原型规则（2026-11-06）

> 本文优先于旧的 V0.3 设计草案。当前是可运行的 GitHub 战斗实验室规则，不等于已实现服务器联机，也不代表数值最终平衡。可玩入口：[`/combat-lab/`](../../site/combat-lab/index.html)。

## 保留的核心玩法
- 全员共用世界时间。每轮 10 个游戏内分钟/时间格；玩家在本角色的轨道上自由放牌，允许空位等待，只有时间上最右侧的牌可越过第10格；全员提交后同步逐格计算。
- 每张卡有前摇（浅色）、作用（类别主色）、后摇（深色），长度全部占格；普通攻击通常仅在一个作用格造成伤害，多段攻击在多个作用格分别判定；敌我使用同规则。
- 防御只在作用格内有效，一张防御牌所有作用格共享有限防御池，池耗尽立即破防，中断后续行动；破防失能3格、晕倒失能6格是测试参数。
- 绝杀独立固定槽，不参与抽洗牌；能量跨关保留，达到100且满足条件才能安排，成功收尾提高评分、奖励和绝杀者的个人收益。

## 修订：洗牌与空格（V0.5 覆盖 V0.3）
1. **每个新回合自动免费补满手牌**（默认4张）。此时抽牌堆不足会自动把可用的弃牌堆洗回，整个过程不占时间格。
2. **主动洗牌才花时间**：手牌空时1格，手牌非空时2格。已摆放的动作与其时间位置锁定、不可撤销或移动。
3. **此前留白的时间格仍可放牌**：洗牌后新抽的牌可以放到仍空着的更早位置，只要不与已摆动作/洗牌格冲突。洗牌是本作规划阶段的牌库资源重整操作，允许这种非物理时间因果的战术回填。上一版“禁止倒填空格”的句子已废弃。
4. 规划中已经摆放、但尚未在实际结算中完成的牌是“预留牌”，不可被提前计入弃牌堆以供本轮再次抽取；执行后按常规进入弃牌堆，杜绝无限循环。
5. 如果当前时间轴再无合法空格，不能追加洗牌；不能因为调换拖动顺序，在第10格以外额外塞入新的普通卡。

## V0.5 新增肉鸽成长
- 五场连续战斗，4职业×2预设流派；胜利后按战斗评分获得金币、少量战后恢复和3张不重复奖励卡（任选1张或跳过）。
- 评分档 C/B/A/S/SS 调整稀有卡概率和金币；奖励受关卡奖励池上限限制。绝杀收尾可以改变团队评分；操控角色完成收尾追加个人金币。
- “深夜超市”可购买新卡、遗物、治疗、升卡、删卡、刷新卡牌商品。金币、牌库、HP、绝杀能量、遗物完整继承下一关。
- 每职业预设卡池加入**全体攻击牌**，全体敌人在该牌每个作用格内分别判定命中、防御与破防。多段全体攻击可以同时打击多个敌人。

## 平衡与验收
- 首测职业生命：斧卫77、枪手77、守护74、调律71。单人与4人NPC以不同怪物人数和数值系数测试，见 [BALANCE_REPORT_V0_5.md](../../site/combat-lab/BALANCE_REPORT_V0_5.md)。
- 8个官方预设；静态合法性穷举了16,588种“最多5次战后加牌”的最终计数组合（未算超市、升级、遗物），不等于16,588个已平衡流派。
- V0.5 使用6,400个自动冒险样本和25个引擎/肉鸽断言；单人平衡策略模拟通关率67%–90%、四人NPC为62%–93%。**当前仍有职业差距，需要真人测试后继续调校。**
- 核心实现：[战斗引擎](../../site/combat-lab/engine.js)、[肉鸽经济](../../site/combat-lab/campaign.js)、[交互界面](../../site/combat-lab/ui.js)、[测试](../../site/combat-lab/tests/)。
