# 七大战斗职业与配队联动规则｜2026-11-13

> **状态：当前卡牌肉鸽战斗设计基线，用户提供并要求永久记录。**
> 后续设计职业、人物卡、设施、遗物、时间步战斗、Anima 提示词之前，先阅读本文件。
> 本文件定义的是**战斗角色职业/队伍玩法**，不擅自覆盖现有世界观、阵营组织、人物原画，以及五种固定 XP 分类中的“职业+服装 XP”。具体对应关系尚待逐角色核对。

## 一、七个正式战斗职业（固定名单）

| 职业 | 战斗定位 | 能给其他职业提供什么 | 典型关键词 |
| --- | --- | --- | --- |
| **工程师** | 建造、生产、设施与环境战术 | 制造设施、改变地形、放置陷阱、生产经济资源 | 设施、农田、水车、炮塔、城墙、陷阱 |
| **守卫** | 承伤、防线、站位控制 | 保护队友、卡住路线、聚集或击退敌人 | 护卫、阻挡、聚怪、击退 |
| **战士** | 正面近战、突破防线 | 破甲、击退、打开敌方阵型 | 破甲、重击、突破 |
| **射手** | 远程输出、区域压制 | 标记敌人、集火、掩护队友 | 射程、标记、压制 |
| **游击者** | 机动、侦察、突袭 | 潜行、绕后、暴露目标、破坏敌方设施 | 侦查、潜行、绕后、破坏 |
| **医师** | 生存与辅助 | 治疗、增益、解除异常、延长持续作战能力 | 治疗、净化、强化 |
| **召唤师** | 召唤单位、阵地与人口优势 | 增加单位、占位、代替队友承担风险 | 小兵、召唤物、占位、牺牲 |

**严格禁止**私自更名、删减、合并、新增所谓“第八职业”，或把“工匠→机械师→工程师”等未经同意的路线说成职业体系。不同组织/阵营（骑士、猎人、马戏团等）**不等于**这里的七大战斗职业。

## 二、核心体验：配队，而不是凑七张最强卡

玩家要能围绕一张角色卡、一项能力、一种设施或一件遗物，逐步构建完整流派。七个职业是一张**互相创造机会、互相利用机会**的关系网。

**三层职业联动系统：**

1. **职业层：创造战术机会。** 例如击退、标记、召唤、筑墙、治疗、生产资源。
2. **人物层：利用并改变机会。** 同职业不同角色具有不同战斗特性与独特机制，不只差属性数值。
3. **设施与遗物层：连接、放大、改变机会。** 将职业和人物机制串成一个稳定流派，遗物作为可持续构筑要素。

**禁止以“同职业攻击力+10%”这类纯数值羁绊代替实质联动。** 数值增益可以辅助，但核心应是棋盘局面、行动与资源产生真实变化。

## 三、五种目标流派（玩法方向，并非已实现）

| 流派 | 角色组合示例 | 战术过程 | 主要风险 |
| --- | --- | --- | --- |
| **要塞防守流** | 工程师＋守卫＋射手＋医师 | 工程师建城墙/炮塔/农田 → 守卫拦截 → 射手利用阵地输出 → 医师维持防线 | 被绕后、被拆设施、前期投入 |
| **陷阱处决流** | 工程师＋守卫＋战士＋游击者 | 工程师布陷阱 → 守卫控路线 → 战士击退敌人触发陷阱 → 游击者处决落单目标 | 依赖位置和地形 |
| **召唤军团流** | 召唤师＋医师＋工程师＋射手 | 召唤师出小兵 → 医师强化关键单位 → 工程师提供补给 → 射手利用视野集火 | 范围伤害、召唤物管理 |
| **高速突袭流** | 游击者＋射手＋战士＋医师 | 游击者绕后 → 射手标记高价值目标 → 战士突破 → 医师提供速度/生存支援 | 持久战与控制 |
| **经济发展流** | 工程师＋守卫＋召唤师＋医师 | 农田/水车/加工生产 → 召唤物与守卫保护资源 → 医师续航 → 后期资源升级 | 前期弱势、设施被破坏 |

同职业与混职业队伍**都应具有成立的可能性**：例如七射手压制队、七召唤师兽群队、七工程师炮塔阵地队，但必须有明确弱点，不能出现无代价万能配置。这些“七个职业相同”的示例描述队伍构筑，不自动决定一场战斗允许七人同时站场。

## 四、全职业共用的六种联动机制

1. **击退、拉扯、位移**：战士击退 → 敌人进入工程师陷阱 → 射手追击。
2. **标记、暴露、视野**：游击者侦查 → 射手狙击 → 召唤物追踪。
3. **破甲、虚弱、异常**：守卫或战士制造破防 → 后续职业针对弱点行动 → 医师支持或解除负面效果。
4. **高度、掩体、地形**：工程师建造高台/掩体 → 射手利用射线/射程 → 守卫保护关键阵地。
5. **召唤物与设施**：小兵可搬运资源、操作炮塔、占领建筑，或作为占位/牺牲资源。
6. **时间步与行动顺序**：前一名角色改变局面，后一名角色在剩余时间步中连锁利用；可探索缩短准备时间、移动后触发预备攻击、插队与反应行动。

**时间步是核心深度，不是装饰性 UI。** 具体单次行动耗时、行动队列长度、自动攻击/手动触发优先级等尚需与真实战斗原型核对；不得把“准备3时间步”等设计举例当成已确认固定数值。

## 五、人物卡的能力层次

建议每张人物卡都具备：

- **1 个主职业**：来自固定七职业之一，决定基础战术功能；
- **1 个战斗特性**：描述人物的战斗风格；
- **1 个独特机制**：真正改变战场规则、资源流转或行动触发条件。

例子（**仅作机制方向示例，不擅自覆盖已批准角色档案**）：

| 人物示例 | 主职业 | 战斗特性 | 独特机制方向 |
| --- | --- | --- | --- |
| 驯兽师 | 召唤师 | 指挥型 | 召唤物协助保护队友 |
| 鸟嘴医生 | 医师 | 异常状态型 | 治疗时制作特殊药剂 |
| 骑士 | 守卫 | 反击型 | 被攻击后提供反击机会 |
| 飞刀演员 | 射手 | 连击型 | 攻击被标记目标触发追加飞刀 |

所有人物职业归属、具体技能、数值与已批准身份必须逐角色核对，不能直接把上面的示例当作最终实装登记。

## 六、当前 Anima / 卡牌素材硬约束

- **单张人物/设施卡素材画布：704 × 1024 px（宽×高），竖版。** 用户在 2026-11-13 明确纠正：不是 704×704。
- 需要独立合成的设施素材默认**透明背景、完整显示、无裁切**；构图以实际设施为主。
- **704×1024 是卡牌原始素材尺寸，不是棋盘的“1格长度”、设施物理占地或像素比例换算式。** 不准据此自动推导 2×1=1408×1024 等数值。
- 新 Anima 提示词先读现有 [双画风预设](../../docs/ANIMA_STYLE_PRESETS_NORMAL_CUTE_20261109.md) 与 [官方提示词记录](../../docs/ANIMA_OFFICIAL_PROMPTING_REFERENCE_20261108.md)。默认负面只用用户批准的通用质量负面，不要添加 safe。
- **设施必须体现工程师职业价值**，优先生产、动力、自动化、防御设施及职业联动，不再在未经讨论时随意选“木制路障”作为职业首张代表素材。
- **当前待制作建议：农田 → 水车 → 炮塔 → 城墙 → 陷阱**，是最近讨论的提议顺序，**并未全部获得逐项最终美术确认**；第一张“农田”也应按后续用户选择调整。

## 七、严格区分已确认与待定

**已确认的设计基线**：七职业名称与主要定位；配队优先；职业—人物—设施/遗物三层联动；六种通用机会机制；时间步产生连锁战术；704×1024 竖卡素材尺寸。

**待确定/待核对**：各职业实际初始行动时间与范围；正式战斗同时上场人数及棋盘可站位置；设施能否占用角色位置、持续时间和资源数值；每个已批准人物的职业归属、独特机制和属性；哪一个设施先画及其准确画面。

**落地顺序**：先核对现有游戏棋盘和时间步规则 → 确定七职业的基础能力/攻击范围/时间开销 → 将已入库角色逐个归类 → 设计第一批体现联动的设施和遗物 → Anima 作图及游戏内实测。
