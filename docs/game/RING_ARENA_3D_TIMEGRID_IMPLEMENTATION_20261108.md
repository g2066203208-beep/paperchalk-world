# 3D 环形战斗场景 × 时间步卡牌系统（2026-11-08）

## 本次实装范围

正式战斗入口：`site/index.html?scene=ring-arena`。直接加载 `site/combat-lab/engine.js`、`cards-expansion.js` 和 `site/game/ring-arena-timegrid.js`。全局战斗的 HP、行动卡占格、能量、破防、硬直、洗牌、绝杀、预演、胜负与评分**只由 Timegrid 引擎结算**；不得再用旧导演测试按钮的固定「12 点伤害」冒充真实结算。

- 战场仍为 3D WebGL，队友 4 人的宽间距 2.4m 不变，敌方 4 人位于原来的紧凑一列。
- 四角色控制映射：`hero → hero`（斧卫），`ally-2 → ai-gun`（枪手），`ally-3 → ai-guard`（守护），`ally-4 → ai-mage`（调律）。引擎内部以 `game.controlledId` 切换当前真正出牌者；四条友方轨道可独立排牌，不调用 NPC 友方代打。
- 四敌配置：`surround`，依次映射 `enemy-s1/s2/s3/s4` 到 3D `enemy-1/2/3/4`。敌方依原引擎规则同步预排程。
- 一轮 10 格，前摇/生效/后摇占完整时间长度；全体卡、跨轮卡、预演、有限防御池、状态异常、失稳、绝杀与自动补手牌沿用 `TIMEGRID_CARD_COMBAT_RULES_V0_5`。
- UI 包含共用 1–10 刻度、四敌四友行动轨、预计 HP、每位角色手牌与能量、换手、撤销/移动、独立绝杀槽、单人/全队自动排程、开始执行与战斗评分。战斗画面优先，只在规划时展开；演出阶段自动收起，可手动展开。
- 逐格播放来自 `simulateRound(...,{collectTrace:true})` 的实际引擎记录。伤害数字用当前 3D 摄像机投影至目标身体，攻击脉冲移动相同的真实世界坐标角色和阴影。人物根站位没有被改掉；敌人真实 HP 耗尽后从可见场景退出。
- 旧逐帧攻击演出还保留用于专门的 `?legacyDirector=1` 或 `?directorQA=1` 影视回归测试，不占普通游戏的主操作入口。

## 玩家操作

1. 进入环形战斗场景。使用 1–4 或左上角色按钮切换当前出牌者。相应越肩镜头同一时间跟随对应角色。
2. 点击下方手牌，再点击目标角色行的 1–10 格。友方卡必须选友方行；攻击与多数敌方技能选敌方行。不同角色分开排程，原引擎处理时间冲突。
3. 已安排的动作带可以选中，再点另一格移动，或按「取下」。主动洗牌使用所选格；绝杀按钮进入独立槽放置模式，须满足原引擎能量和目标条件。
4. 按「执行 10 格」；敌我在同一个绝对时间格下按速度和技能效果同步结算。完成后自动进入下一轮规划，直至胜利/失败。

## 验收与边界

- `node tests/ring-arena-timegrid.test.cjs`：原引擎的四人手控、抽排牌、确定性预演、真实 10 格播放与原单角色战斗实验室兼容性。
- `node tests/ring-arena-formation.test.cjs`：已批准的四人宽间距、L2D 背面、4 个敌人和切换镜头安全区不变。
- `node tests/ring-arena-timegrid-browser.mjs`（GitHub Action）：真 Chromium/SwiftShader 中切换四个角色、全队排程、执行、HP 变化、手机和桌面实际截图。
- 本版本是 **一场可重复进行的 4v4 场景战斗**；战后商店、连续五战肉鸽奖励和正式剧情持久化还没有嵌进主游戏流程，不能宣称已经完成。联机也尚未接入。
