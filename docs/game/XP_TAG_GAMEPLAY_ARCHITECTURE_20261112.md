# 七人阵营小游戏｜959 词条候选库如何变成可玩的五 XP 融合系统 V0.1

> 设计提案，非已经批准/实装。配套全库：`XP_TAG_CATALOG_RESEARCH_20261112.md`（28类959项）；结构化数据：`XP_TAG_CANDIDATES_20261112.json`。初始三大类职业/身材/性格、3→4→5 容量、玩家选 XP/同类择一、合成一个全新 C 等规则已经确认；以下第四/第五槽的玩法**由此次研究提出，待用户评审**。

## 核心发现：5 个 XP 槽不等于互联网上只有 5 个 XP 类型

- 网络分类覆盖容貌、发型、眼睛、装扮、语言习惯、关系、身世、种族、行为、技能和复合反差；这些不是同一个层级。
- **解决此前反复失败的设计方法**：1–3 号是固定基础类；4–5 号是由**独立的进阶 XP 收藏池**提供的开放式槽位。进阶词条每一条都归属于具体的**独立体系**，两条进阶 XP 不能同类型；无需强行宣称所有二级都只能获得“种族”“异能”“眼罩”。
- 这是一项**可选架构建议**；如果最终希望第 4、5 类在所有角色身上也完全固定，可以在同一候选池上挑选两个宏类别做最终规则，而不是先无依据猜答案。

## 候选：五个明确不同的进阶收集体系（不包含前三维）

| 进阶宏类型 | 包含的网上 XP 子类 | 角色层面表现 | 与基础 XP 有什么不同 |
|---|---|---|---|
| **容貌识别 XP** | 发色/发型/瞳色/眼形/面部标记等 | 黑长直、双马尾、异色瞳、泪痣 | 直接作用于**脸、头发、眼睛**，不决定身材、工作、性格 |
| **装扮风格 XP** | 服装款式、饰品 | 眼镜、丝巾、哥特衣装、披肩 | 决定**可更换的外观符号**；不得修改已经批准的一级组织制服原画 |
| **生活习惯 XP** | 说话方式、日常行为、生活爱好 | 轻声细语、扶眼镜、爱甜食、爱读书 | 是**持续行为和生活偏好**，不是她的性格性向或职业 |
| **关系羁绊 XP** | 社交关系、对人互动模式 | 师徒、旧友、宿敌、互相扶持 | 是**和谁有什么关系**，不是个人性格；必须有剧情/角色对象支撑 |
| **身世故事 XP** | 过往经历、剧情秘密 | 流亡贵族、失忆者、背负约定、隐瞒身份 | 是**角色的过往事实/背景**，不是当前职业或性格 |

**重要排除**：种族属于生命物种，组织属于所属势力，不强制在任何等级占 XP；高级战斗异能作为固定第四体系已被用户否定；单纯战斗数值词条不作为新核心 XP；反差人设由若干原子 XP 派生，不能用一个复合模板同时绕过多个互斥约束。

## 一、分级收集结构

| 阶级 | XP 容量 | 来源 | 示例 |
|---|---|---|---|
| **一级小兵** | 3 | 固定职业 + 身材 + 随机性格 | 职业·骑士 / 身材·标准 / 性格·谨慎 |
| **二级新人物** | 4 | 前三类各选一个 + 1 条进阶 XP | + 容貌识别·黑长直 |
| **三级新人物** | 5 | 前三类 + 2 条**不同进阶宏类型** XP | + 装扮风格·眼镜 |

### 同类排他（一定要有两个粒度）

1. **XP 宏类型**：职业、身材、性格、容貌识别、装扮风格、生活习惯、关系羁绊、身世故事。每名人物在每个宏类型**最多拥有一个计入槽位的 XP**。
2. **细节标签**：一个容貌识别 XP 可以是复合展示短语，如“黑长直”，但内部解析为黑发+长直发；多条外观属性仍可以存在于立绘上，**只有被选中的一条作为显式 XP，其他保持角色正常外观，不额外占 XP**。
3. **含义不相斥但类型仍相同**：例如新人物拥有“黑长直”与“异色瞳”两种容貌表现没问题，但不能在 4/5 XP 容量内把这两个同宏类型词条当作两条已选 XP。
4. **角色基础设定与 XP 不完全一一对应**：如种族、所属组织、发色等可以存在于人物世界观/原画，不等于必然有相应 XP 槽。不会为了四条 XP 把恶魔小兵画成人类。

## 二、消耗式融合材料如何带来第 4 / 第 5 条

- **一级×一级 + 基础重组材料**：玩家从 A/B 选择职业、身材、性格各一 → 新一级 C（3 XP）。这是同阶横向优化。
- **一级×一级 + 携带某进阶体系词条的中级材料**：从两张人卡选职业/身材/性格各一，再从材料的进阶 XP 候选选择一条 → 全新二级 C（4 XP）。材料**消耗**，C 永久获得第四 XP，原 A/B 在卡库消失。
- **二级×二级 + 高级材料**：两张二级各自已有一条进阶 XP。若这两条属于**不同宏类型**，玩家可以分别选出并用高级材料**开放第五 XP 容量** → 全新三级 C（5 XP）。
- 如果两张二级都带同种进阶宏类型（例如都是容貌识别），**必须二选一**；高级材料可有另一种稀有“提供缺失宏类型的新候选”版本，从而凑齐五 XP；否则只能合成新二级 C（4 XP），不得硬复制同类词条。
- **这是一套策划提案，不是已获确认的具体融合材料掉落表。** 其优点是第五 XP 不必再为了填空而发明一个不符合审美的固定种族或异能体系。

## 三、完成一个实际融合的完整例子

**一级 A**（恶魔商店成员，恶魔种族，仅作为已有世界观身份）：职业·商人 / 身材·成熟丰满 / 性格·精明。
**一级 B**（猎人组织成员，人类种族）：职业·猎人 / 身材·标准 / 性格·冷静。
**材料**：高阶容貌档案（提案：容貌识别·黑长直）。
玩家挑选职业·猎人 + 身材·成熟丰满 + 性格·冷静 + 容貌识别·黑长直 → **全新的二级 C（4XP）**。C 的组织/种族由单独规则决定，而不是 A 或 B 自动保留；C 的容貌不是 A 或 B 的脸。

之后，如果二级 C 与另一名带有 **生活习惯·爱甜食** 的二级 D 融合，高级材料解锁第五槽；玩家可得到新三级 E：猎人 / 成熟丰满 / 冷静 / 黑长直 / 爱甜食。注意这不是最后定案的第五类，只是说明**不同进阶宏类型**可以共同构成五 XP。

## 四、反差萌如何成为额外的收集目标而不占格

- **黑长直 + 冷静** → 冷系美人形象；**冷静 + 爱甜食** → 冷面甜食控；**猎人 + 怕鬼的习惯** → 惧鬼猎人；**商人 + 慷慨** → 慷慨商人。
- 反差是**组合成就/收藏图鉴中的衍生称号**，不是第六 XP，也不凭空创造一条跨分类属性。这样收集欲来自角色组合，不需要无限增加单人物 XP 槽位。

## 五、具体落地约束

- 合成预览显示：A 的 XP、B 的 XP、融合材料提供/开放的进阶标签、互斥分类、C 的 3/4/5 XP、C 的新身份/立绘及消耗。
- **严格禁止**把一张人物卡的“种族、组织、体型、职业、穿搭、习惯”全部当成额外占槽。只有明确带 XP 身份的词条才参与数量和互斥。
- 美术生产依赖已批准人物资产的独立新人物模板；进阶 XP 的视觉表现可以用经审核的新图层、专门新角色图像等实现，**不意味着 959 个词条已经有 959 张画**。
- 基础小兵各阵营现有的三张独立角色原画和七名高级成员原画不自动替换；已登记图片原字节保留。
- 先将 959 候选人工评级（收藏辨识度、视觉可实现性、跨职业适配、同类冲突、材料产出节奏），按 50–100 个首发可玩词条建立测试池，其他词条暂作图鉴扩展，避免首版制作 959 张图。首发 50–100 是开发建议而非用户已批准的数量。

## 六、选型对比

| 模型 | 优点 | 问题 |
|---|---|---|
| 固定五类，每个人必定拥有同样五类 | 规则最直观 | 若第四/第五类不受欢迎，会压垮整个游戏，且互联网上 XP 覆盖困难 |
| **前三固定 + 两个不同宏类型的开放槽（推荐测试）** | 尊重完整 XP 词库，让收集和融合产生分支；不需要改种族或原画 | UI 需要清晰呈现宏类型，世界观/特殊材料掉落也更复杂 |
| 任意五类全部随机 | 自由度最大 | 失去职业、身材、性格作为初始角色骨架的辨识度 |
