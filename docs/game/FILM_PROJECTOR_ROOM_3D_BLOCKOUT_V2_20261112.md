## 渲染和 QA

- 使用项目**已有本地 Three.js**库（`site/sphere-maze/vendor/three.module.js`），不依赖在线CDN。
- 几何体是实实在在的 Mesh、Cylinder、Torus、3D Plane/Box；房间有地板、墙壁并通过透视相机投影；不是一张整体插图、不是平面的 SVG 绘制。
- 光照使用 SpotLight、DirectionalLight、HemisphereLight、PointLight；启用 `PCFSoftShadowMap`，场景能开/关灯。灰模允许局部纯暗面以验收空间阴影。
- **当前未引入任何最终画作或人物立绘**，刻意保留纯灰幕布和空白胶片格子，仅检验占位大小和 7 格是否看全。
- 机械模型仅用基础形体作为体积/枢轴定位标记；以后仍按项目先前要求换上**2D绘画贴图**，不把圆环/箱子当最后成品。
- 下一步美术依次替换：远景墙+地面 → 空白幕布 → 放映机机壳贴图 → 两卷轴贴图（旋转枢轴不动）→ 透镜/摇柄 → 胶片边框 → 已有原版角色立绘。**每个素材独立，可单独上图和受光**。
- 灰模版本不叠加旧版原来的彩色暗金 UI；玩家手和手臂完全不绘制。
- `tests/film-projector-blockout-3d-browser.mjs` 持续校验项目真3D空间、WebGL阴影开关、摇动下一格和1600×900截图，成功前不能宣称空间验收。
