# 七人阵营小游戏｜XP 分类、全新人物合成与消耗式媒介 V0.8

> 2026-11-12 讨论汇总，**已确认的硬规则**与**尚待确认的第四 XP 分类提案**分开记录。用户明确指出这是一款以“收集合成 XP”为核心的游戏，而非普通的攻击数值合成游戏。旧版把“职业、身材、性格”和 XP 完全分开、随意拿“破甲、格挡、速度”作 XP 示例，未符合用户一开始提出的三个角色维度，**不得再当成已确认 XP 分类**。本文件是策划记录，不代表已写好可运行游戏。

## 一、用户已确认的融合与人物规则

- **人物 A + 人物 B → 一个完全不同的新人物 C**；C 有独立身份、相貌与立绘，不是 A 或 B 的身体被保留，不是“主体吸收材料”。
- 两张参与角色**同阶**，需要第三槽融合材料。普通配方：**一级+一级+基础材料**；进阶配方：**二级+二级+高级材料**。
- **一级角色 3 条 XP；二级角色 4 条 XP；三级角色 5 条 XP**。从双方 XP 候选中由玩家选择继承结果，**同一类型的 XP 只能选择一条**。
- **合成不等于升级**：一级×二若只形成 3 XP，C 仍为新一级；有效 4 XP 才是二级。二级×二若只形成 4 XP，C 仍为新二级；有效 5 XP 才是三级。
- 人物素材从可用卡库中移除，两张变为一张（库存净少一）；角色卡上场最多七名、自动攻击。
- 用户指出可重复使用的“融合遗物”可能导致无限抓小兵刷二级，因此最新**认可的平衡方向**：把**永久 Buff 遗物**与**融合一次消耗一件的材料**分开；永久 Buff 遗物仍可以存在，但不是拿来当“赠礼”附在人物身上的第三件材料。
- 世界观表现**不要把真人扔进炼药锅**。三槽只是玩法结构，仪式、新人物诞生的原因和正式名称尚未确定。

## 二、为何第四 XP 必须是新类别？

用户最初提出：**小兵有职业、身材和随机性格**，然后特别强调是**选择 XP 词条且两个小兵的同类型词条只能选一个**。因此建议把小兵的三类基础可收集 XP 整理为：

1. **职业 XP**：骑士、猎人、魔女学徒、恶魔店员等（候选名称，具体阵营兼容方式待设计）。
2. **身材 XP**：娇小、标准、成熟丰满等（三种形体身份均已有独立美术角色）。
3. **性格 XP**：谨慎、活泼、沉着等，获得小兵时随机分配；注意基础立绘的表情不写死性格。

**以上“把三维度正式命名为 XP 类别”属于根据用户意图整理的分类提案，待用户确认，不得宣称他逐字批准了全部分类名。** 在这样的结构下，两张一级小兵各 3 XP，最多能从职业/身材/性格中挑出各 1 条，因此不能凭空从角色身上挑出第四种类别。旧文件中“六个候选四选四、第四条只是从两名小兵原词条多拿一条”不成立，除非小兵原本拥有第四类别。

### 第四 XP 方案（**推荐但未定案**）：特殊萌点 / 特征 XP

- **第四条 XP 是与职业、身材、性格不同的「特殊特征」类**，由对应的**一次性融合材料**提供，而非自动从原三类重复继承。
- 初始候选：异色瞳、魔眼、独角、机械义肢、神秘印记、兽耳、尖牙、眼罩等；这些属于外观识别特征，不是“攻击力+10%”“闪避+5%”这样的纯战斗数值。具体词条、适配阵营、画面实现、数值效果待设计。
- 示例：小兵 A 的「猎人职业/娇小身材/谨慎性格」和小兵 B 的「魔女学徒职业/成熟身材/活泼性格」中，玩家职业选 1、身材选 1、性格选 1，额外消耗材料「魔眼结晶」获得**第四类型「特殊特征·异色瞳」**，最终产生带这四个 XP 的**全新人物 C（二级）**。同类型候选仍只能保留一条，不能同时要「异色瞳」与「兽耳」两个第四类。
- 对于只想优化三类基础 XP 的**横向融合**，推荐让第三槽能够选择不携带第四类型词条的**基础重组材料**，合成新一级 C（3 XP）。这样兼容“两个小兵仍能合成一个小兵”的既有要求。
- 特殊特征应该体现为新 C 的固定人物设定与立绘，不是角色头上暂时飘着一个加成图标。技术上可后续设计定制立绘/可选叠图层/预置结果池，不能承诺无限组合已有完整原画。

### 第五 XP 方向（暂不拍板）

高级材料与两名二级人物再融合时，应引入**不同于前四类**的第五类 XP（例如「血统 / 命运 / 传奇身份」），而不是重复获得第二条特殊特征或把“职业”再选一次。第五星类及其美术、规则、物品池均需另行设计。

## 三、消耗式第三材料与永久遗物的区别

| 物品 | 位置 | 合成影响 | 合成后 |
|---|---|---|---|
| **基础重组材料**（名称待定） | 合成第三槽 | 两个同级一级只能保留 3 类 XP，得到全新一级 C | **材料消耗** |
| **特殊特征融合材料**（提案） | 合成第三槽 | 提供第四类特殊特征 XP，得到全新二级 C | **材料消耗；C 的第四 XP 永久保留** |
| **高级融合材料** | 合成第三槽 | 二级×二级，具备第五 XP 时得到新三级 | **材料消耗** |
| **永久 Buff 遗物** | 独立的局内遗物系统 | 战斗/经济/规则增益，若要影响融合另做规则 | **不会因为合成而消耗** |

- 第三槽材料消耗前，必须显示双方 XP 类型、可选结果、最终阶级及是否带入新增特征。玩家确认才执行。
- **C 获得的正式 XP 和阶级不因素材已经消耗而消失**；获得第四条的人物不会因此变回一级。
- 成功融合后**不能无损拆回 A、B**（推荐）；取消融合发生在提交之前，两人和材料原样返还。若要“回收”应单独设计，不得复制材料或人物。
- 不再写“永久遗物可以作为第三槽无限复用”，也不写“无论是否加入第四 XP 都强制升二级”。
