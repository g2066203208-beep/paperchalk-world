# 七人阵营小游戏｜XP 融合与种族分类 V0.9

> 2026-11-12 新提案：第四个 XP 从“特殊萌点”改为**种族 XP**。用户认为前期小兵都是人类，吸血鬼与恶魔是种族而非组织。下文分清已确认的融合硬规则与新提案；本文件是策划规范，不代表已经实装或改动旧美术。

## 1. 继续有效的融合基础规则

- 本作是**收集、选择和合成 XP** 的游戏。一级 3 个 XP、二级 4 个 XP、三级 5 个 XP。
- 两个**同级**人物 A、B 加一件相应等级的**融合材料**，得到一个完全不同的新人物 C；不保留 A 身份，不是 A 换装，素材卡两张变一张。
- 玩家从 A、B 候选的 XP 中**同类型只能选择一个**。最后 3 XP 得到一级，4 XP 得到二级，5 XP 得到三级；融合不等于必然升阶。
- 游戏最多七个人物自动战斗；一次性融合材料与《以撒》式持续生效的**永久遗物**是两套不同物品系统。融合材料消耗后，不影响 C 已得到的 XP 和阶级。
- 第三个槽位是游戏系统设计，不意味着真的把两个活人放入炼药锅；新人物 C 的世界观诞生方式仍待命名。

## 2. 第四类 XP 改为种族（用户提出、优先推荐；细节待确认）

| XP 槽 | 分类 | 例子 |
|---|---|---|
| 1 | 职业 | 骑士、猎人、魔女、商人 |
| 2 | 身材 | 娇小、标准、成熟丰满 |
| 3 | 性格 | 谨慎、活泼、贪婪等，初始随机 |
| **4** | **种族** | **人类、吸血鬼、恶魔、精灵、兽人** |
| 5 | 未定 | 不要自行定为特殊萌点或血统 |

- 推荐一级小兵**默认是人类**，但这是未开启种族 XP 槽时的隐含生物状态，**不计作第四条 XP**，否则将违反一级只能 3 XP 的既定规则。
- 二级融合新增第四类「种族 XP」。例如消耗带有吸血鬼血统方向的融合材料，新角色 C 获得「种族·吸血鬼」；另有恶魔、精灵等不同类型的可收集种族。材料名暂为占位示例。
- 二级需要能够继续成为**人类**，而非每个二级强制变非人。可由人类传承材料赋予正式「种族·人类」XP，并赋予独特玩法价值；具体名称和效果待定。
- **种族同一时刻只能选一个。** 人类/吸血鬼/恶魔是同类型候选，不能同一张角色卡叠两个；混血是独立待议机制，不自动通过双种族获得。
- 异色瞳、兽耳、角、尖牙等是特定种族或人物的外貌特征，不自动变成独立的第四类 XP；种族还应影响独特机制，不只是纯数值 Buff。吸血鬼吸血、恶魔契约、人类适应性等仅作未定示例。
- 两个一级小兵无种族融合材料时，玩家可用基础融合材料选职业、身材、性格各一个，得到全新**人类一级 C（3 XP）**；使用种族融合材料并合法得到第四条时产生**全新二级 C（4 XP）**。
- 二级×二级+高级融合材料：职业、身材、性格、种族四种类别各选一个；第五种 XP 尚未定案。没有第五条只能得到新的二级 C。

## 3. 必须把组织和种族拆开

**组织/阵营**：她为谁工作、属于哪个团队，决定服装、招募池、协同和剧情；**种族**：她是什么生命物种；**职业**：她做什么工作。组织不应因为名称包含某种族就等同种族，也不应额外占用 XP 位置。

| GitHub 现有七人团 | 推荐重新理解 |
|---|---|
| 骑士团 | 骑士团是组织，骑士是职业 |
| 黑心恶魔商店集团 | 商店集团是组织，恶魔是种族，商人/店员是职业 |
| 七曜魔女工坊 | 工坊是组织，魔女为职业/法术身份，不是种族 |
| 奇想马戏团 | 马戏团是组织，演职人员是职业 |
| 绯月血族 | 可以是吸血鬼家族/势力组织，但吸血鬼本身是种族 |
| 怪物猎人组织 | 猎人是职业，组织本身不是种族 |
| 黑潮海盗团（候选） | 海盗团是组织，海盗是职业 |

## 4. 道具与身份保持一致

- 融合用的**血统/种族媒介**属于一次性消耗的材料；遗物是独立的局内持续加成物品。
- 融合后新 C 的第四 XP 是她自身的种族，不需要继续携带媒介；媒介消失不使她退回人类或降级。
- 不能无成本将 C 拆回原 A、B（这是当前推荐的风险约束）；合成确认前预览职业、身材、性格、种族、XP 数量、结果人物与消耗材料。
- 所有具体种族列表、种族能力、角色造型生产、第五 XP 类别和既有非人小兵迁移仍待设计/确认；本版不宣称实装。
