# 七人阵营小游戏｜XP 融合、新人物生成、逆向拆解与媒介 V0.7

> 2026-11-12 讨论更新。**硬规则**：融合由两张同阶人物卡参与，合成结果是**与 A、B 完全不同的全新人物 C**，不是 A 继承 B、不是更换 A 的服装，也不是原人物的年龄变化。用户已否决“把真人丢进炼药锅”“用遗物当礼物”的世界观直译；三槽为**玩法结构**而非真正的炼药锅。本文件是策划记录，未宣称玩法已经实装。
>
> **此次讨论仍待确认的设计建议**：合成后不可拆回原来 A、B；第三槽物品可回收，遗物常驻 Buff 与融合媒介概念分离。

## 1. 核心玩法与固定数值（已确认）

- 游戏就是**收集、合成、搭配 XP 词条**；角色卡是 XP 的载体，最多 7 名人物自动战斗。
- 一级 3 条 XP、二级 4 条 XP、三级 5 条 XP；**融合后最终拥有的合法 XP 条数决定阶级**，不以合成次数定阶。
- 两张输入角色必须为**相同阶级**。两张一级可合成为一张一级（3 XP）或二级（4 XP）；两张二级可合成为一张二级（4 XP）或三级（5 XP）。
- 双方的全部 XP 显示给玩家挑选；**同一个 XP 类型只能选一个**，由玩家选择；不同类型在结果 XP 容量内可并存。
- 职业、身材与随机性格独立于 XP；**新人物 C 的外貌、身份与人物立绘必须不同于 A、B**。新 C 的职业/身材/性格如何生成，需后续设计，不得直接默认继承 A。
- 两张原人物卡 A、B 在成功融合后退出可用库存，只产生一张新的 C。游戏术语“材料消耗”指卡牌库存减少，不代表故事中的真实人类被烹煮、杀害或拿去做炼金材料。

## 2. 三槽融合配方（玩法形式已确认，名称与消耗方式待定）

| 目的 | 人物槽 1 | 人物槽 2 | 第三槽位 | 满足 XP 条件时的结果 | 没满足额外 XP 时 |
|---|---|---|---|---|---|
| 一级→二级 | 一级人物 A | 一级人物 B | 基础级**融合媒介** | **全新二级人物 C（4 XP）** | **全新一级人物 C（3 XP）** |
| 二级→三级 | 二级人物 A | 二级人物 B | 高级**融合媒介** | **全新三级人物 C（5 XP）** | **全新二级人物 C（4 XP）** |

- 用户先前将第三槽称为“遗物”，现认为直接叫炼药锅/遗物不符合世界观。因此暂以**融合媒介**作系统占位名，不等于已批准最终物品名称、美术表现或物理设定。
- **基础级媒介用于一级×一级；高级媒介用于二级×二级。** 不能以低阶代替高阶。
- 第四/第五 XP 的精确获得机制，以及媒介能否直接赋予 XP、仅提高继承上限、是否有稀有词条，均未最终确定。
- **“投入到第三槽”不必然等于消耗。** 是否允许重复使用、存在冷却/占用/绑定等平衡规则还需最后决定。

## 3. 为什么能创造全新 C？（仅供选择的世界观提案）

**不要再用“主体 A 吸收 B”解释。** 推荐叙事方向：人物卡实际代表可被收集和编写的「命运印记 / 召唤档案 / 角色灵像」，二者组合后形成一个**从未存在过的新独立人物 C**；A、B 的卡牌记录不再独立存在，玩家从它们的 XP 中选择 C 的新构成。一个更高阶媒介允许新人物容纳更多 XP。

此方向仅解决“不是把真人扔锅里”的设定矛盾，**用户并未批准“灵像/命运印记”等具体名词，也尚未决定人物角色是否是真实生命**，不得把建议冒充正式世界观。可用仪式、召唤、档案重构、梦境凝聚等不同表现，后续比较审美与阵营适配后定稿。

## 4. 融合后能否拆开和返还道具？（2026-11-12 新议题，以下为推荐方案）

- **合成前：自由取消**，两张人物、第三媒介完全保留；确认前必须预览新人物类型、外观生成规则、最终 XP 类别和道具去向。
- **确认合成后：不可还原原来的 A、B。** C 是一个真正全新人物，不是 A+B 的临时叠加体。无限无损还原会使 XP 构筑选择失去代价，还容易造成物品/角色复制漏洞。
- **C 可再参与同阶融合**，让玩家通过未来的两张人物重新优化 XP，不要求随意还原初始来源。
- **第三媒介不应因合成一次而直接永久损失**（建议）：若系统采用可重复使用的融合媒介，则合成结算后自动回到玩家媒介库存；**不需要为了返还媒介而拆掉 C**。
- 若最终决定某个媒介是**绑定式物品**：推荐允许玩家解绑/回收媒介，但绑定解除可能影响 C 的 XP 数量，必须事先明确是永久刻印还是实时外部加成，且绝不能导致 C 与原 A、B 双倍复制。
- 永久 Buff **遗物** 与用于合成的第三槽**融合媒介**建议各自有独立规则；不要把“礼物送给小兵”的旧提案带回来。
- 暂不建议直接提供“分解 C 后拿回 A、B”或“无限免费重选 XP”的功能；可另设有限制的纠错途径，但未批准。

## 5. 后续必须由用户确认的决策

1. 世界观究竟如何解释全新人物 C 的诞生，以及 C 是否固定来自已存在的各阵营高阶角色池。
2. 第三媒介正式叫什么，究竟是**不消耗重复使用**、绑定占用还是一次性材料；返还时间与方式。
3. 第四、第五 XP 到底从哪来；媒介到底给的是 XP 还是 XP 继承容量。
4. 同阶未晋升融合和晋升融合，新人物的外貌、职业/身材/随机性格如何生成，以及“反悔/拆解”的具体限制。
