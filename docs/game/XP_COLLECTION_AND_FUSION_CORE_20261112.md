# 七人阵营小游戏｜XP 收集合成已确认规则与待定第四 XP V1.1

> 2026-11-12 最新反馈：用户**明确否定**上一版的「第四 XP = 异能/命印」方案。此前「第四 XP = 种族」同样被否定。**严禁再把这些被否定的设想写成正式方案**。第四 XP 目前没有获批的名称、词条池或效果；必须是**与前三类完全不同且有自己独立收集玩法的一整套体系**。本文保留已经讨论确认的融合机制；对未定部分不擅自下结论。**文档不代表游戏已实装。**

## 一、已确认的核心方向

- 游戏主要玩法是**收集和合成 XP**，不是传统升星或纯战斗技能游戏。
- **一级小兵有 3 条 XP；二级角色有 4 条 XP；三级角色有 5 条 XP**。
- 基础小兵已提出三个维度：**职业、身材、随机性格**。三者与玩家的 XP 收集有关；具体词条与数值库可另设策划表。
- **同类型 XP 只能选一个**：两个输入人物的候选词条向玩家展示，玩家在同类型候选中自己选一个，不叠加。
- **两个相同等级的人物 + 一个对应等级的融合材料 → 完全不同的新人物 C**。C 不继承 A 的人物身份或仅换装，原来 A、B 两张角色卡合并为一张新 C。
- **融合不必然升级**。最后 3 条 XP → 新一级；4 条 XP → 新二级；5 条 XP → 新三级。
- **二级需要两张一级 + 基础阶材料**；**三级需要两张二级 + 更高级材料**。第三槽是融合材料，不代表世界观中真的有炼药锅。
- **消耗型融合材料**与《以撒》式的**持久增益遗物**分属不同系统。为避免无限抓小兵升级，融合媒介按有限消耗品方向规划。合成后第四/第五 XP 留在新角色身上，不依赖被消耗材料持续挂载。
- 游戏最多七位人物出场，自动攻击。

## 二、第四 XP：尚未确定，独立体系是硬性要求

**明确否决的提议（不得擅自恢复）：**
1. **种族 XP**：会与现有恶魔、吸血鬼小兵的自然身份冲突，还导致为规则强改旧立绘。
2. **战斗异能 / 命印 XP**：将主要收集目标变成额外战斗技能，不符合用户要设计的第四类 XP；用户直接表示完全不行。
3. **简单的攻击、速度、防御数值词条**或者将已有职业、身材、性格换个名字再组合，也不能作为新第四类。

**待设计的必要条件**：第四类必须是足以独立建设词条池、收集来源、融合选择与新人物表现的一整套 XP 系统；与职业、身材、性格正交；任何原有组织与种族的一级小兵都能参与，不能推翻已批准美术；要能通过一个实际例子解释为什么玩家愿意为了它收集、融合人物。

**暂不定名，暂不生成正式第四类词条表。** 应先澄清这套游戏 XP 指向的人物收藏体验，再决定最匹配的第四轴，不要连续替用户猜测和宣布定案。

## 三、种族 / 阵营 / 美术保护

- 种族（人类、吸血鬼、恶魔等）与组织（骑士团、恶魔商店集团、绯月血族等）是不同的世界观概念，不自动成为第四 XP。
- GitHub 已有恶魔职员的角和尾巴、血族的小兵原画和原组织七人组全部原样保留；不强制人类化，不迁移到二级，不擅自重画、覆盖或改名。
- 职业/身材/性格在融合成新人物时选择；新人物必须是与两名素材完全不同的独立人物。融合生成新人物的世界观包装及动态立绘制作方案仍待定。

## 四、仍待进一步设计的内容

- **第四 XP 的实际类型体系、收藏价值、获取途径**（当前没有最终方案）。
- 第五 XP 的体系；角色所属种族/组织如何生成及跨组织配方。
- 基础横向融合所需材料的具体类型、失败/取消、拆解、回收规则，以及独立永续遗物的作用。
- 任何涉及创造新原画、战斗效果、自动生成角色形象的实际生产与测试，必须在策划确认后另做，不能用仅保存文本冒充完成游戏。
