# 七人阵营小游戏｜XP 融合核心与独立第四类体系 V1.0（提案）

> 2026-11-12 用户最新纠正：**第四 XP 必须是与职业、身材、性格完全不同、拥有自身规则和收集池的独立体系**；将「种族」硬塞为第四 XP 的 V0.9 方案已被否决。以下仅保留原有确认的融合规则，把「异能/命印」作为新设计建议，尚待用户批准具体名称和内容。本文件是设计文档，不是已实装游戏。

## 1. 游戏已确认的融合逻辑

- 核心：**收集和合成 XP 词条**，一级角色 3 条 XP、二级 4 条 XP、三级 5 条 XP。
- 每次合成投入 **两张同阶人物 A/B + 一份对应等级的一次性融合材料**，A/B 在库存中消失，生成**完全不同的新人物 C**，绝非保留 A、A 吸收 B、或简单换装。
- 在合成界面展示全部材料人物的 XP，玩家主动选择。**同一类型的 XP 只能选择一项**，不能把同类型两种同时堆叠。
- 1+1 基础融合：选择最终 3 XP → 全新一级 C；若有第 4 类合法 XP → 全新二级 C。2+2 高级融合：4 XP → 全新二级 C；第 5 类合法 XP → 全新三级 C。**融合不必然升级**。
- 第三槽使用的**消耗式融合材料**与独立存在的**长期生效的全局遗物**是两套道具，不把融合材料赠送给角色，也不把真人扔入炼药锅。
- 融合完成的新 C 的 XP 属于本人，不依赖被消耗的材料持续存在；不因材料消失而降级。默认不允许无损拆回原 A/B（仍是当前设计建议）。

## 2. 基础三个 XP 与新第四 XP 必须分层

| XP 类型 | 角色提供什么 | 分类关系 |
|---|---|---|
| ① 职业 XP | 工作/战斗定位，如骑士、猎人、店员、魔女 | 一级随机或来自基础身份，可由 A/B 二选一 |
| ② 身材 XP | 娇小、标准、成熟丰满等人物体型 | 一级特征，可由 A/B 二选一 |
| ③ 性格 XP | 冷静、贪婪、活泼等行为倾向 | 一级随机生成，可由 A/B 二选一 |
| **④ 独立融合 XP** | **独有收集池与专属机制，不归属于前面三类** | **只有参与符合要求的融合，才可能出现在新二级 C 上** |
| ⑤ 尚未确定的新类别 | 不擅自定义，三级融合再扩展 | 三级才开启 |

**先前『第四 XP = 种族』的方案作废**。第四类不是把职业、体型、性格重排，也不是直接强制种族变异，更不是单纯伤害、闪避等战斗属性小加成。

### 第四 XP 独立体系的推荐方向（暂定名：异能 / 命印 XP）

- **独立来源**：由特定一次性融合材料决定该融合可选择的第 4 XP；有单独的收集、稀有度和效果库。普通基础重组材料不增加第四类，仍可以合成新一级 3 XP。
- **独立效果**：不决定职业、不决定身材、不决定性格、不改变种族的固定身份。建议每项在自动战斗中提供不同的规则效果：例如「回响」满足条件后再次触发一个效果；「共生」和队友共享指定收益；「逆转」满足条件时反转一次战斗状态；「分身」创造一次临时协同表现。以上均是**示例提案**，不是已经批准的正式技能。
- **独立排他**：第四类本身也是一个 XP 类型，**二级最多持有一种异能/命印 XP**。两个二级 A/B 再融合时，若各带一种不同异能，必须由玩家二选一，不能两种都保留。
- **独立美术**：可通过卡面标记、技能效果及新 C 的专属表现让它可识别；不必为了每种异能强制改变人物的自然种族、肤色或重做所有组织立绘。新 C 本身仍是不同于 A/B 的全新人物。

## 3. 种族、组织与 XP 分开，不动旧人物原画

- **种族**（人类、吸血鬼、恶魔等）是人物生命类型/出身设定，不等同第四 XP，也不由等级自动决定。旧的恶魔与吸血鬼一级小兵仍然可以保持原有非人外貌及角色档案，绝不改成人类或强制升二级；其参与融合后新 C 属于哪个种族的**具体规则待定**。
- **组织**（恶魔商店集团、绯月血族、骑士团、魔女工坊、马戏团、怪物猎人组织等）是所属势力/剧情归属，不等同种族或独立 XP。
- **职业**是人物的工作/战斗身份，是第一类 XP；同一职业并不限定种族或组织。
- 不更改已有三位恶魔职员带角尾巴、血族成员的原画/文件；不迁移这些已完成的角色到二级，也不新建『全部人类一级』美术任务。此前 V0.9 针对种族 XP 所提出的『一级必须全是人类』『旧非人图迁移二级』方案**现已废弃**。

## 4. 具体合成例子（仅示意）

- 一级 A：`职业·猎人 / 身材·娇小 / 性格·沉着`；一级 B：`职业·魔女 / 身材·标准 / 性格·活泼`。
- **只使用基础重组材料**：玩家各选职业、身材、性格一种，获得 3 XP 的新一级 C，仍符合 A/B 全新个体要求。
- **使用附带「回响」第四类候选的特殊融合材料**：从 A/B 各类别中选一个得到前三 XP，再获得 `异能·回响` 作为第四 XP，形成 4 XP 的新二级 C；材料一次性消耗，C 永久保留回响。
- 如果 A/B 已是二级且各有不同异能，新 C 只能保留**一项异能**；想获得第 5 XP，要经更高级的融合材料及未来另定的第五类 XP。

## 5. 未定问题，不可当成用户批准内容

1. 第四类的正式名称，独立类型池里到底包含哪些 XP：目前「异能/命印」仅为推荐方案。
2. 是否存在不参与战斗而专注外观、关系、收集价值的第四类 XP；要确保符合用户最终想要的 XP 收藏乐趣，不能擅自用普通数值技能代替。
3. 新 C 的种族、组织归属、外观/职业/体型/性格的生产方式；不能与 A/B 同一人，也不能自动同种族。
4. 第五 XP 的体系、融合材料名称/掉落、类型不足时处理、已定角色资产如何复用且不侵犯原设定。
