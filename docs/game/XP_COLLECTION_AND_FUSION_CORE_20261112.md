# 七人阵营小游戏｜XP 收集与融合核心规则 V0.1

> 2026-11-12 用户口头确认的核心规则。**本作以收集、选择和合成 XP 为主玩法**；不是普通升星游戏，人物卡为 XP 载体。此文件是策划规范，尚不意味着游戏运行时代码已完成。

## 一、已确认的 XP 槽位数量（正式决策）

| 人物等级 | 固定 XP 词条数量 | 来源 |
|---|---:|---|
| **一级（小兵）** | **3 条 XP** | 获得小兵时携带三条 XP 词条 |
| **二级（进阶人物）** | **4 条 XP** | 由融合材料中的 XP 选择继承 |
| **三级（高级人物）** | **5 条 XP** | 由融合材料中的 XP 选择继承 |

不允许因词条类型重复而越过该等级 XP 槽位上限；二级四条、三级五条不能变成随意叠加六条或八条。获取 XP、搭配 XP、在融合时优化 XP 组合是游戏的核心。

## 二、融合时 XP 的选择规则（正式决策）

1. **两名参与融合的人物卡的 XP 全部展示在同一个选择面板**，能看到每条 XP 的名称、所属类型及效果；由玩家选择最终继承的 XP。
2. **同类型的 XP 只能保留一条。** 如果 A 的「进攻：伤害提高」和 B 的「进攻：攻速提高」都属于进攻类型，必须在这两条之间选一条；不能同时保留，也不能让系统自行合并为一条或者随机替玩家选。
3. 不同类型 XP 不因类型而相斥；实际选择数量受目标等级槽位约束。
4. **一级 → 二级：** 两张一级小兵各携带 3 条 XP，候选最多 6 条，经同类型排重后，玩家**恰好选择 4 条不同类型的 XP**，生成一张拥有 4 条 XP 的二级人物。
5. **二级 → 三级：** 若采用两张同阶角色融合，两张二级人物各携带 4 条 XP，候选最多 8 条，经同类型排重后，玩家**恰好选择 5 条不同类型的 XP**，生成一张拥有 5 条 XP 的三级人物。**注意：两张二级融合的具体消耗配方尚待用户确认，此处为推荐而非已拍板事实。**
6. 必须保留每条 XP 来源，融合预览明确显示目标人物会有哪些 XP，不得只给随机结果。

### 例子

一级小兵 A：`攻击型·破甲`、`防御型·格挡`、`速度型·先手`。
一级小兵 B：`攻击型·连击`、`经济型·战利品`、`治疗型·回复`。
合成二级需要四条：攻击型的 `破甲/连击` **只能选其中一个**，剩下从防御、速度、经济、治疗类型里选三个，共四条。

## 三、尚未定案的边界问题（不能凭空视为已确认）

- **候选不同类型数不足时怎么办？** 例如两张一级合计只有 3 个不同类型 XP，便无法满足二级固定 4 条。建议将该组合标记为“缺少 1 类 XP”并提供可以补充一条新类型 XP 的机制（例如升级候选池或通用词条素材）；该补充机制是否使用道具、是否免费、能否直接改选材料，均待确认。**不要无声生成不足额 3 条的二级，也不要硬塞两个同类型 XP。**
- **二级和三级外观/职业：** 用户已确认有小兵职业、身材、随机性格；它们与 XP 是不同字段。主体与材料的职业/身材/性格如何影响最终人物，仍可讨论，不能自动等同 XP 类型。
- **XP 类型全集、每类具体词条、重掷/保护/补充道具、消耗材料数量、同阵营/跨阵营限制**：均未最终确定。

## 四、用户明确的其他小游戏边界

- 战斗全部由人物卡参与，自动攻击，最多七名上阵。
- 身材为萝莉型/少女型/成熟丰满型三种小兵独立美术人物；随机性格另算。人物卡上存在职业及 XP 等多个维度。
- 遗物和道具服务于 XP 构筑，可参考 Isaac/Brotato 的永久局内增益，但不应取代收集 XP 这一中心玩法。

## 五、正式设计原则

不要再把合成解释为“自动继承素材一个固定特长”、把 XP 当成单纯经验条、或把职业/性格/身材直接当成 XP 词条。不得更改已确认的 **3 / 4 / 5** XP 数量和**同类型只能选一条**规则，除非用户明确修订。
