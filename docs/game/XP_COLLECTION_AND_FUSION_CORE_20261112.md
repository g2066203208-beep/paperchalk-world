# 七人阵营小游戏｜炼药锅融合、XP 与遗物分级 V0.5

> 用户于 2026-11-12 最新确认：**炼药锅必须放入两张同等级人物卡 + 一件相应等级遗物。一级+一级+普通遗物可合成二级；二级+二级+更高级的遗物可合成三级。** 仅保存**设计规则**，未宣称游戏运行时已实现。本文件覆盖历史 V0.1–V0.3 中“不需要遗物开锅”“遗物是送给人物的礼物”等过时设计。

## 1. 主玩法是收集和合成 XP

- 每张一级小兵固定 **3 条 XP**；每张二级角色固定 **4 条 XP**；每张三级角色固定 **5 条 XP**。
- 合成时必须向玩家展示双方全部 XP，并由玩家**主动选择**继承哪些 XP。
- **同 XP 类型只能选一个**，例如两条进攻型词条二选一；不同类型可以组合，但总数不得超过对应等级。
- **合成不保证升级**。目标等级由最终合法 XP 条数决定，而不是单凭进行了融合动作决定。
- 人物职业、身材、随机性格和 XP 属于不同字段，不能把性格或体型充当 XP。
- 游戏最多七名人物上阵，自动攻击；核心是不断收集、交换和优化 XP 搭配。

## 2. 炼药锅：固定三个槽位

**人物 A（同等级） + 人物 B（同等级） + 遗物（符合要求等级） → 一张融合结果人物。**

- 必须有两张**同阶**人物。不能用一级加二级进行这套基础配方。
- **遗物是第三个必需投入槽，不是“送给人物的礼物”**。未放入合格遗物不能启动炼药锅。这修正了先前“没有遗物也能直接融合”的错误。
- 一次融合消耗两张人物的合并关系：**两个人物成为一个人物**，因此人物数量净减少一。可将一个指定为主体，另一个为素材，但相貌、职业、身材和随机性格的继承细节还需后续定稿。
- 用户先前倾向《以撒》式本局永久遗物，因此**设计建议**：投入锅中的遗物是可反复使用的非消耗催化物，融合后回到遗物库存继续生效；**用户尚未最终确认本具体归还规则**。不要把“放入槽位”自动解读成“必须消耗遗物”。
- 礼物系统（若后续另设）与此处炼药锅使用的**遗物**严格区分，不要再混写成给小兵送礼物。

## 3. 已确定的两层融合配方

| 配方 | 人物材料 | 第三个槽位 | 普通/未升级结果 | 满足新 XP 数量后的升级结果 |
|---|---|---|---|---|
| **一级配方** | **一级小兵 × 2** | **普通融合遗物 × 1** | 选 **3** 条不同类型 XP → **一级小兵** | 选 **4** 条不同类型 XP → **二级兵** |
| **二级配方** | **二级兵 × 2** | **更高级的融合遗物 × 1** | 选 **4** 条不同类型 XP → **二级兵** | 选 **5** 条不同类型 XP → **三级兵** |

- **高一级的遗物是三级融合准入条件**；普通遗物不能代替高级遗物完成二级兵的炼药锅配方。
- **人物来源、最终 XP 数量和遗物等级必须同时正确**；例如两名二级兵+高级遗物，不等于自动获得五个有效 XP；若只保留四个不同类型，仍合成二级兵。
- 三级兵再次融合或四级以上如何设计，尚未提出正式配方，不能擅自扩展。

## 4. 遗物如何帮助获得第四/第五条 XP（待细化）

已经确定：**普通遗物参与一级小兵融合，高级遗物参与二级兵融合**；用户此前指出遗物是第 4 XP 的关键，随后提出了分级炼药锅。

推荐但**尚待批准**的易懂方案：遗物充当对应阶的 **XP 继承许可 / 额外选择权**，不是作为一条固定 XP 直接附着角色：
- 两个一级小兵合计最多提供 6 个 XP 候选；普通遗物允许最终从候选中保留 4 条不同类型 XP。若只凑出或只选 3 条，则维持一级。
- 两个二级角色合计最多提供 8 个 XP 候选；高级遗物允许最终保留 5 条不同类型 XP。若只保留 4 条则维持二级。
- 遗物本身可有长期 Buff 或融合特殊效果，但**不自动等于某条 XP**。是否直接提供新 XP、允许重选类型、影响稀有度等尚未拍板。
- 玩家不能选两个同类型 XP 充数，不能凭空生成缺少的 XP，也不能在没有相应遗物时借用其他阶级配方。
- 若合法候选类型不足以填满同阶角色的基本 XP 数量，怎样处理待定；不要自动产生无效人物。

## 5. 记录/开发注意

- UI 必须先展示三个材料槽，再展示**同类型二选一的 XP 继承面板**与合成预览（含最终 XP 数量、等级、人物数量减少一、遗物状态）。
- **不要把遗物与礼物混为一谈**；遗物是否被消耗不因“投入”二字自动决定。
- 保留已批准的六个正式七人团及已有小兵资产；新第七组织仍为独立候选。角色艺术进度与合成逻辑进度不可混淆。
- 下轮需明确：遗物是不是永久可复用、礼物系统是否单独存在、遗物具体来源/掉落/品级与 XP 加成、主体外观/性格继承、三级角色实际定位。
