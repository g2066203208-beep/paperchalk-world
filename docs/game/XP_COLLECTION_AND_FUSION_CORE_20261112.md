# 七人阵营小游戏｜五种固定 XP：体型、性格、职业、种族、故事 V1.5

> 2026-11-12 最近两次用户纠正优先：**恰好五种固定 XP**；第四类**种族 XP**（猫娘、吸血鬼、恶魔等，同类型不能重复）已重新明确；**职业 XP 本身就是职业服装/装扮表现**，不得再额外发明「服装 XP」；**第五类确定采用「故事 XP」这一设计方向：描述人物由平凡走向传奇的关键经历，参与融合生成全新人物**；**全部故事 XP 由击败对应 Boss 掉落，每个 Boss 对应自己的故事头衔**；具体 Boss/头衔对应表和游戏效果待设计。原来文档把种族写成永久否决是过时信息，已废弃。本文件为策划说明，不代表已实现运行时。

## 世界观最高优先级：绝对架空、能量意识不是火、只有主角见到美少女（2026-11-12覆盖旧版）

**最新用户明确纠正：这个精神世界本来没有人、火以及任何人类式的物理、生活或社会概念。它们不会认为自己是“火苗”，因为它们根本没有火的概念。** 火苗形状、大小、颜色仅是游戏给玩家的**焰状UI视觉翻译**，不是本体客观外形、材料或本地自称。

- 【真实本体】可独立自识的精神结构/能量意识。它们通过相应、边界、变化和留痕理解自己与其他结构；并不靠人类眼耳、语言或社会关系生活。
- 【玩家火苗UI】2XP初始：①体型用焰状物大小表现；②性格用焰状物颜色表现。**只代表玩家能读懂的图像编码，它们本身没有“颜色就是性格”“我是一团火”的意识。**
- 【主角特异视界】只有主角将每个能量意识的XP组合感知为独一无二的美少女。她们既不客观拥有肉身/制服/猫耳/尖牙，也不会从职业XP获得后真正长成人类；2XP初始也已经可以有主角眼中的美少女人物投影。
- 【交流】能量意识向主角传递差异而不是讲中文；字幕是主角/玩家的翻译。它们问主角“你所识别的我与我自识有什么不同”，**不是“我们都是火焰、在你看来我是女孩吗”**。
- 【所有五XP的本体解释】①幅域（体型）、②应答倾向（性格）、③作用路径（职业服装）、④基本稳定律（种族）、⑤Boss战带来的结构事件（故事头衔）。**玩家看到的职业、种族、服装、故事称号都不等于本地存在人类社会。**
- 【融合】两个独立能量意识通过重组产生新第三个意识，旧A/B不再分别存在。并非真人人体融合；组合变化在主角眼中对应另一个独特美少女人像。
- **先读完整世界圣经**：[《无形回响》完全架空的能量世界、六大群体与六章主线](XP_ALIEN_ENERGY_WORLD_BIBLE_20261112.md)。旧版 [感知摘要](XP_ENERGY_ONTOLOGY_AND_PROTAGONIST_PERCEPTION_20261112.md) 已修正。六阵营的组织名、职业衣装与已有立绘都只是主角的译像，批准的美术资料全部原样保留。

**状态边界**：不存在真实火与人、主角独有美少女人像、五XP/2XP开局及对应Boss故事头衔等为用户明确规则；“差异结构、幅域/偏应/底律、六种共振生态、归同危机与六章主线”为原创世界背景补完提案，未视为全部逐项确认。

## 0. 最优先强制顺序（2026-11-12 用户最新明确）

**① 体型 → ② 性格 → ③ 职业（含职业服装） → ④ 种族 → ⑤ 故事（对应 Boss 掉落的头衔）。** 这五种是全游戏**唯一固定的五个 XP 体系**。一级恰好①②③，二级恰好①②③④，三级恰好①②③④⑤。同类型候选只能择一。角色组合的结果 key 也按此顺序编码，**每个不同的完整 XP 五元组必须对应不同的全新三级角色**；仅性格或故事不同也必须不同。其组合数量计算方法见 [XP 组合与唯一人物映射](XP_COMBINATORICS_20261112.md)。

## 一、已确认的核心方向

- 游戏主要玩法是**收集和合成 XP**，不是传统升星或纯战斗技能游戏。
- **整个游戏只允许固定五种 XP 类型，五种各占一个独立位置，不能从 28 类候选里自由选择五个宏类型。** **最初普通精神能量体拥有 2 条（①体型、②性格）**；一级职业小兵拥有 3 条（加③职业）、二级4条（加④种族）、三级5条（加⑤故事），即 **2/3/4/5 条 XP**。
- 前三种基础 XP 按固定顺序：**①体型、②随机性格、③职业／职业服装**。**职业以职业装扮和制服为外显表现**（如骑士甲胄、猎人古典长大衣、魔女服、护士服、商人制服）；“职业”和“服装”不是两个独立 XP 家族，不得拆出第六类型。性格系统已在 `docs/characters/FACTION_MINION_CHARACTER_IDENTITY_AND_PROMPT_RULES_V1_20261111.md` 明确：**基础小兵的性格词条在游戏中随机拥有，基础人物立绘不得预先画死性格表情**。此前对性格的详细约定必须沿用，未经核实不得用临时新列出的 63 项覆盖；现有规范未列出完整官方性格名录，需找到原始定稿再核对。
- **同类型 XP 只能选一个**：两个输入人物的候选词条向玩家展示，玩家在同类型候选中自己选一个，不叠加。
- **两个相同等级的人物 + 一个对应等级的融合材料 → 完全不同的新人物 C**。C 不继承 A 的人物身份或仅换装，原来 A、B 两张角色卡合并为一张新 C。
- **融合不必然升级**。最后 3 条 XP → 新一级；4 条 XP → 新二级；5 条 XP → 新三级。
- **二级需要两张一级 + 基础阶材料**；**三级需要两张二级 + 更高级材料**。第三槽是融合材料，不代表世界观中真的有炼药锅。
- **消耗型融合材料**与《以撒》式的**持久增益遗物**分属不同系统。为避免无限抓小兵升级，融合媒介按有限消耗品方向规划。合成后第四/第五 XP 留在新角色身上，不依赖被消耗材料持续挂载。
- 游戏最多七位人物出场，自动攻击。

## 二、目前确认的固定五类结构（2026-11-12 最新）

| 固定 XP 类型 | 来源与表现 |
|---|---|
| **① 体型 XP** | 已确认的基础人物三种体型：娇小、少女型、成熟丰满；是第一 XP |
| **② 性格 XP** | 沿用已定随机性格系统；基础立绘不能画死性格；是第二 XP |
| **③ 职业 XP（包含职业服装）** | 骑士、猎人、魔女、商人等，职业本身决定制服外观；是第三 XP，不能另设服装 XP |
| **④ 种族 XP** | 猫娘、吸血鬼、恶魔、人类等，种族候选同类型互斥；是第四 XP |
| **⑤ 故事 XP（Boss 头衔）** | 击败对应 Boss 掉落故事头衔，融合成为全新三级人物；是第五 XP |

- **五种是整个游戏固定的五大类型**，而非“28类里开放选5个”。每类最多占一个 XP 槽。
- **职业服装**为职业 XP 的同一体系：衣服样式表达职业，不再单独提出「服装 XP」「穿搭 XP」作为第五条。
- **种族属于第四 XP**。用户在否决“所有一级必须人类”这一强行美术迁移以后，**重新明确种族 XP 确实必须有**；种族词条互斥。不能继续援引旧版“第四=种族被永久否决”的说明。
- **历史素材不动**：现有恶魔、血族基层角色的原画已带非人外貌；“一级 3 XP 与已有非人类外观、种族何时成为正式可选第4XP”存在尚未定案的规则衔接问题。**不能为了做第四槽擅自让已画的小兵全部变人类或私下迁移为二级。** 是否将原生种族作为未占槽的基础身份、二级才开放种族选择，仍要后续设计。
- **第五种已由用户提出「故事 XP」方向**（「小兵到将军就缺一段故事」），不能变成简单的职业服装、发型、背景经历、羁绊或额外数值。第五类词条应代表一段有起因、过程、结果的标志性事迹，直接参与创造三级新角色。
 
## 三、种族 / 阵营 / 美术保护

- **种族 XP 是已明确的第四 XP 类型**，必须与组织（骑士团、恶魔商店集团、绯月血族等）区别：组织是归属势力，种族是生命类型；如何兼容现有一级血族/恶魔立绘的默认种族与四号槽须独立定案。
- GitHub 已有恶魔职员的角和尾巴、血族的小兵原画和原组织七人组全部原样保留；不强制人类化，不迁移到二级，不擅自重画、覆盖或改名。
- 职业/身材/性格在融合成新人物时选择；新人物必须是与两名素材完全不同的独立人物。融合生成新人物的世界观包装及动态立绘制作方案仍待定。

## 四、仍待进一步设计的内容

## 六、第五 XP 的玩法方向校正（2026-11-12，未拍板）

**用户已明确否定「第五 XP = 发型」**：发型只是人物美术细节，既无独立系统价值，也不能支撑七人自动战斗的阵容策略。发色/发长/发型保留为美术参数，不额外占第五 XP；「职业 XP」已经包含职业服装，不得重复拆服装 XP。

### 新提案：关系／羁绊 XP（仅供评审，绝非正式确认）

- 区别于职业（战斗职责/职业服装）、身材（体态）、性格（个人行为）、种族（生命物种）：**羁绊 XP 描述角色与另一名具体人物之间的关系，并有独立的关系触发与七人组队联动**。例如师徒、搭档、主仆、宿敌、姐妹、青梅竹马。
- 每个三级人物第五槽只能持有**一种关系类型 XP**；关系对象通过选定另一张上阵角色绑定，不能仅靠人物本人出现就获得全部联动。不强制被绑定对象也是三级，因此前期小兵仍有组队价值。
- 玩法示例：师徒=师父帮助徒弟成长；搭档=共同攻击触发追击；主仆=保护与反向加成；宿敌=双方互相竞争获得成长；姐妹=相互援护；青梅竹马=专门协同效果。这些只是例子，需确定触发条件、数值平衡、无目标时的可用性、关系与剧情身份是否冲突。
- **风险**：关系需要第二名具体角色；单卡的第五 XP 不能没有目标就永久无效。若目标被融合/出售/离队，关系应可按受控规则重新绑定，绝不能复制卡牌或无限刷加成。
- 玩家尚未批准「羁绊 XP」为第五类型，**第五仍标记为待定**；不要因为写入这个候选方向就直接做正式卡库/美术。

## 七、2026-11-12 最新用户纠正：第五 XP 必须共同生成全新人物（硬性要求）

- **第五 XP 不能只是给现有二级角色附加一个技能、装备图标、发型装饰、关系 Buff 或身世背景。** 用户明确强调「第五个 XP 也是加上变成新人物」。
- 融合**两名二级人物 A、B + 对应的高级消耗式融合材料**后，A、B 两个身份退出；得到**真正独立、身份和立绘均与 A、B 不同的三级角色 C**。C 不是 A 的升级装、不是把 B 的能力贴在 A 身上、也不是叠加光效换皮。
- 第五 XP 与先前四种（体型、随机性格、职业及职业服装、种族）**并列参与 C 的角色生成规则**；它必须有自己的整套互斥内容，影响新人物的设计和可玩性，并且只能选其中一个。
- **旧提案「发型、羁绊、身世作为第五 XP」均被否决。** 但本轮用户提出的**「故事 XP」与被否决的「身世 XP」不同**：身世是预先写好的出身背景；故事是一段从基层走向英雄/将军的重大**成长事迹或转折**，必须成为三级全新人物身份与玩法的生成条件。用户已提出并认可故事方向；具体故事列表仍需审核。

## 八、2026-11-12 最新决定：第五种固定 XP = 故事

**用户原意：「故事吧，小兵到将军就缺一段故事」。** 与之前被否决的「身世」不同：身世说明她**过去出生在哪里、原本是什么身份**；故事说明角色经历**什么关键事件、做出何种选择、建立什么事迹**，才有资格从普通人物成为高阶传奇人物。

### 五类的终版框架（类型确定；具体词条/数值不代表全部定案）

| 槽位 | XP 类型 | 回答的问题 |
|---|---|---|
| 1 | 体型 | 她是什么体型？ |
| 2 | 性格（随机；旧规范） | 她什么个性？ |
| 3 | 职业／职业服装 | 她做什么、穿什么职业制服？ |
| 4 | 种族（互斥） | 她是什么生命？猫娘/吸血鬼/恶魔等只能留一个 |
| **5** | **故事（互斥）** | **她经历了怎样的关键事迹，成为怎样的传奇人物？** |

### 「故事 XP」设计要求（具体例子待定）

- 故事 XP 必须是**独立的叙事/成长体系**：**唯一获取来源为击败与其对应的 Boss 获得其专属故事头衔**。不得通过普通敌人、普通事件或商店直接获取第五 XP。**故事材料与消耗式融合材料是否是同一件物品，仍待设计，不能擅自重复收费。**
- 故事词条不是简单「失忆者」「贵族出身」等身世标签，也不是给二级人物加一个被动 Buff；必须让**A+B+高级融合材料→全新三级 C**时，C 的**人物身份、英雄事迹、造型演出和自动战斗定位**都受故事影响。
- 一级→二级：3 XP 基础人物经融合得 4 XP（新增种族）；二级→三级：4 XP 人物融合得 5 XP（新增故事），必须生成**全新第三个人物**，不是升级原来的 A 或 B。
- 五个固定类型各只能有一个正式词条。两名三级角色若将来支持再融合，双方不同的故事词条也必须**二选一**；不能无上限叠故事。
- 故事的示意方向（**非定案词库**）：`百战成名`（从基层到将军的战功）、`绝境凯旋`（在绝境中率队归来）、`弑王`（推翻强敌统治）、`救城`（守护城市而扬名）、`堕落转折`（经历抉择而改变命运）。故事要兼容各职业、各族，不能让每个职业都变成「将军」；不同故事对应可玩差异但不只是数值奖励。
- **故事 XP 的取得方式已明确为「击败对应 Boss → 获得对应故事头衔」**；具体 Boss 清单、头衔名称、掉落几率、可重复刷取、怎样绑定生成角色、具体战斗效果尚未定稿，不得把此处示例写成已批准的掉落表。

**注意**：已有官方小兵/七人团原画全部保留，不强制给旧立绘换性格、改种族、覆盖图片。此项仅为策划记录，不代表运行时实现。

## 九、2026-11-12 用户追加硬规则：全部第五 XP 是对应 Boss 的专属掉落

**用户确认：『xp五都是boss掉落，打对应的boss得到对应的故事头衔』。这一条覆盖历史文档中“可从随机事件/普通关卡领取故事 XP”的旧猜想。**

- 第五个 XP 的分类固定为 **故事 XP / 故事头衔**。**所有故事 XP 的直接来源必须是击败它所对应的 Boss**；每种故事头衔需映射到明确的 Boss，不能把它放入普通掉落、商店礼包或随意的随机事件。
- 玩家先击败对应 Boss，获得其 **专属故事头衔** 作为可收集物，再用于**两名二级人物融合成全新三级人物 C**。C 获得故事 XP 后是独立新人物，故事会影响 C 的最终身份、角色美术/演出与可玩效果，而不是给旧人物多挂一枚成就徽章。
- **推荐且尚待确认的三槽简化法**：将 Boss 掉落的故事头衔本身定义为高级融合材料，作为第三槽一次性投入；配方为 `二级人物 A + 二级人物 B + Boss 故事头衔 → 全新三级人物 C（第五 XP = 该头衔）`。这样不需要先投入高级媒介再额外消耗第四件头衔。该简化仅是策划建议，具体耗材结算/库存/UI 仍需用户批准。
- **示例映射（均为假设，不得视为已有正式 Boss）**：`血月女王 → 破月者`、`深海巨兽 → 深渊征服者`、`不死君王 → 弑王者`、`瘟疫之主 → 疫灾终结者`、`堕落圣骑士 → 圣堂审判者`。
- **尚未确认的规则**：击败 Boss 后是否必掉、同 Boss 是否允许重复挑战刷取头衔、首次击杀是否特殊、头衔是否绑定阵营、三槽高级融合材料是否即为故事头衔。没有确认前不要写成既成事实。
- **既有四类不变**：①体型，②随机性格，③职业/职业服装，④种族。全游戏固定五种 XP，每种最多一个；第五也是故事互斥，不能双持两个 Boss 头衔。

**设计目标：** 第五 XP 是有明确战斗挑战出处的成名故事，只有经历打败 Boss 的这一重大事件，才能为新三级角色提供对应的传奇头衔。
