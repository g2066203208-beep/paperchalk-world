# 七人阵营小游戏｜XP 收集、融合与永久遗物 V0.2

> 2026-11-12 由用户连续确认的规则整理；这是策划规范，不代表已经实现运行时代码。**最新纠错：道具是获得后持续生效的遗物，绝不能在融合时当作消耗材料。** 旧 V0.1 把道具写成“消耗 1 件”的句子已废弃。

## 1. 已确认的根本玩法

- **游戏就是收集、选择与合成 XP。** 角色卡是 XP 的载体，而不是泛用星级提升材料。
- 一级小兵固定 **3 条 XP**；二级角色固定 **4 条 XP**；三级角色固定 **5 条 XP**。
- 合成时双方人物全部 XP 都在选择面板展示。**相同 XP 类型的候选只能选一个**，由玩家自行决定保留哪一条；不同类型允许组合，但总量不能超过目标等级数量。
- 职业、身材、随机性格是角色自身属性，不能当作 XP 词条。上阵最多七张人物卡、自动攻击。
- **道具是类似《以撒》遗物的持续加成物品：获得后留在遗物栏，持续起效；融合、升级、触发增益都不消耗、不销毁、不从物品栏移除它。** 除非以后用户明确要求，否则不引入“消耗一件道具才能合成”的设计。

## 2. 永久遗物与“额外 1 条 XP”的关系

用户提出“道具是第四条 XP 的关键”，并再次明确道具**不消耗，而是遗物式永久加成**。因此遗物的作用应是**长期提供 XP 构筑方向/融合加成**，不是每次要花掉一件材料。

**供下一轮确认的首选实现方案（尚未视为用户最终确认的详细配方）：**

1. **一级→二级：** 两张一级各携带 3 XP（最多 6 个候选），玩家先选 3 条不同类型；**持有的遗物长期提供额外第 4 条 XP 的候选或融合赋予效果**，使二级达到固定 4 XP。无论融合多少次，遗物保留并持续生效。
2. **二级→三级：** 从融合材料选择 4 条不同类型 XP；遗物长期提供第 5 条 XP 候选或赋予效果，生成固定 5 XP。更高等级的具体素材数量及其他限制尚未最终确定。
3. 遗物所影响的 XP **同样不能与已选词条同类型并存**。必须改选其他词条或选择其他遗物效果；绝不能绕开“相同类型只能选一个”。
4. 遗物自身作为**常驻全局加成**与角色 XP 的融合继承要明确分层：永久遗物留在局内收藏，不计作角色的可消耗材料；如果某遗物赋予某角色一条 XP，这条 XP 是角色融合结果，遗物本身仍保留。
5. 需要设计上限与平衡：同一遗物反复赋予 XP 是否需要次数限制、稀有度约束、每场只生效若干次等，目前**均未拍板**。不得擅自声称任何一项已定。

## 3. 示例（用于说明遗物保留，非已定道具库）

一级 A：`进攻·破甲`、`防御·格挡`、`速度·先手`。
一级 B：`进攻·连击`、`经济·战利品`、`恢复·回复`。
玩家从两张小兵里选三条不同类型：`进攻·破甲`、`防御·格挡`、`经济·战利品`。
玩家已经**拥有**遗物「染血戒指」（候选设计：持续提供 `吸血·生命汲取` XP 融合选项），使最终二级得到第四条 `吸血·生命汲取`。**戒指继续留在玩家遗物栏，下一次融合仍可根据遗物规则受益**。没有“消耗戒指”动作。

## 4. 尚待继续设计的问题

- 遗物如何提供第四条 XP：直接赋予固定词条、增加一个候选池、允许另选一条材料 XP、升级/重选词条，这些是不同玩法设计；当前先保留“遗物长期影响融合”的方向，不把任何一种具体实现伪装为确认事项。
- 如果没有提供可用新 XP 类型的遗物，是否允许玩家直接从两名小兵的六条中选四条，或者必须先拿到遗物才能升二级，**仍待决定**。不得自动禁止融合，也不得自动消耗物品。
- 两人类型太重复、无法凑足二级四条或三级五条时应如何补足；不同阵营是否混合、职业与体型继承、个性随机词条处理、XP 类型池、三级融合配方、永久遗物上限与叠加规则，仍待明确。

## 5. 禁止再次犯的错误

- 禁止再写“每次融合**消耗** 1 个带 XP 的道具”。这句话与用户明确要求矛盾。
- 禁止未经确认写死“从人物选 3、道具必须给 1”的唯一强制配方。
- 禁止把遗物永久局内加成与人物 XP 槽数合并记账；二级仍 4 条、三级仍 5 条，类别去重仍是硬规则。
- 后续若修改策划，本文件必须按用户最新指示同步修订，不能拿历史被覆盖的版本当作最终结论。
