# 七人阵营小游戏｜XP 收集、自由融合、等级判定与永久遗物 V0.3

> 2026-11-12 最新用户确认：**融合不等于升级。两名小兵即使只有 3 条最终 XP，也能够正常融合，产出仍是一级小兵。只有取得第 4 条有效 XP，融合结果才是二级角色。** 这项最新确认覆盖 V0.1/V0.2 中任何“没凑齐 4 XP 就禁止融合 / 每次融合必然升二级”的假设。本文件是策划规范，**未宣称已完成游戏运行时实现**。

## 1. 已确认的玩法核心

- 本作主要玩法：**收集人物携带的 XP → 两个人物卡相互融合 → 玩家选择继承的 XP → 不断优化 XP 搭配和数量**。人物是 XP 词条的载体，不是单纯星级材料。
- **一级小兵 = 3 条 XP；二级角色 = 4 条 XP；三级角色 = 5 条 XP**。成品等级由**最终选定且合法生效的 XP 数量**决定，而不是“融合了几次”或“投入了两张卡”。
- 融合时同时展示两张材料人物拥有的全部 XP，**玩家主动选择**保留哪些。**相同类型 XP 只能保留一个；不同类型可以组合。** 同类型不能叠两个，也不能由系统替玩家随机挑选。
- 小兵的职业、身材与随机性格仍是角色自身属性，不等同 XP 类型；它们对融合后身份/外观/行为的具体影响尚待细化。
- 自动攻击，最多七张人物卡上阵。**XP 收集合成**是主线玩法，遗物系统服务这一目标。

## 2. 融合不必升阶（最新确定）

| 融合后选择的有效 XP | 角色阶级 | 明确要求 |
|---:|---|---|
| **3 条** | **一级小兵** | 两个小兵即使未能获得第 4 条 XP 仍**允许融合**，得到优化过 XP 搭配的一个新小兵 |
| **4 条** | **二级角色** | 必须确实得到第 4 条合法 XP，才升级为二级 |
| **5 条** | **三级角色** | 必须确实得到第 5 条合法 XP，才升级为三级 |

**绝对禁止**：输入两个一级小兵就无条件升二级；拿三条 XP 就标为二级；为了升级自动复制同类型 XP；没有第 4 条时阻止玩家进行正常的“三词条小兵融合”。

### 横向融合：仍是小兵

- 小兵 A 的 XP：`攻击·破甲`、`防御·格挡`、`速度·先手`。
- 小兵 B 的 XP：`攻击·连击`、`恢复·回复`、`经济·战利品`。
- 玩家从双方六条候选中选出 `攻击·连击`、`恢复·回复`、`经济·战利品` 等**三条不同类型**。
- **结果仍然是一级小兵**，但已通过融合完成一次 XP 配装优化。这就是即使暂时拿不到第四条 XP，玩家依旧值得融合的原因。

### 纵向融合：升到二级

- 上面两张小兵融合时，**如果合成最终可合法保留四条不同类型的 XP**，结果才成为二级角色。
- 第四条 XP 如何获得，可能受**已持有的永久遗物**加成影响。需要继续设计具体来源/限制，不能仅凭合成动作“凭空加 1”。
- 三级同理：需要最终 **5 条合法 XP**，不能只因两个二级人物被投入融合就自动进阶。具体三级材料配方未定。

## 3. 遗物（用户确认不可消耗）

- 道具是类似《以撒》的**获得后本局持续生效的永久 Buff 遗物**，不是融合消耗品。持有它，融合之后它仍保留，后续可持续发挥效果。
- 遗物很可能是第四条、第五条 XP 得以取得的重要机制，但**不把“某遗物消耗掉，生成第 4 XP”写成规则**。
- **遗物的属性与人物 XP 必须区分**：遗物本身不销毁。此前“所有遗物都只留在全局栏”不是最终决定：用户现在提出更具体的**赠礼式角色持有**方案，见下一节。是否全部道具都赠予角色、是否另有全局遗物，尚待确认。
- **合法性检查永远一致**：若某遗物赋予的 XP 与选中 XP 属于同一类型，不能同时保留；不得绕开“同类型最多一个”的规则。
- 即便没有额外词条来源，也允许**三词条小兵横向融合**。任何遗物不得变成基础融合的强制消耗物。

## 4. 仍待设计，不能冒充用户已拍板

1. 第四/第五 XP 的准确获取方式：遗物直接长期提供额外 XP 还是开放额外继承选择，以及没有遗物时能否从双方候选中选四条；用户目前确定的是**没有第四条仍可融合，但只能是小兵**。
2. 不同阶角色可以互相融合的配方、身份/形象由谁继承、职业/身材/随机性格如何保留。
3. 如果一组候选只有少于三种 XP 类型怎么办；特殊事件、洗词条、XP 类型池、道具稀有度、遗物叠加限制以及局内局外永久性的边界。

## 5. 项目执行约束

- 在 UI 显示合成后**最终拥有的 XP 数量、类别与对应阶级**，并允许玩家先预览再确认；不得把融合按钮默认写成“升级”。
- 旧版关于“至少四条才可以融合”“消耗道具给第 4 条”或“每次融合一定升阶”的说法全部作废。
- 本规则的最新更新优先于旧设计与旧摘要；程序实装必须另行开发、测试，不要用文档登记冒充游戏功能已经完成。


## 6. 新讨论｜将遗物作为赠送给小兵的永久礼物（2026-11-12，方案待用户确认）

**用户提出的最新方向**：融合时将遗物像礼物一样送给小兵，合成后的二级人物继续随身带着礼物，并持续享受效果；用户正在比较这种**非消耗附着**和**一次性消耗材料**两种方案。用户此前已明确喜欢永久遗物，所以推荐选择前者，但**以下具体行为属于设计建议，不得假称全已确认**。

### 推荐方案：持有式赠礼，非消耗
1. 道具是**独立且唯一的礼物实例**；送给角色后出现在角色卡的「礼物」栏，拥有者持续获得效果。融合并不摧毁礼物。
2. 两个小兵融合时，角色 XP 由玩家按「同类型只选一个」从双方挑选；**礼物可以提供额外一条有效 XP**，使最后达到 **4 XP → 二级角色**。不送礼物仍可融合，只有 **3 XP → 一级小兵**。
3. 角色晋级后该礼物**跟着新角色走**，持续有效。原材料角色被合成时，礼物所有权只能转移到**一个**结果角色，**不能凭空复制到多个角色**。
4. 融合双方都带有礼物时，必须在结果预览里处理：可保留的礼物转移到新角色，超出容量的礼物安全退回仓库，**不自动销毁也不复制**。
5. **XP 类别排他仍生效**：礼物若提供「攻击类型」 XP，人物已选的攻击 XP 必须二选一或者换其他类型，不能因为礼物而同时带两条攻击类型。
6. 建议 UI 拆为「人物继承 XP」和「人物持有的礼物 XP/常驻效果」两种来源，同时在卡面计入真正生效的**最终 XP 总数**，避免礼物效果与人物属性混淆。

### 第三级角色的后续方向（未确认）
- 可以考虑让三级人物持有**两件不同礼物**，在角色自身三条 XP 基础上实现 **3+2=5 XP**；也可以另设计更高阶的礼物或第五 XP 来源。
- 赠礼能否自由收回/更换、换下后是否会导致等级与 XP 槽数重新计算，礼物栏容量及叠加限制都待用户决定。推荐在任何移除/替换操作前展示预览，并保留礼物实例、禁止数值与物品复制。
- 如无足够不同类型，仍可只得到三词条小兵；不应拿重复 XP 伪造升级条件。

### 与一次性消耗式的取舍
- **一次性消耗**会使珍贵遗物失去长期收藏与角色养成价值，不符合此前的永久遗物意图。
- **角色携带式永久礼物**让“找到一份礼物、挑适合的角色送出、融合后形成专属构筑”成为中长期收集动力。推荐以它作为下一版设计的默认方向，等用户确认再把所有细节标记为正式机制。


## 7. 赠礼是否立刻升阶？（2026-11-12 讨论中的明确推荐）

**推荐：直接给一级小兵送礼物，不使其自动升级二级。送礼 ≠ 融合 ≠ 晋阶。** 此项是对用户提出的“直接送礼要不要升级”给出的策划建议，待用户最终拍板。

- **送礼当下：** 小兵保持一级，角色自带的正式 XP 仍为 3 条；礼物被该角色持有，**礼物的持续 Buff 即刻生效**。若礼物有 XP 加成，这条尚属于**可在后续融合中启用的候选 XP**，未经过融合不能算作已正式继承的第四条人物 XP。
- **普通融合：** 两个小兵的词条供玩家选择；当最终只有 3 个有效、不同类型的正式 XP，融合结果仍是一级小兵。无第四条 XP 时不能禁止融合。
- **赠礼进阶融合：** 已赠送给参与融合小兵的礼物，可以在融合时提供一条合法、不同类型的额外 XP 候选；玩家从材料中挑选继承的 XP，再利用该礼物满足第 4 条，最终形成二级人物。礼物随结果角色继续携带，持续生效且不消耗、不复制。
- **禁止自动升级：** 直接给一个小兵送两件或更多礼物，也绝不能绕过融合自动从一级升级到二级或三级。
- **数值显示必须区别：** `人物正式 XP 3/3`、`已携带礼物`、`礼物提供的待融合 XP 候选`，避免卡面显示“四 XP 小兵”与按 XP 数量判定阶级冲突。
- **后续需要确定：** 拆下礼物会不会影响已经融合形成的角色正式 XP？以及三级第五条 XP 来源、礼物可携带数量、哪些礼物自带 XP。这些尚未定案，不能自行断言。
