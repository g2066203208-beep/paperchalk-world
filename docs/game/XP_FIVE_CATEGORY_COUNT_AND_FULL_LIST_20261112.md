## 数学只能保留公式

设体型数量B=3，性格P、职业J、种族R、Boss故事头衔S均需正式确定：

- 初始2XP：3×P
- 一级3XP：3×P×J
- 二级4XP：3×P×J×R
- 三级5XP：3×P×J×R×S

**真实总数目前不能确定**。不同五种XP完整组合必须生成不同第三意识和主角独有的美少女人物视像。由于初始是2XP精神能量体，火苗只为UI视觉比喻，不是本地生命真实自称。

## 不得再混淆的旧研究草稿

- 旧研究 `XP_TAG_CANDIDATES_20261112.json` 有62个职业候选、63个性格候选、33个种族候选；它们全部 `approved:false`，只是网上整理的原始素材池，不能冒充游戏定稿。
- 旧世界圣经提过6种Boss与头衔，是写故事的示范而不是用户拍板的Boss掉落数量。
- **不能把「七人团7名成员」「已有7个阵营方向」「职业XP 7个」当同一个概念。**

下次统计必须逐条写出词条名称、批准来源和是否已经进游戏，只有通过这项核验才允许计算确定的组合数。
