## 本次实装

- 纯白/灰无材质原型、无金币贴图、无金属高光、无伪造反光星芒；机台、出币口、托盘和金币都是可由代码控制的白模几何。
- 按钮触发旋转，再进入强力、错峰、收尾放缓的机械出币；12/48/76 规模对照。
- 每枚金币从**机台实际出币口**生成，获得独立线速度、翻面角度、旋转速度、半径、质量和弹性。
- 固定 `1/120s` 物理时间步、`seed` 可重演，`seek(ms)` 可跳转固定时标，暂停、逐步前进、慢放、重复。
- 2D circle-based contact proxy（侧面投影刚体代理）：接币盘底面和两侧边界、金币-金币广相网格碰撞、七次位置校正、法向冲量、摩擦、弹跳衰减与 sleep/wake，形成实际互相支撑的**二维堆叠**。
- 界面内显示实际已吐出、金币互撞、托盘/墙碰撞、睡眠数、仿真时钟；手机竖屏还提供同一画面的金币堆局部放大窗口。
- 当前白模的金币翻转宽度是二维圆片投影，不是经三维刚体求解的真实薄硬币姿态；后续如果需要三维叠放、倾斜接触、滚边、厚度和相互支撑，应升级为 3D 刚体，不能谎称现阶段为三维硬币物理。
