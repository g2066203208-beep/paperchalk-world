## 给代码实现者的直接施工 Prompt
你是本仓库的 Web 游戏程序员，不是画图模型。直接交付可玩白膜，禁止用 AI 绘画代替产品，禁止输出只看得见不能点击的纯截图，禁止改变原始 Anima 人物立绘和已获批卡背。
1. **路由接管**：原 `site/card-battle/character-card-machine.html`（已托管）变成新战斗白膜主入口，原抽卡机完整备份在 `character-card-machine-legacy.html`；`site/card-battle/index.html` 和原主菜单两个战斗入口进入新页面。不要删原 3D 抽卡机源码和贴图。
2. **固定牌桌**：画面上排敌方 **7 个可见、固定、等宽卡位**；下排我方 **7 个可见、固定、等宽卡位**。敌我直接正对，中间薄状态/目标提示区，黑杰克牌桌式阅读秩序。未部署位是真空槽，绝对不是乱画的假人物。人像不用 3D 人物模型，直接使用仓库里已上传的真实 704×1024 Anima 人物原画。
3. **四层功能区**（从上至下）：顶部紧凑状态栏；敌方7槽；中间指向/目标/战报；我方7槽；下部备用人物实体卡、已部署角色各自可点击牌堆、行动手牌区。不要把七人物槽误做成7张技能手牌，也不要插入场景花草遮挡。
4. **人物卡是“卡组开关”**：候补人物卡先不可用牌组；玩家点击或拖动候补人物牌→选择我方空槽→部署该角色→激活属于该角色的独立行动牌堆；部署前不能抽对应角色行动卡。
5. **抽牌**：默认开局行动手牌 0，回合开始不自动抽；只允许从**已部署人物**的独立牌堆手动抽牌，所有人物共用最多10张手牌。未部署角色没有可摸的行动牌。每张行动卡要携带 ownerId，跨人物不串组。
6. **定向出牌**：选择行动卡→点击我方或敌方某张已部署的人物卡→预览合法目标与效果→应用伤害/治疗/护盾/状态。游戏规则必须允许对友方造成伤害或治疗敌方等自由选敌我目标（按卡片定义）；非目标/空位不可消耗卡牌。支持点击两步操作和触摸拖放两个输入渠道；使用同一套结算逻辑。
7. **回合控制**：资源消耗、人物 HP/盾牌数字实时变化；敌方结束回合执行可见反馈；支持重开，胜负结果可见，非法操作给短消息而非静默无效。不要显示虚假的已完成大型关卡或概率系统。
8. **美术白膜**：只做程序化深灰/酒红/暖灰 UI、清晰细边纸质卡槽、真实人物卡、已批准通用卡背作为未翻开位/牌堆背。禁止金属粗边、塑料光滑大框、随机人物、绝大多数 UI 的 AI 静态背景，保留后续替换素材的层次/尺寸位置。
9. **适配**：桌面 1440×900、手机竖屏 390×844、手机横屏 844×390。七张位置一眼可辨；小屏点/触摸操作、滚动手牌及角色细节放大预览，不允许布局被屏幕边界裁切。原画严格保持比例，不能把704×1024角色挤压成正方形。
10. **验收与留档**：真实源码→GitHub Pages托管→Node状态机测试与 Chromium实际点击/拖动/截图→将结果写入仓库文档。没有跑过测试就明确写未验收，不允许把模拟构图伪称成游戏实际截图。

## 技术和范围约束
- 用已有 `site/data/art/seven-card-groups.v1.json` 查真实组织/原画路径：白膜默认己方“奇想马戏团”7角色，对方“绯月血族”7角色，页面可后续加队伍选择；原画路径由 manifest 正确映射到 GitHub Pages 项目子路径。
- 首关为了可读性只在敌方7位置上预置3个敌人，其余4槽真实空着；后续可拓展为全7人或分波登场。七个卡槽始终存在，不等于必须开局14人全部填满。
- 白膜独立于旧森林16×6九宫格对战实验，不篡改旧引擎或已存人物。此处是新“Black Jacket对向7位”玩法原型，须标注是新白膜，不伪称旧专业卡组已经自动迁移。
- 纯规则层、UI渲染适配、CSS布局三者分离：避免交互逻辑硬编码在人像或背景样式里。任何要调整美术的任务都不应重写卡组状态机。
- 这份是可实施的**代码施工规范**，绝不是 Anima Prompt，**无尺寸让模型画UI、无 LoRA、无负面画图提示**。

## 验收必测步骤
A. 打开原老虎机托管URL直接出现新七对七空位白膜，原老虎机只有历史存档URL。
B. 正常情况敌方7槽可数，玩家7槽可数；候补有7张真实图片；没有假人物占位。
C. 开局行动手牌0、未部署角色牌堆不可抽；打出团长到我方某空槽后出现团长的独立牌堆。
D. 点击团长牌堆手动摸一张行动卡，选中行动卡后点敌方合法单位产生伤害；再试己方目标使其发生对应效果。
E. 非法目标不消耗手牌；最多10手牌；结束回合不自动摸牌；回合变化时卡组归属和HP/盾牌保存。
F. 手机竖屏与横屏实际显示14个固定位置、触控可操作，不仅是缩放桌面截图。
