# XP 世界观核心规则｜它们并非火焰，也并非人（2026-11-12 V2.0）

> **此文件已按用户“完全架空、不要用人的思维、它们没有火的概念”重新编写。** 请优先阅读完整世界观圣经：[《无形回响》——不以人类世界为原型的能量世界观、六大阵营与六章主线](XP_ALIEN_ENERGY_WORLD_BIBLE_20261112.md)。原 V1 关于“它们认为自己是火焰”“它们知道人类、女孩、身体”的写法全部失效。这里是硬规则摘要，完整设定以 V1.0 圣经为准。

## 1. 能量体在本体层是什么

- 全架空的精神结构世界。这里没有人类文明，没有真实的火、猫、人类、血、服装、职业、种族国度、父母、婚姻、市场、士兵或人类的空间时间概念。
- 真正的角色是有自我持续性的差异结构/能量意识体；不等于火元素、幽灵、人死后的灵魂、物理肉体。它们不具有“火是什么”的原生概念。
- **它们感知自己与其他个体的方法**是结构、边界、相应、失配、持续、留痕和变化。不通过人类式视觉、听觉、声带和语言交流；对话以给玩家阅读的字幕译文呈现。
- 它们不会平白说“我们都是小火苗”“我是不是女孩”“我穿的是什么”“我是人/猫娘/吸血鬼”。也不会自然拥有性别、血统、商店、骑士团这样的社会认知。

## 2. 二种画面译像，均不等于客观本体

- **玩家观察用的焰状能量图**：用火苗形状、大小、颜色把不可见结构可视化。①体型 XP 对应焰状物大小，②性格 XP 对应焰状物颜色；具体颜色→性格映射尚待确认。**这是画面设计，不代表“它们知道自己是火”**。
- **只有主角的美少女视界**：角色的五 XP 属性被主角感知为独特的美少女、职业服装和幻想种族形象。这并非能量体在真实世界里长出人形、变成人、被其他生命看见少女。
- 原有全部小兵和七人团美少女原画是主角独有的角色译像，不覆盖、不移位、不删改。

## 3. 主角与本地交流

- 主角也**不能默认是来自地球的人类**。关于为何唯独主角会感知人像，属于本作主线悬疑；完整圣经提出主角是本世界的异常观察者「异观」，属于创作提案而非用户逐字确定。
- 能量体之所以会问主角“你所识别的我为什么与我所自识的不同？”是因为它感到主角在用一种无法共享的方法区分自己，**不是它知道“人类少女”却没见过自己**。
- 对话应先以结构关系传递，再翻成字幕；本地原生语言没有“火/人/美少女/眼睛/衣服”等词。

## 4. 五 XP 与 2→3→4→5 进阶

| 顺序 | XP | 给玩家的译像 | 本体对应的结构 |
|---|---|---|---|
| ① | 体型 | 焰状体大小、美少女体型 | 变化影响范围/幅域 |
| ② | 性格 | 焰状体颜色、美少女性格 | 回应倾向/偏应 |
| ③ | 职业（包含职业服装） | 骑士、猎人、魔女、商人等 | 行动模式/行路 |
| ④ | 种族 | 猫娘、吸血鬼、恶魔、人类等 | 稳定自身的基本结构/底律 |
| ⑤ | 故事 | Boss 对应掉落的故事头衔 | 可继承的重大事件之痕 |

- 游戏最初只有①②两个 XP；初始能量体在主角视界中**也已经可以呈现美少女**。第三 XP 不是客观上第一次变成人。
- 各类别同类型只能选择一个；每种不同五XP组合对应独特新意识结果和主角译像。种族/故事均为各自固定 XP 类型。
- 两个同级能量体经融合媒介重组，生成**新第三识 C**；原A/B的独立自识结束，绝非把真人相互拼接或原一个人的升级换装。
- 所有第五 XP 的直接来源均为**打败其对应 Boss**。Boss和故事称号是主角的可读译名，并非本地原生地位称谓。

## 5. 世界观验收红线

- 火苗只可作为视觉语言，不作为它们自认的生命形式。
- 美少女只在主角视界存在；本地不理解人、女性或真实衣装。
- 现有六阵营名（骑士团、恶魔商店、魔女工坊、马戏团、血族、猎人组织）是主角的投影译名；本地群体的真实差异是六种共振模式，细节见完整世界圣经。
- 不以地球地理、血缘、婚姻、军队、金钱解释原生世界。具象森林、海浪、城堡和人物演出可作为主角视听译像与2.5D舞台设计。
- 含主线、世界起源、Boss对应头衔、共识冲突的具体情节均为完整世界圣经的**新策划提案**，不伪称全部都已获用户逐项批准。
