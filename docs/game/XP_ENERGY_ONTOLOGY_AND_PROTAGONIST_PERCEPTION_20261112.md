# XP 精神能量世界｜真实形态与主角独有的美少女视角（2026-11-12）

> **用户已确认的核心世界观硬规则**。本文件优先于此前任何“能量体真正变成人类”或“只有获得职业后才变成人形”的措辞。设计稿不代表已实装。

## 一、存在的本质：全程不是人类

- 这个世界是**精神能量世界**；这里被玩家收集、交谈、融合的角色，其真实存在形式是**火焰般的精神能量体/火苗/能量团**，而不是活生生的人类身体。
- **这些存在在它们自己的眼中，自己是火苗、火焰、能量团等精神能量体；它们看彼此也是能量体。** 外人/同类不会看到主角眼中的美少女形象。
- **只有主角的主观视角**，这些能量体才显现为拥有各种 XP 特征的不同美少女。她们的人类外貌并非所有人共享的客观物理实体，也不是能量体真实长出人体。
- 能量体具有**自己的意识和对话能力**，可以与主角沟通，却未必知道主角看见的是怎样的人物外观；可自然向主角发问「**在你眼里，我是什么样子的？**」「**你看见的我，和我自己看见的一样吗？**」。这样的问话体现主角感知与能量体自我认知之间的差异，不能误写成“她明知自己本来是美少女”。

## 二、玩家看到的初始 2 XP 与五维投影

- 玩家最先**挑选火苗/能量团**：**①体型 XP 用火焰大小表达**（小火苗、中等火焰、大团火等视觉概念）；**②性格 XP 用火焰颜色表达**。颜色→具体性格的精确映射表尚未由用户指定，不得擅自宣布红=傲娇等固定对照。
- **2 XP 初始能量体**已经具有独立能量身份；进入**主角感知视角**时，也可以对应一名只由体型与性格决定的初始美少女形象，**不能再说只有取得职业第 3 XP 后才首次变成人形**。该美少女外观仍只是主角眼中的显像，不是她本体真的变成人。
- **③职业 XP**：在主角的美少女感知外观里决定职业与职业服装（不另设衣服 XP）；**④种族 XP**：决定人类/猫娘/吸血鬼/恶魔等主角感知中的种族形象与对应角色规则，同类型互斥；**⑤故事 XP**：来自击败对应 Boss 后掉落的故事头衔，决定主角眼中传奇新角色的身份与表现。
- 固定顺序严格为 **①体型 → ②性格 → ③职业（含服装） → ④种族 → ⑤故事**；数量阶段为 **2→3→4→5 XP**。初始能量体没有职业，但在主角眼中仍可见角色形象；具体初始服装/裸露规避和视觉规则尚需另外设计。

## 三、融合在世界观中的意义

- 两个同级精神能量体 A、B 经相应融合媒介**重组其精神能量**，形成**客观上新的第三个能量意识体 C**；A、B 不再作为原独立个体存在于可用阵容。**绝不是把两个真人塞进炼药锅，也不是其中一人穿新衣服升级。**
- 不同 XP 组合映射到**不同的 C 的角色身份与主角专属美少女投影**；即使只改变性格 XP 或故事 XP，也不得映射成同一个人物结果。世界里 C 的本体仍是能量体，不论她在主角眼中呈现为何种人类/幻想种族外观。
- **无需对真实世界中的人类解剖、混血、体貌转化寻找生物学解释**；合成就是精神能量重新组织并出现新意识，本体与投影必须分层处理。

## 四、演出与 UI 硬约束

- **双视角规则**：普通能量视角 = 具大小、颜色等可见特征的能量体；主角视角 = 由固定五类 XP 决定的、相互区别的美少女。
- **开局选角**先展示玩家可辨认的不同大小、不同颜色的能量火苗，让玩家通过观察选择初始体型/性格 XP；随后可在主角视角中展示其美少女显像。
- 主角与能量体交谈、剧情演出、角色卡、融合产物的美少女立绘，都应理解成**主角的感知表现**。在能量体自己的自述、世界观客观描述、其他能量体眼中，禁止无解释地把她们当真人肉身。
- **禁止编造**“其他人也能看见她们是美少女”“变成人后再也不是火焰”“职业 XP 才第一次变成人”等设定。主角这种独特感知的来源、是否可切换视角、颜色与性格映射、初始2XP人物的衣装，都还没有定案。
- 本设定改变的是游戏世界观和感知呈现原则，**不表示需要重画已批准的美少女原画**：原画恰好是主角视角里的角色形象。只需要新增能量态对应素材与表现层。

## 五、可直接用于文本演出的短示例（非已经定好的台词）

能量体：「你看着我时，为什么总会露出那种表情？」
主角：「因为在我眼里，你看起来像一个人。」
能量体：「人？我们不都是这样的火焰吗？……那在你眼里，我是什么样子的？」

以上对话是机制说明示例，可根据主角文风改写；不要把它写成每个角色都会说的固定台词。

**重要区分**：能量体**真正发生的变化**是能量重组与新的意识诞生；美少女**发生的变化**是主角因新 XP 组合而感知到的不同人物形象。
