# 五种固定XP的组合数｜公式与已知数据（纠错版，2026-11-12）

> **前一版本用63性格、62职业、33种族和5个假设Boss得到的2,320,164等数字已被撤销。** 这些并非已批准词条表。真实数量要等五类正式词条全部核对完才能算。

## 成长

| XP数量 | 主角所见阶段 | XP条目 |
|---|---|---|
| 2 | 初始能量意识（UI呈现焰状大小/颜色） | ①体型、②性格 |
| 3 | 首次取得职业后的新意识 | ①②＋③职业服装 |
| 4 | 进一步重组的新意识 | ①②③＋④种族 |
| 5 | 融合Boss故事头衔的传奇新意识 | ①②③④＋⑤故事 |

这些生命并非人类或火焰。焰状选角是玩家的UI视觉比喻；只有主角从精神差异中看见人物美少女。每个不同XP键对应不同结果，任一槽位（包括性格或故事）改变都不能返回同一个人物外观/身份。

## 组合公式

设 B=正式体型数，P=正式性格数，J=正式职业数，R=正式种族数，S=正式Boss故事头衔数。

- 初始2XP：B×P
- 一级3XP：B×P×J
- 二级4XP：B×P×J×R
- 三级5XP：B×P×J×R×S
- 四个阶段合计：上述四项之和（若每阶段均计为不同身份）。XP顺序固定，不再乘5!。
