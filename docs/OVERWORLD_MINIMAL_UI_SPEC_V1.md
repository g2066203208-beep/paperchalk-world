# 表世界沉浸式极简 UI 规范 V1.0

状态：**玩家认可的设计方向**。日常游戏画面必须以场景、角色与环境声音为主，禁止恢复「今天的生活」大面板、网游式任务/亲密度/金币统计卡或持续弹出的经营页签。

## 1. 表世界常驻

- **手机、背包、地图**：保留原游戏的三个快捷操作。背包和地图是快捷入口，但数据实际显示在主角手机的物品/地图应用内，不生成另一个全屏管理界面。
- **日期时间**：原右上角低存在感，生活模式由真实的游戏日历驱动。时间是玩家安排上学、打工、营业、22:00前睡觉的重要依据。
- **系统菜单**：仅保留一处可访问的菜单/设置入口，不增加 DEV 相关日常按钮。
- **人物状态**：生命、饥饿、理智继续使用项目原有的真实生存计算。健康时常驻条在表世界隐藏；任何一项低至30%及以下时才显示警示；可在手机「状态」主动查看完整信息，包含现金和精力。正式卡牌战斗不受该视觉规则影响。

## 2. 手机（使用女主已经制作的手机外观，不重画）

- **信息/聊天**：女二在序幕拨来的6通未接来电、3条催作业信息、玩家回复和后续通讯。
- **联系人**：从已建立手机联系方式的人开始；不把路过的陌生商人、邻居自动当成存有电话的联系人。点击列表 → 个人主页 → 备注、已知人物关系、亲密度（0—100，当前为**原型数值**）、玩家确实得知的个人信息。尚未确认的真实姓名和私密履历不补编。女二的初始亲密度55仅为**玩法测试候选初值**。
- **联系人档案**：从个人主页可以返回聊天记录；亲密度和实际社交事件同步，从不在外界屏幕上飘数值。
- **备忘录**：记录今天的作业以及用户已取得的任务线索。重要且有时间限制的事项应写清楚时间，不把长任务清单常驻界面。
- **地图**：当前地点、可选目的地、约需多少分钟、开放状态；触控选点后在手机内确认出发，真正扣除游戏时间。未绘制的正式街景不可用其它场景冒充。
- **状态**：现金、精力、原生生命/饥饿/理智值。购物时显示余额，食用物品时应有结果反馈。

## 3. 环境交互

- 靠近可交互对象、需作决定或剧情人物说话时，局部出现一两行淡入文字或一个清楚的交互提示；结束后自动消失。
- 进入手机时，环境提示收起，保证有限的画面空间内视觉焦点明确。
- 发现恐怖事件优先使用环境、对白、角色反应与声音；不得首次起床就用红色警告、弹窗怪物百科或突脸 Jump Scare。
- 不能破坏已确定的可重玩里世界肉鸽开场→首次死亡卧室醒来构想；眼下开发版直接从醒来序幕开始。
