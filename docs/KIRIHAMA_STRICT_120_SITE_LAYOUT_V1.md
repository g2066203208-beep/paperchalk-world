# 霧浜市 · 15 片区、120 地点严格位置规划（V1）

**定位**：日式都市怪谈恐怖调查游戏的第一座大城市；本文件是城市地点和站前交通的**位置设计档案**，不代表这 120 个地点已有可游玩的美术场景。

## 一、真实规则与项目约束

- 现存城市身份：**霧浜市**（原设人口约 860 万），**10 条已登记运营线路、70 座独立真实地铁站、19 座换乘站**。原有八个剧情交通站点 ID 不改变。
- 游戏世界分为**城际总图**与**各城市独立交通图**；以下位置全部属于霧浜市，不能画进其他 9 城或把地铁横跨城市。
- 下方 32.4km × 23.4km 的虚构城市局部米制规划框架中，北在上、东在右。游戏地铁示意图每格在本次区位规划中映射为 **900 米**，但其本身仍是可编辑**示意图**，不能冒充测绘地图、城市边界或精确轨道线形。
- **每个地点的固定入口坐标**、最近地铁站 ID、偏移方向与楼层已经逐一登记。不使用原先随机极坐标撒点法；**地下** (B1/B2) 与地面/高架分层，平面同址不等于一个场景。
- 前往车站步行接驳：采用**优先 500m、上限 1000m**的公共交通可达性方向；本版长度是 `1.28 × (|东向偏移| + |南向偏移|) + 55m` 的**规划估算**，不是路网实测。参考 [ITDP TOD Standard](https://tod.itdp.org/tod-standard/tod-standard-framework.html)。
- 湾海是不可布置陆地场景的水面；青柳川是必须经桥梁或合法过河设施才能横越的障碍；北部丘陵保留坡道、森林、山地而不是到处堆满商店。
- **严格校验结果**：120 地点一对一固定 ID；原始 30 个地点保留；地面同层任意两处规划入口至少间隔 80m；所有地点最近地铁站正确、估算步行距离最长 925m；既有图可双向寻路，但细节人行道、过河桥梁及实际土地使用仍需下一阶段建模验证。
- **已完成内容与规划必须分开**：原有 6 处日常地点有场景入口、3 处已登记未开放、其余 111 处只是规划；70 站不是 70 套独立车站内部场景。原来 6 个剧情地点游戏 ID 与地铁站 ID 同名，目前引擎为兼容旧存档仍把二者视作同一导航节点，**房门与站台分离的步行演出尚待独立实装**。

## 二、地形—功能布局原则

1. **西北—北部**：赤樫山丘、旧街区、学园带，沿既有西城线和学园北线分布，山地低密度。
2. **中部**：中央都心站与医疗、文化、夜间商业构成混合但功能不同的密集核心，过街天桥和地下街应有独立楼层。
3. **东—东北**：湾岸新都心与东部商业，较高容积率；海滨沿轨道扩展，不把港口工厂塞进居住商场腹地。
4. **中西部河谷**：青柳川、河岸公园、桥与水门，固定岸线地形约束，不能让步行路线穿水。
5. **南部—东南**：先西南工业及郊居，再向东衔接港南仓储、码头及海岸，引入防洪和货运隔离带。

## 五、实施数据与验收

- **权威物理坐标主数据**：`site/data/kirihama-location-masterplan.v1.json`，包含站点 ID、位置偏移、状态、分区和水岸/河流约束。
- **浏览器编译数据**：`site/game/kirihama-location-plan.js`，使用 `node scripts/build_kirihama_location_plan.mjs` 从 JSON 单向生成；CI `--check` 防止数据漂移。
- **现有城市运行时**：`site/game/world-atlas.js` 登记全部 120 处而不再对霧浜采用随机放射撒点；`site/game/destination-network.js` 为各地点注册对应真实地铁站的双向首末端连接，而不是四条虚假的城市辐射接驳线路。
- **独立可视审查页**：`site/kirihama-location-plan.html`，默认只高亮一个片区，不向正常地铁地图塞满 120 个大图钉。
- **严格自动测试**：`tests/kirihama-location-masterplan.test.cjs` 和真实 Chromium 的 `tests/kirihama-location-review-browser.mjs`。
- **以后开发前必须补齐**：站口到店门的真实人行路网、地铁与桥/河堤的高程冲突检查、海湾和陆域精确多边形、各站垂直交通层级，以及为尚未开放地点制作实际场景。这些尚未完成，不得把规划位置冒充已经建成的游玩场景。
