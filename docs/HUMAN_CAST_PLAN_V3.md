# 《错位日常》人物结构与城市生活核心方案 V3.0

> **现行人类角色设计方向（2026-11-02）**。原来“28名学生＋三所高中”的方案已撤回；本稿保留48个既有CHAR ID，但将它们重组为**8名学生＋12名重要非学生角色＋28名城市生活与剧情NPC**。这48人只是可识别身份预算，不等于已做48套立绘或已有48个可玩NPC。怪物另算。

## 游戏到底是什么

**城市生活与社会关系RPG + 原创异常事件与调查 + 有深度的牌组构筑战斗。** 学校只是世界的一部分，而不是主角活动唯一的舞台。学习《女神异闻录5》如何组织日常与关系、《杀戮尖塔》如何让构筑和决策有意义，但**不复制它们的角色、界面、怪物、技能、美术或剧情**。

## 重点不是人数，而是玩法关系

- **学校日常**：只围绕一所学校的一小部分人物开展课程、课间、社团、上学放学；其余学生可以是普通背景路人，且不必拥有448项专档。
- **城市生活**：住宅、便利店、餐饮、交通、夜间活动、公共服务各有用途。职业角色可以提供探索任务、关系事件、卡牌制作或商店功能，但功能不能用职业名称自动替代具体游戏设计。
- **牌组战斗**：先以4个已开始设计的年轻人物做不同战斗定位的原型，然后选择合适的成年人补足战斗职业。战斗人数依据平衡和故事决定，不等同全部20个重点人物。
- **分批制作**：先四位已开展设计的人物和一段可玩城市生活/异常事件/卡牌战斗垂直切片，再补4位学生、4至6位关键非学生，最后扩充城市NPC。
- **身份规范**：永久编号CHAR-001～048不换；旧版还未批准的学生身份（CHAR-012、017、018、019、024、026及14个学生配角）转换为非学生职业提案，但不冒称用户已经批准新职业。已有获批人物脸与素材一律不改。
- **世界资源规范**：不新建另外两所完整校园作为刚需；旧三校文档仅供历史参考，停用其年级班级硬编码。未来新增校区必须证明它有独立剧情和系统价值。
