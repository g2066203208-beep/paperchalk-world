# CHAR-001 女主正面 2048×2048 高精度保真精修 SOP V1（2026-11-05）

> 强制开工阅读： [Anima × Forge Neo 当前插件与 LoRA 清单](ANIMA_FORGE_NEO_INVENTORY_20261105.md)、[画风锁](ANIMA_CHARACTER_ART_STYLE_LOCK_V1.md)、[女主角色档案](PROTAGONIST_CANON.md)、[角色定型规范](characters/ANIMA_CHARACTER_IDENTITY_LOCK_STANDARD_V1.md)。身份始终为 protagonist / CHAR-001，原先批准正背母图不覆盖。本文是**执行方案与未测试参数方案**，不是声称已在用户本机生成完美成品。

## 0. 目的、已知输入与不能妥协的验收

- 输入：用户 2026-11-05 提供的正面 1024×1024 全身单人图（原来白色背景）；必须保留真实原稿，并同时用仓库中已批准的 site/assets/characters/protagonist-front.webp 与 protagonist-back.webp 做身份一致性对照。实际用户发来的新 PNG 不一定与仓库 WebP 完全同一版本，出现细节差异时**以用户指定当前源图为本次修改输入**，任何覆盖正式母图仍需用户审核。
- 目标：2048×2048 RGBA PNG、完整发梢/手/双鞋/脚底、无场景阴影、可独立叠入游戏、可用于后续 See-through / Photopea / L2D 分层。
- 外貌锁：柔和偏窄鹅蛋脸；细长半垂杏眼、灰褐色虹膜；眉眼嘴的相对布局；黑色长直发、齐整的分束刘海、胸前两绺长发；**角色自身左鬓（面对观众的画面右边）两枚浅银色细发夹**，严禁移到反侧；冷淡略带倦意的中性表情，嘴唇闭合；黑蓝西装制服、浅灰白衬衫、酒红领带、灰色百褶短裙、黑色短中筒袜、深棕乐福校鞋；双手自然下垂；前正视、低透视、人物头顶脚底留白比例沿用原图。
- 艺术风格锁：用户已认可的 @akipekostyle / akipekoanima_v1_1（当次 LoRA 卡片截图标签为 akipekoanima_v1_1-step00003000，真实启用名通过点击卡片确认）。轮廓清楚、有轻微手绘线宽变化、块面赛璐璐阴影，禁止写实塑料肤质、彩色特效、无意义的发丝噪声、脸型年轻化/换脸。
- **保真与细化是两个目标**：低去噪保轮廓但可能补不了足够细节；高去噪能画新细节却更容易改脸。不能保证任何扩散模型逐像素身份一致或“完美”；要用 A/B、局部修、人工核对验收。

## 2. 当前 Turbo 的第一轮参数（用户界面可逐项直接填写）

| Forge 控件 | 当前截图 | **首轮建议试验值** | 原因 |
|---|---|---|---|
| Resize Mode | Crop and Resize | **Just Resize**（图为正方且输出正方） | 避免无意裁人。也可 Preserve Aspect Ratio；图片本身1024方图 |
| Sampling Method | ER SDE | **Euler** | Anima Turbo 官方优先建议 Euler；ER SDE 可作为第二项对照 |
| Schedule Type | Beta | **Simple**（有 Simple 时；没有时选 Normal 并记录） | Beta 尤其 beta57 偏纹理化，不适合第一轮保真控变量 |
| Sampling Steps | 32 | **10**（对比 8、12） | Turbo 官方 8–12；32 属 Base 类配置 |
| Width / Height | 1024×1024 | **1024×1024** | 先同尺寸精修确认身份 |
| Shift | 3 | **3 原样不动** | 先遵循当前 preset，Shift 最佳值需按具体 checkpoint/构图验证 |
| CFG Scale | 4 | **1.0** | Anima Turbo 推荐值，负面提示在 CFG1 通常不参与引导 |
| Denoising Strength | 0.6 | **0.25** 起步；A/B 比较 **0.20 / 0.30 / 0.35** | 控制角色漂移。10 steps × 0.2 仅少量有效采样步，可能几乎不重画；若细节不足不用一味加到0.6，考虑 Base/Aesthetic 精修或多次局部修 |
| Batch Count / Size | 1 / 1 | **1 / 1** | 先低成本对照 |
| LoRA | 看卡片列表 | **仅 akipeko，先0.8（并比较 1.0）** | 项目画风锁；其他美化/滑杆不叠 |
| 其余增强项 | 部分关闭 | **全部关闭** | 排除身份干扰 |

注意：这里的 0.25 / LoRA 0.8 等是**针对本项目的待验证实验起点**，不是官方唯一最佳值；不同本地 Turbo 变体会有差异。CFG=1 的 Negative Prompt 虽可存于记录，但可能没有实际生效；形体约束放在**正向提示词+低去噪**里。

## 4. 第一阶段：原尺寸精修的实际点击操作

1. img2img 左侧上传 **原始1024白底人物 PNG**，确认头发、发夹、全身两只鞋都完整可见。若预览只是框不正中，看最终尺寸配置而非网页 CSS 显示。
2. 把以上 Positive/Negative 放入上下两个 Prompt 框；核对第一段 LoRA 标签是否与在 LoRA 卡片上**实际点击后插入的完整标签**一致，不一致只替换首项；不要重复插两次。
3. 按上表设置：Just Resize、Euler、Simple、10 steps、1024²、Shift3、CFG1、Denoise0.25、batch1。
4. 点击 Generate 得到 A1。保存完整 PNG 与信息（Forge 输出下方 Download / Save；PNG Info 可读参数）。
5. 固定 A1 的 Seed，以同一个 Seed 做 A2 0.20、A3 0.30、A4 0.35（只变 Denoise）；选择最像原稿且局部有改善的版本，**不是谁眼睛大、油光多就算更高清**。
6. 再固定选中的 Denoise，用 LoRA 0 / 0.8 / 1.0 做 3 次对照。若风格漂移，优先原来项目实际使用权重；若 LoRA 插入后报错，先核对卡片权重版本与 Turbo 模型兼容，别误判成 Prompt 问题。
7. 放大查看 100%：眼形与瞳色、发夹在画面右侧、刘海分束、领带宽度与红色、袖扣衣领、裙褶数量/方向、指头轮廓、袜口和鞋型。只要有一个关键身份识别点偏离，标为不合格，不能覆盖原稿。

### Turbo 低去噪没增加细节怎么办？

这是可能发生的（10 steps × 低 denoise 有效迭代很少）。不要立刻把 Denoise 提到0.6。按顺序：
1. 可先试 **12 steps、Denoise 0.30–0.35**，仍做眼睛/发夹/鞋对照；
2. 如果依旧无效，考虑**另行确认安装 Anima Base v1.0 / Aesthetic 对应 checkpoint**（截图当前不证明已经安装），再用作者建议 **ER SDE、Simple、35 steps、CFG 4.5、Denoise 0.20–0.32** 作为可控高精度实验；必须先确认模型是原生 Base/Aesthetic，不能把此参数用于 Turbo；
3. 再不满意则采用 **Inpaint 小区域细修**，不整图重画。

## 5. 第二阶段：从合格1024到2048，避免高分辨率变形

**路径 A（最稳定的结构保真）**
1. 保存已批准的1024候选 PNG。到 **Extras** 页面上传这张候选图。
2. 如果已安装合适的放大器（截图未证明 R-ESRGAN/4x-UltraSharp 已安装），选择对二次元线条友好的放大器，例如 4x-UltraSharp 或 R-ESRGAN 4x+ Anime6B（仅当列表确实有它们）；Scale by **2.0**，输出 **2048×2048**。
3. 先保存 Upscale-only 文件并对比细节。如果只是像素更多但脸线没有新的真实信息，请诚实标记为“结构放大版”，不假称已经重画。

**路径 B（真正补画细节，风险更高）**
1. 回到 img2img 上传路径 A 的2048草案；目标 Width=Height=2048，Just Resize；若显存受限或出现脏斑/缝线，不直接全幅高去噪。
2. 优先选 **img2img Hires Fix** 的两段高分辨率工作流，或者 **MultiDiffusion Integrated** 的分块模式；先阅读该插件 UI 的实际 tile/overlap 选项，**不能想当然声称默认 tile 参数**。
3. 第二阶段建议 **Denoise 0.12–0.20** 小步测试，LoRA 和 Seed 仍固定；如有条纹、错层、接缝，降低重绘或关闭该算法，回退路径 A。
4. **不要同时打开 img2img Hires Fix + MultiDiffusion + 参考适配器 + ADetailer**，这样无法知道哪个模块改坏了脸。
5. 在 2048 上局部需要新增真实细节时再 Inpaint，按区域修；先整图轻补、再单处手工精修，不做无意义的多轮整体重采样。Anima 本身主要在 1024级分布上训练，高分辨率可能出现脏网点；Forge 开发者也曾报告某些高分辨率流程的纵向人物破图。

## 6. 第三阶段：Photopea 保留真正透明 Alpha + 人工锁定

1. 在 Forge 顶栏 **Photopea**（或本地 Photopea/PS）打开最终2048图，确认背景实际是否 Alpha。白色画布/棋盘格外圈不等于主体图已有透明通道。
2. 若是白底：将背景转换可编辑图层，**先复制备份图层**，用魔棒选择连续白色背景，调整容差并检查白衬衫/白色头部高光是否误选；用蒙版非破坏式隐藏背景；沿长黑发边缘逐步清理白边与半透明灰边。
3. 对头发散丝、两枚发夹、双手指缝、百褶裙边缘、脚与地面接触像素进行 200–400% 局部检查，必要时人工补画而不是全图再生成。
4. 仅保留人物，**不烘焙站立投影、恐怖黑雾、地板反射或场景光照**。这些在游戏 3D/Canvas 运行时生成。
5. 以 **2048×2048、RGBA PNG、带实际 Alpha** 导出；在棋盘格、纯黑、纯灰三种背景上检查边缘，确认没有大片漏抠、白色光晕或头发透明断裂。
6. 通过 See-through 分层得到 PSD 后，分开验收前/后发、肩/颈、手臂/衣袖、衣服/腰胯、裙摆、腿/袜/鞋以及遮挡区域；**PSD ≠ 已完成 L2D 动画**。
7. 在用户最终确认前，不覆盖 site/assets/characters/protagonist-front.webp/back.webp、现有 PSD/ZIP 或角色编辑器 IndexedDB 内容；新稿进入独立候选目录。

## 7. 参考适配器的可选实验（只在普通 img2img 不够保人时）

**不属于第一轮默认选项**。参考适配器是“根据参考画新图”，不保证逐像素保留原稿；对已确定角色低去噪图像有时会和 img2img 输入相互竞争。

- 确保 Forge Neo 最新版本与 anima-reference-forge-neo 扩展被成功加载。当前扩展说明的**已验证两种方法**：
  - ElectronGirl pilot：Prompt 写 <lora:anima_ref_adapter_pilot_r32:1>；
  - AnticPan Role Ref KV：Prompt 写 <lora:anima-role-ref-kv-v1.0:1>；
  - 两者 **只能选其一**。截图里的 v2_r64 在 ElectronGirl 原生 ComfyUI 插件文档支持，但当前 Forge Neo 扩展的 README列为 pilot 与 Role Ref KV，**不据此声称 v2 已在本机可用**。
- 在 **ImageStitch Integrated** 勾选启用，上传**完整单人人物参考图**到 gallery（Image to Upload / Append Pasted Image）；Settings → [Anima] Enable Reference 保持 **OFF**，避免与 Edit LoRA 混用。
- 参考模式 Prompt 应简单写 **masterpiece, best quality, score_7, safe, 1girl, solo, full body, front view, standing, looking at viewer, plain white background, arms at sides** + 一种方法 LoRA 标签；外貌依靠参考图。
- 在 Turbo 8–12 steps/CFG1 时，Ref Adapter 的 **reference guidance 会被迫为1**（因 CFG1没有负面分支），不能照抄 Base 模型上 guidance4.5。要增强参考，先实验 CFG1.5 与参考引导，逐项记录是否变色/偏脸。 Role Ref KV 根据对应扩展设置处理。
- 若需求是“脸和服装几乎完全不变，只把1024提高到2048”，仍首选本文普通 img2img / 超分 + 小区域 inpaint。Reference Adapter 更适合未来**新姿势、换装、多视图**时做身份一致性候选。

## 8. 局部 Inpaint 与验收矩阵（优于全身多轮修改）

问题与最小操作：
- 眼睛大小/眼距/眼色漂移 → 放弃当前整体图，退回低 Denoise；不要先用 ADetailer 造另一张 AI 脸。
- 两枚银色发夹位置/数量错 → Photopea 局部保留原发夹或 Inpaint 仅圈鬓发及发夹；不要翻转整张图。
- 手指出错 → Inpaint 只圈手指/手掌，采用周围衣袖纹理上下文，小幅去噪；之后核对四肢连接。
- 鞋型/袜高跑掉 → 原图局部贴回或仅重画鞋袜，左右鞋底在一条地面基线上。
- 2048 线条脏点/重复纹理/拼缝 → 回滚到放大前版本，换算法而不是再叠一层细节 LoRA。
- 白边或头发发丝缺失 → 手工蒙版/局部绘制，不通过换脸模型来修。

验收必须逐项人工 PASS：人物同一个人（脸型、杏眼、瞳色、发夹）、相同校服（领带/扣子/裙褶/袜/鞋）、相同身高与大体素描比例、全身不裁切、线条干净自然、无无意义的 AI 噪点、真实 alpha、无烘焙场景光影、保存生成参数/Seed、候选未覆盖正式生产母图。**哪一项失败就不能写“完美复原”。**

## 9. 最小复制操作卡

- **界面**：Stable Diffusion → img2img → img2img 上传原图；Checkpoint 保持当前 Turbo + 当前 VAE/Encoder；
- **选择**：Just Resize；Euler；Simple；1024×1024；10 steps；CFG1；Shift3；Denoise0.25；Batch1/1；先不使用其他增强；
- **提示词**：本文 Positive/Negative；核对 LoRA 卡片真实插入标签与文本第一项 akipeko 标签一致，@akipekostyle 保留；
- **Generate** → 记录 Seed → 固定 Seed 测 0.20 / 0.30 / 0.35 → 选最贴原图者；
- **Extras** → 2x 到2048（先确认有可用 Upscaler）；有必要时仅使用一种 Hires Fix / MultiDiffusion 进行低去噪精修；
- **Photopea** → 透明 Alpha + 边缘/发夹/手指精修 → 导出2048 RGBA PNG；
- **用户验收** → 才能讨论替换 L2D 人物母版，严格不自动覆盖。
