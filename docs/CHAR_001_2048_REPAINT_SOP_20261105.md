## 4. 实操顺序（不禁用/卸载任何已安装插件）

1. 保存原稿。进入 **Stable Diffusion → img2img → img2img**；上传1024女主原图，设置 Width=Height=2048，Just Resize。
2. 选择当前 `anima_turboV11`；核对当前 VAE/Text Encoder 没报错。设置 Euler / Simple / 10 steps / CFG1 / Shift3 / denoise0.25 / Seed-1 / Batch1/1。
3. **原版参考方案**：打开 **ImageStitch Integrated**、勾选 Enable、上传同一个女主原图到 reference gallery；在 Prompt 使用上方“可读工作版”原 Prompt，包括 pilot:1 和 akipeko:1（先核对实际 LoRA 文件名）。保持另一个 **Anima Reference Adapter v2 panel 不勾选**；其余 ADetailer/ControlNet/Regional Prompter/Forge Couple 不勾选。
4. 执行一次 **Generate**。如果出现“参考权重未被识别、模型加载报错、人物重复、2048崩溃”等，保存错误日志，切换**不使用 pilot 的 img2img A/B 基线**：在 Prompt 删除 pilot 标签、ImageStitch 不勾选，仅保留 akipeko:1 和原始文字提示，其他参数原样。**不要同时再把 v2 panel 也勾上。**
5. 对同一 Seed 保存 pilot+ImageStitch 与不带pilot的成品 A/B；选择更像原图、更无重复角色、更完整的一张。低Denoise时参考插件不一定进一步改善身份；应由实图验证，而非默认“插件越多越好”。
6. 如果线条真的欠精细，仅在 2048 画布上采用低去噪 + **Inpaint** 逐部位修脸/发夹/指缝/校服扣/袜和鞋；或在 MultiDiffusion Integrated 设置合适 tile/overlap 分块，**一次只增加一项能力**。不要用 ADetailer 自动换脸。
7. 在 Photopea 给最终2048图抠除白底，生成真实 **2048×2048 RGBA PNG**，核对黑发无白边、双鞋完整、透明通道真实存在、无烘焙环境投影，再进入 See-through/现有L2D编辑器做PSD拆分验收。
8. 保存每次实际 PNG Info、输入源图哈希、实际 checkpoint/LoRA文件哈希、Seed、CFG、steps、sampler、schedule、shift、denoise、使用的参考图、ImageStitch是否启用、输出像素尺寸、显存/错误和人物QA。**未经用户审核不覆盖任何现有主角母版与 L2D**。

## 5. 质量评价与“不可换人”底线

- 女主唯一身份 CHAR-001 / protagonist；已批准的原稿与正/背面 WebP 是身份对照。
- 两枚银发夹在**角色自身左鬓/画面右侧**；深黑直发、灰褐半垂杏眼、窄柔和椭圆脸、冷淡闭嘴表情、低饱和深蓝校服、灰百褶裙、酒红领带、袜长和深棕乐福鞋、站姿肩膝比例都不能改变。
- 不能因“补细节”变成大眼小脸、塑料皮肤、超密发丝噪点、不同扣位、完全不同裙褶。只接受**风格一致且可见的结构化线条质量提升**。
- 每张候选保存透明 RGBA、全身无遮挡、画布2048²、原稿不覆盖、可追踪参数；不通过的候选不进正式游戏。
- 提示词 + Seed 永远无法保证逐像素复现；图像低去噪 / 参考图约束 / 人工小范围修复才是主路径。

## 6. 新证据：参考图像素尺寸、ImageStitch 缩放与低去噪冲突（必读）

- **已经制作**：原始1024² RGB女主图用 Lanczos **不改变构图的2x插值到2048² RGB**，用于 img2img 2048输入工作底稿。此文件在当前对话生成并提供给用户，**没有自动写入仓库**；请本地保存并上传Forge。它不是真正增加了AI细节，也还不是透明PNG。实际源图 SHA256/最终文件SHA256需由本机测量后填入制作记录。
- **两处图片上传位置绝不混淆**：img2img主图片区的2048底稿控制画面布局、身体结构；ImageStitch Integrated gallery的**1024原稿或清晰全身参考图**给 pilot 适配器提供人物身份。若从未上传ImageStitch参考图，仅写pilot LoRA标签不能复刻原始身份。
- **ImageStitch 最大边长（maximum side length）**：扩展官方 API 例子为1024，所以即使上传2048参考图，**ImageStitch可能将它再次缩至1024**；要先检查面板实际最大边长及输出预处理。不要因为“参考图片必须2048”而误判失真，也不要无依据把最大边长设2048导致VRAM暴涨。官方依据：https://github.com/eduardoabreu81/anima-reference-forge-neo
- **Ref Adapter 在 img2img 与原稿竞争**：原扩展 README明确说明，img2img原始图与参考图可能相互牵制；在低denoise时母图通常强于适配器；在高denoise时适配器能主导一部分脸/发色但衣服构图仍可能漂移。**女主任务不能简单靠提高denoise到0.8**：那是插件演示换角色应用的例子，不符合用户要求的高保真原图重绘。
- **Turbo CFG1参考引导**：由于无负向pass，Pilot Ref Adapter额外 reference guidance被强制为1；扩展 README 说明想加强可把CFG轻微升到1.5并与 reference guidance配套尝试，但本任务第一轮仍用Turbo CFG1与pilot1，只有观察到参考不起作用才做单变量A/B。
- **Settings → [Anima] Enable Reference = OFF**，这属于 Anima Edit LoRA，不是用户原Prompt使用的 pilot/ImageStitch 模式；另一个独立 `Anima Reference Adapter` v2面板不勾选（无需卸载）。
- **2048 OOM的处理**：保留输出2048；先 Batch size=1、关闭独立的其他重绘脚本、尝试降低不必要参考开销；如果本机提示CUDA OOM，在尚未验证适配器与MultiDiffusion兼容前不要贸然勾选所有增强。可再单独实验 MultiDiffusion tile/overlap，并对每一块接缝做QA；若仍无条件执行则如实记录硬件限制。
