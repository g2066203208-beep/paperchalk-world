## 2026-11-02 较早一版双人图审查（仅针对旧图，不代表最新中间人物）

对照：用户提供的女二图片在一张 1024×1024 白底图中出现两名相似女生，左侧披发、右侧高马尾；另一张是独立黑长直女主的正面全身立绘。两图均非已存入游戏的正式女二正背面母版。

**审核结论：拒绝作为 CHAR-002 正反面正式素材。**
1. 一张图出现两个人且两个人都露正面：违背 `1girl, solo, exactly one person`；左侧没有单马尾，身份不一致。明确以后一次输出**单个角色**，正面和背面分别跑两个不同提示词，不能让一个 prompt 的两次随机采样自动变成不同视图。
2. 制服不一致：女主外套为合身、正面闭合、沿门襟两颗深色扣子；女二变成宽松敞开外套、金色扣子及金色袖口扣。正背面应该共享同一制服样板：**相同领型、门襟、扣子数量/颜色/位置、袖扣、裙子褶片结构、领带颜色**。穿着方式可个性化，但优先服装系统统一。
3. 女二两腿袜子（尤其右侧人物）颜色不一致，一灰一白。候选女二选**两只同色白短袜**；若学校制服后续规定袜子颜色完全统一，再按用户确认的校规更新。
4. 女二脸眼更圆更明亮、神态活泼合理，但整张图制服阴影、轮廓线的风格、体积感与女主有差距。目标是同一画师的统一线条、阴影层数与布料质感，保留五官个体差异，不是把脸画得一模一样。
5. 右侧马尾符合方向，左侧人物不符合。两人服装、袜子和发型都不一致，不能互相作为正背参照。
6. **身高不能凭两张各自居中铺满画布的图判定**。女主旧档 162cm、女二建议 155cm（相差7cm，按同一缩放尺标女二应约为女主高度的95.7%）。需要同一地面线、相同像素/厘米比的并排比例审核，而不是将两张独立自动居中的全身图以像素高度直接比较。
7. 为便于以后 PSD/L2D，禁止多视图拼版、裁脚、复杂手指穿插；女二单手叉腰一手轻抬招呼属候选动作，必须同时提供**对应背面相同姿态**，不能用随机种子假定正背自动匹配。
8. 三围目前 B80/W62/H86cm、155cm、46kg、18岁、栗棕高马尾、琥珀眼等均是**设计暂定**；真实脸型、胳膊腿围和五官精确坐标暂无验收依据，留空。仅单马尾/活泼/比女主略矮及正面全身差异姿势方向是用户明示。

**提示词控制原则：** Anima 正向短于 500 英文词，最好仅包含必要构图、身份锚点、共享校服结构、轻微性格动作、背景；不能使用 `multiple views`、`character sheet`、`2girls`。正面、背面两个分别独立生成的 prompt 使用同一套身份和制服标签，但只改变 `front view` / `back view` 与朝向视线要求。共同负向阻止多角色、错位纽扣、异色袜子、残缺肢体、半身裁切。Anima 画师与 LoRA token 在提示词中采用用户原有写法，不做 HTML 实体转义。
