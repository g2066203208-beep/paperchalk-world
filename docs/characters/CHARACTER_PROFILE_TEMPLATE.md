## 造型与身体制版

1. **头脸**：骨相、颌线、额头、颧骨、五官相对布局、面部对称性、表情习惯。
2. **头发**：颜色、发量、发长、分缝、刘海、发旋、发饰方向、软硬和高光。
3. **眼部**：眉、上下眼睑、眼白、虹膜色和饱和度、瞳孔、注视与眨眼特点。
4. **鼻、唇、耳、肤质**：细化可辨认的固定特征；不编造不必要的人体细节。
5. **体型**：站姿轮廓、视觉体格类型、肩线、躯干与腿的比例、头身比、手脚、自然重心。
6. **参考数值**：身高、体重、年龄、肩宽、服装版型、鞋码；每项注明 **【锁定／暂定／待定】**，来源与审批人。
7. **体格判断**：只写角色视觉方向和服装制作需要的数据，不根据原画虚构医学体脂指标；未成年角色不登记性化内衣参数。
8. **角色身体构造与外衣制版**：明确角色正/背/侧的肩峰、胸廓厚度、胸部衣料下自然轮廓、腰腹、骨盆髋部、大腿与小腿的连续体积。若角色设定为女性，外观可体现自然女性体态，但不能只凭性别标签随意画成男性板状躯干、过度丰满或夸张沙漏体形。**中性服装尺寸**可以包括胸围、腰围、臀围、肩宽、身高等，但应注明单位、测量性质（圆周而非横向宽度）、是否真实测量、是否已获确认；未成年角色不进行色情化人体规格设计。避免让建模软件把未经批准的建议尺寸反向覆盖原画。
9. **着装**：内外层顺序、颜色、面料光泽、裁片、褶皱、扣件、鞋袜、默认可移除物件。
10. **多角度一致性**：正面、3/4、侧面、背面、表情，统一发饰侧别和人体比例；记录未经遮挡补画的区域。

## 性格、行为与配音

- 核心欲望、恐惧、外显目标、隐性目标、优势、弱点和防御机制；
- 社交距离、对陌生人与熟人态度、信任变化、亲密关系；
- 思考方式、压力反应、习惯动作、隐藏偏见、道德底线；
- 对话速度、词汇偏好、声线、音量、呼吸和典型台词；
- 生活作息、熟练技能、物品使用习惯、交互反馈；
- 人物成长弧线：初始信念 → 挫败 → 抉择 → 改变（剧情未批准前不作已发生事实）。

## 美术与动画

- 正/背人物素材路径、分层源文件路径、派生图路径、版本、许可及责任人；
- 人体骨骼锚点、关节活动范围、穿模保护区、呼吸幅度、软组织/硬布料运动；
- 表情集、动作集、动画循环、碰撞区域、UI和世界比例、可见性规则；
- 新角色不自动变成独立“立绘场景”；复用人物图层和场景模块。
