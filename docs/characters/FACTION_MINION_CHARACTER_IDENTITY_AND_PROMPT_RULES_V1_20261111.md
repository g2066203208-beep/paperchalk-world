# 七人卡牌阵营｜基础小兵角色设计硬性规范（2026-11-11）
 
> 本规范记录用户在对话中确认的基础小兵标准。适用于后续骑士团、黑心恶魔商店集团、七曜魔女工坊、奇想马戏团、绯月血族、怪物猎人组织及未来组织。以已有高级七人组原画为组织美术参考；不要擅自替换已批准素材。

## 1. 三种小兵是三个不同的人，绝不是同一个人换体型

每个组织制作 **3名互相独立的女性基层角色**（娇小型、少女型、成熟型），而不是一个角色的三种形态/换皮。每名角色应有不同的脸型骨相、眼形、眉形、鼻唇、头发颜色、发型、发长、瞳色、肤色或肤质细节、身高、肩腰臀骨架与整体人物剪影。发色差异不等于身份差异；不得共用一张脸、五官模板或同一发型，仅通过放缩或肤色切换制造“不同人”。

- 娇小：身高低、骨架小、脸偏幼态可爱；不等同于默认实际未成年，且不得在此类型添加性感表现。
- 少女：标准匀称的青年女性体型，脸与体态必须与娇小型相异。
- 成熟：明确成年、相对高挑、成熟骨相，丰满胸腰臀腿比例及肩盆骨架整体与标准型明显不同，不能仅通过增大胸部、调高身高敷衍。
- 三名都需是漂亮且值得收集的美少女立绘，不能因“基础士兵”而使用廉价通用人脸。

## 2. 同组织制服完全相同，个体差异不扩散到制式服装

三名小兵同等级、同款制式制服、相同徽章位置、布料层次、衣物结构、金属件、腰带、包具和鞋子，只对不同体型调整裁剪尺寸。服装必须依照 GitHub 中该组织七名已创作人物的真实原画语言、时代感、职业定位，而不是想当然编造跨时代元素（如骑士小兵穿校服、恶魔商人穿铁甲）。高级成员可以各有服饰，但基层小兵统一。小兵级别与身份匹配：普通/廉价/轻便配置，不穿与身份不符的全身精锐铠甲，不因饰物遮挡人物全身主体。

## 3. 性格与动作

基础小兵游戏内可以随机拥有性格词条，**性格不得写死在基础立绘中**。自然日常表情，无明显傲娇/病娇/邪笑/冷酷/害羞/卖萌等性格强调。
三名动作明显不同但都真实自然：可处于不同生活/工作瞬间、转身、迈步、整理装备、搬东西等；禁止三人都普通站立且仅换手或都看账本、单据。允许可读的自然躯体动势和重心变化，但不使用夸张的大动作、高级魔法施放姿态或过强的专属性格动作。每名动作以自己的职业活动逻辑为依据。

## 4. Anima 提示词及裁切

每个人一份完整可独立复制的英文 Anima 正向提示词；任何修改必须重发完整新提示词，不让用户自行拼接片段。之前用户明确要求**不要写 LoRA、画师风格标签及画风提示词**，只写人物/服装/动作/构图。默认负面仅：`worst quality, low quality, blurry, jpeg artifacts, chromatic aberration, watermark`。
基准输出 672×1024 竖版单人，人物及角、尾巴、靴、衣摆、所有携带物完整处于画框中；必要时以较远镜头及更大留白避免裁切，透明背景要在导出后验证真实 Alpha。Anima 多图同款制服并非文字必然保证，必须使用审批的统一制服母图对照验收。
