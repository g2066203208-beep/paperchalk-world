## 1. 三种小兵是三个不同的人，绝不是同一个人换体型

每个组织制作 **3名互相独立的女性基层角色**（**萝莉型 `loli`、少女型、成熟丰满型**），而不是一个角色的三种形态/换皮。每名角色应有不同的脸型骨相、眼形、眉形、鼻唇、头发颜色、发型、发长、瞳色、肤色或肤质细节、身高、肩腰臀骨架与整体人物剪影。发色差异不等于身份差异；不得共用一张脸、五官模板或同一发型，仅通过放缩或肤色切换制造“不同人”。

- **萝莉型（`loli`）：** 每次正向提示词必须**原样包含英文 `loli`**，不能仅写 `petite` 或“小个子”代替。外观显著幼态、身高低、骨架小、圆润可爱的面部；不擅自设定剧情年龄，且绝不对该类型添加性感表现。
- 少女：标准匀称的青年女性体型，脸与体态必须与萝莉型相异。
- 成熟：明确成年、相对高挑、成熟骨相，丰满胸腰臀腿比例及肩盆骨架整体与标准型明显不同，不能仅通过增大胸部、调高身高敷衍。
- 三名都需是漂亮且值得收集的美少女立绘，不能因“基础士兵”而使用廉价通用人脸。

## 2. 同组织制服完全相同，个体差异不扩散到制式服装

三名小兵同等级、同款制式制服、相同徽章位置、布料层次、衣物结构、金属件、腰带、包具和鞋子，只对不同体型调整裁剪尺寸。服装必须依照 GitHub 中该组织七名已创作人物的真实原画语言、时代感、职业定位，而不是想当然编造跨时代元素（如骑士小兵穿校服、恶魔商人穿铁甲）。高级成员可以各有服饰，但基层小兵统一。小兵级别与身份匹配：普通/廉价/轻便配置，不穿与身份不符的全身精锐铠甲，不因饰物遮挡人物全身主体。

## 3. 性格与动作：对话演出立绘优先（2026-11-11 用户再次明确）

基础小兵游戏内可以随机拥有性格词条，**性格不得写死在基础立绘中**。自然日常表情，无明显傲娇/病娇/邪笑/冷酷/害羞/卖萌等性格强调。

**重要：这批是剧情对话演出用的常设角色立绘，不是动作插图或战斗海报。** 三人必须保持易于表情替换和立绘轻微动态的自然站姿，脸部、头发、胸前和手部需清楚可读。可以微微转肩、自然换脚承重、手臂有生活化的不同高度、小幅整理制服或拿极小道具，形成三个不同剪影，但不要让动作主导画面。**禁止蹲地捡东西、大幅弯腰、坐在箱子上、扛大型幕布、跳跃、抬腿、挥舞大型道具、夸张手势，以及脸或衣服被物品遮挡。** 人物主体始终竖立稳定并居中，便于后续对话演出使用；动作的趣味来自自然有辨识度的人体姿态，不是靠夸张职业表演。

三名人物的**身份差异必须写到完整的脸部结构层级**，不仅是发色与体型：轮廓（圆脸、窄鹅蛋、成熟长脸）、眼型（圆、杏、细长）、眉形与眉眼间距、鼻梁/鼻尖、唇形、肤色和肤质、头发长度与质地、身高及肩腰臀骨架。三人必须是独立的人，禁止共用面容模板；萝莉型必须一眼可辨明显幼态小个子，且正向词必须出现 `loli`，成熟型必须一眼可辨丰盈成熟成年人，同时不以表情或肢体动作表现随机性格。
