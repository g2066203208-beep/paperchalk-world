# CHAR-016 男二｜姐姐、天使金币与「绝境天使」正式剧情核心 V1

> 2026-11-08。**本轮用户确认**优先于早期泛化的角色文案。此为剧情与战斗演出规范，**不表示技能已经编码或动作资源已经完成**。外观沿用男二现有 CHAR-016 美术母版，不能因此改造脸、服装或身高。

## 1. 姐姐的交易和当代天使

- 男二当年陷入极端绝境。他的姐姐与天使交易，牺牲正常人生并成为天使，为弟弟换取脱困的机会。
- 男二希望姐姐回来，已成为天使的姐姐称无法做到；男二没有继续依靠向天使许愿，而是以自己的能力努力摆脱绝境，之后持续研究天使，目标是改变/反抗天使制度。
- **核心新规则：男二始终不许愿，因此天使不能完全取代姐姐。** 当代天使身上仍留有姐姐的一部分，故会对男二稍有偏向。天使怎样借男二许愿取得完整取代权限，属于后续要写出证据的世界规则，不能自创为已经完整解释。
- 男二将在主线中期与女主合作建立可运营的反天使组织；这是一条有经营、资源、人员、据点等玩法的势力发展线（细则待设计）。

## 2. 天使金币是什么

**用户确认**：金币用于**联系天使、实现愿望**，不是单纯等价货币或普通子弹。持有金币意味着男二拥有向天使祈求奇迹的选择，他一直拒绝为自己的绝境或换回姐姐而动用愿望；但在主线关键时刻会用精心设计的愿望漏洞反制天使，而非简单一生绝不许愿。

**已明确的区别**：绝杀**消耗一枚金币**，却**不向天使许愿**。把金币抛出并射击金币是拒绝交易的姿态。金币的具体消耗/回收如何在世界规则上实现，以及金币库封存女主灵魂的“盒子”是否与许愿金币相同，仍待具体规定；不能把一次绝杀写成无意间消耗人的灵魂。

## 3. 「绝境天使」绝杀（技能名暂用）

- **消耗**：1 枚天使金币（金币作为愿望媒介，但本技能不构成许愿）。
- **伤害方向**：男二 HP 越低，绝杀越强；**1 HP 为真正的绝杀**。精确公式、伤害上限、条件以及是否满足既有绝杀能量槽均待战斗数值设计。
- **第一段镜头**：男二拿起金币，以酷似向天使祈祷的手势凝视/握持，仿佛准备开口求愿。
- **第二段镜头**：他**坚定地把金币抛到一旁**，没有许愿，也不是把金币直接丢向敌人。
- **第三段镜头**：金币**仍在下落**时，他坚定地开枪击中金币。子弹与金币碰撞的位置成为向敌人延伸的攻击连线/轨迹中心。
- **真正含义**：即使在只剩 **1 HP** 的生死绝境中，即使眼前金币象征着**有机会换回姐姐的愿望**，男二仍然不向天使乞求，而是靠自己打出最后一枪。这是其人格、姐姐残存机制和技能威力三者统一的理由。
- **严禁**：让男二在绝杀中开口许愿、将金币直接投掷到敌人身上作为伤害、跳过下落中精准射击、把 1 HP 处理为纯粹伤害倍率而忽略人物信念。

## 4. 与女主和世界主线

- 女主 CHAR-001 通过 SAN 无畏特例（遇怪不掉、击杀上涨）及洞察敌人行动，具备挑战天使和里世界顶级敌人的独特潜力。
- 男二的姐姐被天使体系束缚，女二 CHAR-002 在女主死亡并失踪多年之后，会为救女主走上下一任天使的继任路线。**姐姐与女二是不同人物、不同时间段的天使继任关系，不可混同**。
- 男二不应该只是女主队伍中的“高伤害枪手”；他是让玩家中期就参与建设反天使组织的关键人物。

## 5. 待定（明确不冒充用户已确认）
