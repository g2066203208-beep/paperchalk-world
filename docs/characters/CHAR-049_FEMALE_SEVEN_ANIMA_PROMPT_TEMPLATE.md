## 使用本范本时必须保持的原则
- 范本成功点是：**现代游戏化服装、强轮廓、单人背面对敌、每个角色各不相同的自然预备动作和武器自然握持**；不是固定一个方向、统一摆拍或者统一下蹲。
- 原稿的武器、职业、人物性格、发色与服装属于 **示例内容**，新的角色必须独立原创；女7本身后续要求 **改脸、换武器**，并分别验收。
- 禁止再把 **一张背面战斗图** 偷换成正反双视图：`character sheet`、`two views`、`turnaround` 非用户指定时不要自行添加。

- 不要引导普遍深蹲、马步、固定弓步。允许人物个体自主重心与各异动作。
- Anima 当前有效风格 `@akipekostyle<lora:akipekoanima_v1_1:1>`；用户已验证原生2048×2048效果。采样参数保持用户现有已成功配置，不随意改sampler/CFG/steps。
