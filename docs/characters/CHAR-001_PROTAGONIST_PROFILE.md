## B. 现有正式造型：从正、背面观察得到的身份锚点

**正面标准图：** [protagonist-front.webp](../../site/assets/characters/protagonist-front.webp)；**背面标准图：** [protagonist-back.webp](../../site/assets/characters/protagonist-back.webp)。以下是“绘画保持一致”的**艺术描述**，不等于从照片精确测量人体。

| 部位 | 正式造型约束／绘画说明 |
|---|---|
| 整体风格 | 常规全身日系叙事游戏插画比例；平静细腻、不过度萌化；人物轮廓一眼可识别，避免 AI 生成感的繁复细碎描线 |
| 肤色 | 偏暖的浅肤色，面部自然少量血色；光源可改变明暗但不更改肤色身份 |
| 头型 | 偏窄的柔和椭圆头部；额头自然，下颌向小巧的下巴缓和收窄；颧骨不突出 |
| 额头与刘海 | 深黑色平顺长直发，刘海细束分区覆盖一部分额头，发束间露出细微间隙；不能改成齐头盔式齐刘海 |
| 发际线与发旋 | 原图未显示足够准确的头顶发旋；动画须顺着原有发丝分组，不发明明显呆毛 |
| 鬓发 | 正面两侧自然长束垂至上胸区域，长度和厚度不完全对称；背面主发尾至肩胛附近 |
| 发质 | 自然顺直、较柔顺但不是硬塑料；大块黑色发面加低对比冷灰棕高光，避免密集无意义细丝 |
| 标志发饰 | **角色本人左侧太阳穴附近两枚细长银白色斜置发夹**（正视时观众画面右侧）；左右不可弄反 |
| 眉形 | 深色、偏细、略平缓，眉峰很低；紧张时只作小幅抬压 |
| 眼形 | 水平方向偏长的杏眼，双眼间距自然，上眼皮略压低；不是大圆眼、猫眼或强烈挑眉 |
| 瞳色 | 低饱和深灰褐／深棕灰；瞳孔深色，少量克制高光；禁改为蓝、绿、紫等 |
| 鼻子 | 小鼻梁、鼻尖结构简约，鼻翼不夸张；保持正面既有鼻眼相对位置 |
| 嘴 | 小而平直，闭口为常态；微笑只轻轻改变嘴角，不使用夸张咧嘴 |
| 耳朵 | 大部分被发束遮挡；不得新加明显耳钉、耳坠、耳机 |
| 脖颈 | 自然偏细，衣领与颈根连接合理；头部俯仰不要让颈部橡皮拉伸 |
| 肩、手臂、手 | 肩线柔和自然下垂，手臂贴近躯干但留少量空隙；手指五指有结构而非画成套袖 |
| 躯干/骨盆 | 整体匀称偏纤细、无夸张曲线；腰胯的形体主要通过校服版型、自然重心体现 |
| 腿与脚 | 双腿比例自然，膝关节位置合理，站立双脚平稳；前后视图需保持腿长和鞋型一致 |
| 默认表情 | 平静、稍显疲倦、保留警觉；不是持续害羞、夸张大笑或故作冷酷 |

### 不可改动的识别组合

**黑色长直发 + 两枚角色左侧银色细发夹 + 灰褐细长杏眼 + 柔和窄椭圆脸 + 深蓝校服外套／酒红领带／灰色褶裙。** 少于这些识别元素时，不能保证仍是同一女主角。任何新画师都应先核对正反母版，再做动作变体。

## D. 服装结构与材质

| 模块 | 固定设计／生产注意 |
|---|---|
| 外套 | 极深海军蓝、略偏黑蓝的制服西装；清晰翻领、前排扣与口袋，肩线略贴合但不是紧身衣 |
| 衬衫 | 淡灰白色有领内搭；袖口、领缘不得在背面消失或错位 |
| 领带 | 暗酒红色窄领带，领结位置清楚，胸前自然下垂 |
| 半裙 | 中灰色百褶校服裙，褶距有秩序；旋转身体时褶片保持同一条腰线与实际遮挡关系 |
| 袜子 | 深灰近黑的短至中筒袜；正面、背面袜口高度一致 |
| 鞋 | 深棕至近黑、圆头、低跟的乐福鞋；鞋底贴地不漂浮 |
| 发夹 | 仅两枚细银色发夹，没有第三枚、蝴蝶结或夸张饰品 |
| 默认随身物 | 无。书包、钥匙、手机、雨伞等都是**场景／剧情状态**，不能永远画死在人身上 |
| 色彩处理 | 低饱和冷暖平衡；黑发、深制服和室内黑雾靠边缘光及层级分离，不依赖发光描边 |

**拆件建议（非现成 PSD 层）：** 后发、头颅、前刘海、左右鬓发、双发夹、眉/眼/口、脖颈、胸腔、骨盆、左右肩臂、左右手、外套领片与衣襟、领带、裙腰与裙摆、左右腿、袜子、鞋。原图如无足够遮挡背面像素，补画修复要独立存档并由用户批准，不能假称已切分完美。

## E. 性格、行为和内心世界（**全部是创作提案**）

**一句话人物核：** 外表看似平静的少女，习惯先确认事实、再决定自己是否要相信周围的人和正在发生的事。

| 维度 | 暂定提案 | 在游戏里的可观察表现 |
|---|---|---|
| 气质 | 安静内向、克制、稍带倦意 | 默认面部变化微小，话少但有反应 |
| 认知特点 | 注重细节，先观察再推断 | 会记住门是否反锁、声音从哪一侧传来、物体是否被移动 |
| 情感基线 | 不是冷漠，也不是天真；有戒备心但能关心他人 | 熟人靠近时肩膀放松；陌生人提问时先停顿 |
| 社交方式 | 不主动制造话题，回应简短、准确 | 常先问一句问题，再决定要不要进一步说明 |
| 优点 | 耐心、谨慎、观察敏锐、能保持基本行动能力 | 异常发生时先确认退路，而不是立刻大喊 |
| 缺点 | 容易独自消化压力，对不确定性反复思考 | 同一条不合理细节会在心里回放，影响判断 |
| 恐惧机制 | 主要害怕失去对环境的理解与控制，而不是“天生怕鬼” | 确认门缝变化或猫眼外异常时会短暂停住动作 |
| 防御方式 | 先沉默、保持空间距离、细查证据 | 听到敲门时不直接开门，也不无故攻击门外的人 |
| 幽默方式 | 极少的干冷自嘲或反问，不刻意搞笑 | 紧张过后才出现一两句带冷幽默的思考 |
| 亲密与信任 | 难以快速信任，但信任建立后比较可靠 | 判断 NPC 根据其长期行为而非一句话 |
| 冲突倾向 | 更偏避免正面冲突，必要时也能坚定拒绝 | 不强行赋予“软弱”“不敢说话”刻板标签 |
| 价值观 | 秩序、求真、保护重要的身边人 | 遇到证据冲突时愿意重新评估自己的第一判断 |
| 成长主题 | 从执着于让日常恢复原状，到逐渐敢于面对异常真相 | 由剧情揭示过程，绝不预写未获批准的重大秘密 |

**说话风格：** 语速中等偏慢，语尾轻，不把每句话都写成问号；信息量简洁但有观察。建议避免“啊啊啊”“呜呜”等重复拟声，恐怖感更多通过呼吸、停顿、视线和行动表达。

**自然小动作（动画提案）：** 听见异响视线先移、头略跟随；思考时眼睑轻垂、下颌略收；紧张时手指短暂蜷起但不总握拳；回到安全区域后慢慢松肩；默认呼吸是胸腔、肩带和发尾的极轻联合形变，不能突然大幅膨胀。

**台词节奏示例（非正式剧情）：**
- “刚才……门锁有响过吗？”
- “先别开门。我想再听一次。”
- “灯一直亮着，可我记得离开前关掉了。”
- “我需要确认的不是声音，是时间。”

## F. 动画、镜头与正背一致性

- **正面**服务人物对话/表情演示；**背面**作为探索场景中的实际主角图层。同一身体、衣服、发长和鞋底高度。
- 角色图层与房间背景分离；鼠标/陀螺仪主要驱动背景视差，人物不随背景一同剧烈翻转。
- 胸腔/肩膀呼吸建议保持“能感觉到而不明显夸张”的幅度；头发是软组织二级运动，西装结构偏硬，裙摆轻微滞后。
- 视线、眼皮、呼吸和小幅重心转移是情绪表现第一层；大动作必须由剧情触发。
- 新正侧背角度须先与当前母版对齐，而不是重生成随机脸；确保手臂关节可转，头颈处遮挡补画足够，任何分层修复不覆盖原始素材。
- 游戏中的角色切换应按人物 ID 加载，不给每个人另造“立绘场景”。

## H. 美术验收／新增角色去重

1. **先确认人物身份。** 新角色有独立社会角色和剧情功能时才分配 CHAR-002；同一主角的新表情/换装绝不重新编号。
2. **先对比全身轮廓。** 对比头发长度、发夹左右、脸颊形状、眼型与眼色、制服结构、鞋子。
3. **新人物必须不同。** 不得把 CHAR-001 的脸换个瞳色就当成新 NPC；从年龄段、头发结构、脸骨、职业服装和姿态多个维度设计差异。
4. **精度诚实。** “17岁、162cm、49kg、约7头身、肩宽35–37cm”是制作提案；无批准前全部可改。绝不把草案数值写成用户原话。
5. **锁定资源。** [正面](../../site/assets/characters/protagonist-front.webp)和[背面](../../site/assets/characters/protagonist-back.webp)未获授权不能覆盖、重绘或重新量化。
6. **存档与工程分离。** 档案更改只更新文档和 JSON；游戏的用户浏览器设置、现有场景、L2D 文件不随人物文案更动。
