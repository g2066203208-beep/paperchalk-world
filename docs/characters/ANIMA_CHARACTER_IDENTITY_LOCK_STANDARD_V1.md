# 《错位日常》｜Anima 角色定型提示词强制规范 V1.0
> 2026-11-04：用户明确要求以后所有角色的 Anima 提示词写死人物年龄、脸型、五官结构及坐标、身体尺度和比例，防止换人和随机体型。此规范属于**项目制作规则**，适用于今后的新角色、正背面、不同服装、动作与表情差分。新增标准不是自动修改已有已批准角色视觉母图。

## 一、全角色必须提供“定型锁”

每个人物有唯一 CHAR-ID，经过用户验收后锁定“已批准原画+结构约束+生成参数”。在原画未获批准之前，可提供**定型候选**，不得宣称尺寸已经被用户验收，不得伪造精确面部实测坐标。

**1. 身份和年龄**：唯一ID、职业、成年状态、年龄（准确岁数）、性别表达。
**2. 身高体重及头身比**：cm/kg、头身比、骨架与肉感、身材类别；同画布人物间需使用身高比例和镜头统一基准，不允许每人单独自由自动缩放造成错乱。
**3. 躯干与四肢尺寸**：肩宽、胸/腰/臀围、肩/腰/臀宽比、颈长、躯干长度、臂展、裆高/内侧腿长、上臂/前臂/手长度及围度、大腿/小腿/足长度及围度。每一项有获批设计数值或 unknown，不能用纯文本脑补测量。
**4. 头部骨相**：头宽、头长、额头比例、脸长宽比、颧骨宽度、下颌收窄走势、下颌角和下巴形态。脸型不能仅用漂亮/娃娃脸替代。
**5. 五官几何**：眼睛中心高度、双眼中心间距、单眼宽/高、眼头眼尾高度、眼尾倾角、眉眼距离、眉角、鼻根/鼻尖高度、鼻宽、鼻口距离、嘴中心/嘴宽、唇角倾斜、耳朵上下缘。采用统一0—1参考脸坐标，坐标只能经批准设计或获批母图测量，不能编造为“已确定”。
**6. 五官造型**：虹膜形状/直径、瞳孔与高光、上下眼睑及睫毛形态、眉形、鼻梁鼻尖、唇厚/牙齿/虎牙、默认开合程度。角色间需做对比，拒绝同脸。
**7. 头发**：发色和hex、发际线、刘海分缝及左右位置、侧发/后发层次、长短、质感、马尾/辫子数量与高度、发饰固定在哪边。正背侧必须同一识别符。
**8. 配色与标记**：虹膜、发色、肤色基调及服装默认调色板，左右脸痣/疤痕/雀斑等永久特征；写出准确左右定义（角色自身左/右，不和画面左右混用）。
**9. 自然体态与默认表情**：肩斜、骨盆倾斜、站立重心、行走特征、眼神、嘴角、常态眉型、主要情绪微表情。表情差分不得改变骨相与五官位置。
**10. 摄影机与画面配比**：视角（front/3-4/profile/back）、bodyYaw/headYaw、眼平相机、透视（正交近似/长焦弱透视）、固定画布分辨率、头顶/脚底留白、人物中心轴、脚底基线。镜头变换时不允许拿正面图随意镜像代替真实背面。
**11. 美术画风与技术参数**：Checkpoint版本、艺术风格标签、LoRA名称与权重、采样器、Steps、CFG、Shift、分辨率、Seed、VAE、控制网与参考适配器以及权重，确保版本可追踪。对本系列 Anima 当前指定画风：`<lora:akipekoanima_v1_1:1> @akipekostyle`，除非用户另行变更；不要强加已废弃角色参考 LoRA。
**12. 衣服、道具与L2D结构**：服装独立为**可替换模块**，换装不得重塑脸或身材；道具需沿用已批准部件形状。图层遮挡关系、双手和鞋子完整、髋/肩关节、后发与前发、裙摆与袖子都必须能按原图拆层，不可虚构已存在PSD层。

## 二、必须写死的不是只有数字

- **轮廓识别点**：侧脸鼻额线、发型远景剪影、肩宽与髋宽关系、衣服外轮廓；每角色有独特外形识别。
- **角色自己的左右侧**：不对称刘海/发夹/痣/伤疤/单侧虎牙、主手必须按人物自身左/右描述，背面画时自动做镜头换位，不能直接交换人物身体结构。
- **武器/道具母版**：同一武器必须参考已验收原图或透明部件，不让AI随意重设计形状、长度、材质、装饰、握持点。
- **表情基线**：中性/常态笑、开眼程度、嘴角位置和左右眉高度需保留；表情变化只改变表情相关部分。
- **服装模式**：服装专用段应明确替换位置，外形锁不混进服装。若用户用中文【在这里填写服装描述】，必须保留原样占位，不要偷偷补衣服。
- **负面提示词校验**：不得以`child / loli / mature woman / extra accessories / smile`等宽泛词与正向的成人小个子、发饰、特定坏笑相冲突；负面仅排除违反当前角色视觉锁的特征，避免删掉已确定识别点。

## 三、成品提示词结构（以后强制使用）

```text
[LoRA & STYLE LOCK], [QUALITY], [UNIQUE CHARACTER ID & AGE], [HEIGHT / WEIGHT / HEAD-TO-BODY / BODY GEOMETRY], [HEAD SHAPE & FACIAL LANDMARK DESIGN], [EYES / EYEBROWS / NOSE / MOUTH / EARS & COLOR], [HAIR GEOMETRY / LEFT-RIGHT FEATURES / PALETTE], [DEFAULT EXPRESSION], [POSTURE / CAMERA / CANVAS LOCK], 【在这里填写服装描述】, [HANDS / FEET / FULLBODY / L2D LAYERS], [REFERENCE CONSISTENCY]
```

- 一整段英文正向 Prompt；负向另提供一整段，便于直接粘贴。涉及换装时保留中文服装占位符，不把两段混为一个输入框。
- **固定不是胡乱堆积几十个无证据数字**：已经通过原画定稿的实测值和数值设计才硬锁；尚未确定的细分部位在档案里留 unknown，提示词只说可用的形态约束。
- 每个角色的结构优先读其 **512字段扩展档案** 的原始448个 face、measurements、anatomy、hair、visualProduction字段，不得在聊天里创造另一个同ID的相矛盾体型。
- **角色一致性最终来源：已批准母图** > 获批角色档案 > 用户当次修改 > 未批准AI提案。档案与母图冲突时应明确标注待重测，不强制无依据尺寸覆盖母图。

## 四、生成 / 复用流程

1. 新人物：先确定身份和上述核心形状候选，给出正向/负向 Prompt，生成多张候选脸+全身。
2. 用户选定正面母图；测量五官位置和人体画布占比，填写 512 字段档案，标记已批准部分，保存母图来源。
3. 正面、背面、侧面、换装与战斗：使用获批原图与参考/ControlNet约束，同样的模型画风和角色结构，不再凭纯文字随机生一个新人物。
4. 对每个成品检查：脸部坐标、身高比例、发束左右、眼色、服装分层、手指、鞋、脚底基线、武器遮挡；失败则局部重绘，不能直接接受。
5. 保留生成参数与固定Seed作为追溯信息，但Seed/Prompt**不能保证厘米与面部比精确一致**，不能冒充已验收角色基准。

## 2026-11-04｜Anima 每栏 512 words 上限及画风优先（用户修订）

- **用户明确修正：每个 Prompt 输入框最多 512 个英文单词（words），不是 512 个字符（characters）。** 采用按空格分隔的英文单词计数作为项目创作规范；这不等同于扩散模型 tokenizer 的 token 数，也不自动代表 Anima 官方硬限制。正负提示词分别核对用户界面的 word count，保留【在这里填写服装描述】，替换服装后再次校验；不是为了凑满 512 而机械堆词。
- **画风优先且唯一：** 优先保留 `@akipekostyle`、`<lora:akipekoanima_v1_1:1>` 与原本确认的 Anima checkpoint、VAE、sampler 等；不要另写大段 `visual novel art style / cinematic / realistic / painterly` 互相污染风格。
- **Tag优先：** 用简短低重复的 Danbooru/Gelbooru标签，体型`petite, short stature, short torso, short legs, skinny`；脸`baby face, round cheeks, tsurime, pink eyes, fang`；发型`asymmetrical fluffy pink twintails, ahoge`；动作`full body, front view, standing, both index fingers pressing own cheeks`。复杂固定人体数据留在人物档案，而不是长 Prompt。
- **多人物故障**用 `1girl, solo`，负面补`multiple girls, duplicate, collage, character sheet`；SD WebUI 的 Batch size/count 另检查。绝不把四视图、四宫格语义加入正向。
- **技术边界：** 提示词长度上限是用户当前工作流要求，不能冒充官方 Anima 模型硬限制；精确体态要参考图/结构控制，不能单靠多写数字做到。
- **服装换装：** 正向保留中文 `【在这里填写服装描述】`；换装优先原图Inpaint，禁止覆盖已验收人物母图。


## 2026-11-07｜官方 Anima Prompting 改写规则（覆盖此前『把具体厘米公斤写进 Prompt』的字面理解）
**角色数据库继续记录年龄、身高体重、比例及坐标，但这些是身份/场景量尺，不是必须原样输入扩散模型的有效图像标签。** 按 [CircleStone Labs 官方 Anima 模型卡](https://huggingface.co/circlestone-labs/Anima)，优先用 booru 风格小写标签（空格代替下划线，score_X除外）描述**可见的**脸型、眼睛、发型、体型、服装、表情和动作；多人左右位置、衣服扣子结构、人物相互关系则用简短完整自然语言英文句。不要在生成提示词填入 `158cm, 168cm, 52kg, 6.7 heads tall` 等试图精确指挥模型的测量数值，更不要塞入 `rumor spreader, recurring background actor, event reaction contract` 这类不可直接可视化内容。性格和人物故事仍存角色档案，而不是当画面Prompt。

官方 Base 30–50 Steps/CFG4–5、Turbo8–12 Steps/CFG1；首试单人1024²、三人组1536×1024均是工作建议，2048不是官方保证原生质量。项目风格提示词 `@akipekostyle` 及对应真实已安装 LoRA alias 必须保留。多图同身份由已验收母版/兼容参考模型/局部重绘控制，不能单靠种子和长Prompt保证。新人物严格定型原则仍然有效，只是数据记录精度不能被误当成 Anima 自然语言识别精度。三人组完整模板请见 [9套V2](../NPC-G001_ANIMA_PROMPTS_V2_OFFICIAL.md)。
