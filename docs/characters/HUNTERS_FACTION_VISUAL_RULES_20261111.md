# 第六阵营｜怪物猎人组织：美术与玩法方向（2026-11-11）

## 已确认的设计定位

- **组织性质：** 猎杀各种怪物与异常目标的专业猎人组织，**不是**专门克制吸血鬼或任何既有阵营的对位队。
- **气质：** 冷峻、肃杀、训练有素、危险、沉默、闻风丧胆；角色应体现真正的狩猎能力、经验和职业压迫感。
- **画风方向：** 深沉克制、锐利、实用主义；服装和装备有真实使用痕迹，人物神态、剪影、武器与行动姿势体现专业性。
- **参考方式：** 《血源诅咒》和黑死病鸟嘴医生**只作为冷峻、瘟疫年代职业危险性和令人不安的氛围参考**。**不采用统一哥特风，不强制鸟嘴面具，不把教会元素、十字架、礼帽、长风衣强塞给全员。**
- **人物范围：** 七位成年女性猎人，各自具有鲜明年龄感、体型、脸型、个性、装备与动作，不机械套用从娇小到丰满的固定队列。
- **基层例外（2026-11-12 最新确定）：** 上述七位是独立服装的高级成员；额外三名基础小兵必须分别为 **萝莉（`loli`）/ 少女 / 成熟丰满女性**，三人统一**古典黑色长大衣制服**，并保持不同独立的脸、身材、发型和克制自然的对话立绘动作。此前“不全员穿长风衣”仅针对七名高级猎人，不适用该基层制服。
- **游戏性：** 每位猎人的独立机制都应能在混编队伍中成立，不能只靠猎人队友触发，也不能只是换一把武器。

## 已讨论的七种玩法岗位（职业名与具体服装可继续优化）
1. 寻迹／战前调查、预判与弱点发现
2. 陷阱工程／环境布防与条件连锁
3. 赏金枪手／弹药选择与远程火力节奏
4. 钩索猎手／机动与目标位置控制
5. 巨兽屠夫／部位破坏、失衡与打断
6. 荒野医师／治疗、解毒、样本与材料利用
7. 传奇猎人／战术指挥、目标识破与团队追击

## Anima 生成时的检查
- 七名**高级猎人**已有独立原画，其历史生成约束不用于新增**基层三小兵**。新三小兵请先读 [2026-11-12 猎人三小兵正式完整提示词](HUNTER_MINIONS_ANIMA_CANON_20261112.md)：**萝莉型（正向明确写 `loli`）、少女型、成熟丰满型**；三人同款古典黑色长大衣，只换尺码，不写风格、画师标签或任何 LoRA，也不写 `safe`；负面仅用全项目通用六项。
- 每个人的**装备结构、姿态、武器轮廓、脸与身体比例、职业气质**有独特性，不是统一着装换发色。
- 不因猎人概念而强制增加鸟嘴、瘟疫面具、宗教徽章或哥特装饰。
- 具体的七人角色外观与提示词仍应在这个方向下重新设计，之前那套偏明亮冒险公会的提示词不作为最终美术方案。
