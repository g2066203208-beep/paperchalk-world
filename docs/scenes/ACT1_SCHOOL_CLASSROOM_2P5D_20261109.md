# 第一幕｜日常校园教室 2.5D 五面盒子实装（2026-11-09）

> **用途**：实际游戏内 `school` 场景，和 `classroom-box` 战斗测试房完全分离。自绘矢量材质和角色占位素材，**不是用户本地 Anima 模型生成物**。不覆盖已定的战斗透视和人物 L2D。
>
> **代码**：`site/game/school-room-2p5d.js`、`site/game/school-room-2p5d.css`；`site/index.html` 注册 `PaperWorldSchoolRoomRenderer`；`site/game/overworld-runtime.js` 在第一幕坠楼段落通过 `triggerFall()` 演出。

## 空间协议

- 长方体真实 3D 五面室内：宽 10m、长 9m、高 3.38m，前端面对黑板。
- 近处为教室后侧固定头部镜头，约 1.58m 眼高，67° 水平视角；鼠标只绕固定头部轻微环顾，上限约左右 4.9°，禁止 2D 整图旋转。
- 课桌 4 列 × 5 排，共 20 张桌子及 20 把椅子：**所有桌椅均为独立透明背景的 2D 立牌**，单独 PNG/SVG 等贴图可替换；每个道具由两个三角形组成一个竖直平面，基于真实 3D 世界坐标的透视投影及深度遮挡。绝不使用桌腿、桌板、椅背等立方体实体模型。讲台也为单张独立 2D 立牌。
- 教室仍然保留五面真实墙/地/顶，以保持空间透视和阴天窗外独立背景。右侧教室门为独立整墙贴图，左侧四窗可透出世界空间的窗外建筑。
- 2026-11-09 全纸片化：窗外天空和教学楼分别使用 `exterior-overcast-sky.svg`、`exterior-school-facade.svg` 两张正交 2D 贴图；坠楼人影使用透明 `falling-schoolgirl-silhouette.svg`，沿空间坐标向下移动。删除旧程序构造的实体色块和人形三角面，只保留每个物体的纹理平面、三维坐标、深度缓冲与镜头。
- 规范：除渲染用二维三角面（每个绘图矩形 2 个三角形）外不得建立有厚度的实体模型；未来桌椅、门、书柜、灯、道具、新怪物均先制作单独的二维贴图，再放入三维场景。
- 人物尺寸：场景必须读取每张原始立绘的自然像素宽高，计算实际 Alpha 可见边界，并据此建立世界空间的人物画片；**真实比例保持不变**，可见角色高度对应角色 `h`（身高），脚底触地。禁止把原素材强制塞进统一的 0.49:1 宽高比。参考已确认的环形战斗中 `soleY/crownY` 的做法。
- 镜头：从原先教室广角 67°、眼位 z=-1.45 改成人物尺度 54°、眼位 z=-0.90/y=1.25，允许部分天花板及近景课桌出画，以保证人物是画面的主体。
- 反应镜头：当第一幕坠楼段落进行到 `effect:'fall'` 时，在左窗旁的世界空间画出快速下降的人影；镜头**先目睹再向左转头**，不是屏幕贴图。平时保持日常教室状态，无预警恐怖 UI。
- 人物：位置与桌椅用相同 3D 深度、贴脚地面投影；普通 PNG 的不透明白底在 WebGL 中作极浅白色剔除。女神 Day 2 起不在课堂，小胖 Day 6 起不出现，保持故事世界变化。
- 缓存：静止时不重复绘制 WebGL 大场景；材质加载、日期、镜头角度改变或坠楼动画帧改变才重画；已有的流体黑雾独立继续运行。
- 无强制事件调查清单，课桌、聊天和住处调查仍由原表世界的点按交互触发；不改变既有公司业绩规则。

## 后续不得隐瞒的工作

- 此批材质是**已实装的可替换二维美术纹理**，不是用户指定的 Anima + LoRA 正式绘制。正式 Anima 的墙面、顶面、地板必须分别以正交无透视材质导入，避免双重透视。
- 小胖与班级女神人物仍是本轮临时矢量站姿，画风与游戏 L2D 角色库有差异；不能假装正式人物已出完。其他几位同学借用既有人物资产作为空间检查，不代表剧情设定或固定服装已审核。
- 暂无完整 3D 物理投影阴影、灯光烘焙、昼夜灯光自动变化等高级渲染功能；目前是 WebGL 世界空间立体几何、分面明暗、独立纹理的有效演出原型。
- 小胖家内景/教学楼走廊仍需正式 2.5D 美术重做；第一幕剧情存档与基本互动已接通。
- 截图和浏览器证据以 `tests/act-one-browser.mjs` 和 GitHub Actions `Act One Story Tests` 的真实状态为准，不能因代码提交就写成视觉已验收。

## 动态日光系统 · 2026-11-09

- 将游戏内 `snapshot.minute` 作为唯一的昼夜光照时钟，0–1440 分钟连续插值。日出约 05:55、明亮清晨、正午、傍晚金色时刻、日落约 18:25、蓝色暮光和夜间室内微弱灯光各有独立色温、环境亮度与天空颜色；游戏时间跳变时用 2.2 秒柔和过渡。
- WebGL 根据三维世界位置、太阳方向和左窗墙实际四组十六格透明玻璃位置投射变动的光斑，照亮墙、地板、人物和纸片桌椅；直接复用原透明 2D 道具的 Alpha 在地面投影影子，不生成任何实体模型，也不在原始画里烘焙光影。
- 截图验收可使用 `?storyCapture=1` 下的测试方法 `PaperWorldSchoolRoomRenderer.setLightingPreview(minute)`，正常玩家不可使用。自动测试生成日出、正午、日落和夜间 4 张实际 WebGL 场景图片。

- 表世界学校第 3 日起新增一次明确的场景交互「查看教室中央的异常」，不覆盖第一幕原有的上课、坠楼演出；还可通过 `?scene=school&bossPreview=1` 直接预览出生段落。
