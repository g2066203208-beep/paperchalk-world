## 锁定的画面语言
1. **清晰、有审美的二维角色立绘**，允许成熟的都市漫画气质，但不变成摄影写实、油画或高度Q版动漫。保持原始四人图的人体头身比例、全身构图、低透视变形。
2. **清晰、略带手绘起伏的深色线条**：轮廓与脸部线条有粗细层次；局部可用硬边色块，不能抹成柔光滤镜。
3. **克制的赛璐璐与块面阴影**：大块明暗结构塑造头发与校服褶皱，脸部阴影温和，表面不做塑料光泽、碎裂AI噪点、无限渐变与过量珠光。
4. **整体颜色稍低饱和但不灰脏**：深蓝/炭灰校服和酒红领带是学校的统一识别锚点；允许角色瞳孔/发色有个人差异，肤色与阴影保持真实自然。
5. **真正不同的脸**：每人从上脸宽度、下巴转折、眼睑、眉毛和鼻唇关系设计。禁止批量尖V脸、玻璃高光大眼、过度修饰奶油鼻、相同眼距、一样的偶像微笑。
6. **所有学生首张母版是同校校服**：同款深蓝校服、白衬衫、酒红领带、炭灰裤裙、黑鞋；不同人可有合理的卷袖、扣子与外套穿法，服饰表达性格。私人换装推迟；已认可四人穿法不修改。
7. **单人白底正面全身母版**：完整头发、双手与双脚，背景没有影子与道具，留足脚底和头顶空间。用于用户手动修整后See-through拆层，不强求生成器直接输出PSD。
8. **强调真面貌一致性**：若图像通过用户审核，以实际被认可原图为人物身份标准，正反面、表情、动作都不可换脸；所有未批准原图仅为候选，不能代替正式母版。

## Anima固定配置与提示词骨架
- 当前历史上选用的模型标签/LoRA：`@akipekostyle<lora:akipekoanima_v1_1:1>`。**固定在各角色提示词中**；没有经过实际测试与许可检查，不声称某一个sampler或LoRA版本的参数已锁定。
- 参考模型：[Anima（qasc/Anima）](https://huggingface.co/qasc/Anima)。官方模型是text-to-image扩散模型，**原生输出单幅图像而非可动画PSD图层或Live2D rig**。实际工作流生成单图后再拆分。
- 正向提示词原则：一个人、正面、完整全身、现有校服材料/配色、共同线条/色块光影；在角色段落里写**特定骨相、神态、发束、站姿、校服穿法**。正向不超过500英文词。
- 负向提示词原则：`multiple characters, reference sheet, split panels, generic influencer face, plastic skin, blurry, cropped feet, bad hands`；针对人物补入旧稿失败特征。单幅/多视角对照图不同模式不可混用。
- 具体模型设置（checkpoint、seed、CFG、steps、sampler、分辨率）需随正式每张原画与其PNG元数据真实记录；**不虚构已经复现成功的种子或参数**。
- 模型许可提醒：所查`qasc/Anima`页面展示non-commercial许可字样；如果本游戏计划商业发行，须先明确所用权重及LoRA实际授权，不能把此文档当作商用许可。

- 新要求：**可爱、俏皮、漂亮的女生，同时是假小子**；建议“可爱约70%，英气约30%”作为评审比喻，而非严格算法权重。
- 面相：略短偏圆的鹅蛋脸，轻微肉感颊部，柔软短下巴；琥珀茶棕色灵动杏眼、自然较浓平眉、调皮的嘴角笑意。明确女孩子的五官节奏，**不做小男生脸或普通男高中生**。
- 发型：有空气感的深栗棕短碎发，轻蓬松的局部发束与一处小翘发，刘海非规则锯齿，不是厚重油亮男生乱发。

- 姿态：轻松站姿，重心偏一腿，一只手搭外套，一手可插裤兜；不僵硬，不愤怒；保留完整身体和手指。
- **此阶段目标**：先出符合共同画风的正面全身图并由用户审核；再做后续拆层和动作。不会改动CHAR-001/002/003/016。

## 图片生产与See-through/Live2D边界
`Anima → 单人完整PNG → 人工美术审核并锁定图片与哈希 → See-through输出带补画的分层PSD → 手工校对遮挡/分件 → Live2D Cubism或现有专用角色编辑器绑定骨骼/网格与物理 → 游戏运行验收`。

See-through的论文与仓库注明可输出最多23个语义层与PSD，但**不是自动Live2D模型**；关节、网格、眨眼、头部侧转与衣服运动仍需进一步制作。不要把PSD文件存在视为动画完成。

## 版本与验收
- `STYLE_V1`只定义人物画面的统一识别规则，具体角色的美术母版是唯一真源。
- 未获用户确认的图片和提示词标记为`candidate`；不注册到生产游戏、不覆盖既有素材。
- 以后任何风格版本升级要写版本变更记录，保留能回滚的原画与提示词，严禁因“尝试新风格”批量重绘旧四人。
