## 1. 你的职责与游戏基本定位

扮演独立游戏的**游戏总监、首席关卡设计师、叙事导演、动画导演、玩法程序负责人、UI/UX 导演、音效设计师及质量工程师**。不是让你先写华丽宣传词，而是逐步交付可玩的、可测试的游戏。任何“已经完成”的说法均须附代码、测试和真实浏览器截图/录屏；禁止将静态概念图冒充实机。

这是一款具有经营与权力博弈深度的**扁平二次元场景交互游戏**。玩家主要通过真实场景、人物和物件交互，而不是铺满屏幕的 HTML 管理按钮、卡牌弹窗、纯文本选项和数字增长。

美术：原创二次元扁平图形，大块色面，细致角色轮廓，克制的炭黑/暖白/暗红/蓝灰及少量金色，突出人物性格、空间光线和丰富而整洁的商业世界；借鉴 Persona 5 的鲜明反馈、图形层级和及时响应，**不复制其字体、图标、界面、角色或美术素材**。正式的背景与角色以独立高质量分层素材为主，优先使用用户指定 GPTIMG 原创资产流程；SVG/几何色块只能作空间原型、碰撞热点和临时占位，不得冒称精品正式美术。

## 2. 不许改动的开局设定

- 主角和唯一兄弟阿凯在孤儿院长大，后来一起打工并住在阁楼里；这些是**开场前经历**，不要从孤儿院和打工开始游戏。
- 两人曾蒙面帮助旧港受欺压的工人和百姓，对付一个没有大家族背景、却长期压迫当地人的小头目/恶霸势力。他们因此在街头留下传奇，但**没人知道两人的真实身份**。真相、公众传闻、警方怀疑必须分别记录；人们只会谈论“两个蒙面人”，不会直接指认玩家。
- 启动资金来自此前一次事件的收益及后续对受害者的补偿安排，其中大部分已用于购买**第一间毛坯办公室**。开局只剩较少现金；办公室归属玩家，但地盘、商业楼宇和正式黑帮势力均为零。房间漏风，桌子旧，纸箱未拆，电灯故障，两个人相互打气。
- 开局镜头**直接落在刚买下的办公室**，第一章是“这里将成为帮助邻居的地方”；玩家可以选择未来权力手段，但**不能被强制成为敲诈平民的反派**。
- 架空港城的政府腐朽、失业和贫困严重。普通警察、工会、商贩、居民各有立场，不全坏也不全好；国家背景是社会矛盾的来源，不要为了单纯增加国家数据而做空洞战报。

## 4. 场景优先：五个真实可互动地点

当前代码已存在五处可探索地点（办公室、旧港背街、集市、就业所、码头），路径在 `site/scenes/explore.js`、`artwork.js`、`scene-dialogues.js`，不是从零开始。**先打磨五处场景的可信度，不得新增十个静态空地图充数**：

**办公室**：毛坯墙体、待拆纸箱、漏雨窗、旧木桌、电话、旧城区地图、文件、地契、账本、旧枪、台灯、兄弟阿凯；每件物品独立素材、实体热点和专属动作，视线镜头能轻微缩放/移焦。玩家能推动纸箱、拾起地契、展开地图、接听电话、把照片钉在墙图上、将卷宗递给阿凯。办公室会因真实资金支出逐步装修，家具持续保留位置与状态。

**背街**：居民出门倒垃圾、商户开门、行人聊天、流浪猫、街灯坏掉、雨棚滴水、讨薪海报、小混混冲突；玩家与兄弟可以一起上前沟通、旁观、找见证者、帮助修缮。事件由社会/治安模块触发，不是无限循环脚本。

**集市**：摊位开合、交易、顾客排队、拾取货物、讨价还价、巡查、摊主被欺负、下雨收摊。玩家帮街坊、谈第一份合约、处理实际纠纷，真实改变摊位和人物后续状态。

**就业所**：成年求职者排队、柜台登记、就业公告板、职员盖章、面谈、岗位介绍、薪资合约；人员自愿加入，不允许把儿童之家做成人员买卖系统。

**码头**：车辆、叉车/货箱、轮班工人、船笛、装卸安排、工会代表、路线及货运合同；派遣时货箱和车辆在现场可见，时间变化会产生不同作息与人群。

每个地点至少：3 个非纯装饰互动点、2 名有名字的角色、至少 2 条 NPC 移动/日程规律、1 个随时间/任务变化的环境状态、3 层环境声、1 个可追踪支线入口。不要在 UI 面板里一次性展示全部系统。

## 5. 镜头、场景转场与过场导演

设计并实现独立 `SceneDirector`、`CameraDirector`、`TransitionDirector`、`CutsceneTimeline`。不要把剧情、过场和经济规则混在 app.js。每一次过场有可跳过/快进功能，跳过后必须正确落地所有应执行的剧情状态，绝不能造成重复奖励。

必要转场（各有镜头语言）：
- 点击门 → 主角看向门 → 开门和鞋步音 → 镜头推近/街景擦入 → 下个区域，必须显示目的地的真实空间，不是黑屏换一张表。
- 出办公桌地图 → 手拿纸张 → 展开地图覆盖桌面但环境仍可见 → 路线用笔绘制 → 合上回桌面。
- 电话响 → 听筒震动/铃声/桌面局部镜头 → 玩家拿起听筒 → 来电者声音滤镜/气泡 → 结束放回。
- NPC 登场 → 门口出现影子 → 敲门 → 门开 → 角色走进镜头并转身 → 停住呼吸 → 举出报告 → 说话。
- 冲突演出 → 镜头快速切换两处角色位置、表情/姿态、现场人的反应、环境声和后果；**不要求写实暴力特写**。
- 时间/天气改变 → 太阳/夜灯/窗外车灯/行人/声音变化，不只右上角 DAY 数字变化。
- 任务成功/失败 → 通过现场状态、人物表情与后续消息反馈，不要简单满屏“+15声望”。

动效时间作为调优初值而非固定规范：按下响应 60–120ms，纸张拿起180–300ms，门镜头500–900ms，角色进入800–1400ms；有提前动作（anticipation）、惯性收尾（follow-through）、速度曲线，不允许所有对象同速平移；可在设置中降低运动效果。

## 6. 木偶角色动画系统

为正式角色建立独立分层 sprite/rig（head,hair,eyes,brows,mouth,torso,upperArm,forearm,hand,hips,upperLeg,lowerLeg,feet,heldProp）和 anchor/pivot 参数；所有素材由同一画风资产规范生成，角色之间共用动作协议但允许个性化权重。

`AnimatorController` 要支持 animation layers：locomotion / upperBody / face / gesture / prop / emotion。至少状态 idle_breath, blink, lookAround, turn, walk, stop, talk, listen, think, smile, worry, angry, sit, stand, reach, pickUp, handOver, doorEnter, doorExit, greet；带明确过渡、打断优先级、朝向翻转、手部物件附着和口型分组。玩家与 NPC **共用同一种动画能力接口**；不可 NPC 只会平移、玩家才有动作。

先做**阿凯**的真正站姿/转身/走路/拿文件/递文件/说话/离开一套可回放动画，再用通用 rig 扩展其他人；禁止用几个 CSS translate 和无限循环“左右滑行”声称已经完成骨骼动画。若正式要用 Spine/Rive/自定义 2D rig，先比较许可、包体、性能与当前网页兼容性，再选型，并交代实际软件与资产生产流程。

## 7. 丰富而自然的对话系统

实现 data-driven `DialogueRunner`，故事脚本和逻辑、表现解耦。每个对话节点具有：lineId、speaker、line、emotion、gesture、blocking/standingSpot、cameraShot、voiceCue、timing、choices、conditions、effects、next、interruptible、resumeStrategy、memoryTags、cooldown、localizationKey。

基本行为：
- 场景内气泡与角色位置关联，先发生目光/手势再说话，绝不固定屏幕底部放一条长文本。
- 可以询问、追问、拒绝、沉默、离开。重要节点允许插话；被中断之后恢复或自然结束，要保留必要剧情信息的补偿台词。
- 同一个人下次见到会记得上次说过什么，持续更换开场白，而不是无限重演第一页。
- 同一句话因阵营、信任、身份、消息来源、当天事件不同而换语气、表情和答复。
- 选项必须满足信息、资源、技能、关系或身份的前置条件；错误选择要有真实代价和继续玩的可能。
- 每个关键 NPC 设计目标、顾虑、秘密、社会关系、常用语气、声调、对他人的看法及6个以上情绪动作。
- 初期为阿凯、楼下婶婶、林姨、码头工友、就业所职员、失业工人至少各写3次不同日期的可追踪会面；每次有自然开场、2–4条不同意义的分支、至少一项会在以后体现的变化。通用路人不必全部拥有长剧情，但不能人人复读同一句话。
- 对话事件通过领域命令实现，不允许 UI 直接操纵世界权威状态。

## 8. 活着的居民与城市

NPC 数据：身份、家庭、工作、工资/经济压力、归属组织、性格、信任、欲望、健康和疲惫、已知事实、今天日程、当前位置、当前行动、目标与优先级、社交记忆。分开后台低频模拟和眼前场景高频表现，不要全城每帧高耗运算。

`ScheduleSystem` 驱动上班/通勤/休息/购物/交友，`UtilityAI` 处理饥饿、麻烦、帮助他人、避险等可解释行为，`NavigationSystem` 负责同场景路径、避让、转身、停步与门进出。`KnowledgeSystem` 控制可传播的谣言、玩家隐藏身份、目击者和警方认知；`EventDirector` 从领域事件安排可见的现场演出。人物需要走到真实位置才可交谈，不应玩家点击任何场景就全员瞬移/刷新。

性能目标：仅对镜头内 6–12 名 NPC 启用完整骨骼/寻路；其他居民按时段和位置低频更新。并不是说已经有真实80个人在城里走，必须提供模拟坐标、路径、时刻、冲突避让与跨场景传送的测试证据。

## 9. 可持续的完整玩法闭环

**短环（30–90秒）**：看到现场可见问题 → 与人说话/调查/真实物件操作 → 做出决定 → 人物回应或场景变化 → 获得新的线索/关系/资源。

**中环（5–15分钟）**：帮助居民/接单 → 安排人手/交通/合法服务 → 支付成本 → 其他派系和警方行动 → 通过日报、场景变化和来电得知后果 → 下一次目标。

**长环（1–3小时）**：街坊互助和合法店铺 → 招募成年成员 → 任命店长/队长 → 企业物流收入/员工薪酬/税费 → 派系谈判与争端 → 治安/人心/警方调查 → 城市权力关系改变。

**全局（目标20–35小时、约180游戏日，仍是策划目标而非已实现内容）**：从毛坯办公室→社区互助→自主产业和人事→与大家族对等交涉→政府改革/合法商业联合体/地下管理者的分支终局。任一日有2–5件首领级重要决定，不能逼玩家点几十次无意义按钮；岗位授权可以自动处理低价值事务。

各系统联动：平民求助⇄公开支持⇄收入和成本⇄企业税费⇄地方治安⇄警方证据和案件⇄派系冲突⇄人物忠诚⇄新闻传闻⇄访问场景。**正义和帮助邻居不能在经济上注定失败**，但仍应承担真实资源成本。暴力、腐败、非法业务有长期法律和民心代价，表现为抽象游戏机制，避免具体可复用的犯罪行动步骤。

## 10. 最重要的开场15分钟：必须先做成完全可玩的垂直切片

0:00–0:40：镜头从破窗/旧港远景滑入毛坯办公室；雨水滴落、搬运纸箱、阿凯擦桌和试灯。玩家点击地契，将其放到桌上，阿凯主动说“总算有地方落脚了”。无强制文字大屏。
0:40–2:00：阿凯谈前夜轰动街头的“两个蒙面人”，外面谣言相互矛盾，但他不暴露真实身份。玩家整理两件办公物品，并选定办公室第一件工作。
2:00–4:00：门外婶婶敲门。动画进门和交谈，讲市场商户被欺压的事，玩家可以答应帮忙/先调查/拒绝；皆有后果。
4:00–7:00：点门打开可折叠的城市实体地图，选择背街或集市，镜头切到真实场景，连续可见路人工作、闲聊、路口争执。
7:00–10:00：与林姨及街坊当面交谈，看破损摊位，与巡视人员核实情况；做一个有**场景内动作**的小任务（修摊、整理商品、送货/证据交付），而非点一下“援助+10”。
10:00–12:00：竞争小头目手下在远处出场，发生非强制的可视冲突/调解；不同选择影响现场人群情绪与下一日治安。
12:00–15:00：回办公室，阿凯把现场结果放到桌上；新闻刊登“蒙面人”不可靠流言，玩家用纸质地图标记明日事务、合法订单和街坊联络，保存可恢复全部状态。

每个节点列出脚本、角色、镜头、音效、动作、互动道具、条件、状态变化和失败分支；先交付完整可玩15分钟，再做更远的功能。

## 11. 工程架构：继续用现有仓库，遵守解耦

## 12. 音效和氛围：真正的空间反馈

五个场景分别建立独立音景：办公室（日常钟声、楼下叫卖、窗外风雨、脚步/文件）、集市（交易声/收摊声/推车/人群远近）、背街（车声/猫/脚步/争吵）、就业所（翻页/柜台/等待人群）、码头（海风/吊机/轮船/工友）。声音分 ambience/foley/UI/dialogue/music 总线，能在设置里分别调音，支持静音、自动暂停以及浏览器音频首次交互限制。

同样声音要根据物体材质、距离、视角、动作变化；不是用 `Oscillator` 做五个“滴滴”假装所有声音完成。使用原创或有明确授权的音效资产，给出来源授权记录。声音不能是关键剧情唯一提示，字幕和可视提醒必须同步。
