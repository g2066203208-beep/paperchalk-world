# 《错位日常》｜睡眠与夜间里世界进入规则 V1.0

> 2026-11-03。用户明确修订之前错误解释：**“不想进里世界就按时睡觉”**。用户此前说“就是要强制进入才有危机感”，实际含义应理解为**夜间处于清醒状态时进入不可自愿拒绝**，而不是所有人每天不论睡眠都自动召回。本文件为剧情与玩法规则草案，不代表代码已实现。

## 1. 已确认的主要玩法设定
- 白天是正常城市生活，能够上学、工作、交友、购物、做装备、休息、调查等。
- **22:00是里世界强制判定时刻**：若处于需受判定的人群中，且这时**没有按时入睡**，就必须进入里世界，不是自主点按钮或随机找门。
- **不想进里世界，就在22:00之前按时睡觉。** 玩家可以通过正常睡眠跳过当晚里世界，体验现实生活；不能描述为所有选中者每晚22点都无条件强制进入。
- 里世界的主要探索时间窗暂按**22:00至次日06:00**规划，六点归返；具体归返安全点、伤害和物品结算规则仍需最终确认。
- 里世界目标为**圆形分环结构，自外围逐步向中心推进**，设计参考《杀戮尖塔》的路线分支和决策机制（不得复制具体表现或数据）。建筑师为用户提出的中心Boss或核心存在方向，真正机制未定。
- 不是全世界每个人都进入；选中条件及各方势力、现实起源仍属待完善世界观，不要把以前AI提出的“失锚者”“现实校准机制”误写成用户确认世界真相。

## 2. 规则矩阵
| 状态 | 建议结果 | 确认等级 |
|---|---|---|
| 22:00前已正常睡着 | 安全睡过夜晚，次日06:00进入白天 | 用户确认的原则 |
| 22:00整仍清醒，且属于被选中者 | 强制转入里世界，不得拒绝 | 用户确认的原则 |
| 22:00以后才尝试睡 | 触发已发生，来不及 | 规则的直接推论 |
| 主动希望探索里世界 | 保持清醒直到22点，自动进入 | 玩法方案 |
| 入睡后在22:00—06:00中途醒来 | **建议**醒来后判定入里世界，以免利用凌晨闹钟绕过规则；需用户决定 | 尚未确定 |
| 白天睡觉 | 可休息，但不能用白天睡眠替代夜间判定条件 | 尚未确定 |
| 昏迷、麻醉、自然睡眠、睡眠药、失眠等特殊状态 | 需要定义是否存在安全睡眠资格及反作弊规则，避免强迫玩家药物滥用玩法 | 尚未确定 |

## 3. 游戏与叙事含义
1. 每日生活选择有真实代价。上学、工作、补给、强化、关系和治疗都占白天时间。
2. **睡觉是合法、有效的生存选项**，不是游戏失败、不是假的跳过按钮；不可以又暗中把睡着的玩家强制抓进去。
3. **探索里世界要承担放弃正常睡眠的风险与机会成本**；里世界成长、物资、线索、阶段目标、现实危机对玩家形成长期进入动机，具体经济/强化/时间推进机制尚待设计。
4. 外界重要组织、居民与其他选中者各自拥有日常生活与夜间决策。世界本身不是只围绕主角的学校运转。
5. 重要问题待世界观确定：里世界物品跨界、强化、怪物入侵、死后结算、早上返回位置、选择人的机制、睡眠为什么有效、世界起源与建筑师的角色。
6. **不要再提议“每天无条件强制进入，不论醒着还是睡着”**；该版本被用户修订。

## 4. 核心设计待确认
- 是否需在22点之前主动睡着一定时长，还是在21:59点击睡眠就能进入安全睡眠状态？
- 半夜因意外或被人叫醒是否进入？
- 若一天不进入，外界势力与里世界进度如何变化，确保睡觉可玩又不让长期探索失去价值？
- 门究竟是可见的物理通道，还是只在转移一瞬间显现？目前**不能**擅自确定为夜间随机开门、主动选择入口。
