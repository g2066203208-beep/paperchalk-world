# 《错位日常》｜睡眠与夜间里世界进入规则 V1.2

> 2026-11-03。用户明确修订之前错误解释：**“不想进里世界就按时睡觉”**。用户此前说“就是要强制进入才有危机感”，实际含义应理解为**夜间处于清醒状态时进入不可自愿拒绝**，而不是所有人每天不论睡眠都自动召回。本文件为剧情与玩法规则草案，不代表代码已实现。2026-11-03 用户追加**长期不进入里世界，怪物越积越多，最终溢出现实，使白天城市生活转为恐怖游戏**；这不是随意发生的追逐事件，而是本作主循环的真实长期后果。

## 1. 已确认的主要玩法设定
- 白天是正常城市生活，能够上学、工作、交友、购物、做装备、休息、调查等。
- **22:00是里世界强制判定时刻**：若处于需受判定的人群中，且这时**没有按时入睡**，就必须进入里世界，不是自主点按钮或随机找门。
- **不想进里世界，就在22:00之前按时睡觉。** 玩家可以通过正常睡眠跳过当晚里世界，体验现实生活；不能描述为所有选中者每晚22点都无条件强制进入。
- 里世界的主要探索时间窗暂按**22:00至次日06:00**规划，六点归返；具体归返安全点、伤害和物品结算规则仍需最终确认。
- 里世界目标为**圆形分环结构，自外围逐步向中心推进**，设计参考《杀戮尖塔》的路线分支和决策机制（不得复制具体表现或数据）。建筑师为用户提出的中心Boss或核心存在方向，真正机制未定。
- 不是全世界每个人都进入；选中条件及各方势力、现实起源仍属待完善世界观，不要把以前AI提出的“失锚者”“现实校准机制”误写成用户确认世界真相。

## 2. 核心新规则：里世界怪物堆积并溢出现实（用户明确确认）
- **里世界怪物不是每晚清零的临时敌人。** 即使玩家按时睡觉，里世界仍持续演化，怪物会积累。
- **长期不去清理里世界→怪物逐渐堆满→突破世界边界→进入现实。** 这会把白天的普通城市生活玩法逐渐推向真正的生存恐怖游戏。
- **睡觉的规则依然有效**：22:00之前睡着可避开当晚强制进入里世界；但不能使里世界怪物停止积累，也不能永久保证现实空间的安全。两种危险必须区分：夜间强制进入与怪物跨界入侵是不同事件。
- **不是主角不进一天就机械增加一格惩罚**：世界应独立运行。其他失锚者、组织、清剿行动和怪物本身的扩张，都可以使当地压力增加或降低。玩家缺席会失去直接干预机会，但世界不是只有主角在清怪。
- **里世界怪物入侵有可见的过程**：外环拥堵、边界异常、漏出少量怪物、多个现实地点沦为恐怖生存区域。阶段名称、数值阈值、入侵地点的实际规则仍为设计提案。
- **玩家需要真正承担选择后果，但不能无预警即死或产生不可挽回的软锁**：可设计信息预警、调查、救援、防御、夜间出击及付出较高代价的紧急恢复行动。
- **最终向圆心的长期目标**不仅是挑战建筑师，也要查明怪物为何持续累积、为什么世界边界会失效、是否能从源头解决溢出。建筑师本体动机、战斗阶段和结局未锁定。

## 3. 里世界压力系统（玩法数值均为提案，未获得用户审定）
建议把复杂度拆为**世界压力 GlobalPressure + 区域压力 LocalPressure[zone] + 巢穴数量 Nests[zone] + 现实突破等级 BreachStage[zone]**：
- 每夜里世界自主产生/迁入的怪物推动压力；正常NPC队伍的清剿、玩家战斗和封锁巢穴能降低部分压力。
- 外环区域比内环更容易接触现实，局部临界值溢出后，怪物进入与该区域关联的现实街区，形成可探索和可躲避的恐怖区域。
- 不同城市与势力拥有独立处理能力。大量地区受影响时引发全球新闻、经济、救援和社会秩序变化；不是一张地图上的怪量计数就简单决定全球结局。
- **睡过一晚应仍然可安全跳过当晚里世界**。玩家可以连续多天选择正常生活；随着局部危机增加，现实世界会开始发生异常，不强迫用户通过假睡眠转场进入里世界。
- 分期体验建议：A 正常生活有微小异常→B 夜里门缝与街区出现征兆→C 局部怪物跨界，玩家白天需调查、躲避及应急→D 封锁区扩大，城市变为危险的探索/生存地图→E 大型跨界灾变与势力冲突。阶段是否按日期或剧情触发、难度尺度和回复机制需平衡测试。
- 世界压力不会每天只按固定“玩家缺席次数”上升；应依据生态、敌人活动、各方清理实际成效计算，避免玩家被迫把每夜都打满。
- 防止重复刷外围成为唯一策略：临时清理可以降低溢出，但源头仍产生怪物；必须探索环内层，找到源头/建筑师规则，才可能长期稳定现实。

## 4. 世界隔离规则：超能力仅在里世界生效（用户明确确认）
- **现实世界没有可供人物使用的超能力。** 主角、其他失锚者、组织成员无论夜晚在里世界多强，返回现实都不能释放超自然技能。
- **里世界内部允许超自然能力、强化、异常战斗机制和卡牌技能效果**。这些能力不意味着现实中的人物拥有相同能力。
- **跨界效果不得混淆**：角色的实际知识、学习经验、伤口、疲劳以及普通物理技能可以在两个世界延续；超自然攻击、防护、治疗、飞行、传送、法术等，仅在里世界启用。普通物品能否带回、是否稳定及武器如何带回仍未定稿；即使带回了超自然遗物，在现实中也**不得激活超自然效果**。
- **现实怪物入侵仍成立**，但现实侧主角只能依靠普通人手段逃跑、躲藏、设置障碍、求助、使用现实装备与合理战术。怪物的跨界本身属于两个世界边界破裂事件，而不是任何人获得了魔法。
- **怪物在现实的表现边界**（是否只有实体物理威胁、特殊攻击是否失效、个别区域是否具有空间异常）需要进一步统一设定。默认设计原则：**不让现实常态变为超能力大乱斗**；恐怖感来自普通人在无超能力下遭遇不应出现的怪物。
- 不能把早先草案中「里世界强化直接在现实发动」当作正式规则。跨界掉落如果能带回，现实里应按普通物质、科研样品或非激活遗物处理，不能用于施法。

## 6. 游戏与叙事含义
1. 每日生活选择有真实代价。上学、工作、补给、强化、关系和治疗都占白天时间。
2. **睡觉是合法、有效的生存选项**，不是游戏失败、不是假的跳过按钮；不可以又暗中把睡着的玩家强制抓进去。
3. **探索里世界要承担放弃正常睡眠的风险与机会成本**；里世界成长、物资、线索、阶段目标、现实危机对玩家形成长期进入动机，具体经济/强化/时间推进机制尚待设计。
4. 外界重要组织、居民与其他选中者各自拥有日常生活与夜间决策。世界本身不是只围绕主角的学校运转。
5. 重要问题待世界观确定：里世界物品跨界、强化、怪物入侵、死后结算、早上返回位置、选择人的机制、睡眠为什么有效、世界起源与建筑师的角色。
6. **不要再提议“每天无条件强制进入，不论醒着还是睡着”**；该版本被用户修订。

## 7. 核心设计待确认
- 是否需在22点之前主动睡着一定时长，还是在21:59点击睡眠就能进入安全睡眠状态？
- 半夜因意外或被人叫醒是否进入？
- 其他探索者、组织与防卫行动应如何影响怪物总量？玩家若持续睡觉，现实的风险如何逐步变化、提供预警和恢复途径？
- 怪物跨界的具体物理规律、空间锚点与建筑师的关联，必须由后续世界观统一解释，而不是临时补充超自然借口。
- 门究竟是可见的物理通道，还是只在转移一瞬间显现？目前**不能**擅自确定为夜间随机开门、主动选择入口。
