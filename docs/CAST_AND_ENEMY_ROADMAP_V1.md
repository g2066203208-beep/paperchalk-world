# 《错位日常》角色、怪物与章节规模规划 V1.1 · 原创性修订
> 2026-11-02 · **全部为正式版制作规模提案，尚非已上线内容，也非已完成的人物原画。** 用户目前只批准了女主原画及女二中间裁剪图的基本可用外观；CHAR-003 男主人设完成但原画尚未验收。方案留有调整空间，不擅自注册不存在的游戏素材。

## 原创设计审核优先级

**用户新增硬性要求：绝不抄袭现有作品。** 当前下表15种怪的名称与一两句功能定义只是早期概念占位，**不代表已通过原创性审查，也不代表可以直接画或开发**。本项目禁止把别人有辨识度的怪物外形、面具、动作、桥段、能力设定或交互机制换一个名字就投入使用。

[**完整原创性守则与相似性审查表**](ORIGINALITY_AND_HORROR_IDENTITY.md)

具体开发时：先从《错位日常》已有的猫眼/门框/室内倾斜/固定黑雾、空间与记忆错位出发，构造独立的可验证游戏规则，再从规则设计身体、脸、动作、声音。旧表中“门外静立者”“借脸者”等过于常见的类型不得按现有描述直接定稿；**宁可重写或合并，也不为凑15种而复制套路**。

## 总目标与统计口径

**正式版目标：15名独立人类角色 + 15种独立怪物 = 30种需要独立视觉身份的主体。**

- 人类：3名核心人物 + 5名重要配角 + 7名剧情NPC = **15名**。
- 怪物：8种普通怪（MOB） + 4种精英怪（ELT） + 3位Boss（BOSS） = **15种**。
- 角色的正面、背面、衣服变化、表情差分、重复出现、幻象或L2D动作都是**同一身份的变体**，不重复计数。
- 精英与Boss的“多阶段”按同一怪物ID，额外动画/形态可以增加资源量，但**不新增怪物种类**。连续出现的小怪可重复使用同一模板，不搞换颜色凑数量。
- 五章主线为**创作建议**，场景（当前教室、卧室、客厅、玄关）已有基础资产并不意味着下列章节剧情、怪物或Boss已编入游戏。

### 下一位到底画谁

**先原创重设计 MOB-001 的异常规则、视觉剪影及猫眼互动原型（旧名“门外静立者”作废）**，再制作 CHAR-004 女三（沉默目击者）；原因是三个核心人物已有资料起点，而本作需要先确立能在猫眼和敲门互动中实现、能独立L2D动画的标志性怪物，不能一直增加普通校服同学。

女三不与女主、女二共用一张脸：建议**深茶短发、偏平直的绿灰眼、脸颊更少肉、谨慎的闭嘴表情**，保持同校校服制度，不在设计定稿前锁死其家人或能力。

### 怪物美术与机制规范

- **每种怪物都要有独立轮廓/步态/面部识别点/具体怪异规则**，不能只换黑雾、血色或增加阴影声称是新品种。
- 不采用传统刷怪消耗战、数百个血条、长期追击。**小怪=一次可观察的异常或低强度规避；精英=跨场景持续施压并要求识别规律；Boss=有独立演出和多个互动阶段的剧情节点。**
- 可以有危险、失败与恐怖反馈，但以“观察→判断→行动→后果”为核心循环；敌人的行为符合当场谜题规则。
- 人形怪物可以统一使用游戏 L2D 人物绘制/动画管线，支持眨眼、肢体、头发/衣料/怪异动作；低伏、扁平等非标准人形要有独立rig，**不能以一张静态图或黑色像素斑代替动画**。
- 现有黑雾是**画面效果层**而不是“敌人角色”，不能算小怪；背景场景里不默认摆放NPC私人物品。
- 怪物出场需要场景互动模块（猫眼、门锁、脚步、音源、视角、对话选择等）；当前场景自动注册器**并没有凭空实现这些剧情逻辑**。

| 章节 | 舞台 | 叙事重点 | 主要新怪物/高潮 |

## 实施优先级（先做可玩的，再补齐全量）

1. **核心验证切片**：3名核心人物的人设/至少一张可用母图，经过原创性审核的MOB-001新方案，玄关猫眼/敲门规则，1段可玩互动 + 失败/成功反馈。此时不要求制作15只怪。
2. **第一章可玩**：校园和已存在家庭场景串联，扩充4–5位常驻人物、2–3种普通怪、1种精英的完整互动。
3. **第一幕完成**：完成8名主要人类身份设计，8普通怪骨架/动作库、4精英设计和BOSS-001，再按剧情实际出场实现动画与逻辑。
4. **正式版迭代**：全部15名人类角色 + 15种怪物 + 5章内容与3个Boss，完成游戏内统一L2D、正/背一致性、长期试玩质量验收。

## 人物档案、怪物档案和资产的关系

- 人类唯一ID：`CHAR-001`～`CHAR-015`。此前女主、女二、男主仍引用各自已存在编号，**不创建重复女主或女二**。
- 怪物ID单独命名：`MOB-001`～`MOB-008`、`ELT-001`～`ELT-004`、`BOSS-001`～`BOSS-003`。全是规划编号，未注册游戏实体。
- **每位人类**复用已建的448项角色资料规范，来源分“已确认/候选/未知”，可将剧情不适用的信息标为不适用。**每只怪物**制作独立的“外观+来源+行为规则+交互+游戏状态+rig+音效”档案，不强行给没有人类背景的怪物编造生日三围。
- 新角色图（正反面/表情/拆层）必须经过用户认可才写入实际 `site/assets/characters/` 和游戏人物注册表；**计划数量不是已实现数量**。
