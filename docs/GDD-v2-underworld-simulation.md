# 夜港：黑帮帝国｜专业游戏设计总案（GDD V2）

日期：2026-10-28。状态：已定设计方案，**并非已实现的功能**。代码基线：main@59f0d037796044e56c108b9e3c6e00cd09fe416e。

## 一句话设计

玩家坐在扁平二次元风格的黑帮首领办公室里，通过实物地图、电话、文件、人员册、账本和访客管理一个独立运行的城市。他们只能获知下属报告的部分事实；竞争家族、普通商人、警察、记者和组织内部人员都会自主行动。

**区别于普通策略管理游戏：所有系统通过“老板收到的汇报与可触办公室物件”呈现；玩家做首领级别的决策，而不是亲自控制街头行动。**

### 艺术与叙事
原创架空工业港城“夜港”，建议采用统一的架空1990年代末—2000年代初工艺：纸质城市地图、固定电话、传真机、旧式电脑、纸质人事册、汽车和报纸。不得无故混用智能手机与禁酒时期生活方式。原创二次元人物，扁平剪影、奶油白/炭黑/暗红色块和金色点缀；参考 Persona 5 的高对比图形表达思想，但不得复制它的人物、素材、UI 版式或字体。影视参考《教父》（家族与继承）、《浴血黑帮》（灰色产业与政商扩张）、《无间道》（内鬼与不确定性），不照搬剧情和人物。

## 1. 当前代码真实现状

已完成：办公室原生SVG场景，桌面地图派遣、电话拨号、文件批示、账本、抽屉、旧枪检查、敲门与人物会面、街区访问、日结算、localStorage 存档与浏览器自动化测试。

重大缺口：仅四个街区与一组玩家影响力/压力；固定CREW名单（三人）；无真正敌人AI；无组织阶层与职务；无商店的供需经营；无独立的警察、案件、证据及司法；无卧底或情报可信度。当前 `engine.js` 为v4存档，`office-features.js`为v1独立桌面状态。后续必须兼容已有存档，不能静默重置。

## 2. 地图、地块、交通与势力格局

第一阶段：4 个大区 × 4 个小街区，共16地块（最终24—32）；玩家家族 + 四个对手 + 中立店主和市民社群 + 警察系统。

| 派系 | 核心地盘 | 合法基础 | 性格 | 自主追求 | 可被玩家利用的弱点 |
|---|---|---|---|---|---|
| 无名事务所（玩家） | 旧港边缘 | 小物流订单 | 由玩家选择 | 从零活下来 | 人手与资本稀缺 |
| 钟楼家族 | 中城、旧街 | 房产与娱乐场 | 守旧、讲身份 | 巩固权威 | 继承人与干部分裂 |
| 银帆联合 | 港口与工业区 | 仓储和运输贸易 | 契约导向 | 物流控制 | 信用与线路依赖 |
| 红隼会 | 夜生活区 | 夜场与服务业 | 急躁、好斗 | 高速扩张 | 内耗大、风险高 |
| 灰鸦同盟 | 分散节点 | 中介和咨询机构 | 谨慎、消息灵通 | 情报和调停利益 | 缺少地盘与资产 |

地图对每个地块记录 `ownerId, influenceByFaction, publicOpinion, policePresence, businesses, routes, intelVisibility`。必须区别：地盘控制权、各方影响力、企业产权、社会支持度不是一个变量。占有一家店不代表占有全街；一日影响+20不直接换色；占领和维护要付出人员、运营及关系成本。地图可切换“势力控制、企业分布、运输路线、警方辖区、情报可信度”五层，但始终保持实体纸质地图的视觉。

城市街道建模为图节点和边。可按实际相邻关系计算路线、时间、成本、风险、停靠顺序；地图手绘路线投影到实际 graph path。初期用 Dijkstra / A*，无需做物理化车辆或开放世界。情报未发现时不能显示敌方所有信息。

四个对手的 AI 必须拥有真实钱、人、店、经济计划、策略偏好、行动预算、情报可见性：每日自主投资、争取店主、扩张或撤退、签约、竞争和谈。**不允许AI无成本新增资源，更不能偷读玩家存档全部秘密。** AI 行动生成报纸线索、店主来电或情报汇报，玩家可以反制。

## 3. 人员、组织政治与职位

分开建模：
- **职级** rank：首领 → 副手（Underboss）与顾问（Consigliere） → 区域负责人（Capo） → 正式成员 → 外围合作伙伴。
- **岗位** job：店长、财务主管、业务主管、运输联络、情报员、法务顾问、区域管理员等。组织地位与工作职责不能混为一谈。
- **当前派遣** assignment：在哪个企业、哪个城区，正在做哪件事，何时能回办公室汇报。

人物档案包含 `personId, factionId, rank, job, superiorId, managementCapacity, skills, salary, loyalty, ambition, stress, familyNeeds, relationships, secrets, knowledge, status`；并非全部字段向玩家公开。招募来自长期关系与访客，不是无限雇佣池。每一位关键人物有稳定身份、外观、爱好、财务要求、社会关系、记忆和个人目标。

任命必须真实影响：一名组长最多监督N人，店长决定企业管理效率，副手能批量授权、财务主管能察觉账本异常；工资和待遇有预算成本。晋升会使被晋升者更满意，也可能让同级产生嫉妒，形成争议而不是随机背叛。下属可能请假、辞职、调任、要求独立经营、受伤或被拘捕；出现前应有充分迹象。

点击桌上的**皮革人员册**打开可翻页组织图和二次元人物资料，拖入任命书并盖章，关联员工名下店铺和路线。应在同一画面清楚看见“谁管谁”与“谁向我汇报”。

## 4. 主业 / 副业 / 表面生意与城市经济

必须区分真正盈利的合法业务和抽象的高风险地下业务，**合法公司不是一键降低风险的装饰品**。玩家可选择做运输公司、车行、饭店、夜场、贸易行、物业，合法业务按需求、供货、雇员、固定成本、客户口碑与竞争自主盈亏。灰色与地下业务按抽象游戏类别实现（例如不法赌局、黑市订单、灰色委托），更高利润但有额外证据、信任和公共声誉风险；不做现实可复用犯罪教程。

每家店状态：`id, streetId, ownerId, category, managerId, employees, demand, inputs, output, operatingCost, legalRevenue, undergroundRevenue, reputation, legitimacy, legalExposure, routeIds`。

**真实经济链**：订单 → 供应能力 → 道路/运输费 → 雇员排班 → 客户满意/口碑 → 企业盈亏 → 税务/法律责任 → 当日账本与次日汇报。玩家不能每次“拜访”“收款”都无中生有出现金。竞争家族也必须遵循同一链路。资产可出售、收购、合作经营；有利润、亏损、维护和违约风险。

做三种基础经营策略都可行：高利润高风险地下路线；稳定扩张的合法企业路线；通过联盟人情与情报获取控股和谈判优势的路线。资金账户可分现金、企业余额及地下收入等 **抽象游戏账目**，只展示经济/法律结果，不展示现实违法资金处理技巧。

## 5. 警方、司法、政治与舆论

将旧版单一 `heat` 降级为总体警务摘要，**警方必须独立存在**：至少两个分局，各有负责人、人员、巡逻资源、辖区、政策、案件积压和优先级；警方亦会调查其他家族和独立违法事件。警察之间有廉洁与利益冲突之分，不能默认人人收钱办事。

每起案件要有明确当事人、地点、事件、证据来源、调查机关和状态：`事件登记 → 获取线索 → 正式调查 → 证据审查 → 司法程序 → 处罚或撤案`。没有具体证据就不能因为全局数值超过阈值随机将一家公司抹掉；案件进展应可回放，并让玩家有法律咨询、申辩、合法经营调整、赔偿与整改等可选策略。

公众有居民满意度、商户信心和媒体报道：暴力事件损伤商业机会，正常经营和公益投入会影响长久支持。企业合法发展、城市治理变化、媒体与政治关系会与势力竞争交叉，但任何单一资源（例如政客好感）都不能无限豁免法律后果。

警方不是玩家的“敌对第五家族”，其目标是处理案件和公共安全。合法与地下组织之间灰度的空间来自人际冲突、规则、证据和制度，不来自超能力。

## 6. 情报与《无间道》式卧底

关键原则：**真相 state 与角色认知 knowledge 分开**。玩家在人员册看到的是报告，不能看到真实卧底标签。间谍、两面派、虚假线人、内部泄漏都从明确动机、关系网络和信息访问权衍生。

线索举例（仅为剧情）：只有三个人知道的货运会议，竞争者却提前出现；账本日期与回执矛盾；某成员在另一家族控制区被拍到。每条情报记录 `source, observedAt, target, confidence, access, possibleBias`；同一事实可因人物立场被误解。玩家用问话、审阅业务记录、交叉验证、调整授权或聘请内部审计人员查证。错误指控伤害忠诚与社会关系，合理调查也耗费时间。

验收要求：每起重要泄密至少两条可获得的证据、每条矛盾能追溯来源；同一个随机种子能复盘结果。不能单次随机抽奖生成不可验证叛徒。敌我都可能使用假消息，角色也可能是单纯犯错而非间谍。

## 7. 单日完整循环与叙事

每日分为：①办公室查看消息与访客 → ②玩家下达首领级指令（2—5项即可，避免点击疲劳）→ ③对手按自身情报与资源规划 → ④统一裁定行动与经济、路线冲突 → ⑤企业收入/维护/薪酬 → ⑥关系、忠诚、证据、警方进展 → ⑦生成日报、人物会面、电话与可看的新闻 → ⑧进入新一天。关键岗位可以自主处理日常重复事务，使玩家后期管理更大组织而不需要操作更多次。

三层架构：
1. **可信模拟状态层**：纯函数 `state + action + seed → nextState + domainEvents`；
2. **自主决策层**：每一方 Utility AI，小规模行动预算、只能用可见情报，受同一经济约束；
3. **演出与叙事层**：领域事件变成话音、文书、报纸、地图标记、角色立绘；不允许界面事件自己偷偷加钱。

次日汇报不应只是“货款+155”。必须包含相关人物、店铺、行动、对手干预及可能遗漏的信息，并可点击原始凭证核实。实现时既有规则结算，也有撰写良好的多种文风的事件模板。

## 8. 依然必须是“办公室游戏”而非换皮战略网页

办公室为常驻核心场景，玩家看到并点击**实际物件**：
- 地图：势力分界与交通路线、店铺分布、警方覆盖；
- 皮革人事册：组织树、人事档案、职务与分权；
- 电话：主动拨号、回电、联系家族/客户/律师/警方；
- 文件/印章：业务合同、内部争议、任命审批、账目、调查材料；
- 账本/保险抽屉：实际经营收支、现金周转、风险；
- 门/沙发：当面会谈、属下汇报、敌方谈判、陌生客人；
- 报纸/收音机：独立派系行动、社会舆论、警方事件；
- 旧枪/照片/纪念品：人物故事、收藏与部分决策，不能全是产钱按钮。

所有界面保持二次元扁平色块与人物差异化设计。文件盖在场景上时能看见办公室；地图是真正铺开的地图，路线可交互；角色不是只有一张立绘，还应有说话、紧张、犹豫、愤怒、离开等表情与动效。保证手机触屏可读性和高质量转场。

## 9. 首个“七日完整体验”作为真正的目标

不先一次做完50套系统，先做一套**有因果、有竞争、有危机**的7日垂直切片：

DAY1：阿凯带来第一份货运合同，银帆联合控制短途路线；玩家可绕行/交涉/不接单。  
DAY2：对手与商户签约，地图的归属/合同确实改变；阿凯回来报告真实运费与路线损耗。  
DAY3：玩家买入第一家运输小店；米娅出任店长，真实工资与利润出现。  
DAY4：钟楼家族主动提出合作；玩家看清哪些条款会损失自主经营权。  
DAY5：竞争者抢单，某人提出升职；职位安排改变次日公司运作。  
DAY6：一项物流纠纷引来警方调查，日报中有事件来源和部分证据。  
DAY7：局面有可验证分支：守住订单、被合约挤压、错怪自己人、与对手合作等。无需写死唯一结局；系统由状态决定。

初期规模：16地块、5派系、6个有名人物、2类完整业务、2种可任命职务、1条可追踪警方案件、1个可推理情报疑点。这些都必须互相影响，才有资格再扩充内容数量。

## 10. 技术架构与现有代码兼容

建议引入：
- `core/state.js`：单一版本号、schema、确定性seed、旧版v4+办公室v1迁移；
- `core/world.js`：地块、控制权与交通图；
- `core/factions.js`：各派系AI、外交和记忆；
- `core/people.js`：职级、职位、个人关系与权限；
- `core/business.js`：经营、订单和成本；
- `core/routes.js`：路线图、物流成本与边界；
- `core/police.js`：案件、证据与独立执法；
- `core/intel.js`：角色知识、消息来源和不确定性；
- `core/sim.js`：单一日结算与领域事件；
- `ui/*.js`：只演出领域结果，不自行改变世界数值。

开发策略是渐进迁移，现有 `site/engine.js`、`site/office-features.js` 首阶段保留兼容包装。旧存档保留现金、日数、组织成员、账目和报告，新增固定seed和AI默认初始势力，迁移必须幂等；不能悄悄将玩家进度清零。

推荐性能预算：初期16地块、5派系、约40—60个持久NPC及20—30个商业体。低重要性人口聚合模拟，重要角色和企业细算；每日推进目标桌面<150ms、低端手机<500ms（目标，非现已达标），静态办公室不必要重复绘制。剧情日志按ID去重，任何行动不能重复结算。

## 11. 工程里程碑与验收

| 阶段 | 实际交付 | 达标测试 |
|---|---|---|
| M0 数据架构 | V5单一状态、旧存档迁移、事件记录、统一结算 | 旧v4进度继续玩；同seed回放结果相同 |
| M1 多势力城市 | 16地块、5派系、各自现金与行动、初始地图归属、对手扩张/外交 | 放置30天AI自主变化但不瞬间吞城；每次地盘变化有对应行动事件 |
| M2 人事组织 | 人事册、真实招募、组长/经理、薪酬、忠诚和岗位权限 | 晋升后操作额度或绩效真的变化，降职/辞职可恢复 |
| M3 双轨经济 | 合法运输公司和夜场、订单、交通路线、地下业务抽象层、利润表 | 真实订单盈亏和库存闭合，竞争者抢单有经济后果 |
| M4 独立警察 | 两分局、一个案件全过程、证据链、律师与舆论 | 警方能调查非玩家对象；证据不足不能强制关键处罚 |
| M5 信息战 | 知识隔离、暗线、假情报/泄密、交叉查证 | 可复盘、有多个证据，错误指控造成社会成本 |
| M6 视听和内容 | 精品人物立绘/表情、场景动效、平衡、结局、操作与音效 | 真实截图/视频和至少30日游戏验证，手机横竖屏检查 |

PR实施顺序：**A状态/迁移 → B五方地图与对手AI → C人事与职位 → D合法生意与路线 → E警方案件 → F情报与剧情演出**。每个PR具备Node单元测试、100种seed×30天的模拟回归、电脑/手机真实Chromium测试，发布仅在CI通过后进行。另专门校验AI资金和产出守恒、权限越权、负现金、重复奖励、存档破损、地图不可达线路。

明确不做：单一影响力数字代替地盘、所有成员只有攻击/防御数值、公司仅是风险减免按钮、警察只在heat>阈值随机抓人、卧底纯随机无证据、把所有系统放成网页侧边栏、复制受版权保护的影视角色与其他游戏UI。

## 12. 制作人决策与下一次实际开发

**下一次应该先完成M0+M1的最小可玩部分**，而不是优先扩展枪械、小游戏或装饰道具。最低交付是：桌面地图打开后可看见五个势力瓜分16个地块；玩家结束一天后至少两个竞争家族会真实行动并消耗自己的资源；出现争夺或谈判事件及次日汇报；读档后格局不倒退。之后立即落地人事册与店铺经济，让“老板”的行为开始有层次。

验收时以实际运行和测试的结果说话；尚未实现的系统不得标为已完成。
