# 纸片纵深冒险｜章鱼托管入口升级 V1

游戏入口：https://g2066203208-beep.github.io/paperchalk-world/?scene=paper-ocean

沿用原 paper-ocean 场景、相同的 view/scene 结构和 github 托管链接；没有另起项目，没有改动其他恐怖游戏场景。原章鱼和海浪的图片依旧留在仓库。

## 已实现的纵深

六层顺序为：灯火村庄 → 村外原野 → 迷雾森林 → 荒废墓园 → 诅咒遗迹 → 深渊王座。每关前景向画面下方退出，后面的关卡上移、放大、接替。初始画面可以看见远处的最终 Boss，关卡之间没有黑屏场景切换。

技术上是六个独立 DOM 图片层和不同的非矩形遮罩，只有 2D 位移、缩放和透明度，不使用 3D 网格或透视。第一版使用之前生成的一张 1672×941 纵深场景原画，根据区域分割六层；后续可以给每层换成真正独立精修的透明 PNG，场景控制逻辑不用改变。

## 玩法接口与限制

当前只有关卡推进的可操作原型，并**没有实装真正的七人卡牌自动战斗**，所以右下角按钮明确标注“测试：本关完成”，模拟胜利后才能点击“继续深入”。全部六关通关后可以从村庄重新开始。

卡牌战斗引擎将来应在真正的关卡胜利事件中调用以下 API：

    window.PaperWorldPaperOceanRenderer.markCleared();
    window.PaperWorldPaperOceanRenderer.advance();

其中第二个方法应该在胜利结算界面的“继续深入”按钮触发。内部还向舞台派发 paper-depth-cleared 和 paper-depth-stagechange DOM 事件供玩法系统监听。

## 验收

从 site/ 目录启动本地 HTTP 服务器（端口 8765），然后运行 node tests/paper-ocean-stage-preview.mjs。测试检查一共 6 层、所有纹理加载、初始村庄、依次推进至 Boss、重开，并写出 1920×1080 的村庄与终点截图。

本次是实装的场景移动机制，不应将六个分层版的画面叫成六套各自重绘完毕的最终正式场景。
