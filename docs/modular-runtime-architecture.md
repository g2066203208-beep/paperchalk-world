# 夜港 / 模块化游戏运行框架 V0.1

> 设计与代码均在 `feature/modular-world-runtime`，属于实际可运行的**首个垂直功能架构**，绝非声称所有玩法完成。旧 `engine.js` 和 `office-features.js` 作为兼容适配器保留。

## 分层

- **core/runtime.js**：模块/依赖注入注册、拓扑序、纯命令分发、每日模拟 tick、确定性 seed 与事件日志。系统只能更新自己的 slice，跨系统通过上下文快照和领域事件，UI 无权任意加钱。
- **core/game.js**：装配公共 facade、旧 v4 与新世界持久层对齐、命令/每日结算桥接。
- **systems/factions.js**：五家族/16 地块/各自真实预算/每日行动、邻接扩张与控制权更迭。
- **systems/people.js**：七名角色初始对象、性格、士气、忠诚、职务、成长、训练和今日任务经验；岗位容量与重复任命规则。
- **systems/civic.js**：城市安全、公众心态、两处分局、带初步来源的案件、两个国家关系与战略紧张度背景值。
- **systems/dialogue.js**：可配置的有向对话节点和选择后果，记录对话与声望影响。
- **systems/news.js**：从派系、治安、国际背景领域事件生成夜港晚报，每篇保留 day、来源、可信参考值。
- **ui/world-panel.js + CSS**：办公室桌上的文件/地图扩页，真实 16 街区颜色、职务册、人物性格、报纸、公共安全、交谈。
- **presentation/stage.js + CSS**：浏览器原生音频合成、静音开关、NPC 木偶手臂/嘴部试验动作、对话气泡、翻页转场；只消费世界领域事件而不持有规则。
- **app.js**：原办公室入口桥接；新指令以 `effects` 承载经济变动，成功后与存档一起原子提交；旧的电话/抽屉/任务/来客继续能用。

## 当前确实实现

独立运转的家族与街区争夺；玩家在地图扩页主动建立街区关系（付真实现金）；组织成员任命与培训；每日新闻、情绪、安全与国家背景新闻；树状分支对话；简单演员木偶口部/手臂动效和可选的原生合成音效。

## 明确尚未实现

成熟企业、供应网络全链路、警方抓捕审判完整生命周期、民众个体调度、真实国家战争与前线、全人物骨骼IK及表情图集、广域NPC行走、复杂间谍知识隔离、商业成品级配音。这些各自以新系统/新演出适配器接入，而不是插进一个 switch 或巨型 App 组件。

## 测试

100 seeds × 30 world days 自动模拟，预算不透支、世界唯一控制权、确定性、旧存档迁移、人物任命独占、训练限次、对话后果、浏览器操作和截图。浏览器逐场景点击：打开报告卷宗 → 人事册任命/培养 → 16区地图 → 世界报纸 → 城市公报 → 对话 → 日结算 → 刷新仍保留状态。CI 先运行 `node --check` 所有 JS，再执行 Node tests，随后真实 Chromium 截图。测试未通过时**不能发布主站**。
