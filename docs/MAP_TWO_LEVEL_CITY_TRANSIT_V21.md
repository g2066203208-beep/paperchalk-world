# 地图分层与「地铁只做地铁」严格规范 V26

2026-11-08 两项不可违反的用户决策：

1. **城际地图与每一座城市的地铁图彻底分开**。点城市进入自己的地铁图；其他城市的线路绝不出现。缩放不能切换地图层。
2. **地铁只做地铁**。地铁线路图只允许显示：已注册的正式运营地铁线、地铁站名、换乘站、纯地铁的线路图例与路线预览。**不能**把市内巴士、有轨电车、公路、步行/林道接驳线、商店/学校/咖啡厅的场景图或普通调查地点标记成地铁线或地铁站。

## 游戏实现

- 一级「城际交通总图」：十城门户、城际铁路、城际公路/巴士及轮渡；无任何城市内部线路。点城市才进入其专属地铁页面。
- 二级「某市 · 地铁线路图」：使用城市 ID 精确隔离，仅真实地铁。当前霧浜市 `metro-graph.js` 已登记 **10 条地铁、170 座独立物理车站、19 座跨线换乘站、179 段可点击点阵轨道**。前两条「住宅线」「环城线」保留原有站点 ID 和站序；其他八条真实导入相同图模型。切忌在另外九城用 `world-atlas.js` 的 `LOCAL_TRANSIT_LINES` 伪造地铁：未登记运营地铁时显示「本市暂无已登记运营地铁」。
- 真实地铁站使用官方站名 `metro.STATIONS[id].label`（例如「学园前」），不能偷换成附近 POI 「学校」；画站点标签和图钉即可，世界地点照片留给未来单独的地点规划，不属于地铁图。
- 地铁线路只能由 `metro.LINES`、`metro.STATIONS`、`metro-map-geometry.js` 绘制。地下环城线拐角用简洁正交轨道，不要绕到天外再折回，也不可重叠回头画线。住宅线水平直达；环城线以真实站点顺序形成连续可双向乘车的闭环。禁止插入假的地铁站、额外南线或无效段。
- 点击地铁站使用 `metro.path(here,id)` 的**纯地铁**寻路和换乘，乘车入口使用原有 `onTravel` / `onBoard`。一般地图的目的地去回路线仍在 `destination-network.js` 独立保存，**不删除城市道路/公交数据**，只是地铁页不渲染它们。
- **黑色范围框禁止**：线路不是整幅图片；每段轨道为 SVG path 的实际笔划碰撞，按下只沿轨道高亮，不显示 path 外接矩形的浏览器焦点框。站点操作保留**点击处附近的悬浮菜单**，绝不改成固定面板。
- **密集点阵大图**：全部 170 站均是独立按钮，缩小时只显示不会碰撞的站名，放大后显示更多名称；站点不是大黑色照片卡片。
- 地图全域按钮仅当前层；显式「← 城际地图」返回。地铁页有清晰的真实线路颜色图例。电脑端、手机端同样禁止公交/步行或其他城混画。

## 验收

- `tests/world-map-browser.mjs`：真实 Chromium 点十座城市，区域图不泄露任何市内线；所有不具正式运营地铁数据的城市不出现虚假地铁，正确显示空状态；霧浜有 179 段真实 SVG 轨道、170 个独立站点，无公交、步道、旅游照片。
- `tests/transit-map-browser.mjs`：进入霧浜后检查 10 条正式运营线路、站名、真实站点及路线颜色，仍能从现有地铁线实际进入乘车演出。
- `tests/metro-map-geometry.test.cjs`：环线有真正的连续正交弯道、没有超远折返或轨道重叠。
- `tests/destination-network.test.cjs`：世界交通规划的数据保持双向可达，但不导入地铁专用视图。

之前 V21 文档允许在「城市内部交通图」混画市内公交、电车、步行接驳，这是**已经明确废弃的错误设计**。任何后续开发不得恢复。
