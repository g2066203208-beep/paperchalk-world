# 《夜港》逐日叙事与时间玩法 / 章节设计与验收

本轮实际开发：`feature/calendar-daily-story-chapter01`。目标让游戏拥有自主的日历、可到场参与的日常剧情，而不是弹出纯文本面板。

## 背景和开场
1998年9月7日开始。主角和阿凯在同一所孤儿院长大，后来住在打工的阁楼。匿名揭露恶债主马顺及其欠薪骗局后，街头开始流传“两个蒙面人”的传奇，却无人知道他们真实身份。故事从买下一间**毛坯办公室**的当天开始，只有190元、两个人、没有帮派地盘。

## 完整战役的设计目标（并非已经制作完成）
主线四章：DAY1—15《雨漏的屋顶》；DAY16—45《街巷的名字》；DAY46—105《钟楼下的协议》；DAY106—180《城的继承者》。预计20—35小时仅为长期目标，非当前内容量。第一周剧情为独立完整的“互助办公室是否成立”事件；后续第8—15天有可循环的独立社区支线，第二至四章尚未制作日常主线剧情，故不能宣称已有180天完整剧情。

## 本轮可玩玩法
- 实体办公室墙上的挂历可点击，显示日期、星期、当天活动、剧情期限、街坊支持与线索数；
- 场景中纸张型互动入口，仅在当前事件对应地点出现；主角直接前往背街、集市、旧厂就业所、码头、办公室进行真实场景事件；
- 每天有下午与晚间两项独立活动，两个不同地点和至少两个选择；选择决定街坊支持、证据线索、互助理念、物资、收入/支出，不可重复刷奖励；
- 活动推进钟表到黄昏/深夜；次日早晨恢复。玩家可以优先完成其他经营和人物交往，剧情可能因此错过，而世界仍然运转；
- 第7日是否成立“自愿互助办公室”，取决于前7天实际累计支持、证据和理念；失败仍可继续发展；
- 每日结束可留空闲活动，不强制通过接电话或派遣才能睡觉；
- 仍然保留原有办公室实体交互、人物木偶、城市行人/街区动画和经济系统。

## 工程分层
`systems/campaign.js` 全部日期、剧情选择、条件、剧情后果、章节结构；不访问 DOM。`scenes/explore.js` 仅在现有画面上挂载可点击的纸张与场景内对话；不重建走路NPC。`scenes/daily-story.css` 管理实体日历、日系扁平图形化日期、公告互动动画。旧 `systems/clock.js` 保留独立时间。`app.js` 只将剧情规则事件接到持久化/表现和合法资金变化，保证刷新后进度保留。

## 测试与限制
Node 测试完整推演7日14次活动，检查证据/支持与两种分支结果、重播行为、时间阶段与旧存档迁移。Playwright 使用真实浏览器点击“第一天开场 → 背街人物事件 → 集市人物事件 → 回办公室翻日历 → DAY2 → 刷新恢复”；包括390×844手机触屏截图。测试成功前只发布功能分支，不改正式主站。后续追加第一章 Day8—15 的独立人工剧情，以及多季人物故事、主角社会关系、昼夜场景差异和更生动的角色动作。
