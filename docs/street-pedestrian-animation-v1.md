# 夜港：连续进出场行人系统（已实现的首个垂直切片）
以最新 main 6ec6f0f 为基线，合并此前的边缘穿越修复与新的独立场景导演。

- pedestrian-routes.js：与世界人口/时段联动，居民有ID、双向场景外入口、街道纵深、停留点、商铺入口和出口。
- pedestrian-director.js：每帧真实推进坐标，跨越场景/进入店铺后移除角色再补充；对话时指定居民停步，结束后继续；镜头切换销毁并重建，普通对话不重建。
- pedestrian.css：扁平原创 SVG 木偶，四肢独立步态/摆臂，朝向和纵深缩放，闲聊气泡；手机竖屏专用镜头。
- artwork.js：固定 NPC 比例与活动路人更协调。
- 验证：59项节点规则测试、桌面 1440px 与手机 390px 的实际位移、出入场统计、停步对话、原办公室玩法完整回归。

本阶段尚不等于成熟开放世界 NPC AI：完整避障、进店后经营交互、精致美术素材、群体事件/争执和社会关系仍需后续单独开发。
