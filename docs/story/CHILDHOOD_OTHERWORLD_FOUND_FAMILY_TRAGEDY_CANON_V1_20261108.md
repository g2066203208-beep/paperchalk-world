# 《错位日常》｜女主童年里世界长期生存、故友异变与誓言：剧情核心 V1

> 记录 #012｜2026-11-08。**用户确认的是长期的本地生活与人际联系被摧毁、善良的朋友遭痛苦异变、女主含泪亲手杀死昔日同伴并决心对抗里世界的作恶者。** 事件具体幕后、怪物异变机制、时间长度、回归现实方式均未定。**禁止重用此前助手凭空制造的「返还契约、必须有人替换才能回家、抹除邻居」等设定。** 本文只含剧情规划，未实现游戏剧本/系统。

## 1. 用户已经提出并明确采用的童年核心

- 女主 CHAR-001 **小时候有很长一段里世界生活史**。不是短暂误入、仅一场战斗或当晚返家；长期建立当地生活、住处、居民友谊、共同经历和情感联系。
- 在这段经历中，玩家体验上的高位意识已经是**身经百战的强大存在**，有能力带领年幼女主经历险境、看穿敌人行动、协助她活下来。其来源为后来衡川假天使**第一次试启动失败**意外送其到女主童年，绝不是男二绕弯许愿启动完整版后送往童年。
- 经历长期共同生存，**年幼女主对高位意识形成绝境中的深刻信任**。女主并非无意识的傀儡，她会成长、学习独立行动和判断。
- 女主在里世界与**很多当地好人及朋友**建立深厚联系。她们生活的社区、居民之间的友谊与安全感是值得守护的真实生活，不要把里世界所有居民写成恶意怪物。
- **关键悲剧**：女主在里世界建立的本地人际关系和生活遭摧毁；原本善良的人遭受**痛苦的怪物化**；女主最终**含泪亲手杀掉变异后的曾经的朋友/并肩生活的伙伴**。这不是轻描淡写的怪物刷怪素材，而是玩家亲身认识过的人物。
- 这一创伤及真切愤怒让女主形成长期明确的对抗目标：**消灭导致此类灾难的里世界坏人、真正的幕后敌人和作恶机制**。不能直接偷换成「杀光里世界全部居民、否认所有原住民值得保护」；那会推翻女主珍惜当地友谊的根本动机。
- **女主的无畏和 SAN 规则仍成立**：她在战斗时面对怪物及精神污染不掉 SAN、有效击杀怪物可增 SAN（50～100），但不意味着她丧失悲伤、流泪、愤怒、内疚、爱与同情；**SAN 免疫 ≠ 情感麻木**。童年时期的具体技能成长与何时完全掌握该机制可另议。

## 2. 推荐的可玩剧情节奏（助手建议，未定稿）

### 第一幕：险境中的相识
- 小女孩误入/置身里世界（**具体诱因尚未决定**）。高位意识帮助她判断敌人行动、找到暂时安全的道路。
- 初期强调「高位存在战斗经验老到」与「女主年幼、技能未成熟」的协作对比，不用强行解释现实玩家。

### 第二幕：把里世界当作第二个家
- 长篇可玩生活与探索：居所、共同吃饭的居民、固定去的商铺、救援、探险、朋友之间的矛盾和和解。
- 重要 NPC 要有具体生活习惯、对女主不同的态度与成长事件，**不仅是为了被杀的炮灰**；让玩家主动投入感情。
- 给女主留下当地的物件、口头禅、习惯、共同经历。这些可在序幕的成年女主心理活动中不解释地出现，二周目/剧情揭露后才明白来源。

### 第三幕：当地联系遭摧毁
- 一场有责任主体的真实灾难（**幕后、动机、触发方式未定；不能自动写成任意新契约条款**）毁坏这段生活。
- 善良的居民在痛苦中逐渐异变、产生不可挽回的危险；女主及高位意识尝试辨认和救援。不要直接跳切成「所有朋友一瞬间无因变怪」。
- 正面展现有人没能救下、有人被迫撤退、有人可能尚存；**是否有幸存者及具体人数未定**。

### 第四幕：含泪与故友交手
- 战斗参与者是此前可玩章节中真正认识的朋友，外形/声音/动作保留可识别细节；变异过程使他们受苦。
- 女主不因「无畏」而机械无情；她含泪作出自己的选择，亲手击败被异变的故友，战斗后也没有轻松的胜利气氛。
- 玩家有战术能力可赢下战斗，但不能凭一次胜利恢复故友、消除本次灾难的事实；这不是对玩家能力的无意义削弱，而是从「打赢眼前的敌人」转向「查明并消灭制造敌人的幕后黑手」。

### 第五幕：立下目标、回归现实、慢慢失联
- 女主确定敌人是**恶意造成异变与破坏的具体势力/机制**，而非所有里世界居民。
- 之后她怎样回到现实、当地善良居民是否继续与她保持联系、初期如何隐瞒/诉说这段经历、和高位意识联系何时不稳，仍需设计；**不要未经批准设定「家被侵袭、父母死去、为了回家必须签替人受害的契约」**。
- 最终多年脱线、序幕重联时，女主早已是身经百战、有确定敌人目标的成年人；玩家首次玩游戏却还不知道这段共同生活史。

## 3. 下一轮最应该一起决定的剧情问题

1. **究竟是谁令好人痛苦变成怪物？** 应与已建立的天使制度、里世界深层势力、部分作恶者之间存在可调查的因果；但目前用户未确认责任方及方法。**不能另发明任意凭空生效的合同**。
2. **悲剧是突发屠杀还是渐进污染？** 这是场景、选择、角色死亡次序与玩家是否有救援空间的核心。
3. **女主亲手杀死哪些人？** 需要先设计足够鲜明、善良且各不相同的核心 NPC，并写他们各自的愿望与日常，再决定谁被变异，避免堆「一群好人死了」的扁平悲剧。
4. **为什么回到现实、怎么回去？** 与里世界的真实边界规则要一致，不添加随意交换人命条款。
5. **与女主的无畏和高位意识读心如何相容？** SAN 不掉不表示不会流泪，读到敌人的意图也不代表能够逆转生命和异变。
6. **这批童年 NPC 的历史与现在还有没有幸存者？** 这可以支撑主线重新寻找线索、揭露幕后责任，但幸存人数不宜现在擅定。

- 男主 CHAR-003 是衡川真实幕后老大，公开的衡川老头是替身，男主从一开始接近众人是为了研究/解析天使。
- 男二 CHAR-016 后期利用绕弯的真天使许愿骗局，突破衡川假天使**完整启动**的能力限制；此事**不同于第一次失败试启动送走高位意识**。
