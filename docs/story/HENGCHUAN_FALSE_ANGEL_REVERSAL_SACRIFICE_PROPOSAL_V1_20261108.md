# 《错位日常》｜衡川「假天使」时空倒转与女二牺牲：旧候选提案 V1（#008 已更正启动者）

> **更高优先级：记录 #011 区分两次假天使启动。第一次试启动失败意外把高位意识传回女主童年；后来在女主死亡失踪多年的悲剧线，才由男二绕弯欺骗真天使，使假天使的完整时空倒转能力突破限制。此稿早先把各阶段混为「首启夜」的描述与女二自己许愿启动均为旧助手提案，已被修正。**
>
> 共创日期：2026-11-08。**状态：用户提出新方向，核心牺牲机制属于助手提案、未经用户审定。** 本文件不表示已经实装假天使、时间倒流或剧情演出。不可把「为什么一定得牺牲女二」的解释私自升级成既成事实。

## 1. 用户当前明确提出的方向

- **时空倒转不是天使通过许愿直接完成**，而是**衡川研发的「假天使」真正负责执行**。
- **许愿的作用是获得假天使的启动条件/资格/授权**；并非「向天使许愿，天使直接把时空倒回去」。
- **待解的核心创作问题**：既然衡川假天使能倒转，为什么非要让女二牺牲？必须有一场具体事件和不能靠简单替身、补能源解决的真实抉择。
- 先前用户已设定：女主死于里世界后灵魂入金币库盒中，失踪多年；里世界入侵现实、天使公司公开招募、社会斗争多年；女二亲密好友救女主，女主只得到一次复活，女二走向下一任天使；男二姐姐成为现任天使，其残留在男二不许愿的条件下不会被完全取代；男二坚持不许愿。
- 衡川此前只是一家具有工程、物流、风控、技术研发与直属行动组等现实能力的**候选**集团，原文件未批准「假天使」能力。新增技术线不能倒写成已实装或过去已设定完毕。

## 2. 强推荐的剧情逻辑（待用户拍板）

**核心句：女二不是被当作“时间机器的燃料”，而是在主动启动假天使后，成为不得返回新时间线的“历史见证者”，承担所有被抹去岁月的因果；因此成为下一任天使。**

假天使可能复原旧世界的状态，但存在一个逻辑灾难：如果连触发它的历史、实验事故、女主被封存的记录也同步被重置，新的世界无法验证“复活的是谁、哪段记忆是真、谁阻止衡川将历史按公司利益重写”。

建议设置**时空见证/原始契约承接机制**：
1. 假天使是执行设施，不是独立道德主体。它可以重写/重构现实，但要从真实天使系统的**愿望通道**取得一次操作许可。**真实天使仅开通入口，不直接执行倒流**。
2. 启动还必须有一个**持续位于改写之外的主体**保存“旧世界确实发生过”的证据/因果及所选时间节点的身份连续性。这是**观测、身份、验证、决定改写权限**，不是无意义的献祭血量。
3. 任何人不必天生神选才能做见证者；代价是改写后不能以原来身份回到被恢复的人生，成为时间之外的持续契约执行者，**在社会被称为/正式成为「下一任天使」**。她是否接替男二姐姐同一席位、二者是否可并存，需要进一步严格设定。
4. 女二志愿承担：她与女主关系极好，在女主失踪的多年持续追查，掌握手机合影、失踪前线索与灵魂盒子等身份关联证据；因此在剧情中**有动机、调查能力及验证责任**。不能写成「她拥有特殊血统，所以只有她能」。
5. 真正的选择不是「牺牲一个人换所有人」，而是当衡川内部某派试图将这项技术用于**选择性改写受保护名单/排除异议者**时，女二夺回启动权，以整个世界都不被公司任意删改为目标，放弃自己的正常未来。
6. **旧未来女二留在历史之外**、成为下一任天使；被复原时代的**年轻女二仍可作为普通人生活**，与女主一起拥有当初的手机合影。她们是同一个人的两个时间阶段，而非新发明的平行替身。未来女二是否能接触自己、保留何种记忆、是否存在同一时间双重天使席位，均待定。

> 该方案的情感重点：女二付出的是「和挚友重新一起生活的权利」及「多年奋斗中形成的自我」，而不是一条随便献祭就能当燃料的生命。她主动选择让女主拥有自己无法再享有的未来。

## 3. 推荐的高潮事件：衡川「假天使」首启夜（全为提案）

- **时间**：女主在表世界失踪多年、里世界入侵严重、天使公司公开活动、社会历经多年战争之后。精确年份未定。
- **外部危机**：里世界侵蚀突破人类防线，政府、企业、清道夫和普通人开始失去最后几个安全区；衡川的假天使研发终于逼近可运行阶段。
- **人祸危机**：衡川部分主导者准备抢先启动，把「重写历史」变成企业控制世界存续权的手段；可用重置保全名单、抹除未授权见证和牺牲灾区记录来表现，不必把整个集团写成全员邪恶。
- **行动**：女二带着多年找到的女主灵魂盒子/定位资料，与坚持研究天使的男二及内外部合作人员，抵达衡川的真实装置/数据验证区，阻止公司垄断改写。
- **最残酷的一步**：男二仍能通过手里的愿望金币尝试申请许可，但**不会许愿**，因为他不愿让天使完全取代姐姐。女二不以「你来牺牲姐姐吧」要求他行动；她选择用**自己的愿望**取得假天使启动资格。
- **明确代价**：启动许可不代表时间已倒流。假天使还要求历史外的契约承接者。女二得知一旦成为见证者，她在新历史里将失去继续做人类、与女主共同度过未来的资格；她依旧选择留下，成为下一任天使。
- **转场**：旧未来的女二留在时间之外；假天使将女主灵魂与历史身份重新接合，重构过去。女主回到熟悉的卧室，手机上仍是二人的合影，年轻的女二依旧给她打电话催作业。观众初期只感受到普通温暖，后面才知道这张照片跨越了多年的代价。

## 4. 与男二姐姐/金币/反天使组织的连续性

- **男二“不许愿”与女二“许愿”不是谁更高尚的道德比赛**。他们都主动承担自己的选择，而真正对抗的是天使把亲情和生命变成可利用权限的制度。
- 姐姐是**当前天使残存的人格/身份**，男二不许愿使其无法被完全取代；女二是**未来的时间见证者/下一任天使候选**。两代/两种天使权柄的继承关系尚未批准；不能让女二启动假天使时顺手消灭男二姐姐。
- 反天使组织在女主回到可玩时间线后**主线中期才正式由她与男二共建并作为势力经营**。旧未来男二可以已有研究线索与少量盟友，但不能偷换成玩家已经建设完成的组织。
- **金币是向天使联系/许愿的媒介**；启动许可与许愿联系。假天使执行时间改写是另一套机制。男二绝杀消耗一枚金币却不许愿、1 HP 仍拒绝，这一信念保持不变。

## 5. 必须解决的硬逻辑（后续共创）

1. 假天使为什么必须保留一个历史外见证者？需要能在故事里看到的失控案例，而不是NPC口头说“规定必须献祭一个女孩”。
2. 「女二变成下一任天使」究竟是**真实天使的契约继承**，还是衡川假天使的终身操作者？若用户坚持前者，需要写出真正的接班链路，而不是把假天使改称真天使糊弄。
3. 真实天使为什么会同意启动许可？现任姐姐残留会不会帮助开启通道？男二拒绝许愿是否形成特殊防篡改条件？
4. 未来女二如何在旧时间线确认灵魂盒中正是女主（仅凭合影远远不够），为何必须回溯而不是把灵魂安置于多年后的身体？女主的旧身体与寿命、记忆连续性都需自洽。
5. 回溯到女主死亡前、原日常清晨，还是更早的时点？如何保留玩家技能/记忆而不破坏「一次复活」。
6. 如果无死亡硬闯序章直接通关，女二是否无需继任，世界危机是否解除？这是既有的高难奖励路线，应真实成立。
7. 如果将女二的许愿理解成对天使的**正式愿望交易**，她成为天使是一种债务/义务还是假天使的技术需要？二者可合一但不可在规则上自相矛盾。
