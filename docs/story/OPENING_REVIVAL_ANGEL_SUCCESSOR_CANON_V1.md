# 《错位日常》｜序章一次性复活与女二天使继任分支（V1.1）

> 修订：2026-11-08。**用户直接确认的主线规则**优先于同日旧版记录 #002 的错误解释。本文只锁定剧情方向，不代表网页已经实装分支。

## 1. 已确认，严格按此执行

1. **女主 CHAR-001 整段故事总共只有一次复活机会。** 不是每死一次就自动刷新复活；**第一次死亡消耗唯一复活**。已用掉后不能继续按该交易复活。
2. **女二 CHAR-002 与天使交易救了女主。** 这一次性复活来自女二的交易，而不是女主天生不死或可无限次回档。
3. **女主只要死亡过一次，就进入“女二成为下一任天使”的时间线。** 第一次死亡是该剧情分支的触发条件；女二成为下一任天使是这条时间线的关键走向。
4. **序章不是必死关卡。** 玩家可以坚持里世界冒险并尝试在第一次死亡之前直接通关；这条挑战路线极难，但不能被剧情杀、无限刷怪或强制失败偷换成必死。
5. **序章有人劝女主先返回现实世界准备。** 对方警告不在表世界准备而直接突破里世界的难度极高。劝说者具体身份、台词、劝说时点及回现实的操作机制，后续再定。
6. **现实世界准备的重要性**：常规推进以回到表世界继续生活、筹备并再挑战里世界为主要节奏；不在现实侧做准备仍坚持深入，属于高难挑战路径。
7. **不要把“进入女二成为天使的时间线”擅自解释为宇宙重置/时间旅行。** 现在确认的是分支条件及女二的对应命运，不是底层物理机制。

## 3. 必须防止的误读

- 错误：『每次死后复活一次、次数未知』。**正确：整个故事只有一次复活机会。**
- 错误：『第一次死亡永远强制发生，游戏从不存在无伤通关序章』。**正确：可以不死直接挑战通关，只是极难。**
- 错误：『女二无论玩家是否死亡都已经确认最终必定成为天使』。**正确：用户确认了女主**死过一次**后进入女二继任天使时间线；无死亡线路的女二终局尚待讨论。**
- 错误：『复活本质是回到过去』。**正确：时间线指故事分支，时空机制仍未定。**
