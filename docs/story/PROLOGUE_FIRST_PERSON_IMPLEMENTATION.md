# 序章｜第一人称演出规则与当前实现

更新于 2026-11-03。此文档覆盖同名文档前期关于“71 节拍 / 二选一 / 清扫名单 / 强行放大人物”的旧描述。

## 核心演出规则（最新用户反馈）

1. 整体严格保持**女主第一人称**：玩家就是女主视角。不能用第三人称镜头表现女主挥刀、背影或面部。
2. **未正式露面的角色必须用纯黑剪影演出**：角色已有 18 个真实 L2D 部件，仍需正常运动；只能给可见的最终人物画面施加黑化滤镜，保留原始 alpha 透明度和轮廓，不做方块黑遮罩、不改纹理、不改骨骼。
3. 只有明确的露脸事件（本例为灯重新亮起）才能从纯黑剪影变为正常贴图。揭晓前对白使用“？？？”，不能提前从文字透露发色或身份。
4. 不要擅自添加交互选项。用户否定此前的 71 句冗长对白、强行悬疑的清扫名单和菜单按钮；现在简化为 28 个短节拍的临时演出切片，仍**不等于正式定稿剧情**。
5. 镜头和人物尺寸必须继承 DEV 场景设置，不得在剧情 CSS 里强改 72% 高度等数值；女二始终位于前方“敌人区”景深槽，但剧情关系上不是敌人。
6. 未经新素材开发，不得声称已有真实怪物模型、完整走廊场景、可操作战斗机制、近战命中判定。

## 游戏代码

- `site/game/prologue.js`：当前 28 个短对话/环境音效节拍，人物在节拍 8 作为未知黑色剪影出现，节拍 16 的灯光事件后才揭露身份及原始 L2D。
- `site/game/prologue.css`：通用的 `data-identity-visibility="silhouette"` 属性适配所有 L2D actor；对 `[data-l2d-canvas]` 和动画 WebP 进行 `brightness(0) saturate(0)`，不触及底图、不破坏 alpha。
- `site/index.html`：沿用游戏已有的第一人称场景、黑雾、对话推进、AUTO/LOG；无“剧情选择”UI。使用新独立键 `paperchalk-prologue-v2`，不覆写旧 `paperchalk-prologue-v1`，更不会覆盖人物 IndexedDB。
- `site/dev/character-bridge.js`：临时以 `char-002` 的正面 ArtMesh 演出，只在运行中分配，不写入用户敌人区存档。
- `tests/test_prologue.js`：不产生菜单选项、黑剪影、揭晓节点、存档隔离等单元合同测试。
- `.github/workflows/l2d-modules.yml`：新增 Chromium 浏览器回归，验证未揭面时最终画布滤镜严格黑化，灯亮后恢复，女主背影不出现，无按钮选项。
