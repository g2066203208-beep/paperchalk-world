# 《错位日常》｜童年篇：双女孩失散、好人聚落、数月生存与毁灭逃亡 V1

> 2026-11-08｜共创记录 #015。**确认的主轴来自用户，章节节奏与回归方式是助手建议，尚未逐项定稿。** 本档只整理剧情规划，没有制作可玩地图、人物素材或游戏代码。

## 0. 不能再写错的核心

- 主人公童年不是独自走进一个空旷恐怖世界。**女二先被绑架/卷入里世界，两个女孩入界后失散**；女主独自寻找女二，玩家所对应、在主线未来已经身经百战的高位意识帮助年幼女主度过险境。
- **女二已经被里世界当地善良居民救起并保护起来**。女主经过千辛万苦终于寻到女二，玩家一同发现里世界并非处处恶人和怪物。
- **多年前里世界与现在的面貌、日常和危险格局不同**；旧聚落及其居民在现在时间线可能已经消失或遭毁。不是把目前敌人地图原样换贴图就当“过去”。
- 通往现实的入口不稳定，**没人知道下一次何时重开**。两女孩无奈长期与本地居民共同生活、生存、结交朋友，持续**数月量级**；不要硬塞此前助手凭空编造的「返还契约」或交换生命的出界条件。
- 经过足够漫长的平静日子，**突发灾难令聚落惨遭覆灭，很多原本善良的人痛苦异变为怪物**。女主含泪亲手击杀旧友，两个女孩在玩家协助下逃亡，与幕后真正作恶者结下深仇。
- 最后两个女孩**需要有合乎世界规则、可被前文铺垫的返回现实办法**，不能为了结尾突然发一张万能传送券。
- 女二长大后在序幕自然欢迎重联的神秘先生，鞠躬/尝试握手/道谢。这种信赖来自她也亲历过两人被保护的童年，而不是听传说。
- **两个假天使事件不可合并**：假天使**第一次试启动失败**把高位意识意外送至女孩童年；以后在女主死亡、金币库囚禁多年相关的悲剧线上，**完整能力启动**才涉及男二绕弯向真天使许愿突破限制。童年被拐误入另是一个物理入口事故，与这两次事件都不是同一事。

## 1. 分章节剧情骨架（场景、选项及具体 NPC 尚是助手建议）

### 第一章：分离
- 两个女孩本来从小一起长大。女二遭人贩子抓走，女主追去营救。人贩子在逃窜中误入现实与里世界错位的入口，两女孩也被卷入。
- **入界之后两女孩落在不同区域**。女二先被当地善良居民发现并收留；女主则必须自己追踪她的去向。分离原因可由具体入口空间结构解释，尚不把「入口自动挑选孩子」写成规则。
- 后世高位意识因衡川失败试启动而来到这个时点，帮助女主看穿敌人动作、选择通路、躲避危险。但无法代替孩子吃饭、承受伤痛或单方面瞬移救出女二。

### 第二章：寻找
- 女主和高位意识穿过残旧通道、危险街区、废弃设施；途中发现补给、救援标记与仍在经营的本地人类/异界居民设施。
- 重要的情感发现不是强行给女二绑架虐待戏，而是**最初以为女二已经落难，后来发现她一直被当地好人照料**。
- 两女孩重逢，女二第一次认真知道神秘先生是女主长期可以信赖的对象；她对“听不见的朋友”抱有一点好奇与郑重感谢。

### 第三章：长期生活
- 因两界入口重现时间不可预测、孩子们无法自行开门，她们不得不在里世界停留数月。
- 好心居民提供暂住与照料；孩子们不是坐等救援：两女孩帮忙、参与日常生产、委托/探险、整理庇护所、结交本地不同个性的 NPC。
- 玩家掌握强大战斗信息优势，但两个孩子身体年幼，只能通过观察、协作、武器技巧/隐匿逐步成长。女二应拥有自己的个性和贡献，不只是等待被救的道具。
- **至少先让几名本地人拥有足够真实的正面关系与非战斗日常**，后来异变才痛。具体角色人数、姓名与立绘不应在未审批前锁死。

### 第四章：异变前兆和聚落毁灭
- 原本能生活的社区遭受不明作恶势力制造的灾难，居民陆续/突然痛苦异变成怪物，建筑和生活秩序崩溃；具体始作俑者、感染/异变原理尚未决定。
- 女主先尝试保护或营救旧友，最终在逃亡中不得不含泪亲自杀死已异变的朋友。**不掉 SAN != 没有正常情感**。
- “聚落全灭”应表现为文明、家园和深厚关系的灾难性毁灭；是否有极少数幸存者尚未由用户明确指定，暂不胡乱挽救或取消全部死亡。
- 女主的仇恨有明确方向：**毁掉这个地方、把好人变成怪物的幕后坏人**，而非一概杀光里世界原住民。

### 第五章：逃离与未完成的誓言
- 逃亡不是突然开门：两女孩与聚落居民在前几个月**已经调查/积累过关于边界裂口、旧路线和重叠迹象的资料**。
- 到灾难时，玩家与两个孩子将这些旧线索用于寻找可能重新出现的**自然错位入口**，以此完成生存篇终局。路径不稳定且危险，不能保证随时抵达现实。
- 具体为何恰好在灾难末尾出现可通行窗口，必须和之前铺垫的入口不稳定机制及灾难触发条件建立因果，**绝对不能仅以「感情到位所以门开了」敷衍**。
- 最后两个女孩回到表世界，伤心但并非没有成长；她们记得神秘先生和过去的朋友、携带证物/身体习惯或共同约定，给成人主线留下可追查线索。女二后来的牺牲决心拥有儿时被女主与高位意识救过的个人基础。

## 2. 返回现实的两种合理候选（助手建议，未定）

**A｜优先：提前铺垫的物理边界窗口。** 里世界当地居民知道两界偶尔会再次重合，但不能预测准确日期，平时帮助孩子收集曾出现开口的路段、噪声、外界时钟/列车声等线索。危机时发现实际边界重叠的可验证迹象，按准备已久的路线冒险撤离。需要后续说明为什么其出现恰好与灾变相近：例如两者都受到同一轮两界边界变化影响；这仍是**提案**，不能写成魔法定律。

**B｜更硬的逃亡：救援/勘探人员在新重叠窗口短暂进入。** 现实侧有合乎现实机构能力的调查/救援人员在寻找失踪孩童的过程发现异常入口；消息通过可验证的线索传到本地，两个孩子带领玩家逃向窗口。具体跨界技术、通讯条件不得超越已确认世界规则，不能写成全天候便利传送。

两种方案都必须遵守：**不是凭空发明新的天使许愿/回归契约，不交换别人的命，不直接使用后世的假天使完整启动。**

## 3. 跟游戏世界规则尚待对齐的问题

1. **为何儿童一旦经错位入口实体进入便可长期滞留？** 既有 22:00 强制召回、06:00 返归的清道夫制度针对被选中者的夜间流程。此种实体错位入界是否是不同机制，需要明确，不可暗自假设女孩适用一般清道夫返归却又连续困数月。
2. **两个世界时间流速是否一致？** 用户确认两个女孩在里世界生活数月量级；现实是否也失踪数月、是否影响年龄/家属寻找与媒体记录，要共同决定。
3. **女二被居民救起之后是否能见到高位意识？** 她可能无法直接看见，但能从女主的心理回应和战斗合作判断其存在；序幕鞠躬握手可以保留亲切而含蓄的形式。
4. **古老聚落为何后来消失、敌人为什么毁灭它？** 必须有可靠的幕后势力与原因，不能只为催泪而随机杀全员。
5. **真正毁灭聚落的人同后期天使、里世界契约、建筑师等的关系**要保留悬念，不能现在擅定。
6. **数月可玩时间的节奏**：以事件推进+可重复生活玩法+适量时间跳转而非重复几百次吃饭睡觉，使玩家真的与好人形成关系。
7. **玩家时间闭环的时点**：第一次失败试启动发生在玩家主观游戏后段，意识被送入上述童年生存篇，并在越来越长的失联后，于序幕与成年女主重联；返抵失败实验后数日的方式与童年里世界回现实是不同问题。不可混同。

## 4. 语气与演出

- 前半暖：信赖、简单友谊、小小的生活胜利，女主很弱但不懦弱，女二有主动贡献，高位意识提供洞察与安全感。
- 后半冷：地理上还是同一条小路、同一张餐桌、同一间店，熟悉的人异变并发出熟悉的声音。女主哭，但必须作出抉择；不要打完庆祝。
- 重要道德边界：里世界本地居民不全是坏人，主角恨的是**制造异变的人和背后的作恶体系**。不得把所有 NPC 一律写成必杀敌人。
