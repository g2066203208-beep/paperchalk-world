## 六、编剧筛选方法

1. **不借用题材表皮**：怪物放在地铁或医院不等于已经写出故事；首先明确女主/女二/同学/老师/亲友之中谁受影响、该角色平时生活为何值得记住。
2. **SAN 故事不是一律“降到0就发狂”**：失真感知、错判、误信、羞耻、回避、依赖等机制可分别存在；SAN 概念与感染/替代/被天使交易不可无依据混成同一种超自然法则。
3. **故事类型应多元**：人性悲剧、家庭宗教、真伪身份、寄生、诅咒传播、现实空间、信息污染、民俗、宇宙法则、长期生存、社会崩溃各有不同恐怖感。
4. **主线案件要有残留后果**：人物关系、学校日常、手机聊天、同学态度、政府措施、势力战略、怪物分级与任务生态被改变。
5. **Ⅰ级怪物专门设计**：第一只“女主完全不知不觉被替代”的认知恐怖已列为重大后期事件，不要让前期普通怪谈轻率复制这个能力；它先把自身Ⅰ级伪作Ⅴ级，邀请时才亲手恢复Ⅰ级。此时的真实女主去向待定。
6. **先建参考库，不等于自动决定第二主线是老师寄生**：仍应由用户确认故事主题与中心人物，再编具体梗概。第一案小胖/女神是天使交易恐怖。
