# 霧浜市 · 真正的点连线地铁编辑器 V28

地铁地图只画地铁：没有整张线路图片、没有图片范围黑色矩形选框、没有固定乘车侧栏。正常游戏中点击轨道，仍然在点击处附近显示乘车方向选项。

## 线网与绘图

- 点阵：36 × 26 格，40 世界像素间距。车站与线路控制点全部严格使用整数格点坐标。
- 已有基线：10 条线路、170 个独立站、19 座换乘站、181 段相邻站轨道。环城线是可往返的真实闭环。
- 每个线段由实际起站、可编辑的有序圆角控制点、终站组成；轨道以 SVG path 连通，不使用贴图或矩形点击框。
- 两个格点不在一条水平/垂直线时，自动插入正交转折点；SVG 二次贝塞尔 Q 自动圆滑 90° 拐角。
- 一座换乘站只有一个物理站 ID，拖动它会同时带动所有所属线路的连接。
- 仅霧浜市编辑模式可用；不把其他城市、道路、公交、轻轨、普通调查 POI 混进地铁。

## 在游戏中怎么操作

进入地铁地图 → 点击霧浜市 → 顶部点击「编排」。

1. **选取**：点击任何彩色轨道选中；拖动车站圆点，更改站位并自动吸附格点。
2. **折点＋**：选中一段轨道后在该轨道或空白格点点一下，增加圆角控制点。金色折点可拖动；双击轨道也能添加控制点。
3. **站点＋**：选中一个真实轨道段后点击格点，把新站插进两座邻站之间；新站可拖动、重命名、删除。
4. **删除选中**：删除所选金色折点，或自己创建的新站。原来的 170 个剧情基础站点受保护。
5. **↶ ↷**：撤销、重做；桌面支持 Ctrl/Cmd+Z 与 Ctrl/Cmd+Y。
6. **保存**：当前蓝图草稿保存在此浏览器；点击「完成」离开编排模式时也会自动保存。再次进入继续修改。
7. **应用游戏**：确认后保存并重新加载页面；修改后的站序、站点位置、自动圆角和新车站正式进入**本机**可乘坐地铁网络。游戏存档保留，其他人的 GitHub Pages 尚不会受影响。
8. **导出 / 导入**：完整 JSON 保存/恢复各线路停站顺序、格点和全部有序圆角折点；导入前校验合法性。
9. **复原**：回到当前开始编辑时的基线蓝图，可撤销。

这些编辑控件仅在「编排」模式显示，**正常乘车模式的就地点选选项保留**。

## GitHub 与保存边界

- 本轮 GitHub 已保存代码、基线真实图、编辑器和自动化测试。
- 浏览器草稿使用 localStorage 键 paperchalk-kirihama-dot-metro-blueprint-v1，只保存当前用户的规划数据，**不会暗中修改全体玩家的正式运营线路或伪称同步 GitHub**。
- 导出的完整 JSON 蓝图可在审核连通、站名、换乘与剧情关键站 ID 后导入 GitHub 正式线路数据。
- 每站独立站厅/站台场景属于后续任务，本轮只制作地铁线网可视化编排。
