# V18 地点先行的交通地图：双向路线与照片站牌（2026-11-08）

## 用户确认的开发顺序
1. **先规划地点和交通线，不做任何大地图地形背景**。取消已擅加的海岸、山脉、森林、河流面片/贴图；保留原项目点阵网格与清楚的交通路线。
2. **交通网占据画面主体**，默认放大而不是为了塞下所有地点缩小整个地图。玩家用滚轮、双指和拖拽探索。
3. **每个地点都有真正的交通节点**：图片和名字组合成较大的卡片，底部用连接杆/圆钉准确连到相应的车站或道路上的站牌。若城市标签为了避免重叠被移开，绘制一条连接实际站点的引导线，不能随意漂浮。
4. **每个地点必须能去也能回来**：从实际当前位置到具体地点的全程有线路，包括市内道路与步道、真正的地铁、区域铁路和可用的城际公路／渡轮；不可只做到“城市中心”然后瞬移。
5. 站点图片与路线**使用相同的地理坐标**。对 `entrance/school/convenience/cafe/mall/park` 等已有地铁站的地点，以正式地铁几何坐标为准，不能沿用以前随意生成的城市相册坐标。

## 当前可验证规模
- [地点与城际档案](../site/game/world-atlas.js)：10 个城市，121 个实名地点（不生成虚假编号地铁站）。
- [具体地点交通网络](../site/game/destination-network.js)：40 条接驳道路/步道支路，加上真实市内交通、正式地铁与城际交通，合计 67 条连通路线，386 条有向边。
- 每个 `atlas.POIS` 点都在至少一条接驳线路上，每条边两向可走，城市转乘节点与城际铁路、巴士、高速公路、渡轮接通。Dijkstra 路由状态包含换乘线，去程返程对称。
- [显示交互](../site/game/transit-map-ui.js)：图片站牌在路线站点的物理节点，轨道和道路由一张 SVG 点阵投影；大图片并不是另造的大地图背景；照片只在可见时加载。
- [角色旅行状态](../site/game/daily-life-state.js)：区域地点以及城市交通枢纽都进入合法可到达地点表；进入/离开地点使用`destination-network.journey(from,to)` 的路线时间。全城地图仍尊重开放时间、能量、剧情限制等。
- [回归测试](../tests/destination-network.test.cjs)：121 地点都有去程、返程、各站点统一坐标、禁用被锁定的地铁线、没有额外地形背景。

## 重要区别
- `mode='access'` 是有图示的接驳道路与步行路线，并**非已开通的地铁或公交**。已实际开通的地铁使用原项目 `metro-graph.js`；市内交通依旧以 `LOCAL_TRANSIT_LINES` 原有名称为准；跨市主要依旧靠铁路、大巴和渡轮。
- 现存照片中有临时参考图、重复使用的类别图，它们是**地点参考**而不是已经正式绘制的独特场景，不得谎称每张地点图都已完成定稿。当前优先保证位置和可读性。
- 相同网格视图允许大幅平移、按层级缩放，不会一次展示121张大图互相遮挡。没有当前图片的站点仍有对应交通圆钉、可点击、可规划去回。
- 不更改 NPC 立绘与已批准人物档案；这个任务只负责地图与交通服务。
