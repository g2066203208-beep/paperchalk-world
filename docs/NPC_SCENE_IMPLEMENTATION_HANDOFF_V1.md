# NPC 实装分工与场景归属契约 V1 · 2026-11-08

## 双任务边界（禁止互相覆盖）
- **立绘/人物任务**：拥有角色设计、身份/情绪/换装素材、1024/2048 图片、透明抠图、模型/图片版本与人工验收记录。更新 [美术生产清单](../site/data/npc/production-manifest.v1.json)，只填写 `id`、`artApproved`、`production`、`sprites`、`geometry`。不得凭图片推断角色应该在哪，也不要直接改地铁渲染器或人物行程。
- **本游戏实装任务**：拥有 [场景归属](../site/data/npc/scene-assignments.v1.json)、[唯一身份日程](../site/game/npc-life-sim.js)、[逐场景准入](../site/game/npc-scene-presence.js)、[WebGL真实地铁演员](../site/game/ring-arena-runtime.js) 和 [2.5D校准](../site/game/metro-npc-staging.js)。不重画、不改人设、不擅自把待验图标记为批准。
- **正式显示的条件**：art`artApproved===true` 且 `production===true` + 场景归属表中有相同`id` + NPC 日程确实位于该处（或正在搭乘相同区间/线路/方向） + 对应场景存在经过校准的 2.5D 角色层。
- 图片路径、一个NPC编号或一句“地铁里要有人”**都不能单独触发刷出**。未批准素材永远不回滚为生效版本。

## 什么时候显示 NPC
- **学校**：只有同学/具有明确学校剧情身份、且人真的到校时；不要刷店员、上班族、陌生成人群，除非另有合理身份/访校故事。
- **便利店**：值班店员、正在购物且属于正确地点的顾客。不得把制服学生随机刷新成店员。
- **公园/商场/咖啡馆**：仅日程或事件调查路线抵达者；NPC-G001也必须是放假或放学后真实到达，不是“公共场景都刷新”。
- **地铁车厢**：必须实际处于 `leg.mode='metro'`，并与玩家 `lineId / station / direction` 全部一致；世界空间站位 `metroSlot` 由本任务指定，按米制真实相机与脚底锚点计算。
- **公交/城际铁路/乡村/海岸/异地**：没有相应行动路线或场景/交通模块时不显示；不能从城内地铁直接传送到其他城市。
- **家、卧室、厨房、玄关**：禁止随机公众 NPC；只有故事明确允许的人物和该时刻的事件可出现。
- **恐怖事故/流言**：先决定哪个 NPC 会被吸引，再查人物兴趣与是否来得及赶到，沿地图路线移动，最后选九大类对应情绪动作；不能靠情绪分类硬刷“当前场景的路人”。

## 运行结构与交接
1. 艺术任务把新演员 `id` 和已验收角色图提交到 GitHub，并在 `production-manifest.v1.json` 的 `records` 填写正确 `sprites.idle` 与动作版本。路径需 `./assets/characters/...`，以实际提交目录为准。**只会自动加载 artApproved=true 且 production=true 的记录。**
2. 游戏实装任务审核身份是否与既有 `CHAR-...` 或 `NPC-...` 冲突，然后在 `scene-assignments.v1.json` 添加该 **唯一人物** 的 `home`、`life.kind`、`life.interest`、`allowedLocations`、`allowedTransport`、`metroSlot`。职业工作地点填 `life.work`。
3. `npcLife.registerActors` 会把首次出现的身份加入持久化世界：**从家的实际节点出发、开始计时行进**，绝不因为用户进场或图片加载就立即传送到公共场所。
4. `npcPresence.forLocation(place)` / `forMetro({lineId,station,direction})` 双向交叉检查场景与日程，不合格则返回空名单。
5. 地铁当前有真正的 WebGL 2.5D 接入：`ring-arena-runtime.js` 以 `metro-npc-staging.js` 的真实米制脚底坐标、同一个相机矩阵、车厢灯/站台灯与纹理阴影绘制。**不使用CSS百分比人物贴图**，新图尚未提交时不会凭空生成。
6. 学校/商场/咖啡馆等**尚无逐场景完整的2.5D站位+遮挡校准层**；目前拥有**正确的场景资格与生活路线**，但不会拿一张插画直接粘到屏幕上冒充实装。每种场景需要自己固定的地面与摄像机标定后才能启用可视层。
