# 序幕场景方案：21:00，放学归途

状态：开发规划，2026-10-02。本文确定下一阶段的场景目标与实现顺序，城市场景尚未制作或上线。

## 已确定的方向

- 现代城市，晚上九点晚自习结束，主角从学校回家。
- 横版开放模拟世界，2.5D 纸艺舞台；角色主要左右移动，可停留、折返、查看与进入开放地点。
- 总体冷色、阴沉、有生活气息。夜晚强烈的蓝色冷光束是视觉重点。
- 延续薄立体彩纸与绘本分色。建筑、汽车、树木和街道设施采用有厚度的纸片，轮廓、折面与接触阴影表达体积。
- 光照系统同时规划清晨、黄昏的红紫气氛；序幕首次游玩固定从 21:00 开始。

## 建议的体验节奏

以“校园余温 → 商街喧闹 → 路口空旷 → 住宅安静 → 到家”组织空间和声音。首版建议约 3–5 分钟，包括简单观察和互动，纯步行时间更短。此时长为设计目标，需用实际步速与镜头宽度调整。

| 段落 | 场景与纸艺资产 | 光影重点 | 可玩内容 |
| --- | --- | --- | --- |
| 1. 校门口 | 有灯教室、教学楼、校门、围栏、保安亭、校园钟、少量离校学生 | 窗内淡暖光；楼缝斜切下来的强蓝光；栏杆切断光束 | 显示 21:00；短暂校铃与收书声后交还控制，学习走动与查看 |
| 2. 校外街段 | 文具店、便利店、自行车架、公交站牌、路沿和连续人行道 | 便利店冷白灯铺在人行道，雨棚形成清楚的遮光边界 | 查看店铺、与少量路人交互，建立日常生活氛围 |
| 3. 商业街主体 | 便利店、药店、小餐馆、关闭的店面，上方办公楼与住宅高楼 | 主打蓝冷路灯光柱；少量暖店窗；远处低饱和紫色广告光 | 可选商店入口或橱窗观察，沿主路自由前进和折返 |
| 4. 路口与公交站 | 柏油路、斑马线、信号灯、公交雨棚、轿车和少量经过的公交 | 最强的一组冷蓝斜光，车灯扫过地面，玻璃棚与立柱切出光束层次 | 观察车流和站牌，沿过街路线继续回家；车辆有明确让行规则 |
| 5. 住宅入口与家 | 收起的卷帘门、老住宅、门禁、楼道灯、信箱和少量亮窗 | 蓝灰暗部加窄冷光；家门附近保留小范围柔暖光 | 到门前交互进入；保存序幕进度，衔接后续内容 |

校名、街名、商铺名先使用项目内临时名称。下雨、剧情转折、异常事件不作为已确定设定；建议先用雨后微湿路面与薄雾建立气氛，持续降雨另行安排。现有角色立绘用于比例与交互占位，现代学生服装和书包作为单独角色资产任务。

## 街道空间与镜头

从镜头向远处分层：近景路牌/灯杆局部轮廓 → 马路与汽车 → 主角所在人行道 → 店面与校门 → 中景楼体 → 远景高楼和冷雾天空。

- 可走的人行道是一整条连续地面，路沿只产生小幅高度变化；路口与建筑入口明确连接。远处马路、侧街和地面延伸须覆盖相机可见范围。
- 汽车拥有独立交通路径。主角在人行道上，车流在马路上；交汇处以信号灯与让行处理，不能穿过人物、栏杆或店面。
- 近景设施适量用于框景和视差，经过角色时不能长期遮住头部、身体与交互提示。
- 高楼主要出现在第二、第三景深层；近景可裁出画框，远景保留完整天际线。用大小、明暗、雾和真实层距表达城市规模。
- 横屏镜头以接近平视、微俯视为基础，保留人行道与马路宽度；沿行进方向轻微提前看。竖屏保持角色和当前交互目标可见。
- 首版以连续街区为基础，不将每间店做成独立加载关卡。室内按入口切换小场景，外街状态保留。

## 色彩与表面

建议的颜色锚点，仅用于调色起点，最终以手机实画为准：

| 用途 | 色值 | 用法 |
| --- | --- | --- |
| 天空和最深暗部 | #101827 / #182437 | 保持轮廓可分辨，避免大面积纯黑 |
| 建筑纸色 | #33465C / #56667B | 低饱和蓝灰，少量灰紫立面 |
| 马路、人行道 | #273342 / #677487 | 路沿与标线提供行走边界 |
| 强冷光 | #8DBFFF | 主要光束、薄切边与局部落地亮区 |
| 次要紫光 | #8C79AD | 背景和局部广告反射，控制面积 |
| 有人店窗与家门 | #E0B77C | 小范围的生活温度与方向引导 |

纸面保持哑光，粗糙颗粒和强凹凸不进入主视觉。轻微纸纹留在近距离可见层级。微湿路面使用限定区域、拉长且不完整的灯光倒影，维持纸面色块，不把街道改成镜面塑料。纸板切边采用被环境光染色的冷灰边，瓦楞结构只在真正暴露的断面和镜头能看到的前沿出现。

## 光照系统的实质升级

当前事实：`createPaperScene.js` 的 night 预设为 time=0，即现有日时定义中的午夜；21:00 对应 0.875。`volumetrics.js` 只支持太阳/月亮两个方向光。介质集中在 z=-6.6 附近、宽度参数 1.7，低雾在 y=4.5 以上消失，前景空气权重只有 0.035。这套森林分布无法直接承担城市楼缝、路灯和车灯光束。夜间环境补光较强，也降低了明暗对比。

下一阶段分四类光源：

1. **城市冷色主光。** 从楼宇间斜射入画，设计成数束有间隔的蓝冷光，照亮纸边和局部街面。主方向光与物体投影共享方向和遮挡依据。21:00 的艺术光向允许单独设置，不要求依赖当前钟面轨道。
2. **局部路灯。** 新增有距离衰减、锥角与遮挡的局部体积光。近镜头优先处理 1–2 盏主路灯；雨棚、立柱和建筑遮住的区域必须中断光束。灯罩发亮、地面照明、空气中的光锥各自控制。
3. **店窗与招牌。** 主要用绘制的发光区域和有限范围的地面/墙面染色。只有对构图重要的店铺承担局部体积光，窗户数量不等于实时灯数量。高亮不覆盖文字与纸面插画。
4. **车辆灯。** 车灯随车辆移动；近车使用简化的局部光锥和地面亮区，远车只保留灯形与弱光晕。与建筑相交时裁切，不允许光束直接穿墙。

体积雾改为可配置的城市分区：楼缝、路灯周围、路口和远景各有介质范围。抑制无光暗区的全屏散射，保留灯间的暗部。先降低过平的夜间补光，再提升局部光束能量；保持人物脸部、路沿和交互对象的可读性。Bloom 只润色最亮光源边缘，光束由实际体积采样和遮挡产生。

实现时扩展同一体积积分器，优先限制为一个主方向光和最多两个近景聚光灯；夜间跳过无贡献的太阳采样。合成需要包含介质透射率，避免只向原画面不断叠加颜色。保留现有深度边缘重建，不能为存透射率直接覆盖仍被读取的距离通道。纸片透明轮廓要参与正确的阴影裁切。当前不支持 HDR 的设备会关闭体积光与 AO，后续需提供经过遮挡裁切的简化光束降级方案，并在设备诊断中明确标记，不能宣称与完整体积积分相同。

清晨与黄昏使用独立调色：清晨为蓝紫暗部、玫红低角度光与局部浅暖边缘；黄昏为灰紫环境、红紫逆光与少量橙红落地亮区。天空、环境填充、物体主光与体积散射分别调色。首个序幕夜景不会因自动昼夜循环变成白天；晨昏在同一测试街段单独验收。

## 资产和性能组织

- 建筑按立面、招牌、雨棚、窄侧边组合薄纸轮廓。窗格、砖缝、店内陈列和大多数装饰绘入共享图集。
- 汽车使用侧面纸片加窄厚边，可动轮子和灯光独立；转弯需要相应角度资产，不能直接旋转侧面图当完整车模。
- 护栏、灯杆、自行车与候车亭使用少量薄片；远景楼群合并成较大轮廓纸层。
- 按街段组织可见性、交通、行人和局部灯；屏外内容卸载/停更规则独立于剧情状态。
- 初始手机预算建议：当前可见街段主体几何不超过约 2 万三角形、普通画面约 50 次绘制以内；含阴影/深度/体积/AO 的行走帧单独记录。以上是预算目标，不能据此宣称实际帧率。
- 沿用小图集、合批、静态遮挡缓存和低分辨率体积重建。重点检查透明过绘、阴影更新次数和实际帧耗时，而非只看面数。
- 真机先验证稳定 30 fps 档，高档目标 60 fps。若必须降级，优先减少远处光束、行人、阴影更新频率，保留主角可读性与一组标志性冷蓝主光。

## 实现顺序与验收

1. **先完成校门＋便利店约两屏的夜景样片。** 连续人行道、马路、一个店面、教学楼/高楼分层、一辆经过的车、一个行人和主角移动。同步做城市冷蓝主光与一盏可遮挡的体积路灯。这一步决定最终资产尺度、光影与材质，不先铺完整街道。
2. **打通街区基础。** 抽离当前固定森林装配，建立城市场景配置、街段数据、交通路径、交互点和灯光分区。场景标识写入存档，旧森林坐标不能直接应用到城市。保留回归用的森林展示场景。
3. **扩展完整回家路线。** 商业街、公交站/路口、住宅入口；建立返回探索、商店进出、交通让行与进度保存。
4. **完成序幕演出。** 21:00 开场提示、学生离校、短对白/查看、步态与书包摆动、到家衔接。声音按场景距离与位置分层。
5. **统一晨昏光照并完成移动端验收。** 检查昼夜过渡、光束遮挡、贴图清晰度、横竖屏、手机发热/帧耗时与版本更新恢复。

样片通过标准：第一眼读作现代商业街；无孔洞、悬空路沿或车辆穿帮；纸片厚度与人物比例一致；夜晚肉眼可见强烈冷蓝光柱且建筑/雨棚能遮挡它；光束之外保持暗部，角色和人行道仍清楚；没有大面积蓝雾发灰、粒子噪声、塑料路面或满屏霓虹。用同机同镜头的光束开/关截图与行走录像验证，不只展示静态漂亮帧。
