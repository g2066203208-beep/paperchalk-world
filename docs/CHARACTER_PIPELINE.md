# 主角正式形象 / 静态立绘接入规范

## 角色正面母版
- 用户提供的 1024×1024 主角原画：黑色长发，发夹，深蓝校服外套、灰色百褶裙、酒红领带、黑袜、黑色皮鞋。
- 游戏透明资源：`site/assets/characters/protagonist-front.webp`，保留原有造型和表情，仅自动去除原图白底、裁掉大块透明余量、缩小为高约 512 px 的用于预览的资源。
- 原始画像属于角色身份母版，绝不把正面图水平翻转伪装成背视图。
- 通过 **主菜单 > 场景预览 > 主角立绘** 或 `?scene=protagonist` 可在卧室背景上检视新的主角正面立绘。

## 我方战斗背面规则
- 原课堂战斗立绘 `site/assets/battle/player-back.webp` 保留现有角色站位和层级；这是旧的临时背面素材，尚未按新主角绘制。
- 未得到同一角色的匹配背面画稿前，不能宣称战斗主角形象替换完毕。
- 战斗我方背视、敌方正视、纵深运动；不要直接使用正面立绘冒充战斗背面。

## 动态黑斑
- 位于原有 `#fog` WebGL/CPU 显示合成阶段的黑色扭曲污渍，可通过「动态黑斑」按钮开关；不新建另一个 canvas，不影响基础动态黑雾和纯黑安全边缘。
- 正面人物预览层放在雾后，以便查看黑色斑点对人物和场景同时作用的效果。
- 游戏设置开关本地保存；旧 DEV 分层的存储键和坐标不变。
