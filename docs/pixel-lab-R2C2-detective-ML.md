## 实际已执行内容

1. 用现有V4完整25格图鉴独立提取R2C2侦探；**R2C2完全排除训练**。
2. 对21格训练来源生成有限色数的**伪标签**，使用模拟模糊、插值与少量噪声来构成去伪像素恢复任务。
3. 真实PyTorch CPU CNN，150步，3个整人物留出验证（R1C5、R4C3、R5C4）。
4. 把CNN结果映射到独立14色离散色板，保留部分高对比五官与香烟线条。

## 不能越界宣称的内容

- **这不是已训练于专业画师素材的艺术模型**。训练使用V4图鉴自身衍生的伪标签；仓库高质量人工像素画正样本库尚未获得审查通过的足量数据。
- **L1改善只是合成退化恢复成绩**，不是评价眼睛、鼻子、嘴巴的美术水平。
- 整数像素网格 ≠ 完美像素簇；衣服锯齿、脸部微小杂点、框外孤立形状仍需逐格人工判断。
- 本地的完整1254×1254源图与GitHub的640×640 WEBP源图不是同一套像素输入；不可把二者模型误差直接比较。两边都不是GPT重新生成人物。
- 不覆盖V4认可母图，不自动晋升为作品Gold。
