# 霧浜市地铁与城市地图：统一交互规范 V40（2026-11-08）

## 唯一正式地图编辑入口

- 角色位于霧浜市时，从游戏手机/快捷地图打开 **霧浜市正式地铁图**，不再自动把玩家送入住宅前站周边地图。
- **返回城际地图**：只看不同城市之间的真实交通，不混合各城市内部的地铁线。
- **住宅前地区**：明确点“↓ 住宅前地区”才进入住宅前站周围的七处实际地点。
- **查看地点**：这是独立可切换的城市地点视图，显示 15 个片区 / 120 个真实规划点。未开启时不得用城区卡片、图钉遮挡地铁。
- **编辑地铁**：直接进入同一张实际运营 SVG 轨道图，不允许跳入不连通实际线路的另一张空白画布。

## 地铁编辑操作

1. 先在编辑器内选择“全部线路”或按颜色点选十条线路；点线路会把画面聚焦到它的实际车站范围。
2. “移动车站”：在轨道图点车站并拖动，自动吸附 36×26 的正式格点。共享换乘站只有一个真实 ID，所有线路自动跟随。
3. “定位车站”：在下拉框选取站名，直接导航到该车站；随后可改站名。
4. 点选任意真实轨道段后，“调整轨道”添加并拖动有序折点；“线路加站”在所选两站间插入可乘坐车站，不生成脱离线路的伪站。
5. 主工具只保留移动、调整、加站、删除、撤销、重做、保存到游戏。恢复基线、导入、导出、保存草稿放在折叠区。
6. 保存草稿与结束编辑的自动保存仅写入当前浏览器的草稿键，**刷新不会自动投入运营**。**保存到游戏**先校验线路、换乘和站序，将蓝图另存为当前浏览器正式运营版本，再重载进入实际乘车线路；不是推送全服 GitHub 改版。旧版单键存档仅在第一次升级时迁移一次，避免原有已应用路线丢失。
7. 组件触摸命中区大于视觉圆点，轨道和圆点仍然保持精细点阵风格，鼠标点击与手机拖动都不能触发页面滚动。

## 模块与旧版本边界

- 当前 GitHub 基线依旧是 10 条、70 站、19 换乘、81 相邻段。不得把已缩减的旧 170 站草稿静默恢复成正式地图。
- 游玩中的路线和可用乘车选项来自 `site/game/metro-graph.js` 和 `site/game/metro-map-geometry.js`；编排器 `site/game/metro-map-editor.js` 只管理有状态蓝图。不能用一张图片代替这些数据。
- 原自由城市搭建器 `site/game/city-builder*.js` 及原浏览器草图 **保留**，只在 `?cityBuilder=1` 开发测试模式显示。它不能冒充正式地铁编辑器，也不能在普通地图上放第二个竞争的「城市拼装」按钮。
- 未来街道、建筑、地块建设应接入同一地图的明确规划图层，先做坐标、连接和保存一致性，再解锁正式游戏；本轮未宣称这部分已实装。
- 城际地图、城市地铁、住宅前站地区是三个明确导航层级，但不随缩放阈值自动穿越层级。
- 正常乘车模式的轨道点选、当前位置和行程弹窗必须保持可用，编辑时只隐藏正常点选层。
