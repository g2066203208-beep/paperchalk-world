# 《夜港》产业经营模拟系统：运营设计与技术契约（V1）

## 设计目标

《夜港》不再以“建筑等级×固定收入”来伪造经营，而建立可供下一阶段继续扩展的**离散商品流与经营账户**。原型研究参考《OpenTTD》的初级产业→次级加工→终端消费者运输结构，以及《Capitalism Lab》的仓储、零售客流、供应链与服务业分类。但所有产业与剧情都按夜港现有1998年城市设定原创实现，未复制外部作品代码或资源。

## 已实施的 26 类企业、25 类商品/服务

农业：谷物农场、蔬菜种植园、渔业码头、棉花农场。
资源：木材场、矿业工坊。
制造：面粉厂、金属冶炼厂、纺织厂、木板加工厂、机械零件厂、家具作坊、电器装配坊。
食品：面包烘焙坊。
餐饮：街角食堂、街区咖啡馆。
零售：服装工坊、社区杂货铺、五金门店。
服务：汽车修理厂、社区诊所、旧城旅馆。
文娱：夜间俱乐部、小型电影院。
文化：街区印刷社。
物流：小型仓库。

每个企业都声明：`sector`、`stage`、`output`、`inputs`、`batch`、`build`、`upkeep`、`visitors`、`staffWage`、`retail`。增加新行业只需添加配置数据、素材/UI 入口和测试，不需要复制一套每日结算代码。

### 真实投入产出样例

```text
谷物农场 [11谷物 / 批] → 面粉厂 [6谷物 → 9面粉] → 面包坊 [6面粉 → 9面包]
蔬菜农场 [10蔬菜 / 批] ──┐
面包坊 [9面包 / 批] ─────┴→ 街角食堂 [3蔬菜+3面包 → 8餐食]
矿业工坊 → 冶炼厂 → 机械零件厂 → 五金/修理厂/电器装配
木材场 → 木板加工 → 家具作坊
棉花农场 → 纺织厂 → 服装工坊
药品进口 → 诊所诊疗服务
咖啡豆进口 → 咖啡馆饮品
```

- 每日运行按照产业层级排序，**先生产、再向自家下游调拨、必要时向外部采购、最后卖给居民或市场**。
- 原料流转必须从上游库存实际扣减；仓库不能凭空销售。自有产业之间的调拨计算距离费用。
- 没有库存时，即使人口需求很高，也没有销售收入。库存有限（200单位/企业），生鲜有损耗，缺货有单独记账。
- 商品销售量由本区模拟人流（80位有作息的居民统计）、街区舆情、价格、员工数量、建筑等级、设备状况和同类自有门店竞争决定。
- 价格分为平价促销、标准、品质溢价三档。降低价格可能带来更多订单，但并不保证更高利润。
- 可招聘/解除成年员工合同（签约费、工资、产能负担）；歇业仍然支付基本成本。
- 建筑扩建、维修可改变产能或需求水平；每家企业分别保留30天经营明细。
- 真实现金账：每企业 `销售收入 − 采购货款 − 内部运费 − 员工工资 − 维护 − 税金 − 许可费 = 营业净现金流`。逐笔体现在原账本，不额外发放“点击奖励”。
- 支持自己的两家企业之间手动转运1至25单位商品，并按实际库存核销。

## 存档与兼容

- **新建产业**：新企业默认启用精细经营，初始库存为0、员工1名，自带生产/服务目录与可设置的经营选项。
- **旧版产业**：原4类建筑保持旧收益算法，玩家可在产业面板手工点击“开启精细经营”升级，避免存档突然遭到供应链冲击。
- **旧房产、路权、地图和主线**保持原规则；经营系统仍复用原 `estates` 系统私有数据切片及旧存档版本号，因此不引入破坏性的全局存档迁移。
- 所有公司数据是可序列化纯JSON，回放同一日期、配置和伪随机种子将得到同样结算结果。

## 已接入实际游戏

办公室的卷宗→**产业经营**页可看到公司列表、产业分类、生产配方、企业详情、价格、人员、采购、维修、仓储调拨、销售额与利润。地产→购买地皮→建造26种不同企业。完成游戏里的一天后正常结算，历史可在公司日报和原账簿查到。

## 验收

1. 单元测试检查商品与企业目录引用、购买建造、初始零库存、真实物料消耗、按库存销售、人员工资与售价需求、跨店转运、无副作用失败命令、旧档案自动收益、100天模拟回放。
2. GitHub Actions真实浏览器点击买地、建谷物农场与面粉厂、雇员、改价、接电话、翻日历，检查`mill.lastTransfers>0`（实际从自有农场收到谷物）和第二天经营报表。
3. CI同时保留原完整主线 Day1—39通关测试，防止经营扩展破坏主线，保存截图、可复核日志。

- 仓储过期批次、跨仓订单预约、陆运车队/驾驶员逐车可视化。
- 行业特有迷你操作玩法、人物动画、商铺内部关卡、美术和配音。

V1是**真实、可操作、可回放的经济垂直切片**，还不是每个行业都有独立玩法、智能竞品与全居民微观消费的完整商业成品。下一步应以真实游玩中“为什么开店”“客人为什么买”“竞争为什么有意义”为优先级继续推进。
