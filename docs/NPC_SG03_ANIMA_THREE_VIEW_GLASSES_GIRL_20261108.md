# NPC-SG03 眼镜妹｜Anima V2：左侧书包可见＋镜片后完全无眼睛

> **用户实际出图反馈 2026-11-08：** 左侧人像缺蓝色书包；中间人像画出有瞳孔的眼睛、反而没有眼镜。当前图片**未通过**，不能作为已批准母图上传人物集。本 V2 从已经固定的 [SG01 成功图序的三视图填空模板](ANIMA_SCHOOLGIRL_THREE_VIEW_FILL_IN_TEMPLATE_V2_20261108.md) 替换 11 个角色外貌/动作槽位，不重写三视固定结构。

## 错误根因与对应修改

1. 旧版写 **RIGHT SHOULDER**（右肩背包），却画**朝左的纯侧面**，右肩处于远离镜头的背侧，包容易被躯干挡住。此次**三个视角一起统一改成 LEFT SHOULDER / LEFT HIP（左肩左胯）**。从左侧面看，背包在镜头这一侧；中正面则在观众右侧；背面在观众左侧。**不是左边一人换包，而是三格同一侧。**
2. 旧版虽写“圆框眼镜不要眼睛”，但模型生成中间有眼睛却缺眼镜。本版将 **THIN DARK ROUND EYEGLASSES / two clear empty round frames / plain skin behind lenses** 作为人物重要特征写在人物道具段，且在左/中/右动作段反复明确镜架连续性；明确禁止瞳孔、眼线、眉毛、眼睑、眼白、镜片反光盖住眼镜。不采用夸张“无脸”提示词，因为仍需保留小鼻子、小嘴、脸形。
3. 道具仍是一只灰蓝帆布书包＋一本合起来的灰蓝笔记本。**笔记本始终在右臂下面**；与旧版本相比换到了右臂以避免左手稳住左肩书包带时不自然。三格动作小且不同。
4. 校服不改：近黑午夜海军蓝双扣西装、白衬衫、酒红长领带、炭灰百褶裙、黑小腿袜、深棕乐福鞋；两颗暖深灰棕哑光圆扣。LoRA 1.0。
5. 视图**左纯朝左 90°侧面／中完全正面／右完全背面**；背面不会看到正脸。
