## 一、2.5D场景的正确方案
项目地铁使用 **真正的WebGL壁面/座椅/地面透视与单摄像机**：
- 场景定义：[site/game/scene-environments.js](../site/game/scene-environments.js) 的 metro：`shape=strip`、`widthMeters=8.5`、`backZ=8`、`heightMeters=2.85`。
- 相机：`eye(-0.95,1.45,10.90)` → `focus(-0.95,1.45,8.0)`，纵向FOV49°；移动版有自己的 eye/focus 混合。
- 主角真实地面坐标 `(-1.6,0,8.94)`；其余乘客须与之同一地面投影，而非把屏幕百分比当作位置。
- 新专用模块：[metro-npc-staging.js](../site/game/metro-npc-staging.js)；三个**空的待验收车厢站位槽** `(-0.55,0,8.37)`、`(0.02,0,8.39)`、`(0.60,0,8.42)`（单位米）。它们只是可计算的校准起点，绝不是自动刷出三个人。
- 用 **游戏已经使用的 `PaperWorldRingArena.project` 和真正的cameraVP** 算出每一个脚底在画面哪里、头顶在画面哪里、实际像素高度，以及是否挡住主角和座位。支持设备纵横比与场景摄像机变更。
- 以实际服装透明图的 alpha 鞋底/头顶测量 `soleY`、`crownY`，画在 `y=0` 的世界地板，实际米制身高带来正确透视。显示尺寸由**米制身高、透视深度、摄像机**共同决定；不允许复用旧的 CSS `height:64%` / `left:25.5%` 等设置。
- **重要镜头事实：** 当前地铁前墙构图有意裁掉地板。试算世界脚底会投射到画面底线以下约13%，人物完整可见高度约七成画面高；不能把PNG整体上移假装鞋落地。要完整展示鞋子，只能改场景取景策略（经用户许可），或让角色坐下/被真实座椅前缘遮挡，不能浮空。
- 未来正式渲染必须是带有脚底锚点、被世界深度遮挡、接受车厢灯/站台灯的WebGL 2.5D角色层。**当前仅完成放置坐标/校准计算与API，并没有把某张不合格立绘冒充正式WebGL NPC**。
- 入口：`PaperWorldGameRingArena.inspectMetroNpcStaging()` 返回实时摄像机下的空位投影；`PaperWorldMetroNpcStaging.approvedActors()` 拒绝未通过美术批准的角色。测试：`node --test tests/metro-npc-world-staging.test.cjs`。

## 二、重新设计普通路人NPC的美术优先级
**不是把可爱的角色画丑，而是减少主角级辨识/装饰，把演出重点给身体和事件。**
- 面部：有眼睛但小，低饱和瞳色、少高光、眉眼和嘴巴用更少线条；无夸张精致妆感、不追求每个人都像有独立卡池立绘。部分刘海自然遮眼，但不把三个人全画成无眼/无脸。
- 头发：朴素的黑/深棕/灰棕，减少高光块和精细独特卷度；3个人可通过短发/中长发/低辫辨认，但不要像女主的人物特征或视觉中心。
- 服装：项目高中深海军蓝校服、白衬衫、暗酒红直长领带、深色无亮金纽扣、灰百褶裙、深棕便鞋；局部生活褶皱合理即可。三人袜子差异可以保留但须身份稳定。
- 体态：年龄相仿但身高、宽窄、肩颈与真实重心不同；普通学生比例，不用偶像身材、夸张胸腰、主角级长腿。
- 画法：保持 `@akipekostyle` 的线条质感、克制阴影和整体色系，但减少面部、头发、服装上的视觉密度和商业卡牌角色感，**不能以降低生成质量换取“路人感”**。
- 表演：9大情绪依然由**三人一起**自然进行、全身动作和互相作用形成因果；情绪差异来自事件反应。强惊讶/恐惧可以大动作，不能每套都像面对镜头拍宣传照。
- 新版本必须先在真正2.5D场景中用相机、落脚、遮挡和光照检验；无法进入场景的一张白底独立图**不算最终验收**。

## 三、验收门槛
1. **世界空间**：没有任意屏幕CSS坐标缩放；地面接触、人物间深度、遮挡和真实灯光全部通过实机截图。
2. **层级**：人物整体比主角显著更朴素、不夺画面焦点；但表达仍自然、生动。
3. **唯一性**：3个群演是一个长期身份组；同一游戏时间不会在多个车站、城市、商场同步出现。
4. **美术**：只有新母版明确获用户确认才能注册 `approved/production` 状态，旧图永久标历史废稿。
