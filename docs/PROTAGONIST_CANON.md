## 1. 外貌识别：绘画不可变的身份证

| 维度 | 锁定特征 | 禁止误画 |
|---|---|---|
| 脸型 | 偏窄的柔和椭圆脸，颌线顺滑，下巴小巧而非尖锥；五官集中自然 | 改成圆娃娃脸、尖锐网红脸、明显不同骨相 |
| 眼睛形状 | 偏细长的杏眼，上眼睑有轻微压低感，眼尾不夸张上挑；默认半垂、安静凝视 | 萌系大圆眼、夸张睫毛、凌厉猫眼 |
| 虹膜 | **低饱和灰褐／深棕灰调**，靠近原图色感 | 亮蓝、翠绿、紫、鲜红等无依据异色瞳 |
| 瞳孔 | 深褐近黑，瞳仁清晰但高光低调 | 发光瞳孔、星星瞳、过大的动漫眼光斑 |
| 眉毛 | 深色，偏细、平缓，和冷静神态统一 | 粗重浓眉、过强挑眉 |
| 鼻唇 | 小鼻子、嘴唇线条极简；通常闭嘴、嘴角平直 | 大嘴笑、厚唇或随意改变五官位置 |
| 肤色 | 偏暖的浅肤色，面颊可有非常轻的自然红润 | 苍白发灰的僵尸肤色、强烈腮红 |
| 发色 | **自然深黑／墨黑**，高光呈冷灰棕，不是纯白或鲜艳彩发 | 灰白发、蓝发、棕金发 |
| 发型 | **长直发**，发量自然；额前平整分束刘海，两侧有垂落至胸前的长发；背面发梢延至肩胛附近 | 短发、波波头、卷发、双马尾、随意盘发 |
| 识别性发饰 | **角色自身左侧鬓发（正面图画面右侧）有两枚浅银色斜置细发夹** | 把发夹换到另一侧、添蝴蝶结或发箍 |
| 身材/姿态 | 匀称偏纤细，正常少年比例；肩自然放松、双手垂在身体两侧、脚站稳 | Q版、成熟夸张曲线、夸张猫步或大动作重心 |
| 默认神情 | 安静、克制、些许倦意或警觉，不主动卖萌 | 夸张笑容、挑逗表情、持续愤怒 |

**正反一致性注意：** 正面由两缕长发垂在胸前、背面整体发束覆盖至肩胛附近；不能用正面的左右翻转替代背面。前后发饰可因遮挡而不可见，不得凭空在后脑加一套新发饰。

## 2. 服装与色彩（原画身份的一部分）

- **上身：** 修身但自然的深海军蓝/黑蓝色校服西装外套，翻领简洁，前襟有扣和口袋；内搭浅灰白衬衫。
- **领口：** 暗酒红色细领带，中央整齐，长度与原图一致。
- **下身：** 中灰色短百褶制服裙，褶线宽度与层级遵循原图；不要加花边、装饰链条。
- **腿部：** 双腿自然露肤；小腿有黑／深灰色短至中筒袜，与原图袜口高度匹配。
- **鞋子：** 深棕近黑的圆头低跟乐福校鞋，非高跟、长靴、运动鞋。
- **材质表现：** 外套为低反光厚布，裙褶软硬适度，头发保留大面积干净色块与少量质感高光；不要加入无意义纹理或复杂饰品。
- **默认携带物：** 无；书包、伞、钥匙、手机、饰品及手持道具须由剧情单独配置，不属于恒定外貌。
- **场景光照：** 暗室里的阴影允许改变画面亮度，不允许悄悄改变原有发色、肤色与瞳色。

## 4. 性格、情绪与演出（**初稿**）

- **基本气质：** 内向、沉静、观察力强，善于先看清环境再行动；对异常细节敏感。
- **沟通方式：** 少言且说话简洁，缺乏表演式热情；不是木讷机器人。面对陌生人有距离感，熟悉后表现出细微关心。
- **优点：** 谨慎、耐心、记忆细节、能在压力下逐步推理。
- **弱点：** 多疑、习惯自己承担情绪、遇到无法解释的事会过度思考；害怕失去控制感。
- **核心矛盾（提议）：** 追求日常秩序，却被不断出现的异常线索逼迫承认自己未必理解周围世界。
- **情绪梯度：** 中性静默 → 微皱眉与视线偏移 → 短暂停顿/轻吸气 → 轻微后退或攥手 → 情绪平复；避免用每一帧的大幅度表情变化代替角色塑造。
- **声音与节奏（提议）：** 中低音区、声线干净、语速中等略慢；情绪变化靠停顿、呼吸、轻微语尾，不刻意娇嗲。
- **互动姿态：** 先观察，再作小幅调整；紧张时目光移向声源，肩臂略绷紧；惊吓后有短时恢复过程。
- **人际关系/立场：** 具体父母、朋友、敌人、爱情线及背景秘密全部留白，不自行给主角增加相互矛盾的经历。

性格段是供剧情策划使用的**提案**，不是从脸部表情分析出来的人格诊断。

## 6. 画新角色时的去重检查清单

1. 先读取本档案及 `registry.json`；如果要画的是本主角的新姿势/表情，**继续使用 `protagonist`**，只新增同身份的变体。
2. 新 NPC 先核验叙事职能确实是另一人；再给**全新且独立**的 `character_id`。
3. 对比主角的脸型、刘海、双银发夹位置、深黑长直发、灰褐眼、衣装剪影；不允许用这些组合直接复制出另一位「新角色」。
4. 各视角统一头身比例、眼鼻嘴相对位置、发旋/发尾长度、校服结构与色彩；若造型改变必须有剧情理由和同身份版本记录。
5. 主角所有原画和数据更新须同时修改本文档、`registry.json` 版本/状态；提交时运行 `python3 scripts/validate_character_identity.py`。
6. 未经允许不得清空本机分层编辑项目、替换已有 WebP 或修改浏览器本地存档。
