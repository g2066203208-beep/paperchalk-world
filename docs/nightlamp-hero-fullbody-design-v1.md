# 夜航灯｜主角「灯」全身演出立绘设定单 V1.0

> 仅确立美术概念。不是最终已审美验收的立绘，不是LoRA训练成果。本版本明确 **Anima Base，No LoRA**；Anima原生 `@artist` 标签**不等于LoRA**。

## 世界、角色与叙事
- **世界：** 架空1998–2005年代感雨夜城市，磁带/列车/纸质记录卡/老屏幕与少量虚构通信设备共存。
- **身份：** 23岁女性夜班值班员、前台记录员。剧情使用全身人物演出，主要场景是小酒馆/夜间接待柜台；人物必须可以在房间层上独立摆放。
- **叙事基调：** 稳重、敏锐、礼貌、疲惫但不冷漠；倾听客人、收集并记录城市里消失的人的线索。
- **比例：** 约6.8–7头身的正常成年比例；非24×24小人、非萌化Q版、非半身。
- **输出：** 原始AI概念母图画幅建议832×1216，人物从头到鞋底全出画面；后续制作原生256×384像素立绘并分层，用最近邻仅做展示，AI图不直接认定真原生像素。

## 面部与发型（身份不变量）
- 偏长椭圆脸、柔和收窄下颌、微尖下巴、不突出的颧骨。
- 灰绿色细长杏眼，上睑清晰、外眼角轻微下垂、可表现疲惫感；不做超大萌眼。
- 小而清楚的鼻尖、较薄的嘴唇、暖中性哑光肤色。
- **头发：** 蓝黑色、下巴与锁骨之间的层次不对称波波头；角色自身**右侧**一束更长，垂至锁骨上方；**左侧**较短露耳；斜向刘海、后脑有自然体积、两至三处外翘发尾。
- 角色自己**左耳**一枚很小的黄铜耳钉。

## 服装（身份不变量）
- 深蓝灰短款小翻领制服夹克，髋骨上方收尾，袖口窄酒红装饰线。
- 象牙白简洁翻领内搭；左胸一枚**不写字**的小矩形黄铜名牌。
- 暗酒红高腰A字短裙，只有两三道明显结构褶线；深灰及膝袜；深棕低跟短靴。
- 角色自身**右侧腰部**一个小型皮革卡片套；不得添加大量花饰/链条/夸张褶边。

## 演出立绘与动画拆分
1. 标准站立：轻微3/4站姿，重心在本人右腿，两手与身体留有可分离空隙。
2. 温和微笑：嘴角轻扬、右手轻靠锁骨。
3. 疲惫沉思：微低头、左手持记录卡。
4. 递出卡片：右手向前，所有手指可辨；全身不能被吧台挡住。
5. 雨夜警觉：身体轻背向画面，回头、冷暖双向侧光。
- 后续可分层：前后头发、眼眉口、头/脖颈、胸腔/骨盆、双臂、双手、裙摆、双腿及靴子；AI生成时无需假装已有可用切片。

## 质量验收
- 五张图必须保持同一头发侧别、眼睛颜色、脸宽、制服剪裁、鞋子类型和黄铜配件位置；不能生成五个不同人。
- 不得裁脚、变成Q版、乱加配饰，也不能把像素风滤镜冒充真像素。
- 不训练LoRA，不创建任何“已训练模型”的假文件；当前只是角色母版与提示词研发。
