# Prior art and references

MC Universal Bridge is an independent generalization effort.

The architecture was informed by public modding work including SkyCraft by chasmlol, which demonstrates running Minecraft beside Skyrim and translating collision, actors, input and rendering between the two games.

SkyCraft repository: https://github.com/chasmlol/SkyCraft

No SkyCraft source file is vendored in this directory. Engine adapters may later reuse MIT-licensed implementation ideas where appropriate, with attribution retained when code is copied or adapted.
