# 夜行档案 / NOCTURNE FILES — Paperworld 独立叙事工作室

> 阶段：**v0.1 可交互原型**（不是完整纵向切片，更不是正式美术版）。
> 开发分支：feat/nocturne-preproduction-20261020
> 页面地址（仅在分支合入主站且 Pages 发布后生效）：https://g2066203208-beep.github.io/paperchalk-world/studios/nocturne/

## 现在能玩什么
- 全新标题画面 → 开始游戏 / 继续自动存档。
- 原创响应式横竖屏 UI：日历、地图、调查档案、秘密委托、人物关系。
- 五处地点：白榆大学、雨滴咖啡、站前广场、主角公寓、解锁后的雾港展馆。
- 点击「◎ 探索」显示场景热点并搜集最多四条互相独立的线索。
- 安排上课、兼职、自习、聊天、休息；消耗游戏内时段，实际修改精力/金钱/学业/人物关系。
- 接受/拒绝事务所的委托；对证据提出可验证的假说；触发公开真相、缺乏证实、保护、服从命令和委托过期等不同结果。
- 3 个手动存档位、自动存档、JSON 导出导入；使用 \`paperworld.nocturne.v1.*\`，与旧游戏完全隔离。
- 文字和场景舞台的原创 CSS 纸片光影视觉；支持手机安全区、竖屏重排、减少动态效果。

## 如何运行
静态 ES Modules，必须通过本地 HTTP 服务而非双击文件。根目录原有服务器可用：
\`\`\`sh
npm run dev:studio
\`\`\`
打开 \`http://127.0.0.1:4173/studios/nocturne/\` （仓库内路径固定；历史项目根路径也支持）。

自动化测试：
\`\`\`sh
node --test studios/nocturne/tests/engine.test.mjs
node --check studios/nocturne/engine.mjs
node --check studios/nocturne/game.js
\`\`\`
工作流：\`.github/workflows/nocturne-checks.yml\`。

## 已知限制 / 真实状态
- **游戏逻辑已写入仓库，但未完成真实手机浏览器逐屏验收。** 需要在手机浏览器进行人工操作检查后才能宣称生产可用。
- **艺术资源尚不符合正式版本要求**：生成的 GPTimg 美术方向稿目前用于风格参考，当前工作室运行时使用 CSS 场景和简化人物；不能把概念展示图当成已经做好的分层立绘。
- 第一章目前是紧凑的机制原型，没有实现完整 25–35 分钟剧本、复杂多镜头人物动画、全日程 NPC 行为或音乐音效。
- 地图为响应式节点图，尚非可以拖拽缩放的高精度城市场景画布。
- 任务行动为叙事抽象和后果选择，不涉及真实伤害实施细节。

## 遵守隔离原则
原有 \`studio/\` 三维纸艺工作室、\`index.html\`、\`visual-demo.html\` 不做修改。新游戏代码只在 \`studios/nocturne/\`，另有该工作室专用独立 CI 工作流。
