# 《夜行档案》NOCTURNE FILES · Paperworld 游戏工作室

## 当前进度：v0.3 横屏电影化序章（开发中）

**这不是商业完整游戏。** 这一版有意推翻此前失败的网页仪表盘式布局，换成单一场景舞台、场景点击、实际持握式手机交互、局部调查、对话演出和可保存的分支结果。原 Paperworld 主站与 Three.js 旧工作室保持隔离，不修改。

- 游戏入口：`studios/nocturne/index.html`
- 逻辑与触摸交互：`v3.js`；样式与电影化覆盖层：`v3.css`
- GPTimg 概念图经裁剪、滤镜和镜头构图整理的场景资产：`assets/room-cinematic.webp`（仅属于序章整体背景板，不是分层骨骼角色）
- 游戏状态使用独立存档键：`paperworld.nocturne.cinematic.v3`，不覆盖旧工作室存档。
- **实际操作**：进入序章 → 点击推进 3 段文字 → 点击角色手机 → 打开匿名会话 → 查看照片 → 点击钟楼时间、检查照片背面 → 进行时间矛盾推理 → 返回手机选择公开、保护或服从任务 → 结局存档。
- 可选行为：回复林见夏；点击床铺进入手账安排休息或学习；游戏菜单中导入导出存档、音效开关、对话记录；选择结束仍可游玩。
- 画面与输入适配基准：667×375、844×390、1280×720、390×844。采用场景、对话与道具遮挡层，而非常驻卡片和多栏导航。

## 这版已经验证 / 尚未验证

- 本地使用 Chromium Playwright 从点击开场到两条证据推理、任务结果，四组屏幕尺寸的自动操作通过，检查无页面 JS 错误、无横向页面溢出。
- 独立 GitHub Actions 检查：`node --test studios/nocturne/tests/engine.test.mjs`（旧引擎兼容）、`node studios/nocturne/tests/cinematic.browser.mjs`（新序章实际浏览器操作、截图）。
- **并未完成真机人工测试**，也尚未完成商业级别逐帧动画与完整 25–35 分钟剧情序章。浏览器模拟通过只是基本门槛。
- **人物与房间目前同属一张复合背景图，不能单独切换角色表情、位置和骨骼姿态。** 需要经 GPTimg 生产与人工审核的分层人物母版和独立房间背景。绝不能把一张 GPTimg 概念游戏截图说成全部已经变成正式分层素材。
- 房间是唯一精细画面的演出场景；其他地点、真正的地图和职业任务演出还需后续制作。
- 道具照片插画目前由 CSS 绘制，待美术确认后会独立出图；交互逻辑已从表现层分离。

## 美术设计纪律

1. 固定成年角色面貌、头发、服装、镜头、灯光，再制作表情和姿态。
2. GPTimg 负责插画素材，真实界面中的文本和触控交互由 HTML/CSS/JS 实现。禁止把假消息和假按钮烘焙在背景图中。
3. 多素材必须有统一调色、透视、光源和细节密度，不允许 AI 随机更换五官或堆砌无意义小物。
4. 不把参考游戏受保护的 UI、Logo、角色立绘和独有构图当正式游戏资产。

后续正式资源约束参考 `ART_PROMPTS.md` 和 `MASTER_PROMPT.md`。
