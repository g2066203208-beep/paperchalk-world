# 室内美术返工：风格锁定

用户明确指定 I Have No Change 的扁平图形动画画法；以用户橙底参考帧和已认可的主菜单为视觉依据。仅取近似配色不算统一风格。

当前程序方框室内已被用户拒绝，不作为验收基准。保留营业规则、存档、联机和手机 CSS 像素输入，替换实际美术与场景构图。

固定要求：硬切色块、干净有力度的外轮廓、藏蓝/矢车菊蓝/奶白/橙黄，图形化造型；不要普通柔和动漫渲染、写实材质、厚重渐变、管理后台式圆角货格。物件与人物必须共享相机和透视。实际可售货物、门板、抽屉、台面、价签和角色表情分别成层；不能把完整界面烘焙为背景。

先做统一室内建筑、独立货架、独立台面，再做储柜和摆件。以实际手机画面与主菜单并排比对，通过后才能称为完成。
