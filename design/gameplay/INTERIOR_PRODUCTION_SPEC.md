# 第一小店：完整空间、细拆素材、镜头与横竖屏规范

状态：生产方案，尚未实现。2026-10-27 用户指出：参考图空洞、货架承托不清、商品烘焙、缺少镜头外资产和横竖屏镜头方案。前面的插画仅为风格探索，不得直接作为可交互场景底图。

## 1. 固定视觉依据

画法：用户提供的 I Have No Change 橙底人物参考，以及已认可的主菜单；空间密度：1000047925 对比图最左栏。室内要窄且有货物密度，但操作区、商品轮廓、人物面部必须清楚。新增美术用 GPTIMG，不能退回程序方块占位作为正式美术。人物原创，完整全身母版；运行时按真实台面/窗沿遮挡。

## 2. 先闭合空间关系

先验证店铺平面和简易体块，固定服务窗、入口、店员站位、柜台、货架、储柜的物理关系和一套透视。体块仅用于空间核对，不作为正式素材。

采用一组连续服务台：顾客在外侧，手搭外沿；台面向店内延伸到玩家面前；交接托盘、账本和收银机放在同一有厚度的工作台上；台面下为实心柜体和可拉出的抽屉。店员通道在柜台内侧，即镜头所在一侧，不在服务窗与台面之间留下不明深坑。确需通行开口，应有明确侧向位置、门或翻板和行走逻辑。

货架必须有背板、立柱、层板、前沿和承托关系；商品底部落在层板的摆放面上。拿走商品后应露出完整空货架，不得残留烘焙商品或阴影。

## 3. 生产资产按行为、遮挡与状态拆分

| 组件 | 独立素材/实例 | 状态与约束 |
|---|---|---|
| 建筑 | 墙段、顶面、横梁、地面、门框、窗框 | 完整覆盖所有允许镜头范围；遮挡物后面有底层 |
| 服务窗 | 左右窗扇、玻璃、窗框、窗台、窗闩、卷帘及拉手 | 旋转/平移轴明确；开窗不能把整个人物一并切掉 |
| 货架 | 背板、左右立柱、每块层板、前沿、隔板、价签 | 层板摆放面、前沿遮挡层分开；不含可售商品 |
| 储柜 | 柜壳、内腔、左右门板、可操作把手、内部层板 | 开门后内腔完整；门板有铰链轴和开合轨迹 |
| 抽屉 | 柜体内腔、抽屉盒底、侧壁、前板、把手 | 货物跟随抽屉盒；前板可遮挡货物下缘 |
| 服务台 | 台面、外沿、柜体、侧板、柜脚/底座 | 台面连续；放置区域与视觉表面一致 |
| 商品 | 每种商品的单件完整透明母版 | 每一件在售实物是独立对象，可取放、交换、售出、存档 |
| 包装状态 | 按需增加袋口、瓶盖、封条、内部物 | 只有确需开封/倒出/撕开时再拆；包装印刷无需拆成无用碎片 |
| 收银机 | 外壳、现金抽屉、显示/票据区域、独立纸币硬币 | 收款、找零、开屉、出小票各有状态 |
| 托盘/账本/铃 | 托盘、账本封面/可翻页面、铃身/可按铃帽 | 独立操作热点、动画轴与放置锚点 |
| 灯/悬挂件 | 灯罩、灯绳、挂件、独立影形/效果 | 摆动不带动整个房间；不能把灯光烘焙到可移动商品 |
| 人物 | 全身母版、前后发、脸部基底、眼眉嘴、躯干、上下臂、手型、衣摆等 | 表情/手型可换帧；肢体按层级运动；全身不因表情而重画替换 |
| 效果 | 蒸汽、飘雪、递交轨迹、局部反馈 | 表现层；不得重复变更真实库存或付款 |

拆分原则：按实际独立行为、遮挡、状态替换、换装需求划分。不要把每一条画线拆成文件，也不要将整组可售商品画死在货架上。

同一 SKU 可以复用一张母版，但每件可见商品独立实例化。只有在明确为整包销售/整箱搬运的情况下，才把整包/整箱作为一个对象。被遮挡库存与画面抽象表示必须有明确规则，不能同时宣称每件可见物独立可拿却只维护一个无位置计数。

## 4. 完整性与素材交付

- 柜门、抽屉、商品、人物都交付完整形状，不按某张手机截图边缘截断。
- 被商品、柜门、前板、人物遮住的底层需要补画，移动后不得露洞。
- 根据允许的镜头移动、缩放和动画包络确定完整绘制范围；先定义范围，再补足范围。仅加一圈随意的出血不能替代完整侧区。
- 对从不展示的实体背面可暂不制作；若玩法允许转身、旋转物件或翻到背面，则该角度必须有素材或几何支持。
- 场景保存世界坐标、资产 ID、实例 ID、状态、父子关系和物件锚点；点击区不能由截图像素随意猜测。
- 每项资产至少声明：透明源图、完整边界、原点/旋转轴、摆放锚点、抓取/接触点、命中形状、遮挡层、状态资源、相机视角适用范围。
- 透明区域不烘焙背景；接触阴影若需要跟随商品，单独归属商品或实时表现，不固定留在货架上。
- 源素材分开保存；发布时允许打包图集。图集仍保留各精灵矩形与锚点，不能把相互独立的场景对象烘焙成一张屏幕截图。

## 5. 镜头系统

完整小店场景与手机屏幕是两回事。世界物件不因屏幕旋转改变物理位置；屏幕只是一个取景窗口。

| 机位 | 重点 | 转入方式 |
|---|---|---|
| 营业主机位 | 顾客面部/双手、窗口、连续服务台、交接托盘 | 默认；交付后返回原构图 |
| 左货架取货 | 左侧商品、完整层板与价签 | 拖动/轻扫视线，或点可见货架进入 |
| 右货架取货 | 右侧商品/新业务设施 | 同上 |
| 台面近景 | 商品放置、收款、账本/工具 | 点物件短推近；保留周边空间线索 |
| 下方收纳 | 抽屉、柜体内腔、回收物 | 看向下方；返回时保留手持物和状态 |

连续运动优先；明确转角/大幅换视角可短切。不是每点一个物体都强制播放长转场。镜头切换时正在拖动的物体不得跳位置，普通拾取/手持物可保持并有一致的落点。

### 视角边界

固定透视二维插画只能直接支持它所覆盖的平移/缩放视域。不能宣称移动一张正面图就实现真实转向侧墙。第一店采用受约束的二维主视图和完整横向延伸区域；如需明显转向侧墙，另制作对应视角并共享同一物件身份/状态，或先用有真实空间关系的简单三维体块支撑 2.5D 镜头。视觉仍可保持扁平，不以转换到写实 3D 为目标。

## 6. 横竖屏与输入

- 竖屏：优先保证营业核心区域足够大；侧架/下柜不必同时全部挤进屏幕，通过受限平移和取货近景触达。
- 横屏：拓展左右视野，按实际高度保护人物面部、双手与交接位置；需要时看向下方操作抽屉。不能把竖图拉宽或整体缩成小邮票。
- 同一场景、相同世界坐标、相同商品实例、同一库存。竖屏的左抽屉不能旋转后变成墙上的柜子。
- UI 的安全区、文字重排、长内容滚动与场景镜头分离处理。文字/气泡附着说话者的世界锚点后再做屏幕边缘避让，不能盖住面部、交接点和正在操作的目标。
- 点击统一由屏幕坐标逆变换到世界坐标，再按遮挡与交互优先级拾取。摄像机平移、缩放、转场与视觉物件使用同一变换。
- 小物件不靠互相覆盖的巨大隐形点击框补救；优先合理构图、近景或局部聚焦，获得足够可点面积。触控命中放宽必须有冲突解法。
- 9-slice 用于适合伸缩的纸面 UI、提示框、规则边框等；不能拿它任意拉伸人物、透视货架、完整房间来做横竖屏适配。

## 7. 实际验收门槛

1. 连续台面、店员站位、顾客站位、入口、货架承托全部能在空间草图上说明。
2. 去掉全部商品，空货架仍完整合理；拿走任一商品不残影、不露背景洞。
3. 任意开门/开屉、商品从柜中拿出、顾客进入离开均不露缺图。
4. 所有允许机位走到边界，所有允许缩放范围均有完整素材；越界由镜头限制阻止。
5. 横竖屏切换不挪动物件、不丢手持物、不重置交易，画面与点击位置始终吻合。
6. 人物抓物/交物在同一接触点；前沿、手指、商品的前后遮挡正确。
7. 多人同时操作，同一件物品只被一个角色拿走，付款只发生一次；镜头属于本地表现，不同步成全房间强制镜头。
8. 所有实际可见场景物件有对应响应：拿放/开合/使用/查看等，按对象用途定义，不把装饰伪装成可出售库存。

## 8. 官方技术依据与适用范围

以下用于验证通用技术方法，不意味着本项目已迁移引擎：当前运行时仍为 JavaScript Canvas + Android WebView。

- Godot Camera2D：世界场景与视口/相机变换、缩放、相机限制。
  https://docs.godotengine.org/en/stable/classes/class_camera2d.html
- Godot Multiple resolutions：不同宽高比下的视域扩展、比例保持与 UI 适配。
  https://docs.godotengine.org/en/stable/tutorials/rendering/multiple_resolutions.html
- Godot Cutout animation：分部件骨架、旋转轴、层级、遮挡与表情/手型换帧混用。
  https://docs.godotengine.org/en/stable/tutorials/animation/cutout_animation.html
- Unity Cinemachine Confiner 2D：约束摄像机使屏幕边缘留在定义的区域内。
  https://docs.unity3d.com/Packages/com.unity.cinemachine@2.10/manual/CinemachineConfiner2D.html
- Unity 9-slicing：保持四角与按方向拉伸边框的规则。
  https://docs.unity3d.com/6000.2/Documentation/Manual/sprite/9-slice/9-slicing.html
- Unity Sprite atlases：发布时打包精灵以优化纹理管理；与场景烘焙区分。
  https://docs.unity.com/en-us/engine/6000.0/manual/unity2d/sprite/atlas/atlas-introduction
