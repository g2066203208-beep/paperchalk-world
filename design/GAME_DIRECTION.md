# 未命名多人模拟经营游戏｜当前权威设定

> 更新：2026-10-27。用户明确要求先写入 GitHub。本文件优先于旧的「伪人判断/投票」「永久冬夜窗口」「主菜单只是一张固定片头」「先无条件回退到墙体 Gate 0」等历史方向。历史原型不等于当前目标。

## 已确定的核心

- 开局只有一间**小小的杂货店**，一处服务窗/门、一张操作台、有限货位与少量商品。
- 核心成长是持续拓展大量真正不同的**新业务**，具备各自操作、设施、成本、收入、产能/容量和升级；不是只增加商品名称。
- 主菜单就是存档里的**当前店面**。装修、扩建、营业项目、换店必须同步改变菜单和经营画面。
- 菜单与营业是同一家店的两个视角，读取同一套店铺状态。菜单演出不能自己结算交易或消耗库存。
- 主菜单构图以用户确认的 `design/menu/reference-approved.jpg` 为基准：棚布、左侧公告纸、右侧店员、前景左侧顾客、柜台与摆件。禁止再擅自换成孤立人物展示或另一套菜单布局。
- 风格固定为扁平 2D 大色块、硬边轮廓和少量色片阴影。角色五官学习指定参考的形状与画法，身份设计必须原创；所有人物资产先制作**完整全身**母版。
- 人物要融进实际营业：视线、手势、接触点、遮挡和物品归属一致。眨眼/蒸汽只是补充，不能代替取货、交接、付款和顾客回应的演出。
- 交互对象多，但入口依附真实货架、柜门、抽屉、商品、顾客、票据与设备。订单/交谈用角色旁气泡，不堆底部消息栏与悬浮按钮。
- 保留 1–4 人同店协作，房主统一处理库存/现金/交接；客户端只发送请求和播放表现。
- APK 保持联网获取最新网页内容；手机横竖屏、安全区、触控尺寸和旧存档持续兼容。
