# 主菜单实现记录（2026-10-27）

当前菜单以用户最终指定的 1000047928.jpg 为唯一构图基准，恢复棚布、公告纸、柜台、顾客与店员的场景关系。实际 DOM 交互和独立素材分层，不是整张图片热点。

- 人物：原创栗棕短发店员。全身睁眼/闭眼母版保留完整双脚；两位人物都保留完整全身母版。店员头/身体/握杯前臂共享完整源坐标，通过前景柜台自然遮住下半身；顾客侧向店员托着礼盒，手与物件一同运动。参考只指导五官和色块画法。
- 图层：背景结构 → 灯具 → 身体 → 头/表情 → 柜台 → 壶/杯 → 蒸汽/雪 → 菜单吊牌和实时文字。资产尺寸/透明性/支点见 assets/menu-approved/manifest.json。
- UI：无存档开始，有存档继续；营业中继续返回当前世界，不重置或切断联机。多人二级菜单保留称呼/创建/加入/连接状态。设置有动态、音效、大字；新店替换存档前可取消。
- 自适应：竖屏人物在上、菜单在下；横屏左右分列。真实 DOM 文字换行、44px 以上主按钮、界面内部长内容滚动、safe-area。
- 动态：眨眼、托腮倾听、轻微前倾递杯、顾客回应、蒸汽、落雪、菜单悬停/按压；动作按同一个 14 秒营业片段组织，握杯手与杯子绑定。支持系统减少动态以及手动关闭；切到后台暂停。
- Android：保留从 Pages 加载网页的壳；冷启动带独立查询参数，网络优先 SW 与 WebView 不使用旧页面缓存；存档仍在同一 origin。状态/导航栏与左右刘海均避让。后续 debug keystore 缓存延续签名；versionCode 以 workflow run number 增长。APK 自身更新仍走 Android 安装流程，网页内容更新无须每次重装。
- 图片均由 GPTIMG 制作原创角色/背景/壶；简单平面柜台和 UI 形状用独立 SVG（用户明确允许部分电脑绘制）。不复制参考图角色、女仆服饰或品牌标志。

美术仍需用户审阅，不以通过代码测试代替参考图质量验收。现有经营场景及旧 NPC 的全面全身资产重做未包含在本次主菜单改动中；后续人物生产必须完整全身，禁止以窗口裁片作为母版。

最终构图已恢复用户指定的公告纸方案，取消中途的独立吊牌方向。当前真正使用 `assets/menu-approved/` 下两张完整全身人物母版与独立运行层。柜台/静态摆件共用同一前景层，杯子与握杯前臂独立联动。字体采用附带 OFL 许可的 Noto Sans CJK Black 菜单字形子集。
