# 年代、物资与双主角服装系统｜美术制作圣经 v1
> 最新制作约束：先锁定时代经济与物品设计，后画人和商品。不要擅自扩写剧情。本文件为美术/世界生产规范，**不是正式人物立绘已获验收**的宣告。

## 1. 世界运作方式（待用户最终确认名称，生产工艺先锁）
架空北方工业国家，故事时间暂沿既有文档 **2002 年**。这里不是现实俄罗斯 2002 年：保留**国家统配就业、重要民生物资定额供应、国营制造/维修网络**，同时允许街区授权的有限个体或合作经营。时代科技水平**不等于时尚消费水平**——虽有收音机、CRT 电视、机床、拉链和合成纤维，但民用衣物的常见款式、供应和维修观念整体滞留在 **1980s–1990s 工业制品**水平。现代户外时装与全球快时尚在普通小城**不普及**。

就业逻辑：角色在青年登记及轮岗制度中拥有城市劳务分配表。**玩家选择女或男主角经营街区特许小卖部；未选择的另一位被劳动管理所分派到城里的正式岗位。** 这是根据选角即时互换的就业状态，不可再写死为「女角色固定经营小店，男角色固定做维修」。分配的岗位应有实际时间表、工牌、制服/工具、通勤、收入、同事及回家路线；玩家经营者要有租约/每日库存与取暖成本。若国家统配就业，绝不能再用「完全市场经济、两人同时是无业自由职业者」作为默认故事背景。

相邻住户/青梅竹马关系保留为当前暂定人物关系，不自动生成恋爱剧情。已设定家庭具体职业和名字仅是**可修改提案**，避免未经批准写成锁死剧本。

## 2. 本国制衣和工业可见工艺
- **纤维材料**：厚斜纹棉布、帆布、粗纺羊毛呢、旧混纺大衣面料；寒区填棉绗缝夹克、旧羊毛针织、耐脏棉衬；皮革或人造革、小部分低档橡胶；人工缝补与旧衣改裁。
- **可制造工艺**：平直机缝、包边、锁眼、扣眼、少量粗大金属或塑料拉链、铆接、普通鞋底模压、简单绗线、翻修旧鞋。旧衣袖口与下摆的换布、同色系补片、褪色差，是生活细节。**不要「破烂末日风」**：即使经济一般，人也会努力把衣服保持干净整齐。
- **服装常态**：家里有1–2件长期穿的冬外衣，父母衣服改小，街区分配制服；为保暖穿羊毛衫和厚布裤。围巾与帽子可以亲手编织，但不需要铺满复杂花纹。
- **鞋靴**：旧皮靴/人造革工作靴＋简洁厚底；防滑橡胶鞋底和维修钉；部分低收入居民使用毡靴。禁把高端球鞋、潮牌战术靴、夸张多段注塑鞋底作为普通城镇服饰。
- **五金**：大塑料纽扣、金属纽扣、基础拉链、皮带扣。严禁装饰性大把绑带、复杂快拆扣、莫名其妙口袋、聚合物户外机能包、闪亮现代织物。
- **外观执行**：固有色＋少量明确的大块硬边暗面，突出布料厚度、重力和关节折叠；人物头发**严格一整块固有色**，不加高光、纹理、渐变、分缕阴影。人体脸、脖子、裸露的手等必须纯黑不画五官；但不能以「全黑衣服」代替面料颜色。
历史参考取**真实1980s末日常平民服装、城市冬季工作服和服装物资供应**的制作逻辑，不直接复制任何照片人物或把史实硬套架空国。参考：https://www.gw2ru.com/lifestyle/3022-soviets-dress-winter 、https://www.latimes.com/archives/la-xpm-1989-01-09-vw-198-story.html 。

## 3. 双主角的「主角级轮廓」区别（不能靠十几个饰品）
角色设计从32–96px缩略图开始审：脱离脸部细节、去掉背景，仍然一眼区分是两个可玩主角。

### 女主·斜向长轮廓
头部：**清楚的偏斜旧式头巾/羊毛包头＋一整块深栗棕发色**（不画发丝高光），头部呈不对称的三角型，不是通用毛球帽。
身体：家庭改裁的厚呢长外套，肩线不追时尚宽肩，衣摆做**不对称一长一短的三角叠层**；一条暗砖红宽围巾沿衣身形成**唯一醒目的斜向色块**。外套基本固有色偏灰绿/褪色瓶绿，暗面相近低明度。裤/裙服务实际店务和冬天通勤，不超短、不露肤，朴素旧工作靴。
识别道具：只有**一本压在臂弯里的旧账本/凭证夹**；不能再加手提包、背包、钥匙串、胸针、绳带、十个口袋。这个道具**不等于固定店主人设**：若女主被分配城内岗位，她拿工作票夹；若玩家选择她开店则是账本。
她独特的不是“漂亮冬装”，而是斜向构图、手掌贴住账本、稍稍缩起的肩和强烈的轮廓负形。禁止将其做成年轻时尚咖啡店女孩。

### 男主·横向方轮廓
头部：低而方的旧式翻耳布帽或简洁毛线帽；**一整块灰褐色头发**，绝无亮边/挑染。头部造型不要与女主的三角头巾相同。
身体：旧式**棉絮填充工装短外套**，简洁的箱型宽肩、直下摆，主体灰蓝或暗靛蓝，只有必要的肘部补片或绗线段；底下是普通工装布裤、修补过的耐寒工作靴，工装不等于潮流机能潮牌。
唯一识别物：**一只装票据/修理工具的旧长方形帆布小箱**，作为整体下部的方块轮廓；不堆挂件、胸针、背包和粗链条。城市岗位时是工作箱，开店时可放零钱/票据。
他不是女主角换一套蓝大衣。由**方肩、短身、厚袖、偏低的重心、垂直线条**形成独立的人物形状。

### 角色双职业切换：一副母版，两套合理外搭
身份与成长独立于工作岗位。
- **玩家选女主**：女主在同一小卖部开店（可罩旧布围裙/上工小坎肩），男主穿劳动所分配岗位的外套去城里上班，下班再出现在街区；
- **玩家选男主**：男主在同一小卖部开店（简洁布围裙或旧袖套），女主去城市统配岗位（工牌/工作外衣），两人的家庭与性格不因为玩家选角而被交换；
- 每人各一套全身民服母版，**店务工作变体与城市工服变体**另做可拆配件；不把围裙和工具腰带永远焊死到角色上。场景内角色职业变化必须真实显示出对应服装。
- 为角色建立三档美术来源：远景96px仍可识别的大轮廓；营业中约200–350px的标准精灵；独立高分辨率全身母版。正式素材需一致，不能拿立绘直接裁到小像素人物上后变成脏噪点。

## 4. 衣服 vs 商品 vs 制度一套世界规则
每件商品入库必须通过「年代工艺 / 国内生产和来源 / 供应方式 / 售价或票证 / 主要用途 / 耐用包装 / 上架体积 / 过季变动」八项审查。
最初店里可以买卖：粗麦面包、散装红茶/简易保温茶、糖块、盐、火柴、蜡烛、肥皂、罐头鱼、简易绷带、普通日用电池、旧灯泡、国产香皂、套织手套。部分用品有纸票限购或被区里短期挪用；并不意味着玩家需要逐个手动盘存每个罐头。包装可用纸裹、蜡纸、简单铝/马口铁罐、玻璃瓶、旧纸标签与朴素打印文字，不允许现代渐变彩印、LED屏标签、精品咖啡杯和包装时尚化。
正常**出售电池**是符合时代的商品；用户否决的是此前擅自加入的**收旧电池回收经营任务**，二者要区分。
食品、家庭居所、工作站、街道交通工具、照明、取暖、工具材料必须同一工业设计系统：缺乏花哨营销，维修痕迹真实，节约但并非一切破败。必要的恐怖异变也先发生在**普通可信的物品**上。

3. 面部/手部纯黑、不可有任何五官或皮肤；**头发仅一块固有色**；
4. 两个主角各自有独特、时代可信的剪影，脱离细节缩成纯色仍能区分；
5. 衣服正常低饱和彩色，只有1–2级大块硬边暗面、无厚涂纹理/noise，所有衬里与缝合有技术合理性；
6. 贴着世界经济过日子，带旧物感但不是扮乞丐；不借用当代穿搭平台常见的羽绒时尚造型；
7. 不要把用户否决稿误记为获验收最终稿；提供母版检查结果再进入动作生产。
