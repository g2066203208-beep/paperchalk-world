# 未命名 · 冬夜小店经营 Demo（可玩垂直切片）

**在线直接玩：** https://g2066203208-beep.github.io/paperchalk-world/

从冬夜路边的狭窄杂货窗口开始经营。本版本是 **HTML Canvas 互动游戏原型**，不是完整原生安卓引擎，也不借用其他游戏的角色和素材。视觉结构参考冬季窗口售货亭，像素背景、窗闩、柜门、货架、抽屉、商品精灵、客人均由独立绘制函数生成，没有使用 GPT 图片生成器、现成截图或一整张贴图。

## 玩法
1. 单人开始后，点击中央小窗下方的金色窗闩，开窗营业（可再次关窗）。
2. 当前客人会出现在窗口；左／右货架可直接拿货，上面的吊柜和下方的抽屉需要先打开才能取放。
3. 点击货品拿起来，再点中间绿色交接台放下。放错可以再点取回，或放回同种商品货格。
4. 按「收款」对照客人需求完成交易。错货不会交易，正确商品会获得收入与好评；连续五位客人算一天。
5. 从底部选择进货商品，再点击有空位且容量足够的货格补货；每个货格有明确容量，不同商品占用体积不同。库存和资金保留至第二天。
6. 双人至四人可以创建／加入一个房间，多个玩家操作同一小店，库存、柜门状态、顾客和收入统一由房主结算。

**支持手机竖屏、手机横屏、桌面横屏**。整个画面是固定一屏 Canvas，并为横屏重排镜头与信息区；不会竖向滚动。

## 现在做到了什么
- 顾客连续出现、首次商品销售、营业收入、货架／抽屉／吊柜取放、资金约束进货、5 客人日结、第二天继续营业；
- 可点击的真实店内商品、可反复开关的窗口和四个储物部件、各自容量与状态；
- WebRTC 房主权威房间联机，共享变更；新版单人游戏本地存档键 \`untitled-kiosk-save-v1\`，旧版存档键不修改；
- GitHub Actions 中 Node 规则测试及两个独立手机尺寸 Chromium 客户端联机、真实截图、电脑横屏截图、Android APK 构建。

## 尚未完成（不作为正式游戏宣传）
这是最小经营循环，不是完整连锁经营游戏。还缺少 NPC 排队实际路径动画、独立玩家手部与岗位移动、可自由布置的多商品堆栈、配方制作、委托系统、店长与店员的权限经济、分店、长久社会关系和真正的完整原生 Android 客户端。手机上的 Android 测试 APK 仍是 WebView 包裹网页，**不得称作原生游戏**。公网 WebRTC 可能被 NAT/防火墙阻止，暂无 TURN 和房主迁移； debug APK 每次不同签名的升级存档兼容性也未经证明。代码增量逐步解决。

## 开发
\`npm test\` 运行规则回归，\`npm run check\` 检查语法；
\`python3 -m http.server 8000\` 在仓库根目录本地预览；联网功能需要 PeerJS。
