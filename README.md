# 未命名 · 冬夜小店经营 Demo（可玩垂直切片）

**在线直接玩：** https://g2066203208-beep.github.io/paperchalk-world/

从冬夜路边的狭窄杂货窗口开始经营。本版本是 **HTML Canvas 互动游戏原型**，不是完整原生安卓引擎，也不借用其他游戏的角色和素材。视觉结构参考冬季窗口售货亭，美术正在由简陋程序化像素图逐步替换为 GPTIMG 原创透明精灵。本轮先接入一位顾客的独立 WebP 肖像；窗闩、柜门、货架、抽屉和商品仍保留真实 Canvas 点击与状态，尚未完成整套高质量美术。

## 玩法
1. 单人开始后，点击中央小窗下方的金色窗闩，开窗营业（可再次关窗）。
2. 当前客人会出现在窗口；左／右货架可直接拿货，上面的吊柜和下方的抽屉需要先打开才能取放。
3. 点击货品拿起来，再点中间交接台放下；长按台上商品可取回，或将手中商品放回同种货格。顾客说话在窗口内短暂出现气泡，不常驻底部文字栏。
4. 点击柜台实际钱盘完成收款（新场景也支持在交接台直接交付商品）；错货不会交易，正确商品会获得收入与好评；连续五位客人算一天。
5. 店长长按已有商品的货架或打开的柜子/抽屉准备补货，再点目标货格购买入库；售罄货格保留原商品身份。每个货格有容量约束，资金与库存跨天保留。
6. 双人至四人可以创建／加入一个房间，多个玩家操作同一小店，库存、柜门状态、顾客和收入统一由房主结算。
7. **第二种独立业务（旧电池回收）**：完成第一笔零售交易后解锁。下一位携带旧电池的顾客会在窗口展示一节可点击的旧电池；直接点击电池接收（先支付 ¥1 处理费），打开右抽屉并点击抽屉放入回收格。收集 3 节后，长按已打开的右抽屉打包交运，获得 ¥12 批次结算。回收业务有独立的接收→暂存→交运状态、库存容量、成本和收益，不是给商品换名；多人操作和旧存档均兼容。右抽屉作为回收格使用时不可同时存放零售商品。

**支持手机竖屏、手机横屏、桌面横屏**。整个画面是固定一屏 Canvas，并为横屏重排镜头与信息区；不会竖向滚动。

## GPTIMG 美术集成状态
- `assets/gptimg/customer-uncle.webp`：本项目 GPTIMG 原创像素图集裁切的透明角色肖像，已接入第一位顾客的等待/进场画面。
- 说话、接物、拒绝等动作暂时保留旧版独立像素精灵，避免以静态肖像冒充完整动作帧；后续必须补齐同角色一致的 GPTIMG 表情与肢体帧。
- 旧版 `assets/anime/` 是废弃素材，未进入正式发布包；新资产按独立物件逐步替换，不使用整张假游戏截图。

## 尚未完成（不作为正式游戏宣传）
当前真正独立可玩的业务为 **2 类：窗口零售、旧电池回收**。旧电池回收目前采用现有商品精灵和现有抽屉交互，批次交运仍是长按结算，尚无独立的快递交接动画和物流等待；不能把它宣传成完整回收产业链。这是最小经营循环，不是完整连锁经营游戏。还缺少 NPC 排队实际路径动画、独立玩家手部与岗位移动、可自由布置的多商品堆栈、配方制作、委托系统、店长与店员的权限经济、分店、长久社会关系和真正的完整原生 Android 客户端。手机上的 Android 测试 APK 仍是 WebView 包裹网页，**不得称作原生游戏**。公网 WebRTC 可能被 NAT/防火墙阻止，暂无 TURN 和房主迁移； debug APK 每次不同签名的升级存档兼容性也未经证明。代码增量逐步解决。
