# 余烬之夜 / Night Remains — 叙事桌游场景版

正式网站：https://g2066203208-beep.github.io/paperchalk-world/

APK：https://github.com/g2066203208-beep/paperchalk-world/releases/download/apk-latest-debug/paperworld-latest-debug.apk

## 视觉重构

此版本参考桌游场景如何把界面融入真实物件（如《邪恶冥刻》的沉浸桌面，以及《恶魔轮盘》的材质与聚光），不复制它们的卡牌、图像、道具或 UI。

- 为墓园、教堂、暗巷分别绘制原创 **分层 SVG 场景**（`site/environment.js`）；包含场景建筑、背景轮廓、雾、颗粒、灯光和前景烛火。
- 主战场是一张有木纹、铜线、纵深透视和反光的真实桌子；五条路不再是五个框。
- 怪物仍是能前进、后退、相互遮挡的立式卡牌，脚座、地面投影和景深仍由 CSS 2.5D 计算。
- 移除左侧常驻数值仪表盘；全局资源收进顶部一条细带。五条道通过桌面**圆形印记**切换，前进/后退通过两枚圆形方向印记，结束回合通过**铜铃**完成。
- 手牌从五张扁平按钮改成桌面上自然扇形铺开的 **四张功能卡牌**；玩家状态由 HUD 与站位标记显示，不再占用手牌。
- 右侧场地改为带钉孔和纸张切角的实体场地票卡，手机竖屏移动至顶部，并保留所有实际可玩操作。
- 完全静态托管，APK 的 WebView 继续每次启动获取网页最新版，无需重新打包原生 APK。

## 战斗保持不变

仍有五道六级纵深、正面与背后夹击、近排阻挡后排、射击、照明弹击退、移动、换弹、回血及三处场地独立存档。游戏玩法和数据仍由 `site/rules.js` 管理，场景只影响视觉表达。

## 质量验证

GitHub Actions 强制运行 Node 规则测试与真实 Chromium 浏览器测试，包含 1440×900 电脑、390×844 手机竖屏和 844×390 手机横屏的场景截图、触摸战斗、场地切换和溢出断言。测试通过才会自动部署 GitHub Pages。

**说明**：场景是精细化程序 SVG 和 CSS 氛围层，并非专业人员绘制的最终游戏插画；不能声称所有安卓真机已经过实机验证。
