# PixelLab / 原创四色游戏素材工作室

Pixel Lab 只有两个主系统：
1. [真像素转换](site/pixel-lab/repixelize.html)：D 风格原生四色、逐像素网格、上传转换及 PNG 导出；
2. [像素绘画学习](site/pixel-lab/learn.html)：**仅保留 V2 离散扩散研究模型**，人物两姿势、程序化道具/场景、留出参数验证。

主网页： https://g2066203208-beep.github.io/paperchalk-world/pixel-lab/

D 风格四色：`#393657`, `#F2A5C2`, `#A9BAE9`, `#FFF5E6`。

源数据、纯像素画编辑器及 GitHub Pages 现用源码保留；所有过时的神经训练实现、旧训练结果和旧入口已从当前分支清理。历史仍在 Git 中。
