# 留灯 · LAMPKEEP

**重新设计的手机竖屏多人合作悬疑小店游戏。**

线上预览： https://g2066203208-beep.github.io/paperchalk-world/

本版**不再是《以撒的结合》式弹幕游戏，也不是照搬证件检查游戏**：玩家在一家深夜营业的杂货店中共同工作，从对话、店铺旧账、窗外雨夜和货架实物中对照证据，辨认可能冒充人的「借脸者」。看似异常的真人也有真实的故事。详情参阅 [游戏设计方向](design/GAME_DIRECTION.md)。

## 游戏当前实现的内容
- 竖屏优先的独立布局，分层店景 SVG 与 8 张单独人物 SVG；文字与按钮都是原生 HTML 元素，不在生成图片中烘焙。
- 9 段独立事件，3 个夜班阶段，4 个可切换工作位：柜台、临街窗、货架、旧账。
- 单人离线模式与本地继续游玩存档。存档位于浏览器或安卓 WebView 的应用私有数据里，不依赖 GitHub。首次联网访问完成缓存后，通过 Service Worker 可在断网时打开已缓存的单人游戏（联网合作仍需网络）。
- 双人到四人 WebRTC 互助：共享场景、调查结果、线索板、表决；超过半数同意才继续。连接客人不能单方面更改正确答案。
- GitHub Actions 规则测试、两个真实 Chromium 客户端联机测试（含手机 390×844 截图）、静态站发布。
- 试验性 Android WebView APK 外壳，竖屏、保留 WebView 本地数据。每次全新打开从 GitHub Pages 加载最新版游戏网页。

## 联机规则
房主创建房间，好友输入 8 位邀请码，最多四名值班员同时操作 **同一间店**。每位玩家能独立查看不同工作台，但调查结果和贴在墙上的线索同步；2 人不同意时不会强行推进。单人可自行切换所有工作位。

本版本仍使用 PeerJS 的公共信令建立 WebRTC 点对点联机。公共网络上的防火墙与 NAT 可能阻断连接；断线重连、迁移房主、专用 TURN 服务器尚未完成，不承诺所有手机环境均可连接。

## APK 的“自动获取最新版”和存档限制
Android 壳的主页固定加载 GitHub Pages 的网页。**游戏网页发布后，下一次冷启动 APK 会请求服务器上的最新版本**，无需每次手动安装新 APK。

APK 程序壳本身不会在后台静默安装替换：Android 系统需要用户参与 APK 更新安装。手机内的私有 WebView 存储通常跨 **同包名、同签名** 的应用更新保留；卸载、清除应用数据或切换签名都会使其丢失。本项目默认 CI 只产出**测试 debug APK**，它可能随不同 Runner 使用不同 debug 签名，因此不能作为稳定升级路径。为持续升级并保留存档，请配置 GitHub Actions 四个 secrets：`LAMPKEEP_KEYSTORE_BASE64`、`LAMPKEEP_KEYSTORE_PASSWORD`、`LAMPKEEP_KEY_ALIAS`、`LAMPKEEP_KEY_PASSWORD`，此后使用签名 release APK 更新。不要将私钥直接提交仓库。

## 运行
本机 Node 22+：`npm test`、`python3 -m http.server 8000` 后打开 localhost。多人联机还需要 PeerJS CDN 可访问。

GitHub Actions → **Build Android Lampkeep APK** → 最近成功的运行 → **lampkeep-debug-apk** 可以下载测试版安卓安装包。

## 状态和后续任务
这是**可测试的初始玩法原型**，不是承诺完成专业级全部资产。接下来要做的是完整的人物分层动画、强辨识度的美术细化、故事状态连续性、可交互的商品与柜台道具、真正独立的多人操作反馈、断线恢复、稳定签名发行版以及多安卓机型实际检查。
