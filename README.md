# WORLD Studio — Blockbench 建模工作室

旧版游戏已备份在分支 **archive/old-kiosk-before-model-studio-20261027**，新的主分支只有建模项目与 Android 容器。

**在线建模：** https://g2066203208-beep.github.io/paperchalk-world/

**公开项目：** [售货亭](examples/kiosk.bbmodel) · [归家雪街](examples/street.bbmodel) · [工人住宅](examples/home.bbmodel)

**最新测试 APK：** https://github.com/g2066203208-beep/paperchalk-world/releases/download/studio-latest-debug/world-studio-latest-debug.apk

提供 Three.js 实时 3D 场景、三个公开原型、方块增删复制、面板精确位置/大小/颜色/旋转、3D 选取、撤销重做、相机缩放旋转、手机触控、.bbmodel 导入/导出、本地保存、PNG 预览截图。

**不是完整 Blockbench 克隆。** 支持原生 .bbmodel cube/free 格式的几何数据与自有色板；暂不支持复杂 mesh、动画骨骼、原生贴图全部属性及完整材质编辑。高级建模可在 https://web.blockbench.net/ 打开导出文件。

APK 是 GitHub Pages 最新网页的 WebView 包装；打开时加载新版，不可能未经允许静默安装新 APK，需从稳定 Release 下载并手动安装。
