# 夜港：街头帝国 / Night Harbor — Underworld Tycoon

**GitHub Pages**：https://g2066203208-beep.github.io/paperchalk-world/

**Android APK**：https://github.com/g2066203208-beep/paperchalk-world/releases/download/apk-latest-debug/paperworld-latest-debug.apk

本分支完全替换此前的卡牌战斗和未完成的侦探设计，**现在是一款以黑帮题材为背景的虚构城市经营模拟游戏**。照片卡保留在右侧；手机竖屏时转为顶部横排。原生 Android WebView 容器与 GitHub 自动部署/构建配置不变。

## 从零开始
第一周只有现金 $320、1 名伙伴、0 产业、0 已控制街区。可以自由选择五个街区经营，不采用之前的五条道战斗、不限制每回合 3 AP。

可操作功能：
- 街头委托：一次性收入，但会增加关注度；每个街区每周有一个机会；
- 结识联系人 / 商谈合作：建立影响力、获得声望、降低竞争；
- 招募团队：增强组织规模，但是每周增加薪资成本；
- 投资产业 / 升级产业：各街区业务不同，提供真实的每周持续收入；
- 资助社区 / 低调休整：恢复忠诚、降低热度；
- 确立街区控制：必须满足影响力、资金、人手与声望，并带来被动收益；
- 下一周：结算收入、工资、监管成本，推进竞争压力并生成随机但可复现的城内决策事件。
- 全城目标：掌控 5 个街区、声望 70、现金 10,000；达成后仍可继续自由经营。

所有存档放在 localStorage，没有服务器；重开/刷新继续最新存档。所有数值、事件和街区均为虚构，用于游戏平衡，不是现实中从事犯罪的操作建议。

## 代码
- `site/engine.js`：纯业务逻辑、经济账簿、势力、人手、事件、存档验证。
- `site/app.js`：照片与交互、三个管理工作区、决定事件、通知。
- `site/style.css`：桌面 / 手机横竖屏自适应。
- `tests/*.test.mjs`：规则测试。
- GitHub Actions：Chromium 桌面、手机竖屏和横屏点击测试+截图；全部通过后自动部署。

照片通过 Unsplash CDN 远程载入。如果设备无网络，界面提供暗色背景，但原图不能离线显示。APK 保持原有签名与网页实时获取机制（原生代码未改动）。
