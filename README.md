# 深渊共鸣 · Cryptbound

一个**原创**的俯视角 Roguelike 地牢合作游戏。灵感来自《以撒的结合》的房间清怪、方向射击和随机探索，但角色、画面与游戏代码均为独立设计。

**在线试玩**：[https://g2066203208-beep.github.io/paperchalk-world/](https://g2066203208-beep.github.io/paperchalk-world/)

## 第一版已实现

- 纯 Canvas 2D 渲染，浏览器中直接运行，无安装步骤。
- 单人离线模式、创建 8 位房间码、好友加入，最多 **4 人同时合作**。
- WebRTC 点对点传输 + 房主权威模拟：房主负责碰撞、敌人 AI、生命、伤害、战利品、房间切换、随机地牢种子与通关判定；客人发送输入并接收状态快照。
- 3 层程序化连通地图，每层含战斗、遗物、Boss 房间；战斗胜利解锁门、拾取金币/红心、炸弹范围伤害、遗物升级、首领传送阵及结局。
- 电脑 WASD 移动、方向键或按住鼠标射击、B/空格使用炸弹；触屏提供移动和射击方向键。
- GitHub Actions 使用 Node 内置测试器跑规则回归，并部署 GitHub Pages。

## 联机使用

1. 两个人分别打开相同的在线网址。
2. 房主填写名字，点击「创建联机房间」并复制 **8 位房间码**。
3. 其他人填写名字和房间码，点击「加入房间」，进入同一个地牢。
4. 房主必须保持浏览器页面打开；每次重开将使用新地牢。最多 4 人（1 房主 + 3 客人）。

**真实限制**：GitHub Pages 只能托管静态文件，不能直接运行常驻 WebSocket 游戏服务器。本项目通过 PeerJS 的公共信令服务建立 WebRTC P2P 连接；已有连接直接传输游戏数据。这种模式不需要自己部署服务器，但连接成功率受公共信令服务、网络防火墙、NAT 和 TURN 可用性影响；某些网络环境下可能无法联机。房主关闭或断线后该局游戏无法继续，当前不支持迁移房主或中途断线重连。本版本不提供账号、联网排行榜或持久化存档。

**隐私提醒**：房间码不是加密密码。仅把房间码分享给你信任的队友。房主可以接收加入玩家的名字和游戏输入；WebRTC 连接可能向通信对端暴露网络相关信息。

## 本地开发

Node 22+ 可运行测试，无需安装第三方包：

```bash
npm test
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。联机功能需要联网加载 PeerJS CDN 并访问 PeerJS 云信令服务；单人游戏核心是独立 JS 模块。

项目结构：

- `index.html` / `style.css`：玩家界面和地牢容器
- `src/logic.js`：可测试的确定性地图、碰撞、战斗与房主模拟
- `src/network.js`：房间码、P2P 连接和快照
- `src/client.js`：渲染、键鼠/触屏输入、UI、游戏循环
- `src/logic.test.js`：地图连通性、操作校验、战斗与房间回归
- `.github/workflows/deploy.yml`：CI 和 Pages 部署
