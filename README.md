# PAPERWORLD · 四色程序像素游戏

原 Android APK 的**唯一游戏首页**：https://g2066203208-beep.github.io/paperchalk-world/

## 2026-10-30｜主菜单实际程序开发

用户批准了此前生成的 PAPERWORLD 粉蓝纸飞机像素主菜单参考图，但明确要求将其**用程序画进实际游戏**，不能把 GPTIMG 的 PNG 当作游戏界面。

- `site/index.html`：原 APK 打开的根页面，游戏主菜单。只使用两个 Canvas，不引入图片。
- `site/game/background.js`：保留原奶油白/雾蓝斜条纹，GPU 连续平移、8秒循环、沿条纹法线同时移动 X/Y。
- `site/game/menu.js`：全部程序绘制纸飞机、简洁像素云、PAPERWORLD 手写像素字母、四个按钮、按钮图标，以及仅在点击时短暂出现的像素碎片。使用**整数像素矩形和扫描线多边形**，避免真实画面产生第五种抗锯齿颜色。
- 正式四色：深紫 `#393657`、樱粉 `#F2A5C2`、雾蓝 `#A9BAE9`、奶油白 `#FFF5E6`。界面不加载生成图片或额外颜色。
- 触控：Android 手机单击、按压回弹、短振动反馈、屏幕任意触点产生16颗四向扩散像素碎片＋菱形涟漪（约0.42秒消失）；鼠标指向反馈与键盘↑↓/回车/ESC，横屏竖屏自动布局。
- **开始游戏**：进入序章界面并建立真实本地起始存档。**继续游戏**：有起始存档才进入序章，否则提示暂无存档。**设置**：实际切换背景运动、点击粒子和振动；设置本地保存。**退出游戏**：网页环境显示结束画面并能返回主菜单（浏览器不能静默退出 Android 应用）。
- 游戏的后续世界、剧情与操作**尚未实现**；当前交付范围为可交互的程序化主菜单，不谎称整款游戏已完成。
- `tests/background-home.test.mjs`：源代码约束、只允许四色、主菜单逻辑和原 WebView 地址。
- `tests/game-browser.mjs`：Playwright 实际桌面、竖屏手机、横屏手机、平板，点击/继续/保存/设置/退出路径，保存截图至 GitHub Actions artifact。
- `.github/workflows/deploy-pages.yml`：校验、发布并在公网核对真正的菜单代码，不再依赖机器学习训练结果才上线。

## 原 APK 与自动更新

原包名 `com.paperchalk.lampkeep`，每次冷启动/回前台请求网站根目录。网站每60秒对比在线版本标识，有新版菜单会自行刷新。此前根目录离线 Service Worker 也有一次性迁移清理逻辑。APK 原生代码更新需要重新安装一次，通过 GitHub Actions 发布固定 Debug APK：

https://github.com/g2066203208-beep/paperchalk-world/releases/download/apk-latest-debug/paperworld-latest-debug.apk

请注意 GitHub Actions 是否通过；仅有提交记录不等于公网发布或 Android 实机验收成功。

## 2026-10-30｜点击反馈与转场修正

- 不使用常驻星空、背景粒子、全屏烟花；所有页面点/触任何位置（空白、纸飞机、标题、按钮）都在真实触点出现16颗短寿命（约0.42秒）四色碎片与菱形像素涟漪。无触摸时保持干净。
- 取消左右双门合拢效果，改为**同方向斜向纸页扫场**：0.23秒纸页扫满，遮盖后切换场景，再用0.29秒从左上向右下揭开下一页；深紫主面、奶油白折边和少量雾蓝/樱粉接缝，全部用无抗锯齿整数矩形绘制。
- 字体按最终逻辑像素尺寸生成 1-bit 字形，不再先画大图再压缩模糊。尊重系统减少动态效果设置。
- 游戏首页的版本号已更新，原 APK WebView 会以网页版本标识重新加载。注意实际线上 GitHub Pages 成功部署须以 Actions 及公网验收为准。

## 2026-10-30｜任意位置点击反馈（v4）

- `site/game/menu.js` 的 `pointerdown` 全屏响应，不依赖 `hit()` 的按钮命中。触点反馈在按下时立即触发，按钮功能仍在 `pointerup` 判定，键盘确认也会产生按钮中心反馈。
- 每个触点最多16颗像素碎片＋四方向菱形涟漪；仅四个官方颜色，全不透明像素，不使用模糊、渐变。0.42秒消失，最多同时保留6次触摸，不制造持续杂乱视觉。
- 设置页保留“点击粒子”开关，版本改为 `paperworld-menu-v3`，确保老用户先前关闭了旧按钮粒子也能默认看到新全屏反馈。
- 自动测试覆盖手机竖屏、横屏、平板、桌面；空白区域、页面内区域点击触发、坐标正确、残留清理及按钮独立操作。
