# 像素画结构学习笔记 v1 · 以《小丑牌》Joker 为观察参照

本文件只记录**构图和像素绘画方法**，不存放、重绘或训练商业原图。

## 一、经过核验的参照数据

- 观察对象：《Balatro》普通 Joker 卡面。
- 原图集以 71×95 像素为单格，放大必须使用最近邻。
- 针对该**单张 Joker** 的原始像素分析记录为 14 种 RGBA 值（包含不同透明度），不能推断所有小丑牌都是 14 色。
- 其画面由**可手工控制的小尺寸像素图**与**运行时 Shader / 动画**两层组成，不能把 Shader 的光晕误认为卡面原始像素。
- 注意：商业游戏素材并非开放训练数据。以上仅用于研究一般美术原则。

## 二、程序化学习目标，而不是机械临摹

| 专业像素画要求 | 可测量的技术代理指标 | 人工验收 |
|---|---|---|
| 缩小后依然可辨 | 前景占比、连通域面积 | 去色只看剪影，是否一眼认出？ |
| 色板克制且有层次 | 唯一颜色数、颜色面积占比 | 高光、暗部、焦点是否各司其职？ |
| 像素簇而不是随机噪声 | 孤立像素比例、色块面积分布 | 明暗色块是否围绕体积成形？ |
| 有节奏的阶梯边缘 | 边缘密度、局部变化 | 曲线台阶是否连贯、有意图？ |
| 主题和角色个性鲜明 | 不能仅依赖像素统计 | 遮住文字后是否仍有记忆点？ |
| 卡牌效果与素材分离 | Shader 开关下的原图对比 | 去掉特效后，卡牌本身够不够好？ |

质量报告目前只实施分辨率、调色板上限、边缘密度。其它代理指标是下一阶段增强项目，不能谎称已完成。**任何数字都不能证明“好看”。**

## 三、以后画卡牌的操作顺序

1. **文字设计简报**：一句话说明角色概念和视觉符号，不写无关世界观。
2. **2—3 色剪影**：先能读懂形状，再做复杂结构。
3. **体积和光源**：每个同色像素簇说明对应的表面、投影或材质。
4. **有限色板**：将颜色角色固定为深轮廓、阴影、中间色、主色、高光和少量强调色。
5. **像素边缘审查**：不得使用模糊抗锯齿描边，优先自然阶梯。
6. **实际尺寸回看**：71×95 是展示卡牌目标；当前 VAE 只产生 32×48 图标，须分开评审。
7. **消除装饰性噪点**：没有材质或造型用途的孤立像素要删除。
8. **分别检查静态图与动态特效**：避免把闪光、放大或动效掩盖的造型问题当成已解决。
9. **原创性审查**：不能直接拼贴、训练、仿造某张受保护卡面的独特画面。

## 四、机器学习迭代路线

**已实现：** 数据许可清单 → 原创合成教学图 → VAE 梯度训练 → 留出验证集 → 图标预览 → 10 色量化 → CI 自动测试与产物保存。

**尚未实现：**
- 大规模经许可的**人工绘制**像素图训练集；
- 语义条件（角色主题、构图）控制；
- 对孤立像素 / 连通域的专业质量评估；
- 真人盲评与偏好模型；
- 满足“与商业作品同等的视觉完成度”的验收证据。

要避免“白学”，今后每次新素材进入实验室，必须增加**来源记录、训练版本、验证指标、前后对比、人工评价结论**。只有模型在保留测试样本和人工评价上均有进步，才允许宣称有质量提升。
